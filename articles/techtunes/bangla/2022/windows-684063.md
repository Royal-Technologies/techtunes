হ্যালো বন্ধুরা, আশাকরি ভালো এবং সুস্থ রয়েছেন। আজকে আপনাদের সামনে একটি মজাদার টিউন নিয়ে হাজির হয়েছি। আশাকরি ভালো লাগবে এবং উপকারে আসবে। আপনারা হয়তো টিউনের টাইটেল দেখে বুঝে গেছেন আজকে কি নিয়ে কথা বলব। আজকে কথা বলবো আপনি কিভাবে উইন্ডোস ব্যবহার করে থাকলে সেখানে সহজেই ম্যাক বা লিনাক্স ব্যবহার করতে পারবেন। তো চলুন আর কথা না বাড়িয়ে টিউন টি শুরু করা যাক।

এই কাজের জন্য আমাদের একটি সফটওয়্যার এর প্রয়োজন হবে। কিভাবে সফটওয়্যার টি ডাউনলোড করবেন তা নিচে আলোচনা করা হলো।

## কিভাবে সফটওয়্যার টি ডাউনলোড করবেন?

আমাদের যে সফটওয়্যার টির প্রয়োজন হবে সেটির নাম হচ্ছে VirtualBox। এই সফটওয়্যারটি উইন্ডোস এবং লিনাক্স সব অপারেটিং এর জন্য পেয়ে যাবেন। সফটওয়্যারটি ডাউনলোড করার জন্য [এখানে](https://www.virtualbox.org/) ক্লিক করুন। তারপর নিচের মতো একটি পেজ ওপেন হবে।

![](https://dnc.techtunes.io/tDrive/tuner/2021/03/techtunes_7e15c6e55c7b1429fe95356db9fda905.png)

এখানে আপনি যে অপারেটিং ব্যবহার করেন সেই অপারেটিংএর জন্য সফটওয়্যারটি ডাউনলোড করে নিন। তারপর অন্য সফটওয়্যার যেভাবে ইনস্টল করা হয় এটিও সেভাবে ইনস্টল করে নিন। ইনস্টল শেষ হয়ে গেলে সফটওয়্যার টি চালু করুন। সফটওয়্যার টি সঠিক ভাবে চালু হলে নিচের মতো একটি পেজ দেখতে পাবেন।

![](https://dnc.techtunes.io/tDrive/tuner/2021/03/techtunes_7f54b6c36ce64ef115e434c76f635d21.png)

চালু হলে উপরে থাকা new বাটনে ক্লিক করুন। new বাটনে ক্লিক করার আগে অবশ্যই ডাউনলোড যে অপারেটিং সিস্টেম ব্যবহার করতে চাচ্ছেন তার একটি iso file ডাউনলোড করে নিবেন। iso file ডাউনলোড করার জন্য গুগল এ গিয়ে অপারেটিং এর নাম লিখে শেষে iso file download লিখে সার্চ দিলে সহজই iso ফাইল টি পেয়ে যাবেন। তারপর ফাইল টি ডাউনলোড করে নিন। ডাউনলোড শেষ হয়ে গেলে এবাৰ new বাটনে ক্লিক করুন। তারপর আপনার সামনে নিচের মতো একটি পপআপ ওপেন হবে।

![](https://dnc.techtunes.io/tDrive/tuner/2021/03/techtunes_c3bb507a4099c352e4a870450e827120.png)

এখানে থাকা প্রথম বক্সে আপনার অপারেটিং সিস্টেম এর নামটি লিখুন। যেমন উইন্ডোস হলে windows লিখুন তারপর নিচে থাকা next বাটনে ক্লিক করুন। তারপর আবার নিচের মতো আরেকটি পপআপ আসবে।

![](https://dnc.techtunes.io/tDrive/tuner/2021/03/techtunes_77266f359388e9700c55f82ed39887a6.png)

এখানে আপনার কাছে জানতে চাইবে আপনি নতুন যে অপারেটিং সিস্টেম টি ইনস্টল করতে চাচ্ছেন তার জন্য কতটুকু ram দেয়া হবে। সেখান থাকা লম্বা লাইন টি টেনে ram কম বেশি করতে পারবেন। আপনার ইচ্ছা মতো ram দিয়ে নেক্সট বাটনে ক্লিক করুন।

এখানে যেভাবে আছে সেভাবে রেখে create বাটনে ক্লিক করুন।

![](https://dnc.techtunes.io/tDrive/tuner/2021/03/techtunes_7f07fd2a695f10d9137a650e9f7a3a14.png)

এখানে আপনার কাছে জানতে চাইবে নতুন অপারেটিং সিস্টেম এর জন্য কতোটুকু হার্ড ড্রাইভ বা মেমরি দিবে। এখানে ও আগের মতো যা ইচ্ছা তা দিয়ে create বাটনে ক্লিক করুন্

![](https://dnc.techtunes.io/tDrive/tuner/2021/03/techtunes_d270189cad289d8f3934edef5fcb38df.png)

এবার দেখতে পাবেন নতুন একটি অপারেটিং সিস্টেম তৈরী হয়ে গেছে। সেটি সিলেক্ট অবস্থায় start বাটনে ক্লিক করুন। তাহলে আপনার সামনে নিচের মতো একটি উইন্ডো ওপেন হবে।

![](https://dnc.techtunes.io/tDrive/tuner/2021/03/techtunes_cd1532263b73dd35d79cb16c98492b1c.png)

এখানে আপনাকে অপারেটিং সিস্টেম এর iso ফাইল টি দিতে বলতেছে। যেটি আপনি ডাউনলোড করেছেন সেটি দিবেন এখানে। তার জন্য সেখানে থাকা folder আইকনএ ক্লিক করুন। তারপর এবার আপনার সামনে আরেকটি পপআপ ওপেন হবে।

![](https://dnc.techtunes.io/tDrive/tuner/2021/03/techtunes_d1486b711fae2caa9a52ae354ff6f3a1.png)

এখানে থাকা add বাটনে ক্লিক করুন। তারপর আপনার iso ফাইল টি সিলেক্ট করে দিন। সব শেষে choose বাটনে ক্লিক করে start বাটনে ক্লিক করুন।

সব কিছু ঠিক থাকে থাকলে আপনার সামনে সেই অপারেটিং সিস্টেম ইনস্টল করার অপসন চলে আসবে। আপনি নরমালি যেভাবে সেই অপারেটিং সিস্টেম ইনস্টল করেন সেভাবে ইনস্টল করে নিবেন। এটি আমি আর দেখলাম না কারণ একেক জন একেক অপারেটিং সিস্টেম ইনস্টল করবে।

আশাকরি এগুলো করার সময় কোনো সমস্যা হবে না। যদি কোনো কারণে হয় তাহলে সমস্যাটি লিখে গুগল এ সার্চ দিলে আশাকরি সমাধান পেয়ে যাবেন। যদি সমধান না পান তাহলে কষ্ট করে এই টিউন এ টিউমেন্ট করবেন। আজকের জন্য এই পর্যন্ত আল্লাহ হাফেজ।
