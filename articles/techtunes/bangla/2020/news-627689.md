## Techtunes Push টেকটিউনস পুশ কী?

Techtunes Push টেকটিউনস পুশ হলো টেকটিউনসের বিশেষ সার্ভিস যার মাধ্যমে আপনি ছোট একটি ৮ আট ডিজিটের কোডের মাধ্যমে বিভিন্ন URL বা লিংকে একসেস করতে পারবেন।

![](https://dnc.techtunes.io/tDrive/tuner/2019/08/techtunes_2dcc914a86c8ed2352ea2fdc84294184-640x360.png)

## Techtunes Push টেকটিউনস পুশ কোড কোথায় পাওয়া যাবে?

আপনি বিভিন্ন টিউনে ৮ আট ডিজিটের Techtunes Push টেকটিউনস পুশ কোড পাবেন এভাবে

টেকটিউনস পুশ কোড: 63456789

## Techtunes Push টেকটিউনস পুশ কোড ব্যবহার করা যাবে কীভাবে?

Techtunes Push টেকটিউনস পুশ কোড ব্যবহার করে URL বা লিংকে একসেস করতে

1. আপনার Browser এর এড্রেসবারে টাইপ করুন push.techtunes.io
2. এরপর একটি slash "/"
3. এরপর ৮ ডিজিটের Techtunes Push টেকটিউনস পুশ কোডটি।
4. মাঝে কোন স্পেস, হাইফেন, ডেস কিছুই হবে না।
5. এবার কিবোর্ড থেকে Enter চাপুন বা মোবাইল থেকে Go বাটন চাপুন।

ব্যস, আপনি URL বা লিংক এ একসেস করতে পারবেন

## পাসওয়ার্ড প্রোটেকটেড Techtunes Push টেকটিউনস পুশ

![](https://dnc.techtunes.io/tDrive/tuner/2019/08/techtunes_8faaf3eebbf1d969c2d32c41d00b40d0.gif)

কিছু কিছু Techtunes Push টেকটিউনস পুশ কোড এর URL বা লিংক পাসওয়ার্ড প্রোটেকটেড থাকতে পারে। পাসওয়ার্ড এর জন্য টিউনারকে টিউমেন্ট করুন। টিউনার আপনাকে Techtunes Push টেকটিউনস পুশ কোড এর URL বা লিংক এর পাসওয়ার্ড প্রদান করবে।

## আমি কি ভাবে আমার টিউনে Techtunes Push টেকটিউনস পুশ কোড যোগ করবো?

Techtunes Push টেকটিউনস পুশ ফিচার শুধু মাত্র 'টেকটিউনস ট্রাসটেড টিউনার' রা এবং [Techtunes Slash টেকটিউনস স্ল্যাস এর Pro ইউজাররা](https://slash.techtunes.io) নিজেস্ব ডোমেইনের মাধ্যমে ব্যবহার করতে পারে।

আপনি 'টেকটিউনস ট্রাসটেড টিউনার' হলে আপনার টিউনে Techtunes Push টেকটিউনস পুশ কোড যোগ করতে পারবেন অথবা আপনি [Techtunes Slash টেকটিউনস স্লাস এর Pro ইউজার](https://slash.techtunes.io) হলে আপনার নিজেস্ব ডোমেইন এর মাধ্যমে ব্যবহার করতে পারবেন।
