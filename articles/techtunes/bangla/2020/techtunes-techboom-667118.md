সম্প্রতি [মাইক্রোসফট](https://www.microsoft.com/) তাদের বহুল ব্যবহৃত Windows Defender রিলিজ করেছে অ্যান্ড্রয়েড এর জন্য।

উইন্ডোজ অপারেটিং সিস্টেমের পর এবার এবার [মাইক্রোসফট](https://www.microsoft.com/) তাদের মার্কেট বাড়াতে Windows Defender রিলিজ করেছে অ্যান্ড্রয়েড ফোনের জন্যও।

ইউজাররা প্লে-স্টোরে গিয়ে "Microsoft Defender" লিখে সার্চ দিয়েই এই অ্যাপটি পেয়ে যাবে। অ্যাপটিতে কোন প্রাইজ ট্যাগ না থাকলেও এটি ফ্রিতে ব্যবহার করা যাবে না। এটি ব্যবহার করতে হলে Microsoft 365 E5 লাইসেন্স লাগবে। বিজনেস ইউজারদের অনলাইন ভাইরাস থেকে রক্ষা করতেই [মাইক্রোসফট](https://www.microsoft.com/) এই পদক্ষেপ নিয়েছে।

Microsoft Defender ফিচার গুলো হল, এটি স্বয়ংক্রিয় ভাবে Malicious অ্যাপ সম্পর্কে ইউজারকে সতর্ক করবে, Malicious ওয়েব পেজ গুলো ব্লক করে দেবে এবং ডিভাইসের সিকিউরিটি বাড়াবে কয়েক গুন।

![](https://dnc.techtunes.io/tDrive/tuner/2020/09/techtunes_a0a9d36a7339171ad96a98413a7881df.png)

ধারণা করা যায় Microsoft Defender এর মাধ্যমে মাইক্রোসফট সাধারণ ইউজারবেজও বাড়ানোর চেষ্টা করছে। বর্তমানে বিভিন্ন সিস্টেমে তাদের এন্টিভাইরাস ব্যবহার করারও পদক্ষেপ নিয়েছে। যেমন বর্তমানে লিনাক্স এবং macOS অপারেটিং সিস্টেমেও Microsoft Defender ব্যবহার করা যায়।

Windows Defender উইন্ডোজের অন্যতম সেরা এন্টিভাইরাস হবার পর মাইক্রোসফট তাদের এন্টিভাইরাস বাজার বাড়ানো শুরু করেছে। ইতিমধ্যে তাদের এন্টিভাইরাস কাজ করছে লিনাক্স এবং macOS অপারেটিং সিস্টেমে। তারই ধারাবাহিকতায় রিলিজ এটি দেয়া হয়েছে প্লে-স্টোরেও।

যদিও এখনো বিজনেস ইউজারদের জন্য এটি এভেলেবল করা হয়েছে আশা করা যায় সেদিন বেশি দূরে নয় যখন সবাই অ্যান্ড্রয়েড ফোনে Windows Defender ব্যবহার করার সুযোগ পাবে।
