টেকটিউনস কমিউনিটি, কেমন আছেন সবাই? আশা করছি সবাই ভাল আছেন। বরাবরের মত চলে এসেছি নতুন কোন টিউন নিয়ে। আজকে আমি আলোচনা করব Hot corner ফিচার নিয়ে।

## Hot Corner ফিচার কি?

আমরা অনেকে হয়তো ম্যাক বুকের Hot Corner সম্পর্কে পরিচিত৷ পরিচিত না হলেও সমস্যা নেই, Hot Corner এমন একটি ফিচার যার মাধ্যমে ম্যাক বুকের স্ক্রিনের যেকোনো কোনায় মাউস রাখলেই আলাদা আলাদা সফটওয়্যার বা উইন্ডোজ ওপেন হবে। যেমন ধরুন কেউ যদি উপরের বাম কোণায় ফায়ারফক্স সেট করে রাখে, তখন ওখানে মাউস রাখলেই ফায়ার-ফক্স ওপেন হবে।

## HotCornersApp কি?

HotCornersApp একটি ফ্রি সফটওয়্যার যার মাধ্যমে আপনি উইন্ডোজ পিসিতে নিয়ে আসতে পারবেন Hot Corner ফিচার। উইন্ডোজ পিসিতে এই ফিচার ব্যবহার করতে Java Run time ইন্সটল থাকা লাগতো। কিন্তু এই সফটওয়্যার ব্যবহার করলে আলাদা করে Java Run Time ব্যবহার করা লাগবে না।
