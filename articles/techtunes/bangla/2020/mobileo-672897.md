দেশের বাজারে একের পর এক নতুন ফোন এনেই চলেছে রিয়েলমি। এরই ধারাবাহিকতায় এবার "৬০০০মিলিএম্প" এর বিশাল ব্যাটারিকে হেডলাইন করে নতুন ফোন, রিয়েলমি সি১২ (Realme C12) বাজারে এসেছে। গতকাল "Ask Realme" নামে একটি ওয়েব ইভেন্টের মাধ্যমে রিয়েলমি C12 ফোনটির ঘোষণা দেওয়া হয়।

## এক নজরে রিয়েলমি সি১২ (Realme C12) এর স্পেসিফিকেশন

|  |  |
| --- | --- |
| ডিসপ্লে | ৬.৫ইঞ্চির এইচডি+ প্যানেল |
| ব্যাক ক্যামেরা | ১৩মেগাপিক্সেল + ২মেগাপিক্সেল + ২মেগাপিক্সেল |
| সেল্ফি ক্যামেরা | ৫মেগাপিক্সেল |
| চিপসেট | মিডিয়াটেক হেলিও জি২৫ |
| র‍্যাম | ৩জিবি |
| ইন্টারনাল স্টোরেজ | ৩২জিবি |
| ব্যাটারি | ৬০০০মিলিএম্প |
| দাম | ১০, ৯৯০টাকা |

দামের দিক দিয়ে বিবেচনা করলে সাধারণ স্মার্টফোন ব্যবহারকারীদের জন্য রিয়েলমি সি১২ (Realme C12) একটি আদর্শ পছন্দ।
