আসসালামু আলাইকুম। টেকটিউনস এর নতুন আরো একটি টিউনে আপনাকে স্বাগতম। আমি স্বপন আছি আপনাদের সাথে, আশাকরি সকলেই অনেক ভালো আছেন। বন্ধুরা কাস্টম HTTP হলো একটি ইন্টারনেট প্রোটোকল যা স্বয়ংক্রিয়ভাবে তৈরি করা হয়। এই HTTP প্রোটোকল সাধারণত ওয়েব সার্ভার এবং ওয়েব ক্লায়েন্টের মধ্যে ডেটা আদান প্রদানের জন্য ব্যবহৃত হয়। কাস্টম প্রোটোকল HTTP (Hypertext Transfer Protocol) একটি উন্নত প্রযুক্তিগত প্রোটোকল, এই HTTP একটি নিদিষ্ট ক্ষমতা বা প্রয়োজন অনুযায়ী তৈরি করা হয়।

কাস্টম HTTP প্রোটোকল বানানোর জন্য আলাদা আলাদা অনেকগুলো উদ্দেশ্যে থাকতে পারে। কাস্টম HTTP প্রোটোকল বানানোর কিছু উদ্দেশ্য হলো ডেটা এনক্রিপ্ট করার জন্য, ইন্টারনেটে নিজের সিকিউরিটি অনেক হাই করা, পারসোনাল কাস্টম প্রোটোকল ব্যবহার করা, ইন্টারনেটে হাইডেন হেডার সেট করা ইত্যাদি। সাধারণ HTTP প্রোটোকলের মধ্যে এই ফিচারগুলো না থাকায় বা পারসোনালি ডেটা ফরওয়ার্ড করার সিস্টেম না থাকায় অনেকেই কাস্টম HTTP প্রোটোকল ব্যবহার করেন।

এছাড়াও কাস্টম HTTP (Custom HTTP) দিয়ে নেটওয়ার্ক কানেকশন ও ইন্টারনেট স্পিড আরো বেশি করার জন্য অনেক ওয়েব অ্যাপ্লিকেশনে কাস্টম HTTP ব্যবহার করা হয়ে থাকে, যা অনেক উন্নত HTTP প্রোটোকলের মাধ্যমে নেটওয়ার্ক স্পিডকে আরো বেশি বাড়িয়ে তুলে বিশেষ কাজে ব্যবহার করা হয়। কাস্টম HTTP সাধারণভাবে একটি ওয়েব সার্ভার এবং নিদিষ্ট ক্লায়েন্টের মধ্যে নির্দিষ্ট ডেটা আদান প্রদানের উপর ভিত্তি করে তৈরি হয়। কয়েকটি উন্নত ফিচার সম্পূর্ণ কাস্টম কাস্টম HTTP প্রোটোকল হলো-

1. ‌SSH
2. ‌HTTP/1.1
3. ‌HTTP/2
4. ‌V2ray
5. ‌QUIC
6. ‌SPDY
7. ‌TCP etc.

এই কাস্টম HTTP প্রোটোকলগুলোকে মডিফাই করে অনেক শক্তিশালী কাস্টম HTTP প্রোটোকল তৈরি করা হয়। কাস্টম HTTP প্রোটোকলগুলি সাধারণত একটি নির্দিষ্ট ব্যবহারকারী গোপনীয় নিদিষ্ট প্রোজেক্টে শেয়ারে ব্যবহার করা হয়।

## কীভাবে কাস্টম HTTP প্রোটোকলে SSH সার্ভার তৈরি করবেন?

অনালাইনে ফ্রিতে SSH সার্ভার তৈরি করার জন্য অনেক ওয়েবসাইট ফ্রি সার্ভার প্রোভাইড করে। এসব ফ্রি সার্ভার ব্যবহার করে আপনি খুব সহজেই একটি HTTP প্রোটোকলে নিজের একটি কাস্টম সার্ভার বানাতে পারবেন। এসব সার্ভিস ফ্রি হলেও অনেক বেশি সিকিউরিটি বা সিকিউর দিয়ে থাকে। তাই আপনি নিশ্চিন্তে এসব ফ্রি সার্ভিস ব্যবহার করে সার্ভার তৈরি করতে পারেন। অনলাইনে HTTP প্রোটোকলে ফ্রি সার্ভার প্রোভাইড করে এমন কয়েকটি ওয়েবসাইট লিস্ট হলো-

1. ‌Createssh
2. ‌Sshstores
3. ‌Akunssh
4. ‌Open Tunnel
5. ‌Greenssh

তো বন্ধুরা, এবার আমি আপনাদের দেখাবো কীভাবে আপনারা নিজেদের কাস্টম SSH সার্ভার তৈরি করবেন। HTTP প্রোটকল ব্যবহার করে কাস্টম SSH সার্ভার বানানোর জন্য উপরে আমাদের দেওয়া যেকোনো একটি ওয়েবসাইটে ভিজিট করতে পারে। ওয়েবসাইটের ডিজাইন এর ভিন্নতার কারণে অপশন আলাদা নামে থাকতে পারে। তবে নিয়ম সবগুলোর একই। কাস্টম SSH বানানোর জন্য আমরা Createssh এই ওয়েবসাইটটি ব্যবহার করবো। এছাড়াও আপনি এখান থেকে Free High Speed Premium VPN & SSH SSL/TLS Server বানাতে পারবেন।

১. সর্বপ্রথম আপনি নিচে দেওয়া Createssh ওয়েবসাইটের লেখায় ক্লিক করে ওয়েবসাইটটিতে ভিজিট করুন।

![](https://dnc.techtunes.io/tDrive/tuner/2024/01/techtunes_a552dbfb6b94d9d04ecac6be6bc5dc5d.jpg)

২. এবার আপনারা একটু নিচে আসুন। একটু নিচে যাওয়ার পর এখানে আপনারা কাস্টম SSH সহ HTTP.1 থেকে শুরু করে সকল ধরনের প্রোটোকল অপশন পেয়ে যাবেন। আপনি কোন প্রোটোকল অপশন টি ব্যবহার করে সার্ভার বানাবেন তা সিলেক্ট করে দিবেন। আমি SSH অপশন টি বাছাই করে Choose Location অপশনে ক্লিক করলাম।

![](https://dnc.techtunes.io/tDrive/tuner/2024/01/techtunes_9c1da964e3ce8079639dfe33e69315ba.jpg)

৩. তারপর আপনারা স্ক্রোল করে আবারো একটু নিচে আসবেন। আপনারা কোন দেশের সার্ভার বানাতে চাচ্ছেন তার সার্ভার সংখ্যা পূরণ হয়েছে কিনা তা চেক করে নিয়ে Select Option ক্লিক করবেন। সার্ভার ইউজার সংখ্যা ফুল দেখালে পরবর্তী পেজে চলে যাবেন। নতুন অন্য একটি সার্ভার বাছাই করে নিবেন।

![](https://dnc.techtunes.io/tDrive/tuner/2024/01/techtunes_32e300c696b8ca03596c87005a6c4aa4.jpg)

৪. এবার সার্ভারটি অ্যাক্টিভ আছে কিনা সেটি দেখে নিন। সবকিছু ঠিক থাকলে আপনারা Create Account অপশনে ক্লিক করবেন।

৫. এবার আপনারা আরো একটু নিচে আসবেন। তারপর আপনাদের কাস্টম SSH সার্ভার বানানোর মেইন পেজ পেয়ে যাবেন। এখানেই আপনাদের ইউজার নাম ও পাসওয়ার্ড সেট করতে হবে।

## শেষ কথা

আপনি যদি নিজের পারসোনাল ডেটাগুলোর সুরক্ষা নিয়ে চিন্তিত থাকেন তাহলে কাস্টম HTTP ব্যবহার করে SSH সার্ভার বানিয়ে নিজেকে সর্বোচ্চ সুরক্ষা প্রদান করতে পারবেন। কীভাবে কাস্টম HTTP ব্যবহার করে SSH সার্ভার বানাবেন আর কীভাবে তা ব্যবহার করতে তা টিউন পড়ে আশাকরি বুঝতে পেরেছেন। আপনি আমার দেখানো HTTP প্রটোকল সিস্টেমকে কাজে লাগিয়ে সুপার ফার্স্ট হাই স্পিডের VPN বানাতে পারবেন। এছাড়াও ডেটা এনক্রিপ্ট এর মতো জটিল কাজগুলো খুব সহজেই করে নিতে পারবেন। এভাবে নিজের SSH সার্ভার বানিয়ে ব্যবহার করার সবচেয়ে জনপ্রিয় একটি কারণ হলো নিজেকে সাধারণ ইউজারদের থেকে আলাদা করা। আপনি চাইলে আজকেই কাস্টম HTTP ব্যবহার করে SSH সার্ভার বানাতে পারবেন।

বন্ধুরা এইভাবে আপনারা খুব সহজেই আপনাদের কাস্টম SSH সার্ভার তৈরি করে নিতে পারবেন। তো বন্ধুরা এই ছিল আমাদের আজকের টিউন, কীভাবে খুব সহজেই আপনাদের কাস্টম SSH সার্ভার তৈরি করে নিতে পারবেন? আশাকরি টিউন টি আপনাদের একটু হলেও হেল্পফুল হবে। আজকের মতো এখানেই বিদায় নিচ্ছি, দেখা হবে পরবর্তী টিউনে নতুন কোন বিষয় নিয়ে। ততক্ষণ অবধি সবাই ভালো থাকবেন সুস্থ থাকবেন এবং টেকটিউনস এর সাথেই থাকবেন।
