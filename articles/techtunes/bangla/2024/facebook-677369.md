বন্ধুরা আশাকরি সকলেই ভালো আছেন। আমরা কিন্তু প্রতিদিনই ফেসবুক ব্যবহার করে থাকি। আপনাদের তো সকলেরই এটা চাওয়া যে, আপনার ফেসবুক url আপনার মনের মতো হোক।

ফেসবুকে আপনাকে নতুন বন্ধুত্ব করার জন্য অন্যকে ফ্রেন্ড রিকোয়েস্ট পাঠাতে হয়। কিন্তু আপনার কোনো বন্ধুকে যদি ফেসবুকে আপনাকে খুঁজে না পায় তবে আপনি কি করবেন? অবশ্যই আপনি তাকে অন্য কোনো মাধ্যমে আপনার ফেসবুকের লিঙ্ক শেয়ার করবেন। কিন্তু সেই মূহুর্তে যদি আপনার হাতে মোবাইলই না থাকে তখন আপনি কিভাবে লিঙ্ক তাকে দিবেন? এজন্য অবশ্যই দরকার একটি সহজ এবং ইউনিক URL.

## কিভাবে আপনি একটি সহজ এবং আপনার নামের URL তৈরি করবেন?

১. এজন্য প্রথমেই আপনাকে চলে যেতে হবে আপনার মোবাইলের মেসেঞ্জার অ্যাপে। এরপর উপরে আপনার প্রোফাইল আইকনে ক্লিক করুন।

![messenger profile icon](https://dnc.techtunes.io/tDrive/tuner/2020/12/techtunes_fdd75bf3b67efb5daba6fa49f686f95b.jpg)

২. এরপর এখানে username এ ক্লিক করুন।

![messenger username](https://dnc.techtunes.io/tDrive/tuner/2020/12/techtunes_471c4b9f6141d16555b059138d3e6a06.jpg)

৩. এরপর edit usermame এ ক্লিক করুন।

![edit usermame](https://dnc.techtunes.io/tDrive/tuner/2020/12/techtunes_2b918e99d27a762e5a3e29759ad471cb.jpg)

৪. এরপর আপনি উপরের ঘরে আপনার মনের মতো username দিয়ে দেখুন সেটি ইতিমধ্যেই ব্যবহৃত হয়েছে কিনা। আপনি এখানে যে নামটি দিয়ে দিবেন সে নামটি facebook.com/এর পরে এখানে যোগ হবে।

![username input](https://dnc.techtunes.io/tDrive/tuner/2020/12/techtunes_7f361efc5b988204d8d765b3d22e26d7.jpg)

৫. আপনার username দেওয়া শেষ হলে উপরে দেখতে পাবেন save লেখা, আপনি এখানে ক্লিক করে এটি save করে দিন। এরপর থেকে সেই নামটি আপনার ফেসবুক url এর facebook.com/ এর পরে যোগ হবে।

![facebook username save](https://dnc.techtunes.io/tDrive/tuner/2020/12/techtunes_f88cd79f680dfb86b432674c25ba9fea.jpg)

ফেসবুকে আপনার পছন্দের url যোগ করার মাধ্যমে কিন্তু আপনি খুব সহজেই আপনার url মনে রাখতে পারবেন। এতে করে আপনার বন্ধুদের সেই url টি শেয়ার করতে সুবিধা হবে। আপনি চাইলে তাকে মুখেও বলতে পারেন অথবা যেকোনো মাধ্যমে শেয়ারও করতে পারেন।

## আপনার URL দেখবেন কিভাবে?

আপনি দুই পদ্ধতিতে আপনার url দেখতে পারেন। আপনি মেসেঞ্জার অ্যাপে এবং ফেসবুক অ্যাপে গিয়ে দেখতে পারেন।

### মেসেঞ্জার অ্যাপে

১. এজন্য আপনি অ্যাপে গিয়ে উপরের প্রোফাইল আইকনে ক্লিক করে, এখানে username এ ক্লিক করুন।

![username](https://dnc.techtunes.io/tDrive/tuner/2020/12/techtunes_4d0bd8ddb477a7ca9065c41f6cda98ab.jpg)

২. এরপর edit username এর নিচে copy link এ ক্লিক করার মাধ্যমে আপনার url কপি করতে পারেন।

### ফেসবুক অ্যাপে

১. এজন্য আপনার ফেসবুক প্রোফাইলে চলে যান। এরপর three dot ক্লিক করুন।

![Facebook profile](https://dnc.techtunes.io/tDrive/tuner/2020/12/techtunes_7461a9d5124822c832f3ddb861c7adbe.jpg)

২. এরপর নিচে দেখতে পাবেন আপনার ফেসবুক আইডির url প্রদর্শিত হচ্ছে। আপনি copy link এ ক্লিক করার মাধ্যমে এখান থেকেও আপনার url টি কপি করতে পারেন।

![copy url](https://dnc.techtunes.io/tDrive/tuner/2020/12/techtunes_36781ed4fea1291287a481862f64b870.jpg)

বন্ধুরা এই ছিল আজকের টিউন। আশাকরি টিউনটি আপনাদের কাছে অনেক ভালো লেগেছে। সম্পূর্ণ টিউনটি পড়ার জন্য ধন্যবাদ।
