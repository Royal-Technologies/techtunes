ফেসবুক পরিচালনায় দক্ষ হওয়া সত্বেও অনেকেই ফেসবুকের বিভিন্ন ফিচার সম্পর্কে ভালোভাবে জানে না। এমনই একটি ফেসবুক ফিচার হলো Spam Message। অনেকেই হয়তো এই অপশনটির সাথে পরিচিত না। কিন্তু আমাদের নিয়মিত Spam Message চেক করা উচিত। নয়তো অনেক গুরুত্বপূর্ণ তথ্য বা সুযোগ থেকে হয়তো আমরা বঞ্চিত হতে পারি।

বিশেষ করে যারা নিজের ফেসবুক প্রোফাইল ব্যবহার করে অনলাইনে ব্যবসা করেন তাদের জন্য এটি অত্যন্ত গুরুত্বপূর্ণ কাজ। প্রতিদিন নিয়ম করে একবার Spam Message চেক করা উচিত। কিন্তু আপনাদের মনে হতে পারে যে এই Spam Message টা আবার কী? কীভাবে এই Spam Message চেক করতে হয়? আর কেন আমরা Spam Message চেক করবো?

আপনাদের সকল প্রশ্নের উত্তর পেতে চাইলে সম্পূর্ণ টিউনটি পড়ার অনুরোধ রইল।

## Spam Message কী?

![Spam Message এর সংজ্ঞা ](https://dnc.techtunes.io/tDrive/tuner/2024/01/techtunes_25f22383733d1edba1679a239eb9aafc.png)

ফেসবুক সহ সকল সামাজিক যোগাযোগ মাধ্যমে একটি ব্যক্তিগত Message অপশন থাকে। সেখানে অচেনা কেউ সরাসরি Message পাঠাতে পারে না। তাই অপরিচিত কেউ Message পাঠালে তা Messenge Request অপশনে গিয়ে জমা হয়। আর যারা ফেসবুক ব্যবহার করি তারা সকলেই হয়তো message Request অপশনটির সাথে পরিচিত।

কিন্তু আপনি যদি Message Request এর Message চেক করার আগেই কোনো ব্যক্তি পুনরায় Message করতে থাকে তাহলে তা Spam Message অপশনে গিয়ে জমা হয়। আবার কোনো ব্যক্তির Message ফেসবুক কর্তৃপক্ষের কাছে অবাঞ্ছিত মনে হলেও তা Spam Message অপশনে জমা করা হতে পারে। মূলত Message Request অপশনে জমা না হয়ে Spam Message অপশনে জমা হওয়া Message গুলো Spam Message হিসেবে পরিচিত।

## Spam Message কীভাবে চেক করবেন?

![যেভাবে Spam Message চেক করবেন](https://dnc.techtunes.io/tDrive/tuner/2024/01/techtunes_5182870645c30c8df4571356e12fcdac.png)

এখন প্রশ্ন আসতে পারে আমাদের ফেসবুকে বা Messenger এ তো সচরাচর Spam Message অপশনটি দেখা যায় না। তাহলে আমরা কীভাবে এটি চেক করবো? চলুন এই বিষয়ে একটি টিউটোরিয়াল দেখে নেয়া যাক।

১. Spam Message চেক করার জন্য প্রথমেই আপনাকে ফেসবুক বা Messenger App এ প্রবেশ করতে হবে। আমি আমার মোবাইল থেকে Messenger App দিয়ে টিউটোরিয়ালটি করে দেখাব। তাই আমি Messenger App এ প্রবেশ করছি।

![মেসেঞ্জারে ঢুকতে হবে](https://dnc.techtunes.io/tDrive/tuner/2024/01/techtunes_15ccbbd75d3af4f10f8f73d61f96fb23.png)

২. Messenger App এ প্রবেশ করলে ওপরে বাম দিকে কোনায় এই অপশনটি দেখতে পারবেন। স্ক্রিনশট দেখে অপশনটি চিনে নিন।

![এই আইকনে ক্লিক করুন](https://dnc.techtunes.io/tDrive/tuner/2024/01/techtunes_92fc23483bef6097be3d49dfd1ff0fb7.png)

৩. উপরে চিহ্নিত অপশনে ক্লিক করলে অনেক গুলো নতুন লেখা দেখতে পারবেন। তার মধ্যে একটি অপশনে দেখবেন Message Request লেখা আছে। ঐ লেখাটির ওপর ক্লিক করবেন।

![Message Request অপশনে ক্লিক করুন ](https://dnc.techtunes.io/tDrive/tuner/2024/01/techtunes_09cecd06d7622d9f61326d8cc4fce4fa.png)

৪. এরপর নতুন একটি পেইজে Message Request এর মেসেজ গুলো প্রদর্শিত হবে। এবার ওপরের দিকে লেখা দেখবেন Spam Message। ঐ লেখাটির ওপর ক্লিক করবেন।

![Spam Message অপশন](https://dnc.techtunes.io/tDrive/tuner/2024/01/techtunes_a30c4a45dd8e49756708d8c1905ed045.png)

৫. এবার আরেকটি নতুন পেইজ ওপেন হবে। ঐ পেইজে সকল Spam Message গুলো দেখতে পারবেন। এখানে দেখতে পাচ্ছেন আমি আমার Spam Message গুলো পেয়ে গেছি।

![Spam Message ](https://dnc.techtunes.io/tDrive/tuner/2024/01/techtunes_6ee5b854f21219db8b5d6ef865f378b3.png)

এভাবে আপনি খুব সহজেই ফেসবুক বা Messenger App এর Message Request অপশনে ঢুকে Spam Message গুলো খুঁজে বের করতে পারবেন।

## কেন Spam Message চেক করা জরুরি?

![যে কারণে Spam Message চেক করবেন](https://dnc.techtunes.io/tDrive/tuner/2024/01/techtunes_7aeba568c245e32c5ae0795593f6666c.png)

হতে পারে আপনার সাথে গুরুত্বপূর্ণ কেউ একজন যোগাযোগ করতে চাইছে কিন্তু তার Message টি Spam Message অপশনে গিয়ে জমা হলো। আর আপনি জানতেও পারলেন না কেউ একজন বার বার আপনার সাথে যোগাযোগ করার চেষ্টা করছে। এভাবে হয়তো গুরুত্বপূর্ণ কোনো তথ্য বা সুযোগ মিস করে ফেলতে পারেন।

আবার যারা অনলাইনে ব্যবসা করেন তাদের জন্য তো Spam Message চেক করা অত্যন্ত জরুরি। কেননা অনেক ক্রেতার Message হয়তো Spam Message এ পড়ে থাকবে আর আপনি তা জানতেই পারবেন না। এতে করে আপনি অনেক ক্রেতা হারাবেন। আর এভাবে সম্ভাব্য অনেক ক্রেতার-ই আপনার সম্পর্কে খারাপ মনোভাব সৃষ্টি হবে।

তাই প্রতিনিয়ত Message Request চেক করার পাশাপাশি Spam Message অপশনটি চেক করুন। আরেকটি বিষয় হলো Message Request এর জন্য আপনি Notification পাবেন কিন্তু Spam Message এর জন্য কোনো ধরনের Notification পাবেন না। তাই এই অপশনটি নিজে থেকেই চেক করতে হবে।

## শেষকথা

হয়তো অনেকেই Spam Message অপশন সম্পর্কে জানতেন না। আশাকরি ইতোমধ্যে এই বিষয়ে পুরোপুরি ধারনা পেয়ে গেছেন৷ এরপর থেকে প্রতিদিন কমপক্ষে একবার এই অপশনটি চেক করে দেখবেন। এরকম আরও নতুন নতুন টিউটোরিয়াল টিউন পেতে আমাকে ফলো করে রাখতে পারেন। ধন্যবাদ।
