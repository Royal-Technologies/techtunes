আসসালামু আলাইকুম, কেমন আছেন টেকটিউনস কমিউনিটি? আশা করছি সবাই ভাল আছেন। আজকে আবার হাজির হলাম নতুন টিউন নিয়ে।

কখনো কখনো এমন হয় হটাৎ করেই ইন্টারনেট কানেকশন চলে যায়। সব কিছু করার পরেও কাজ না করলে আমাদের হাতে একটি অপশনই থাকে আর সেটা হল রাউটার রিসেট করা। যে মডেলের রাউটারই হোক রিসেট করা কঠিন কোন কাজ নয়। আজকের এই টিউনে আমরা জানব কীভাবে আপনার রাউটার রিসেট করবেন।

## কেন রাউটার রিসেট করতে হয়?

![](https://dnc.techtunes.io/tDrive/tuner/2023/05/techtunes_1e4ccd3a945cbec1a9f5fe406da10968.jpg)

অনেক কারণেই আপনি আপনার রাউটার রিসেট করতে চাইতে পারেন। যেমন ইন্টারনেট কাজ না করলে এবং ইস্যু খুঁজে না পেলে একটা অপশনই থাকে সেটা হচ্ছে রিসেট করা। তাছাড়া রাউটার কাউকে দিয়ে দিলেও রিসেট করার প্রয়োজন পড়ে। এছাড়া বিভিন্ন কারণে রাউটার রিসেট করতে হতে পারে।

### রাউটার রিসেট করলে কী ঘটে?

রাউটার রিসেট করা হলে রাউটারে স্টোর করা সব কিছু মুছে যায়। রাউটারে ম্যানুয়ালি কনফিগার করা সব সেটিংস ডিলিট হয়ে যাবার পাশাপাশি, Wireless Network Settings, Backup Schedules, Firewall Rules, ইত্যাদি মুছে যায়। মোট করা রিসেট করা রাউটার এমন অবস্থায় পৌঁছে যায় যেমনটি নতুন অবস্থায় ছিল।

আপনার মনে রাখতে হবে যে রিসেট করার পর সব সেটিংস চলে যাবে, সেক্ষেত্রে প্রয়োজনীয় সেটিংস গুলো ব্যাকআপ রাখা ভাল সিদ্ধান্ত হতে পারে। এ বিষয়েও আলোচনা হবে।

### রাউটারের লগইন ইনফরমেশন বের করা

রাউটার রিসেট কর‍তে প্রথমেই আপনার যে জিনিসটা লাগবে সেটা হচ্ছে রাউটারের লগইন ইনফো। ইউজারনেম আর পাসওয়ার্ড দিয়ে আপনাকে রাউটারের সেটিংস এ প্রবেশ করতে হবে।

বেশিরভাগ রাউটারে ডিফল্ট ভাবে ইউজারনেম ও পাসওয়ার্ড admin হয়ে থাক। প্রথমে উভয় ফিল্ডে admin লিখে ট্রাই করুন। যদি কাজ না করে তাহলে রাউটারের ইউজার ম্যানুয়াল ফলো করুন অথবা অনলাইনের সাহায্য নিন।

## কীভাবে রাউটার রিবুট করবেন

![](https://dnc.techtunes.io/tDrive/tuner/2023/05/techtunes_34aab8866b16a7796675db3f39c8a3c2.jpg)

রাউটারে মাইনর কোন ইস্যু ফেস করলে প্রথমে হার্ড রিসেট না দিয়ে রাউটার রিবুট করে ট্রাই করতে পারেন। রাউটার রিবুট করার দুটি পদ্ধতি রয়েছে,

### ১. ফিজিক্যাল বাটন প্রেস করে

আপনার রাউটারে যদি অফ অন করার ফিজিক্যাল বাটন থাকে তাহলে বাটম প্রেস করে রাউটার অফ করে ২ থেকে তিন মিনিট পর অন করুন। যদি বাটন না থাকে তাহলে পাওয়ার লাইন খুলে আবার কয়েক মিনিট পর লাগান।

### ২. রাউটারের সেটিংস পেজ দিয়ে রিবুট

চলুন বিভিন্ন রাউটারে কোথায় রিবুট অপশন পাবেন দেখে নেয়া যাক,

**Advanced DrayTek রাউটার:**

- ব্রাউজার ওপেন করুন
- রাউটারের আইপি এড্রেস লিখে এন্টার দিন। রাউটারের আইপি পেতে মডেল লিখে গুগলে সার্চ দিন।
- লগইন ইনফো দিয়ে লগইন করুন
- বাম পাশ থেকে System Maintenance এ ক্লিক করুন
- এক্সপান্ড ম্যানু থেকে Reboot System এ ক্লিক করুন
- ডান পাশের Reboot System সেকশন থেকে Using current configuration এ টিক দিয়ে Reboot Now এ ক্লিক করুন। এখন রাউটার অফ অন হতে কিছুক্ষণ অপেক্ষা করুন।

**ব্যাসিক iBall রাউটার:**

- ব্রাউজারটি ওপেন করুন এবং রাউটারের আইপি এড্রেস দিয়ে এন্টার দিন
- রাউটারের লগইন ইনফো দিন
- লগইন করার পর Maintenance এ ক্লিক করুন
- বাম পাশ থেকে Restart বাটমে ক্লিক করুন

## কীভাবে রাউটার রিসেট করবেন

![](https://dnc.techtunes.io/tDrive/tuner/2023/05/techtunes_3b705b805cab38b8e439ba239b5ad711.jpg)

যদি রিবুটে সমস্যার সমাধান না হয় তাহলে আপনার হতে সহজ একটা অপশনই থাকবে সেটা হচ্ছে রাউটার রিসেট করা।

চলুন দেখে যাক কীভাবে রাউটার রিসেট করবেন,

আমি আগেই বলেছিলাম রিসেট দিলে সব সেটিংস চলে যাবে তাই গুরুত্বপূর্ণ সেটিংস গুলো ব্যাকআপ নিয়ে নেয়া বুদ্ধিমানের কাজ হবে।

### রাউটারের সেটিংস ব্যাকআপ নেয়া

এবার আমরা দেখব কিভাবে রাউটারের সেটিংস ব্যাকআপ নেয়া যায়।

**Advanced DrayTek রাউটার:**

- রাউটারের সেটিংস পেজে প্রবেশ করুন
- System Maintenance এ ক্লিক করুন এবং Configuration Backup সিলেক্ট করুন
- Backup সেকশন থেকে Backup এ ক্লিক করুন
- সর্বশেষ ব্যাকআপ ফাইলটি সেভ করে রাখুন

**Basic iBall রাউটার:**

- রাউটারের সেটিংস ম্যানুতে যান
- উপর থেকে Maintenance এ ক্লিক করুন
- বামপাশ থেকে Backup/Restore এ ক্লিক করুন
- ডান পাশে Backup এ ক্লিক করুন। এটি আপনার জন্য ব্যাকআপ ফাইল তৈরি করবে।
- পরবর্তীতে এই ব্যাকআপ ফাইল গুলো নির্দিষ্ট রাউটারে রিস্টোর করে নিন।

## রাউটার রিসেট করুন

![](https://dnc.techtunes.io/tDrive/tuner/2023/05/techtunes_e4ce45d5f6e06015898c7a32924867a8.jpg)

এখন আমাদের সেটিংস ব্যাকআপ রয়েছে এবার নিশ্চিতে রাউটার রিসেট করতে পারব

**Advanced DrayTek রাউটারের ক্ষেত্রে:**

- সেটিংস ম্যানুতে যান
- System Maintenance এ ক্লিক করুন
- Reboot System ম্যানুতে ক্লিক করুন
- ডান পাশের Reboot system সেকশন থেকে Using factory default configuration ক্লিক করে Reboot Now এ ক্লিক করুন

**Basic iBall রাউডারের ক্ষেত্রে:**

- রাউটারের সেটিংস এ যান
- Maintenance ট্যাবে ক্লিক করুন
- বাম পাশ থেকে Factory Default Settings এ ক্লিক করুন
- ফাইনালি Factory Default Settings বাটমে ক্লিক করুন
- ব্যাস আপনার রাউটার রিসেট হয়ে গেছে

রিসেট করার পর যদি আপনি আপনার সেটিংস ফিরে পেতে চান তাহলে, আগে করে রাখা ব্যাকআপ রিস্টোর করতে হবে। এবার আমরা দেখব কিভাবে ব্যাক রিস্টোর করা যায়।

**Advanced DrayTek রাউটারের ক্ষেত্রে,**

- সেটিংস ম্যানুতে যান
- Maintenance থেকে Configuration Backup এ ক্লিক করুন
- Restore সেকশন থেকে Choose file এ ক্লিক করে ব্যাকআপ ফাইলটি সিলেক্ট করে দিন
- সর্বশেষ backup file এ ক্লিক করুন

**Basic iBall রাউটারের ক্ষেত্রে,**

- সেটিংস ম্যানুতে যান
- Maintenance এ ক্লিক করে Backup/Restore সিলেক্ট করুন
- ফাইলটি সিলেক্ট করে, ব্যাকআপ আপলোড করে দিন।

## শেষ কথা

ভুল ভাবে কনফিগারেশন করলে রাউটারে অনেক সমস্যা দেখা দিতে পারে আর যেকোনো সমস্যায় আশা করছি উপরের পদক্ষেপ গুলো আপনাকে সাহায্য করতে পারে। ধাপ গুলো ফলো করে রাউটার রিসেট করে নিন। কখনো কখনো রাউটারের সাথে পিসির নেটওয়ার্কেও সমস্যা থাকতে পারে তাই সেদিকেও নজর দিন।

তো আজকে এই পর্যন্তই পরবর্তী টিউন পর্যন্ত ভাল থাকুন আল্লাহ হাফেজ।
