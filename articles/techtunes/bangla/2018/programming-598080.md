আশা করি সবাই ভাল আছেন। নতুন আর একটি টিউটোরিয়াল নিয়ে আসলাম।

গত কয়েক দিন হলো  Laravel তাদের নতুন ভার্সন রিলিজ করেছে। Laravel 5.7 এর নতুন ফিচার গুলো নিয়ে আজকের টিউটোরিয়াল।

**Laravel 5.7 এর সার্পট পলিসি**

 Laravel 5.7 ভারসনটি রিলিজ হয় September 4th, 2018 এই ভারসনটি Bug Fixes করা হবে March 4th, 2019 সাল পর্যন্ত  এবং Security Fixes করা হবে September 4th, 2019 পর্যন্ত।

| Version | Release | Bug Fixes Until | Security Fixes Until |
| --- | --- | --- | --- |

|  |  |  |  |
| --- | --- | --- | --- |
| 5.7 | September 4th, 2018 | March 4th, 2019 | September 4th, 2019 |

***নতুন  ফিচার***

- Laravel Nova
- Email Verification
- Guest User Gates / Policies
- Symfony Dump Server
- Notification Localization
- Console Testing
- URL Generator & Callable Syntax
- Paginator Links
- Filesystem Read / Write Streams

উপরের এই চমৎকার চমৎকার ফিচার গুলো সম্পর্কে জানতে নিচের ভিডিওটি দেখুন

[Embedded External Content: https://www.youtube.com/embed/ONdpguCEzss?feature=oembed]

Laravel 5.7 এর নতুন ফিচার গুলো নিয়ে আলাদা আলাদা ভিডিও আছে [এই লিংক](https://www.youtube.com/watch?v=ONdpguCEzss&list=PLPoLMl4y9d7C3nGBh3TMbpo1C8nUiBgo5) থেকে দেখে নিতে পারেন অথবা একটু অপেক্ষা করুন পরর্বতি টিউটোরিয়াল এ Laravel 5.7 এর নতুন ফিচার গুলো নিয়ে টিউন করব।
