আশাকরি সবাই আছেন। বাংলায় PHP Laravel Framework টিউটোরিয়াল পর্ব ৪ আবারও চলে আসলাম। যারা ১ম, ২য় এবং ৩য় পর্ব  এখনও দেখেন নাই তারা উপরের এর লিংক গুলো থেকে ঘুড়ে আসলে এই পর্ব টা বুজতে সুবিধা হবে। আর কথা না বাড়িয়ে Laravel Basic Route কি ভাবে কাজ করে বা কি ভাবে আপনি Route এ কাজ করবেন চলুন জেনে নেওয়া যাক।

বরাররের মতই Project টি ইডিটরে ওপেন করব। আগের পর্ব ৩ এর Laravel Project ফোল্ডার পরিচিতিতে বলেছি কোথায় কি থাকে। Routes থেকে **web.php**Routes file টি ওপেন করে কাজ করব।
