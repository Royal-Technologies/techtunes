আজকের টিউনের বিষয়, পিসি বা ল্যাপটপে স্ক্রিনশট নিন কোন রকম সফটওয়্যার ছাড়াই। স্ক্রিনশট নেওয়ার জন্য অনেকেই অনেক সফটওয়্যার ব্যবহার করে থাকে, তবে আজ আমি আপনাদের সাথে শেয়ার করবো যেভাবে সফটওয়্যার ছাড়া পিসিতে স্ক্রিনশট নিবেন।

স্ক্রিনশট অনেক প্রয়োজনীয় একটা বিষয়, যেমন আপনি যেই বিষয়টা একজনকে লিখে বুঝাতে অনেক সময় লাগবে, সেই বিষয়টাই আপনি স্ক্রিনশটের মাধ্যমে অল্প সময় খুব নিক্ষুধ ভাবে বুঝাতে সক্ষম হবেন। এছাড়াও কোন [Blog](https://www.blogger.com/) এ Tutorial আকারে টিউন করতে গেলে স্ক্রিনশট নেওয়া ছাড়া কাজ করা সম্ভব না। তাই যারা সফটওয়্যার ছাড়া স্ক্রিনশট নিতে চান তারা নিচে থেকে নিয়ম টা দেখে নিন।

## কোন রকম সফটওয়্যার ছাড়াই স্ক্রিনশট নিবেন

- আপনি আপনার কিবোর্ড দিয়ে নিতে পারেন, সে জন্য আপনাকে কীবোর্ড থেকে  **Windows**Key**[Start**key**]**চেপে **PrntScr** key চাপলেই আপনার স্ক্রিনশট  হয়ে যাবে। আপনি পিসির যে কোন স্থান থেকে এ ভাবে স্ক্রিনশট নিতে পারবেন।

*নোটিশঃ* এই নিয়মটি বেশী কার্যকর Laptop এবং Windows 8 / 8.1 / 10 তাই যদি আপনার কাজ না হয় তা হলে নিচের নিয়মটি অনুসরন করুন।

[![Make screenshot using by keyboard ](https://4.bp.blogspot.com/-oNJbZRkf6OI/WgYW1JPku-I/AAAAAAAAIos/_LSB-ZdY9XkY-pL_zd8GDu1B9tnZ0dQrACLcBGAs/s640/screenshot-on-windows-without-software.jpg "Make screenshot using by keyboard ")](https://4.bp.blogspot.com/-oNJbZRkf6OI/WgYW1JPku-I/AAAAAAAAIos/_LSB-ZdY9XkY-pL_zd8GDu1B9tnZ0dQrACLcBGAs/s1600/screenshot-on-windows-without-software.jpg)

- Snipping Tool এটা সকল উইন্ডোজ এ বাই ডিফল্ট ভাবে দেওয়া থাকে তাই কারো যদি উপড়ের নিয়মে কাজ না করে তাহলে এই নিয়মে কাজ করবে। উইন্ডোজ স্টার্ট মেনু থেকে Snipping Tool লিখে সার্চ করেন আশা করি পেয়ে যাবেন> এরপর Snipping Tool অপেন।

[![Make Screenshot by Snipping Tool](https://1.bp.blogspot.com/-oDp4oBVYKP0/VYmACPmaP_I/AAAAAAAAEv0/vcpDBT_z6_I/s1600/snipping%2Btool.png "Make Screenshot by Snipping Tool")](https://1.bp.blogspot.com/-oDp4oBVYKP0/VYmACPmaP_I/AAAAAAAAEv0/vcpDBT_z6_I/s1600/snipping%2Btool.png)

- Snipping Tool অপেন করলে নিচের ছবির মত আসবে এবার আপনি Full Screen অথবা যে সাইজের স্ক্রিনশট নিতে চান সিলেক্ট করুন স্ক্রিনশট হয়ে যাবে।
