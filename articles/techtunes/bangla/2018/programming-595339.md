আশাকরি সবাই আছেন। বাংলায় PHP Laravel Framework টিউটোরিয়াল পর্ব ২ আবারও সবাইকে স্বাগতম জানাই। যারা প্রথম পর্ব এখনও দেখেন নাই তারা উপরের **পর্ব ১** এর লিংক থেকে ঘু েআসলে েএই পর্ব টা বুজতে সুবিধা হবে। আর কথা না বাড়িয়ে Laravel Project তৈরি করতে নেমে পরি।

Laravel শুরুকারার জন্য বা Laravel Project তৈরি করার জন্য কম্পোজার দরকার। আপনি Laravel ইনস্টল করার আগে আপনার সিস্টেমে কম্পোজার ইনস্টল  নিশ্চিত করুন। এই অধ্যায়ে, আপনি Laravel এর ইনস্টলেশন প্রক্রিয়া দেখতে পাবেন। আপনার সিস্টেমে Laravel ইনস্টল করার জন্য নীচে দেওয়া পদক্ষেপগুলি অনুসরণ করতে হবে -

পদক্ষেপ 1 - নিম্নোক্ত URL টি দেখুন এবং আপনার সিস্টেমে এটি ইনস্টল করার জন্য কম্পোজার ডাউনলোড করুন।

[**কম্পোজার ডাউনলোড করুন**](https://getcomposer.org/download/)

অন্য সপটওয়ার গুলোর মতই ইনস্টল করুন। এরপর চেক করুন ইনস্টল হয়েছে কি না। কিভাবে করবেন?

> টারমিনাল বা সিএমডি ওপেন করে টাইপ করুন  composer

যদি নিচের মত আসে তাইলে ইনস্টল ডান।

![](https://dnc.techtunes.io/tDrive/tuner/2018/08/techtunes_524268b76f00c8148f6f2a9c4145a2e7.png)

এখন Laravel Project তৈরি করব। এ জন্য আবার টারমিনাল বা সিএমডি ওপেন করে টাইপ নিচের কোডটা লিখে ইন্টার চাপুন,

> ```
> composer create-project laravel/laravel –-prefer-dist
> ```

composer  ইনস্টল  Laravel Project তৈরির সময় অবশ্যই নেট থাকতে হবে। Laravel Project ডাউনলো হতে কিছু সময় লাগবে।

Project তৈরি হয়ে গেলে  টারমিনাল বা সিএমডি দিয়ে Project root এ ডুকুন, তারপর নিচের কোডটা লিখে ইন্টার দিলে আপনার Project লাইভ দেখতে পাবেন।

এ পর্যন্ত কারো বুঝতে কোন সমস্য হলে নিচের ভিডিওটি দেখতে পাবেন।
