হ্যালো টেকটিউনস বন্ধুরা, কেমন আছেন সবাই? আশাকরি সবাই ভালো আছেন এবং প্রযুক্তির নতুন নতুন ব্যবহার নিয়ে এক্সাইটেড আছেন। আজকের টিউনে আমরা এমন একটি অনলাইন টুল নিয়ে আলোচনা করতে যাচ্ছি, যা শুধু আপনার লিংক শেয়ার করার অভিজ্ঞতাকেই সহজ করবে না, বরং আপনার অনলাইন Security এবং Control-কেও নিশ্চিত করবে। আমরা প্রায় সবাই-ই এখন Social Media, Email অথবা অন্য কোনো মাধ্যমে বিভিন্ন লিংক শেয়ার করি। এই লিংকগুলো হতে পারে কোনো দরকারি ওয়েবসাইটের ঠিকানা, মজার কোনো ছবি, শিক্ষণীয় কোনো ভিডিও অথবা ব্যক্তিগত কোনো ফাইল। কিন্তু লম্বা URL যেমন দেখতে বিরক্তিকর, তেমনি শেয়ার করার সময়ও একটা অস্বস্তি কাজ করে।

যদি এমন হতো, লিংক ছোট করার পাশাপাশি ছবি ও ভিডিও শেয়ার করার জন্য আলাদা আলাদা Platform-এর ঝামেলা পোহাতে হতো না, এবং সব কিছুই একটিমাত্র জায়গা থেকে নিয়ন্ত্রণ করা যেত, তাহলে কেমন হতো বলুন তো? আজকের টিউনে আমরা এমনই একটি চমৎকার এবং কার্যকরী অনলাইন টুল নিয়ে বিস্তারিত আলোচনা করব – MyPPT! শুধু তাই নয়, MyPPT ব্যবহারের কিছু Secret Tips এবং Tricks-ও আপনাদের সাথে শেয়ার করব, যা আপনাদের অভিজ্ঞতা আরও সুন্দর করে তুলবে।

## MyPPT আসলে কী? কেন এটি অন্যান্য লিংক শর্টনার থেকে আলাদা?

![MyPPT ](https://dnc.techtunes.io/tDrive/tuner/2026/01/techtunes_082108b5b16adf5a5ef4a456ff1e2bad.png)

MyPPT শুধু একটি সাধারণ URL Shortener নয়; এটি একটি Complete File Sharing এবং Management Solution। বর্তমানে বাজারে Bitly, TinyURL-এর মতো অনেক জনপ্রিয় লিংক শর্টনার সার্ভিস রয়েছে। তাহলে কেন আপনি MyPPT ব্যবহার করবেন? MyPPT-কে কেন আমরা অন্যান্য সার্ভিস থেকে আলাদা বলছি? চলুন, কারণগুলো জেনে নেওয়া যাক:

- **স্মার্ট URL Shortener:** MyPPT-এর প্রধান এবং সবচেয়ে গুরুত্বপূর্ণ কাজ হলো যেকোনো লম্বা URL-কে ছোট এবং সহজে ব্যবহারযোগ্য করে তোলা। যখন আপনি কোনো জটিল এবং দীর্ঘ URL শেয়ার করেন, তখন সেটি দেখতে Professional মনে হয় না, এবং মানুষের মনে Link টি নিয়ে সন্দেহও জাগতে পারে। MyPPT ব্যবহারের মাধ্যমে আপনি একটি Clean এবং Short Link তৈরি করতে পারবেন, যা দেখতে সুন্দর এবং শেয়ার করতেও সহজ।
- **Integrated File Sharing Platform:** MyPPT আপনাকে Photo এবং Video Upload এবং Share করার সুবিধা দেয়। এর মানে হলো, আপনাকে আলাদা করে Image Hosting অথবা Video Hosting ওয়েবসাইট ব্যবহার করতে হবে না। আপনি সরাসরি MyPPT-এর মাধ্যমে File Upload করতে পারবেন এবং সেগুলোর জন্য Short Link তৈরি করতে পারবেন।
- **শক্তিশালী নিরাপত্তা ব্যবস্থা (Advanced Security):** অনলাইনে File শেয়ার করার সময় Security-এর বিষয়টি সবচেয়ে বেশি গুরুত্বপূর্ণ। MyPPT আপনার Security নিশ্চিত করতে Password Protection-এর মতো গুরুত্বপূর্ণ ফিচার দেয়। আপনি আপনার File-গুলোর জন্য Password সেট করতে পারবেন, যার ফলে শুধুমাত্র যাদের কাছে Password থাকবে, তারাই File গুলো Access করতে পারবে।
- **সম্পূর্ণ নিয়ন্ত্রণ (Complete Control):** MyPPT আপনাকে আপনার শেয়ার করা Link-এর উপর সম্পূর্ণ Control রাখতে সাহায্য করে। আপনি Expiration Date সেট করতে পারবেন, যার মাধ্যমে একটি নির্দিষ্ট সময় পর আপনার Link টি Automatic-ভাবে কাজ করা বন্ধ করে দেবে। এছাড়াও, আপনি Reading Count Limit সেট করতে পারবেন, যা নির্ধারণ করবে কতজন আপনার File টি দেখতে পারবে। এই ফিচারগুলো আপনাকে আপনার File Sharing-এর উপর আরও বেশি Control দেবে।
- **ডাউনলোড সুরক্ষা (Download Protection):** আপনি যদি চান আপনার আপলোড করা Photo এবং Video কেউ Download করতে না পারুক, তাহলে MyPPT-এর Right-Click Lock ফিচারটি ব্যবহার করতে পারেন। এই ফিচারটি চালু করলে কেউ Right Click করে আপনার File Download করতে পারবে না, যা আপনার Content-এর Intellectual Property রক্ষা করবে।

সংক্ষেপে বলতে গেলে, MyPPT হলো একটি All-In-One Platform, যা URL Shortening-এর পাশাপাশি File Sharing এবং Security-এর মতো গুরুত্বপূর্ণ ফিচারগুলো একসাথে প্রদান করে। PPT.CC, Imgus এবং Risu.io-এর মতো Similar কিছু সার্ভিস থাকলেও, MyPPT এর Security এবং File Management সুবিধাগুলো এটিকে বিশেষভাবে আলাদা করে তুলেছে।

## MyPPT ব্যবহারের A to Z : Step by Step গাইড

![MyPPT ব্যবহারের A to Z](https://dnc.techtunes.io/tDrive/tuner/2026/01/techtunes_2d15dad4e4930c1ba866fbc673dd3925.jpg)

MyPPT ব্যবহার করা খুবই সহজ, কিন্তু নতুন ব্যবহারকারীদের সুবিধার জন্য নিচে একটি বিস্তারিত Step-by-Step গাইড দেওয়া হলো:

**ধাপ ১: ওয়েবসাইটে যান (Visit the Website)**

প্রথমে আপনার পছন্দের Web Browser-এ MyPPT-এর Official Website এ যান। ওয়েবসাইটটি ডিফল্টভাবে Chinese ভাষায় রয়েছে, তাই এটিকে Translate করে English করতে, Chrome ব্রাউজার এর ক্ষেত্রে উপরের Translate অপশনে ক্লিক করে "English" সিলেক্ট করুন।

![MyPPT-এর Official Website](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_bdaeb30eff1d0c3b788b50919f595b55.png)

**ধাপ ২: আপনার কাজের অপশন নির্বাচন করুন (Select Your Task)**

MyPPT-এর Homepage-এ আপনি প্রধানত তিনটি অপশন দেখতে পাবেন:

**URL Shortener:** এটি ব্যবহার করে আপনি যেকোনো লম্বা URL-কে ছোট করতে পারবেন।

![URL Shortener](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_6a76f98517f728ab749cba457675a420.png)

**Small Photos:** এই অপশনটি আপনাকে Photo Upload এবং Share করার সুবিধা দেবে।

![Image Upload option](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_ab875ae7765ab6a6a6a20b8e22819be2.png)

**Short Video:** এই অপশনটি ব্যবহার করে আপনি Video Upload এবং Share করতে পারবেন।

![Short Video](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_123a5c988c128e6803c4e5c05d0ab1a9.png)

আপনার যা প্রয়োজন, সেই অনুযায়ী অপশনটি সিলেক্ট করুন। আপনি উপরের Menu থেকেও File Sharing-এর অপশনগুলো খুঁজে নিতে পারেন।

**ধাপ ৩: File Upload করুন অথবা URL দিন (Upload File or Enter URL)**

আপনি যদি Photo অথবা Video Upload করতে চান, তাহলে "Small photos" অথবা "Short video" অপশন সিলেক্ট করার পর আপনাকে File Upload করার Page-এ পাঠানো হবে। সেখানে "Choose File" Button-এ Click করে আপনার কম্পিউটার থেকে File টি সিলেক্ট করুন।

![File Upload করুন](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_5e494b4775c04fb3cbd0e6a92fbd4d54.png)

অন্যদিকে, আপনি যদি শুধুমাত্র URL ছোট করতে চান, তাহলে Homepage-এর Text Box-এ আপনার লম্বা URL টি Paste করুন।

![URL টি Paste](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_b8e9cced44d6f87a2f1bf2914b586db3.png)

**ধাপ ৪: File Edit করুন (Optional - ছবি সম্পাদনা)**

MyPPT-তে "Edit Image" নামের একটি দারুণ Feature রয়েছে, যা আপনাকে Photo Upload করার আগেই Edit করার সুযোগ দেয়।

![Edit Image](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_96a5eec6bbad7735c0bc11e192d1e50c.png)

আপনি এই অপশনটি ব্যবহার করে আপনার Photo-তে Mosaic Effect যোগ করতে পারবেন, Text লিখতে পারবেন অথবা ছোট Icon যোগ করতে পারবেন। এছাড়াও, Brightness, Contrast এবং Saturation Adjust করার মতো Basic Editing Tools-ও এখানে রয়েছে। যারা দ্রুত কোনো ছবি Edit করে Share করতে চান, তাদের জন্য এই Feature টি খুবই কাজের।

![Basic Editing Tools](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_8a3ccffeb395d6eef191aa2b3f6028c4.png)

**ধাপ ৫: Security Settings কনফিগার করুন (Configure Security Settings)**  
 File Upload করার আগে Security Settings কনফিগার করা খুবই দরকারি। MyPPT আপনাকে নিম্নলিখিত Security অপশনগুলো প্রদান করে:

**Password Protection (পাসওয়ার্ড সুরক্ষা):** আপনি যদি চান শুধুমাত্র নির্দিষ্ট কিছু মানুষ আপনার File দেখুক, তাহলে Password Protection অপশনটি ব্যবহার করুন। এখানে আপনি নিজের পছন্দমতো একটি Strong Password সেট করতে পারবেন। Password সেট করার সময় চেষ্টা করুন যেন Password-টি Strong হয়, যাতে কেউ সহজে Guess করতে না পারে। আপনি ছোট ও বড় হাতের অক্ষর, সংখ্যা এবং Symbol মিশিয়ে Password তৈরি করতে পারেন।

![Password Protection](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_44b0f85681e72d002cc222df5187dcea.png)

ডিফল্টভাবে আজকের তারিখ সিলেক্ট করলে সেটি চার ডিজিটের সংখ্যায় দেখাবে, তবে আপনি অবশ্যই নিজের মতো করে একটি Strong Password সেট করবেন।

![Password সেট](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_20adbeb1b0ddf54c4048634523955a62.png)

**Expiration Date (মেয়াদ উত্তীর্ণের তারিখ):** আপনি যদি চান একটি নির্দিষ্ট সময় পর আপনার Link টি Automatic-ভাবে কাজ করা বন্ধ করে দিক, তাহলে Expiration Date অপশনটি ব্যবহার করুন। আপনি ১ মিনিট থেকে শুরু করে ৩০ দিন পর্যন্ত সময়সীমা নির্ধারণ করতে পারবেন। Expiration Date সেট না করলে Link টি ডিফল্টভাবে ১ দিন পর্যন্ত Active থাকবে।

![Expiration Date](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_0f3b26d1a7abf506f68b62989835a872.png)

এই ফিচারটি তাদের জন্য খুবই উপযোগী, যারা Limited Time-এর জন্য কোনো Confidential File Share করতে চান। Expiration Date সেট করার ফলে আপনার File নির্দিষ্ট সময়ের পর আর Accessible থাকবে না, যা Security আরও বাড়াবে।

**Reading Count Limit (পড়ার সংখ্যা সীমা):** আপনি যদি চান আপনার File টি শুধুমাত্র একটি নির্দিষ্ট সংখ্যক মানুষ দেখুক, তাহলে Reading Count Limit অপশনটি ব্যবহার করুন। এর মাধ্যমে আপনি নির্ধারণ করতে পারবেন কতবার Click করার পরে Link টি Automatic-ভাবে কাজ করা বন্ধ করে দেবে।

উদাহরণস্বরূপ, আপনি যদি চান আপনার File টি শুধুমাত্র ১০ জন মানুষ দেখুক, তাহলে Reading Count Limit 10 সেট করুন। যখন ১০ জন মানুষ Link-টিতে Click করবে, তখন Link টি Automatic-ভাবে Deactivate হয়ে যাবে।

![Reading Count Limit](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_06b4d5ef824bdcd978cea17b96ab5c7e.png)

এই Security Settings গুলো ব্যবহার করে আপনি আপনার File Sharing-এর Security এবং Control আরও বাড়াতে পারবেন।

**ধাপ ৬: Link তৈরি করুন এবং শেয়ার করুন (Generate and Share the Link)**

সব Settings কনফিগার করার পর "Upload" Button-এ Click করুন।

**ধাপ ৭: পাসওয়ার্ড দিয়ে File দেখুন (View File with Password)**

যদি আপনি Password Protection অপশনটি চালু করে থাকেন, তাহলে অন্য কেউ যখন আপনার Short URL-এ প্রবেশ করবে, তখন তাকে Password দিতে হবে। Password দেওয়ার পরেই সে File টি দেখতে পারবে। প্রতিটি Page-এর নিচে Short URL টি কতবার Browse করা হয়েছে, তা দেখানো হবে।
