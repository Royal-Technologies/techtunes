প্রিয় টেকটিউনস টিউডার, আশাকরি সবাই ভালো আছেন। আজ আমরা এমন একটা বিষয় নিয়ে কথা বলতে যাচ্ছি, যেটা অনেকের জীবনেই একটা গুরুত্বপূর্ণ প্রভাব ফেলবে। যারা Pocket ব্যবহার করেন, তারা জানেন যে জনপ্রিয় অনলাইন বুকমার্কিং সার্ভিস Pocket বন্ধ হয়ে গিয়েছে। Pocket এর মালিকানা সংস্থা Mozilla Corporation এই কঠিন সিদ্ধান্ত নিয়েছে। এই খবরটা হয়তো আপনাদের মন খারাপ করে দিয়েছে, তাই না? চিন্তা নেই! আমি আছি আপনার সাথে, সব কিছু সহজ করে বুঝিয়ে দিতে।

## Pocket কেন বন্ধ হয়েছে? আসুন, কারণগুলো একটু বিশ্লেষণ করি

![Pocket কি সত্যিই বিদায় বলছে? আপনার বুকমার্কগুলো বাঁচানোর সহজ উপায়!](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_83336fea2f9754716857280553834894.jpg)

আসলে Pocket বন্ধ হওয়ার পেছনে বেশ কিছু যৌক্তিক কারণ রয়েছে। সময়ের সাথে সাথে আমাদের Internet ব্যবহারের অভ্যাসে অনেক পরিবর্তন এসেছে। এখনকার দিনে মানুষজন Social Media এবং অন্যান্য Platform-গুলোতে সরাসরি Content Share করতে এবং দেখতে বেশি আগ্রহী। Pocket টিম মনে করছে, তাদের বর্তমান Resource গুলোকে আরও আধুনিক এবং দরকারি Project-গুলোতে বিনিয়োগ করা উচিত।

অন্যদিকে, Mozilla একটি বিশাল সংস্থা, যাদের নিজেদের Browser (Firefox) রয়েছে। তাদের জন্য Pocket-এর মতো আলাদা একটি Service-এর দিকে সবসময় মনোযোগ দেওয়া কঠিন হয়ে পড়ে। Mozilla এটাও জানিয়েছে যে তারা সম্ভবত একমাত্র Mainstream Browser যাদের কোনো বিলিওনিয়ারের আর্থিক সহায়তা নেই। তাই তাদের Resource গুলো সঠিকভাবে ব্যবহার করাটা খুব জরুরি।

## Pocket বন্ধ হওয়াতে আপনার কী ক্ষতি?

![Pocket কি সত্যিই বিদায় বলছে? আপনার বুকমার্কগুলো বাঁচানোর সহজ উপায়!](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_a5635f87cccdb3de6149823ed55bd8e5.jpg)

যদি আপনি আমার মতো Pocket-এর নিয়মিত User থেকে থাকেন, তাহলে নিশ্চয়ই অনেক গুরুত্বপূর্ণ Article, Blog Post, News এবং Tutorial Save করে রেখেছিলেন। বছরের পর বছর ধরে কত দরকারি Link যে সেখানে জমা করেছেন, তার কোনো ইয়ত্তা নেই! Pocket বন্ধ হয়ে যাওয়াতে সেই Data-গুলোর কী হবে, সেটা নিয়ে চিন্তা হওয়াটা খুবই স্বাভাবিক। তবে ভয় পাবেন না!

Mozilla যেহেতু আমাদের Data Export করার সুযোগ দিচ্ছে, তাই আপনার Data হারানোর কোনো ভয় নেই। আপনি খুব সহজেই আপনার সমস্ত Data Pocket থেকে Download করে অন্য একটি একই রকম Service-এ Migrate করতে পারবেন।

## Data Export করার শেষ তারিখ কবে?

![Data Export করার শেষ তারিখ কবে?](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_a19629f444bec6891ed6b62cf8518098.png)

আপনাকে অবশ্যই মনে রাখতে হবে, Data Export করার জন্য একটি নির্দিষ্ট সময়সীমা রয়েছে। আপনাকে **২০২৫ সালের অক্টোবর মাসের ৮ তারিখের** মধ্যে আপনার সমস্ত Data Export করে নিতে হবে। এই তারিখ পার হয়ে গেলে আপনার Data উদ্ধার করা কঠিন হয়ে যেতে পারে।

তবে একটা বিষয় অবশ্যই খেয়াল রাখবেন, **২০২৫ সালের জুলাই মাসের ৮ তারিখের** পর Pocket শুধুমাত্র "Export Mode"-এ থাকবে। মানে, আপনি শুধু Data Export করতে পারবেন, নতুন কোনো Link Save করতে পারবেন না।

## Pocket Premium User-দের জন্য দারুণ খবর!

![Pocket Premium User-দের জন্য দারুণ খবর!](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_0442d4fababc4b58624f77018fb15ec0.png)

যদি আপনার Pocket Premium Account থাকে, তাহলে Mozilla Corporation আপনার Remaining Subscription Period-এর জন্য Refund দেবে। **২০২৫ সালের জুলাই মাসের ৮ তারিখের** পর আপনার Account-এ যত দিন Remaining থাকবে, সেই অনুযায়ী Refund পাবেন। Refund সরাসরি আপনার Payment Method-এ পাঠিয়ে দেওয়া হবে, তাই আপনাকে আলাদা করে কোনো Request করতে হবে না।

## Data Export কিভাবে করবেন? ধাপে ধাপে গাইডলাইন

![Data Export কিভাবে করবেন? ধাপে ধাপে গাইডলাইন](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_58f0efbf40ee0e15a83a2e656d2bfa35.png)

Pocket থেকে Data Export করা খুবই সহজ। আমি নিজে এই Process অনুসরণ করে Data Export করেছি, এবং আপনাদের সুবিধার জন্য নিচে একটি বিস্তারিত গাইডলাইন দেওয়া হলো:

1. প্রথমে Pocket-এর Official Export Tool Page-এ যান: <https://getpocket.com/export>। এই Page-টি Pocket Website-এর একটি Official Section, যেখানে Data Export করার জন্য Option দেওয়া হয়েছে।
2. Page-এর বাঁদিকে আপনার Account Name Check করুন। এটা নিশ্চিত করা জরুরি যে আপনি সঠিক Account থেকেই Data Export করছেন।
3. "Export HTML File" Button-এ Click করুন। HTML File-এর মধ্যে আপনার Saved, Archived, এবং Favorite Link গুলোর Information থাকবে। Pocket আপনার সমস্ত Data একটি HTML File-এ Convert করে Download করার জন্য তৈরি করবে।

## Email Inbox চেক করতে ভুলবেন না!

![Email Inbox চেক করতে ভুলবেন না!](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_3810b349af17db1c7d1cb6a257ffb109.png)

Data Export করার Request পাঠানোর পরে, আপনাকে একটু অপেক্ষা করতে হবে। Pocket সঙ্গে সঙ্গে Data Export করে না।

1. কিছুক্ষণের মধ্যেই Pocket থেকে আপনার Email Inbox-এ একটি Confirmation Mail আসবে। এই Mail-টি Confirm করবে যে আপনার Data Export করার Request তারা পেয়েছে।
2. সাধারণত ২৪ ঘণ্টার মধ্যে আপনি Data Download করার জন্য Link পাবেন। এই Link-টি একটি নির্দিষ্ট সময়ের জন্য Valid থাকবে (যেমন ৪৮ ঘণ্টা), তাই Link পাওয়ার সাথে সাথেই Data Download করে নিন।
3. যদি কোনো কারণে ৪৮ ঘণ্টার মধ্যে Link Expire হয়ে যায়, তাহলে চিন্তা করবেন না! আপনি Export Process আবার শুরু করতে পারবেন।

## Raindrop.io: Pocket-এর সেরা বিকল্প!

![Raindrop.io: Pocket-এর সেরা বিকল্প!](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_584d3cea40c6963edac2d5380484926a.png)

Data Export করার পরে, আপনার একটি Similar Service-এর প্রয়োজন হবে, যেখানে আপনি আপনার Data Migrate করতে পারবেন। বাজারে অনেক Option পাওয়া যায়, কিন্তু আমি ব্যক্তিগতভাবে Raindrop.io ব্যবহার করার পরামর্শ দেব। Raindrop.io শুধু দেখতেই সুন্দর নয়, এর অনেক কাজের Feature রয়েছে।

Raindrop.io-তে Data Migrate করার Process নিচে দেওয়া হলো:

১. প্রথমে Raindrop.io-তে একটি Account Registration করুন: Raindrop.io Website-এ গিয়ে একটি নতুন Account তৈরি করুন। Registration Process খুবই সহজ এবং দ্রুত।

![Registration Process](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_3dbf8053aacdc87e1f6fb519773d8e64.png)

২. Account Registration করার পর Settings Option-এ যান: Raindrop.io-এর Interface-এ Settings Option খুঁজে বের করুন। সাধারণত, এটি Profile Icon বা Menu-তে থাকে।

![Settings Option](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_c825adc31a46359a1b5b53cc58e98043.png)

৩. Settings Menu-তে "Import" Option খুঁজুন এবং Click করুন: "Import" Option-টি Data Migrate করার জন্য বিশেষভাবে তৈরি করা হয়েছে।

![Import Option](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_1243981223efb09229a5ec726f78fd9f.png)

৪. "Upload Document File" Option Select করুন: এই Option Select করার পর, আপনাকে আপনার Download করা Pocket Backup File (CSV File) Upload করতে বলা হবে।

![Upload Document File](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_89a2fa2c208217df73efb1d207e5bebf.png)

Raindrop.io-এর Free Version-এ আপনি Unlimited Bookmark, Collection এবং Tag ব্যবহার করতে পারবেন। এছাড়াও, Cross-Platform Support এবং Collaboration Feature-ও রয়েছে, যা Team Work-এর জন্য খুবই Useful।
