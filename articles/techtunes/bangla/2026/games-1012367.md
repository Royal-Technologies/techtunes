![Save State](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_b834de9ff128496f35ea3bbc6994e7a6.png)

আপনি যদি Cloud Storage ব্যবহার করতে চান, তাহলে আপনাকে Register করে Login করতে হবে। Google Account দিয়ে Login করার Option ও রয়েছে, যা Register করার প্রক্রিয়াটিকে আরও সহজ করে দেয়। আর যদি Cloud এ Save করতে না চান, তাহলে "Save Locally" Option ব্যবহার করে আপনার Computer এ Game Record Save করতে পারবেন। Cloud Storage এ Save করা Record গুলো দেখার জন্য Game Page এ Login করুন। প্রতিটি Save এর Date এবং Time দেওয়া থাকবে, যা আপনি সহজেই আপনার Save File খুঁজে বের করতে পারেন এবং ঠিক যেখান থেকে শেষ করেছিলেন, সেখান থেকেই আবার খেলা শুরু করতে পারেন।

![Save Locally](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_3a3fd2e4a56e2cb9902735d0f5b144a8.png)
