হ্যালো বন্ধুরা! কেমন আছেন সবাই? আশাকরি ভালো। আজ আমি আপনাদের সামনে হাজির হয়েছি একটি অসাধারণ Cloud Storage এবং File Sharing Platform নিয়ে। যারা Online এ নিজেদের Creativity Showcase করতে চান, Team এর সাথে Collaborate করে কাজ করতে চান, তাদের জন্য Drop হতে পারে এক নতুন দিগন্ত। তাহলে চলুন, আর দেরি না করে জেনে নেই Drop (drop.Space) সম্পর্কে a টু Z!

## Drop কি? কেন এটা আপনার Workflow এর অংশ হওয়া উচিত?

![DROP](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_7b6462528f2caca60dacc7b83bab1aaa.png)

Drop হলো এই সময়ের নতুন এবং আধুনিক একটি Free File Sharing এবং Hosting Platform। এই Platform টির মূল উদ্দেশ্য হলো Art Creatorদের তাদের Work প্রদর্শন এবং Share করার সুযোগ তৈরি করে দেওয়া। যারা ছবি আঁকেন, Video বানান, Design করেন, অথবা অন্য কোনো Digital Content তৈরি করেন, তাদের সবার জন্য Drop একটা Must-Have Tool।

এখানে শুধু File রাখা আর Share করাই নয়, Teamwork করার জন্য রয়েছে অসাধারণ সব Feature। আপনার Team এর Members দের সাথে Space Share করতে পারবেন, File Upload করতে পারবেন, সবার Feedback জানার জন্য Review করতে পারবেন এবং Comment ও করতে পারবেন।

Drop কে শুধু একটা Storage Platform ভাবলে ভুল করবেন, এটা আপনার File Transfer করার Tool হিসেবেও সমানভাবে কার্যকরী। বড় Size এর File Email এ Share করা কতোটা ঝামেলার, সেটা তো আপনারা জানেনই। Drop এর মাধ্যমে সেই ঝামেলা থেকে মুক্তি পাওয়া যায় সহজেই!

Drop এর কিছু Key Feature:

- **2 GB Free Storage:** শুরুটা হোক Free তেই! প্রত্যেক User 2 GB পর্যন্ত Storage একদম Free তে পেয়ে যাবেন। যারা ছোট Project নিয়ে কাজ করেন, অথবা Trial হিসেবে দেখতে চান, তাদের জন্য এটা যথেষ্ট।
- **Large File Transfer Support:** free Account ব্যবহারকারীরা 5 TB পর্যন্ত File Transfer করতে পারবেন! তবে হ্যাঁ, Single File এর Maximum Size 5 GB। বুঝতেই পারছেন, Video বা Design এর মত Heavy File Share করার জন্য এটা কতোটা উপযোগী।
- **No Speed Limit and Ads:** file Transfer করার সময় Speed নিয়ে আর চিন্তা করতে হবে না, কারণ এখানে কোনো Speed Limit নেই। এছাড়া বিরক্তিকর AD এর যন্ত্রণা থেকেও মুক্তি। Download এবং Upload হবে ঝড়ের গতিতে!
- **Customization এর সুযোগ:** drop এর অনেক Customization Feature ব্যবহার করতে Paid Upgrade করতে হয়। তবে Free Plan এও আপনি অনেক Important সুবিধা পাবেন। Download Page এর Template নিজের মত করে সাজানো, File এর Expiry Time সেট করা, Password দিয়ে Protect করার মত অপশনগুলো Free তেই পাওয়া যায়।
- **Easy and Seamless Collaboration:** teamwork করার জন্য রয়েছে File Review এবং Comment করার সুবিধা। ধরুন, আপনি একটা Design তৈরি করেছেন, Team এর বাকি Membersরা Comment করে Feedback দিতে পারবে। এর ফলে কাজটা আরও দ্রুত এবং কার্যকরী হবে। Creative Teamগুলোর জন্য এটা আশীর্বাদের মত।
- **Integrated Payment System:** যারা Online এ নিজেদের Work বিক্রি করতে চান, তাদের জন্য Payment System এর Integration করা আছে। Artist, Illustrator, Photographer অথবা যারা Digital Work বিক্রি করেন, তাদের জন্য এটা খুবই কাজের একটা Feature। নিজের Work এর Price Set করে সরাসরি Sell করতে পারবেন!
- **Best Alternative of We Transfer:** যারা We Transfer এর Alternative খুঁজছেন, তাদের জন্য Drop হতে পারে সেরা পছন্দ। We Transfer এর অনেক Limitation এখানে নেই।

## File Upload এবং Share করার নিয়ম

![FILE upload এবং SHARE করার নিয়ম](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_dc217b22f972cfeacc2d875a7fd34819.jpg)

১. এজন্য এখানে থাকা "Add Files" অপশনে ক্লিক করুন।

![Add files](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_a0b4ab6ef296350ab9fa8eff2e445fc9.png)

File সফলভাবে Upload হওয়ার পরে "Get Sharing Link" অপশনে Click করে Link Copy করতে পারবেন। এই Link আপনি Email, Social Media Platform অথবা অন্য যেকোনো মাধ্যমে Share করতে পারবেন।

![SHARING LINK](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_e4d744ff7da859e9ebb542d08a314da4.png)

এছাড়াও, File Select করার পর উপরের ডানদিকের Share Option এ Click করেও File Link পেতে পারেন। যদি File Share করার কোনো Immediate প্রয়োজন না হয়, তাহলে Drop কে শুধুমাত্র Cloud Storage হিসেবে ব্যবহার করতে পারেন।

![FILE LINK](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_9395f299c72bed04ddce7b1c95a089d8.png)

এটা অনেকটা আপনার ব্যক্তিগত Hard Drive এর মতই, যেখানে আপনি নিজের File গুলো নিরাপদে Store করে রাখতে পারবেন। এর জন্য আলাদা কোনো Software Download করারও দরকার নেই।

## Advanced Setting গুলো কিভাবে ব্যবহার করবেন

![ADVANCED SETTING গুলো কিভাবে ব্যবহার করবেন](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_c99f41e3e371a210e8d9b75b997b4e17.jpg)

File Share করার সময় Access Method (public, Paid অথবা Password Protected) Set করতে পারবেন। Public করলে সবাই File দেখতে পারবে, Paid করলে Access এর জন্য Payment করতে হবে, আর Password Protected করলে শুধুমাত্র যাদের Password জানা থাকবে, তারাই File Access করতে পারবে। Sensitive Information এর জন্য Password Protection খুবই জরুরি।

![PASSWORD PROTECTION](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_b55e7b80aa0166e4c41af4a003564782.png)

Free Version এ File এর Expiry Time ৩ দিন Set করা যায়। অর্থাৎ, ৩ দিন পর Link টি Automatically Expire হয়ে যাবে। Premium Users দের জন্য এই Limitation নেই। উপরের ডানদিকে Share Link পাওয়ার Optionটিতে Click করলেই Link পেয়ে যাবেন।

![FREE VERSION এ FILE এর EXPIRY TIME](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_377f66a696bbd81686d5c78f4f183d38.png)

Paid Upgrade করলে Comment করার অনুমতি, Invitation Event এ Add হওয়া, Download Page এর Template Customize করার মত Advanced Feature গুলো ব্যবহার করতে পারবেন। Premium Feature গুলো আপনার Workflow কে আরও Productive করে তুলবে এবং Team Collaboration কে করবে আরও Effective।
