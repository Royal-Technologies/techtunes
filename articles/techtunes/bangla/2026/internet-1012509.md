## tmpfiles আসলে কী? কেন এটা এত জনপ্রিয়?

![tmpfiles](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_39226fb24116a8d56cf197a63e6c3c35.png)

tmpfiles হলো একটি অস্থায়ী File Storage Service। এটা Anonymous File Sharing এর সুযোগ দেয়। মানে, আপনি নিজের পরিচয় গোপন রেখে File Upload এবং Share করতে পারবেন। এর সবচেয়ে বড় আকর্ষণ হলো এর Simplicity এবং Speed। কোনো Registration Process ছাড়াই, কয়েক Click এই File Upload করে Download Link Generate করতে পারবেন।

tmpfiles এর Homepage এ /tmp/files লেখা দেখে অনেকের Terminal Command মনে হতে পারে। সত্যি বলতে, এর Interface Design ও Terminal এর মতোই Clean এবং Simple। যাদের জটিল Website বা Software ভালো লাগে না, তাদের জন্য এটা দারুণ একটা Option।

কিন্তু মনে রাখবেন, Tmpfiles File গুলো Upload করার পর মাত্র এক ঘণ্টার জন্য Save রাখে। এরপর Automatically Delete হয়ে যায়। তাই, এমন File Share করার জন্য এটা ভালো, যা Share করার পরপরই Delete হয়ে গেলেও আপনার কোনো সমস্যা নেই।
