## XML Code: কিভাবে ব্যবহার করবেন? 👨‍💻

![XML Code: কিভাবে ব্যবহার করবেন?](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_50d3809eced82f4dfa73a280e20a2566.jpg)

যেকোনো Icon ব্যবহার করতে, সেটির ওপর Click করলেই Extensible Markup Language (XML) Code Clipboard-এ Copy হয়ে যাবে। এবার আপনি আপনার Design Project-এর Code Editor-এ Code টা Paste করে দিন! যদি Website-এ ব্যবহার করেন, তাহলে HTML-এ Paste করতে পারেন।

যদি Graphic Design Software (যেমন: Adobe Illustrator, Adobe Photoshop, Affinity Designer) ব্যবহার করেন, তাহলে সেখানে Import করে নিতে পারেন। Illustrator-এ Direct Import করা যায়, আর Photoshop-এ Smart Object হিসেবে Import করতে হয়।

যদি আপনার PNG বা JPG Format দরকার হয়, তাহলে SVG Converter ব্যবহার করে Format Change করে নিতে পারবেন। অনলাইনে অনেক Free SVG Converter Available আছে, যেমন:

- **CloudConvert:** <https://cloudconvert.com/>
- **OnlineConvertFree:** <https://onlineconvertfree.com/>
- **Convertio:** <https://convertio.co/>

এই Website গুলো ব্যবহার করে আপনি সহজেই SVG File কে PNG বা JPG তে Convert করতে পারবেন।

## কেন এই Icon গুলো ব্যবহার করবেন? Top 3 Reasons! 💯

![কেন এই Icon গুলো ব্যবহার করবেন? Top 3 Reasons](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_1d76bbfd4ce5a132c368cd06d2cf60b9.jpg)

1. **Hand-Drawn Style:** প্রায় 120টির বেশি ভিন্ন Hand-Drawn Style-এর SVG Icon রয়েছে, যা আপনার Design কে দেবে Unique একটা Touch। সাধারণ Icon-এর ভিড়ে আপনার Design কে আলাদা করে চেনাতে এটা খুবই কাজে দেবে।
2. **Vector Format:** Icon গুলো XML (Extensible Markup Language) Format এ আছে, তাই Quality Loss হওয়ার কোনো ভয় নেই। Resizing এর ঝামেলা থেকে মুক্তি! আপনি যেকোনো Size-এ ব্যবহার করতে পারবেন।
3. **Completely Free:** সবচেয়ে গুরুত্বপূর্ণ বিষয় হলো, এই Icon গুলো Personal এবং Commercial Use এর জন্য একদম Free! কোনো Hidden Cost নেই, কোনো Subscription নেই। আপনি কোনো চিন্তা ছাড়াই ব্যবহার করতে পারবেন।
