আসসালামু আলাইকুম, টেকটিউনস ওয়েব ডিজাইন এবং ডেভেলপমেন্টের দুনিয়ার বন্ধুরা! কেমন আছেন সবাই? আশাকরি, ডিজাইন এবং কোডিং এর কাজগুলো ভালোই চলছে।

আজ আমি আপনাদের সাথে এমন একটা Chrome Extension নিয়ে কথা বলতে এসেছি, যেটা আমার নিজেরও খুব পছন্দের। বিশেষ করে যারা Responsive Web Design নিয়ে কাজ করেন, তাদের জন্য এই Extension টি একটা আশীর্বাদ বলতে পারেন! নামটা শুনেই হয়তো কিছুটা আন্দাজ করতে পারছেন - **Window Resizer**!

আমরা যারা Website তৈরি করি, তাদের সবচেয়ে বড় চ্যালেঞ্জগুলোর মধ্যে একটা হলো বিভিন্ন Device এ (যেমন স্মার্টফোন, ট্যাবলেট, ল্যাপটপ, ডেস্কটপ, এমনকি স্মার্ট টিভি!) ওয়েবসাইটের ডিজাইন কেমন দেখাচ্ছে, সেটা নিশ্চিত করা। ক্লায়েন্ট হয়তো বললেন, "আমার Website টা যেন Mobile এও দেখতে সুন্দর লাগে", কিন্তু শুধু শুনে তো আর কাজ হবে না, তাই না? বাস্তবে কেমন দেখাচ্ছে, সেটা নিজের চোখে দেখতে হবে। আর এই দেখার কাজটাকেই সহজ করে দেয় Window Resizer।

আগেকার দিনে এই কাজটা করতে হতো ব্রাউজারের Window সাইজ ম্যানুয়ালি টেনেটুনে রিসাইজ করে। কিন্তু সেই পদ্ধতিটা ছিল খুবই ঝামেলার और সবসময় নিখুঁতভাবে কাজ করতো না। তাই আমি একটা সহজ সমাধানের খোঁজ করছিলাম। তখনই আমার নজরে আসে এই অসাধারণ Chrome Extension টি - Window Resizer!

## Window Resizer আসলে কী? 🤔

![Window Resizer আসলে কী?](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_9926de9e7fb1e1d9d1d879c2e2259499.png)

Window Resizer হলো একটি ফ্রি Chrome Extension, যেটা মূলত আপনার ব্রাউজারের Window এর Size খুব সহজে পরিবর্তন করতে সাহায্য করে। এর সবচেয়ে গুরুত্বপূর্ণ Feature হলো, এটা বিভিন্ন Device এর Screen Size সিমুলেট করতে পারে। তার মানে, আপনি আপনার ডেস্কটপ কম্পিউটারেই বসে Website টি বিভিন্ন ডিভাইসে কেমন দেখাচ্ছে, সেটা সরাসরি দেখতে পারবেন!

ধরুন, আপনি একটা ই-কমার্স Website ডিজাইন করছেন। Website টির ডেস্কটপ ভার্সন দেখতে খুবই সুন্দর, কিন্তু Mobile এ গেলে সবকিছু কেমন যেন ভেঙে যাচ্ছে! Window Resizer ব্যবহার করে আপনি সহজেই Mobile View টা পরীক্ষা করতে পারবেন এবং ডিজাইনটা Mobile ফ্রেন্ডলি করার জন্য প্রয়োজনীয় পরিবর্তনগুলো করতে পারবেন।

## কেন Window Resizer ব্যবহার করবেন? 🤷‍♂️

![কেন Window Resizer ব্যবহার করবেন?](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_3dc7f10988aa65aacab2b4b72fa2c213.jpg)

এখন হয়তো ভাবছেন, "আচ্ছা, এই Extension টা ব্যবহারের দরকার কী? ব্রাউজারের ডিফল্ট টুলস দিয়েই তো কাজ চালানো যায়!" হ্যাঁ, কাজ চালানো যায় ঠিকই, কিন্তু Window Resizer আপনার কাজকে যেভাবে সহজ করে দেবে, সেটা অন্য কিছুতে পাওয়া কঠিন।

Responsive Web Design (RWD) এর যুগে, Website এর ডিজাইন বিভিন্ন Screen Size এর সাথে খাপ খাইয়ে নেওয়ার ক্ষমতা থাকাটা খুবই জরুরি। Window Resizer আপনাকে সেই ক্ষমতা দেয়। এটা নিশ্চিত করে যে আপনার Website যেকোনো Device এ সুন্দর এবং ব্যবহারযোগ্য দেখাচ্ছে।

আগে আমি Windows এ Screenshot নেওয়ার জন্য Sizer নামের একটা Tool ব্যবহার করতাম। Sizer Window এর Size ফিক্স করার জন্য খুবই ভালো ছিল, এবং এর File Size ও ছিল খুবই ছোট। কিন্তু Window Resizer এর সুবিধা হলো, এটা শুধু Window Size ফিক্স করেই থেমে থাকে না, বরং আরো অনেক বেশি Functionality দেয়। Mac ব্যবহারকারীদের জন্য Size up একটি ভালো Option হতে পারে, কিন্তু সেটি ফ্রি নয়।

## Window Resizer এর কিছু অসাধারণ Feature 🤩

![Window Resizer এর কিছু অসাধারণ FEATURE](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_9a4cff3f35d8877d440b59ea17875b2a.jpg)

- **কুইক রিসাইজিং:** কয়েক ক্লিকেই ব্রাউজারের Window Size পরিবর্তন করার জাদু। ✨
- **ডিভাইস লাইব্রেরি:** জনপ্রিয় Device গুলোর Screen Size আগে থেকেই দেওয়া আছে, শুধু সিলেক্ট করুন আর দেখুন। 📚
- **কাস্টম রেজোলিউশন:** নিজের ইচ্ছামতো Width এবং Height দিয়ে কাস্টম Screen Size তৈরি করার স্বাধীনতা। 🎨
- **স্ক্রিন রোটেশন:** Mobile এর মতো Screen লম্বালম্বি (portrait) বা আড়াআড়ি (landscape) করে দেখার ক্ষমতা। 🔄
- **কীবোর্ড শর্টকাট:** Keyboard Shortcut ব্যবহার করে দ্রুত Window Size পরিবর্তনের সুবিধা, যা কাজের গতি বাড়িয়ে দেয়। ⌨️
- **কাস্টমাইজড সেটিংস:** Window Position, Default Icon এবং আরও অনেক কিছু নিজের মতো করে সাজিয়ে নেওয়ার সুযোগ। ⚙️
- **ব্যাকআপ এবং রিস্টোর:** সেটিংস Export করে অন্য কম্পিউটারে ব্যবহার করার সুবিধা, অথবা সেটিংস Backup রাখার নিশ্চয়তা। 💾

আমি মনে করি, এই Extension টি ওয়েব ডিজাইনার এবং ডেভেলপারদের জন্য একটা "সিক্রেট ওয়েপন" এর মতো। এটা ব্যবহার করে আপনি আপনার Website গুলোকে আরও আকর্ষণীয়, User Friendly এবং Responsive করে তুলতে পারবেন।

## Window Resizer কিভাবে ব্যবহার করবেন? 🤔 আসুন, হাতেকলমে শিখে নিই!

![Window Resizer কিভাবে ব্যবহার করবেন?](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_cd93248210d79feadacd64eedc4e3a0d.jpg)

Window Resizer ব্যবহার করা এতটাই সহজ যে, বাচ্চারাও এটা ব্যবহার করতে পারবে! 👶 তবুও, আপনাদের সুবিধার জন্য নিচে বিস্তারিত STEP গুলো দেওয়া হলো:

১. প্রথমত, Chrome Web Store এ যান এবং Window Resizer EXTENSION টি খুঁজে বের করুন। 🔎

![Window Resizer extension](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_ba0f1f072ccfd980329b57bba96355a6.png)

২. "ADD TO CHROME" BUTTON এ ক্লিক করে EXTENSION টি আপনার ব্রাউজারে INSTALL করুন। ➕

![ADD TO CHROME](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_d634a685148d6a923e175c815ca1196c.png)

৩. INSTALL করার পর ব্রাউজারের TOOLBAR এ Window Resizer এর ICON দেখতে পাবেন। 🌐

![Window Resizer এর ICON](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_fc0add36fc80bcd4aa11b19b55c85f3d.png)

৪. ICON এ ক্লিক করে আপনি WINDOW এর SIZE পরিবর্তন করার বিভিন্ন OPTION দেখতে পাবেন। 🖱️

![WINDOW এর SIZE পরিবর্তন করার বিভিন্ন OPTION](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_804bca5e7c0c701d9174947b13be9f26.png)

৫. ডিফল্ট SCREEN SIZE গুলোর মধ্যে থেকে আপনার পছন্দেরটা সিলেক্ট করুন, অথবা নিজের মতো করে WIDTH এবং HEIGHT সেট করুন। 📏

![SCREEN SIZE select](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_a5bbeceb6c554f965265a77dfe679bdf.png)

৬. "ROTATE THE VIEWPORT" OPTION টি ব্যবহার করে MOBILE এর মতো SCREEN ORIENTATION পরিবর্তন করে দেখুন। 📱

![ROTATE THE VIEWPORT](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_f790f2be0abb1bc50a52b8bcfcecf575.png)

৭. আর Settings অপশন থেকে "HOTKEYS" OPTION এ গিয়ে KEYBOARD SHORTCUT গুলো নিজের সুবিধা অনুযায়ী কাস্টমাইজ করুন। ✍️

![HOTKEYS](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_fd0b8349a3a2931c712bc3e17336a2f9.png)
