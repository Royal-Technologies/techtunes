এই Function এর মাধ্যমে আপনি File Upload করে QR Code তৈরি করতে পারবেন, এবং অন্য User রা শুধু Code Scan করেই File Download করতে পারবে। কোনো ঝামেলা ছাড়াই!

ধরুন, আপনি একটি Workshop করছেন, এবং Material হিসেবে কিছু PDF File Share করতে চান। শুধু File টি Upload করে QR Code তৈরি করুন, এবং Workshop এর শুরুতে Code টি Scan করতে বলুন। সবাই খুব সহজেই Material পেয়ে যাবে।

তবে Free Version এ Scan number of times এর Limit থাকবে। সাধারণ Text, URL বা Google Maps এর জন্য এই Limit প্রযোজ্য নয়। যেহেতু এটি Free Space নয়, তাই File গুলো অন্য কোনো Cloud Storage এ Upload করে Code generate করাই ভালো। এতে আপনার File ও সুরক্ষিত থাকবে, আর QR Code ও সবসময় কাজ করবে।

### Step 1: Version Select করুন - আপনার জন্য কোনটা ভালো?

34QR এ Free Version এবং Advanced Version নামে দুইটি Version রয়েছে। আপনার প্রয়োজন অনুযায়ী Version বেছে নিতে পারেন।

১. Free Version: যদি আপনার কম QR Code এর দরকার হয়, এবং Basic Feature গুলোই আপনার জন্য যথেষ্ট হয়, তাহলে Free Version আপনার জন্য একদম পারফেক্ট। Free Version এ আপনি সর্বোচ্চ ১০টি QR Code তৈরি করতে পারবেন, তবে কিছু Code এর ক্ষেত্রে Scan number of times এর Limit থাকবে।

![Advanced Version](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_962f770a80c538cdec87941d1ff2792a.png)

### Step 2: Content Category Select করুন - কী ধরনের QR Code বানাতে চান সেটা Select করুন

Home page থেকে প্রথমে QR Code এর Content category Select করুন। আপনি কি Text এর জন্য QR Code বানাতে চান, নাকি কোনো Website Link এর জন্য? নাকি অন্য কিছু? এখানে বিভিন্ন Option রয়েছে:

- Text: সাধারণ Text এর জন্য এই Option টি Select করুন। যেমন, "Hello World!" অথবা আপনার Address.
- URL: কোনো Website Link এর জন্য এই Option টি Select করুন। যেমন, আপনার Website এর address.
- WhatsApp: সরাসরি WhatsApp এ Message পাঠানোর জন্য এই Option টি Select করুন। এটা Business এর জন্য খুবই কাজের।
- Image: কোনো Image এর জন্য QR Code generate করতে এই Option টি Select করুন। ধরুন, আপনি কোনো Product এর ছবি Share করতে চান।
- Album: অনেকগুলো Image এর Album এর জন্য এই Option টি Select করুন। Vacation এর ছবি Share করার জন্য এটা দারুণ।
- MP4 Video: কোনো Video File এর জন্য এই Option টি Select করুন। Tutorial Video Share করার জন্য এটা খুবই useful.
- Google Maps: কোনো Location Share করার জন্য এই Option টি Select করুন। Meeting এর Location জানানোর জন্য এটা খুব কাজের।
- MP3 Music: কোনো গান Share করার জন্য এই Option টি Select করুন। আপনার পছন্দের গান বন্ধুদের সাথে Share করুন।
- Recording: কোনো Audio Recording Share করার জন্য এই Option টি Select করুন। Voice Note Share করার জন্য এটা কাজে লাগে।
- PDF File: কোনো PDF File Share করার জন্য এই Option টি Select করুন। E-book বা Document Share করার জন্য এটা খুব দরকারি।

ধরুন, আপনি URL এর জন্য Code generate করতে চান, তাহলে URL Option টি Select করুন।

![URL Option টি Select](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_8cbbc64da413ad2f4e1e64c09bc1db3b.png)

কিছু Category ব্যবহার করার জন্য Account create করে Login করতে হবে। যেমন - Image, Album এবং MP4, MP3 Upload Hosting Function ব্যবহার করার জন্য Registration Free হলেও Email Address দিতে হবে। এছাড়াও, generate করা QR Code এর Scan number of times এর Limit ও থাকবে। তাই ব্যবহারের আগে Terms and Condition ভালো করে দেখে নেবেন।
