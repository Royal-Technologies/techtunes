আমরা প্রতিদিন স্মার্টফোন ব্যবহার করি—কল করা, Facebook চালানো, ভিডিও দেখা, গেম খেলা—সবই করি। কিন্তু মজার ব্যাপার হলো, আপনার Android ফোনে এমন অনেক Hidden Feature আছে যেগুলো আপনি হয়তো কখনোই ব্যবহার করেননি। এই ফিচারগুলো ব্যবহার করলে আপনার ফোন আরও Fast, Smart এবং Efficient হয়ে উঠবে।

এই আর্টিকেলে আমরা জানবো ২০২৬ সালের সবচেয়ে Useful ১০টি Android Hidden Tricks, যেগুলো জানলে আপনি অন্যদের থেকে একধাপ এগিয়ে থাকবেন।

## 🔥 ১. Split Screen Mode (একসাথে দুইটা অ্যাপ চালানো)

আপনি কি একসাথে You Tube ভিডিও দেখতে দেখতে Whats App-এ Chat করতে চান?

👉 এই Feature দিয়ে আপনি একসাথে দুইটা App চালাতে পারবেন।

কিভাবে ব্যবহার করবেন:

- Recent Apps Button চাপুন
- একটি App-এর Icon ধরে “split Screen” Select করুন
- দ্বিতীয় App Choose করুন

👉 Productivity বাড়াতে এটা খুব Helpful

## 🔒 ২. App Lock (security বাড়ানোর ট্রিক)

আপনার Personal App (facebook, Messenger, Gallery) Secure রাখতে App Lock ব্যবহার করতে পারেন।

- অনেক ফোনে Built-In App Lock থাকে
- না থাকলে Play Store থেকে App Install করতে পারেন
- এতে অন্য কেউ আপনার Private Data Access করতে পারবে না

## ⚡ ৩. Quick Settings Customize

আপনার Notification Bar-এ যে Quick Settings থাকে, সেটা আপনি নিজের মতো করে Customize করতে পারেন।

ExAMPle:

- Data On/off
- Flashlight
- Screen Recorder

👉 শুধু Swipe Down করে Edit Option থেকে নিজের মতো সাজিয়ে নিন

## 🎥 ৪. Screen Recorder (internal Recording)

অনেকেই জানে না—android ফোনে Built-In Screen Recorder থাকে!

👉 এর মাধ্যমে:

- Tutorial ভিডিও বানাতে পারবেন
- Game Record করতে পারবেন
- Important Moment Save করতে পারবেন

👉 Extra App লাগবে না

## 🌙 ৫. Dark Mode (battery Saving + Eye Comfort)

Dark Mode শুধু Stylish না, এটা Battery Save করতেও সাহায্য করে।

👉 Benefits:

- চোখের চাপ কমায়
- রাতে ব্যবহার করতে আরাম
- Oled Display-এ Battery কম খরচ হয়

👉 Settings → Display → Dark Mode on করুন

## 🔋 ৬. Battery Saver Automation

আপনি চাইলে Battery Low হলে Automatically Battery Saver চালু করতে পারেন।

👉 এতে:

- Background App বন্ধ হয়
- Battery Life বাড়ে

👉 Long Time বাইরে থাকলে খুব Useful

## 📶 ৭. Data Usage Control

অনেক সময় Mobile Data দ্রুত শেষ হয়ে যায়। এই Feature দিয়ে আপনি Data Usage Limit Set করতে পারবেন।

- Settings → Network → Data Usage
- Limit Set করুন
- এতে Unwanted Data Use বন্ধ হবে

## 🧠 ৮. Smart Lock (auto Unlock Feature)

আপনি চাইলে Trusted Place বা Device এ থাকলে ফোন Auto Unlock রাখতে পারেন।

👉 Example:

- নিজের বাড়িতে থাকলে Unlock লাগবে না
- Bluetooth Device Connected থাকলে Lock খুলে যাবে

👉 Security + Convenience দুইটাই পাওয়া যায়

## 🎤 ৯. Voice Typing (typing ছাড়াই লেখা)

Typing করতে কষ্ট লাগে? No Problem!

👉 Voice Typing দিয়ে আপনি কথা বলেই লিখতে পারবেন।

👉 Use Case:

- Message লেখা
- Article লেখা
- Note নেওয়া

👉 Fast and Easy Way

## 📂 ১০. Hidden File/folder (private Data Hide)

আপনি চাইলে আপনার Personal ছবি, ভিডিও Hide করে রাখতে পারেন।

- File Manager-এ Hidden Folder Option থাকে
- Gallery থেকেও Hide করা যায়
- Privacy Maintain করতে Perfect

## ⚡ Bonus Tips

- Developer Options Enable করে Animation Speed কমান → ফোন Fast লাগবে
- Unused Apps Disable করুন
- Regular Update দিন
