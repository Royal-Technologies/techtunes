## ১. Azure-এ Claude Fable 5.5-এর আকস্মিক Leak এবং এর গোপন আখ্যান

![Azure-এ Claude Fable 5.5-এর আকস্মিক Leak এবং এর গোপন আখ্যান](https://dnc.techtunes.io/tDrive/tuner/2026/10/techtunes_c0586efaf436d3d0bfcd30699fa5a64f.jpg)

গল্পের শুরুটা কিন্তু অফিশিয়াল কোনো Press Release বা জাকজমকপূর্ণ Announcement দিয়ে হয়নি! Anthropic-এর সবচেয়ে রহস্যময় ও অঘোষিত Model Claude Fable 5.5 হঠাৎ করেই নির্ধারিত সময়ের আগে বাইরে প্রকাশ পেয়ে যায়।

ঘটনাটি ঘটে তখন, যখন Developers-রা সাধারণ একটি Config File পর্যবেক্ষণ করছিলেন। Light LLM নামক একটি Open-Source সিস্টেমের সাথে Sync করা একটি Code Submission-এ দেখা যায় Microsoft Azure-এর East US 2 Model Directory-তে একটি ব্র্যান্ড নিউ ID দেখা যাচ্ছে, যা হলো `azure.ai/claudefable55` এবং এর Status দেওয়া রয়েছে Generally Available (GA)।

আপনারা কি Fable 5.1-এর কথা মনে করতে পারছেন? ঠিক একইভাবে Fable 5.1 যখন AWS Bedrock-এ Listed হয়েছিল, তার মাত্র 1 Day পরেই সাধারণ Web Users-দের ব্যবহারের জন্য তা উন্মুক্ত করে দেওয়া হয়েছিল। সেই অভিজ্ঞতা থেকেই Tech Community-র ধারণা, Fable 5.5-এর Full Release হয়তো একেবারে দোরগোড়ায়, এমনকি এই Week-েই তা সবার সামনে চলে আসতে পারে!

তবে এই এক্সাইটমেন্টের মাঝেও Skeptics-রা বেশ যুক্তিযুক্ত কিছু Point তুলে ধরেছেন:

- Light LLM যেহেতু Open-Source, তাই Azure Directory-র সাথে এর Config Syncing হওয়া অত্যন্ত স্বাভাবিক একটি ঘটনা এবং এটি কিন্তু দ্বিতীয় কোনো স্বাধীন Source হিসেবে গণ্য হয় না।
- আর কোনো Directory-তে Status 'GA' লেখা থাকার মানেই এটি নিশ্চিত করে না যে আজকেই Announcement চলে আসবে।
- তাই অভিজ্ঞদের Advice হলো, এখনই Account Top Up করার জন্য তাড়াহুড়ো করবেন না!

## ২. Leaked Specs, Pricing এবং Cost-এর কঠিন বাস্তব রূপ

![Leaked Specs, Pricing এবং Cost-এর কঠিন বাস্তব রূপ](https://dnc.techtunes.io/tDrive/tuner/2026/10/techtunes_4830154827d9281f4a1cfa802f5b068d.jpg)

গোপন সূত্র থেকে কেবল নাম নয়, Fable 5.5-এর Leaked Specs এবং Pricing-ও বাইরে চলে এসেছে। চলুন দেখে নেওয়া যাক কী রয়েছে এই শক্তিশালী Model-এ:

- **1 Million Token Context Window:** বিশাল আকৃতির Documents ও ডেটা একসাথে প্রসেস করার ক্ষমতা।
- **128, 000 Max Output Tokens:** একটি মাত্র Response-এ ১২৮, ০০০ Tokens পাওয়া মানে হলো স্রেফ একটি উত্তর নয়, বরং আস্ত একটি Full-Length Novel অথবা কোনো Medium-Sized Project-এর পুরো Codebase একবারে পেয়ে যাওয়া!
- **API Pricing Structure:** প্রতি 1 Million Input Tokens-এর জন্য $10 এবং প্রতি 1 Million Output Tokens-এর জন্য $50।

এখন যদি একটু পেছনের দিকে তাকাই, ২০২৪ সালে Gemini-র 1 Million Token Context Window ছিল এবং গত Year-এ GPT-5-ও 128, 000 Output প্রদান করতে পারত। তাই আলাদাভাবে এই Numbers-গুলো একদম নতুন না হলেও, 128, 000 Tokens Output-এর পাওয়ার মানে হলো দীর্ঘ Documents প্রসেসিং এবং থাম্বস-আপ ছাড়া একটানা চলা Complex Agents চালনার জন্যই মূলত এই Thing-টি Built করা হয়েছে।

### খরচের বিশাল ধাক্কা (The Catch Is Cost):

কিন্তু এখানে সবচেয়ে বড় Catch হলো এর Cost! একজন Commenter বেশ সুন্দরভাবে উল্লেখ করেছেন যে, Fable 5.5 যে পরিমাণ Usage Burn করে, সেই তুলনায় Opus-এর পরিবর্তে Fable 5.5 ব্যবহার করার সিদ্ধান্তকে যুক্তিযুক্ত প্রমাণ করতে হলে এটিকে কার্যক্ষমতায় চরম লেভেলের Excellent হতে হবে।

আপনি যদি API Access ছাড়া সাধারণ Subscriber হন, তবে কয়েকটি Long Prompts ব্যবহার করলেই আপনার 5-Hour Quota এক নিমেষে Wipe Out হয়ে যেতে পারে! তাই প্রাথমিক অবস্থায় বাস্তবিকভাবে কেবল সেইসব Enterprise Clients-রাই এটি বেনিফিটসহ ব্যবহার করতে পারবে, যারা প্রতি Million Tokens-এ 50 Bucks-এর বেশি খরচ করতে প্রস্তুত।

2. **Prompt Cache Trap:** Fast Mode এবং Standard-এর মধ্যে Prompt Cache Share হয় না! তাই সেশনের শুরুতেই Fast Mode On করে নেওয়া ভালো, অন্যথায় মাঝপথে Switch করলে Uncached Input Fee দিতে হবে (তবে এই Fee প্রতি Conversation-এ কেবল একবারই Charge করা হয়)।
3. **Billing:** Pro, Max, Team, বা Enterprise অ্যাকাউন্টগুলোতে এটি Subscription Limits-এর ভেতর না কেটে Extra Usage Quota থেকে কাটা হয়। Logged In অবস্থা দেখতে `{slash} status` রান করুন। Pro এবং Max Users-রা Settings থেকে Claude.ai-এ Usage চেক করুন। Team ও Enterprise-এর ক্ষেত্রে Org's Quota থেকে খরচ কাটা হয়, যা Users-রা `{slash} usage` চেপে এবং Admins-রা Back End-এ দেখতে পান। API Customers-রা Console-এ Usage and Cost থেকে Group By Menu-তে Speed, Research Preview বেছে নিন। Free Evaluation Accounts ক্রেডিট যোগ না করা পর্যন্ত এটি Use করতে পারবে না।

   - Version 2.1.280 থেকে বাই-ডিফল্ট Opus 5.5 ব্যবহার হয়। আপনি চাইলে Profile-এ `fast_mode: true` Hardcode করে রাখতে পারেন। `{slash} model` দিয়ে Sonnet-এ গেলে বন্ধ হয়, আবার Opus 5.5-এ এলে অন হয়। Cloud Sessions-এ এটি কেবল সেই Session-এর জন্যই স্থায়ী হয়।

## ৭. টোকেন বাঁচানোর মোঘল ফিচার: Idle Compaction

![Idle Compaction](https://dnc.techtunes.io/tDrive/tuner/2026/10/techtunes_0ba481cce3cc24ef08b6ee55eb0ab472.jpg)

আমরা অনেকেই কাজ করার সময় Session-এ ২০০, ০০০ Tokens জমা হওয়ার পর কোনো দীর্ঘ Meeting-এ চলে যাই। 1 ঘণ্টা পার হলেই Prompt Cache মেয়াদোত্তীর্ণ হয়ে যায়, আর ফিরে এসে স্রেফ 1 Line of Code চাইলে পুরো ২০০, ০০০ Tokens নতুন করে পড়ে সিস্টেমে কয়েকটি Dollars নিমিষেই গায়েব করে ফেলে!

- **Developer Feedback & Fix:** GitHub-এ এক Developer জানান যে রাতারাতি 7টি Long Sessions Compacted হওয়ায় AI তার প্রজেক্টের গভীরে থাকা Technical Decisions-এর বিবরণ ভুলে গিয়েছিল! Anthropic দ্রুত প্রতিকার হিসেবে `settings.json`-এ `idle_compaction: false` বা Environment Variable পরিবর্তন করে ২০০, ০০০ Threshold বন্ধ বা পরিবর্তন করার অপশন যুক্ত করে দিয়েছে।

তবে এর Agent Numbers অত্যন্ত প্রশংসনীয়! Model Card অনুসারে এটি সার্বিকভাবে উচ্চতর Intelligence Scores থাকা মডেলকেও হারিয়ে দেয়।  
 Meta বেশ স্বচ্ছতার সাথে প্রকাশ করেছে যে Comparison-এ বিভিন্ন Harnesses এবং Vendors-এর Self-Reported Numbers ব্যবহার করা হয়েছিল:

- Muse Spark Open চলেছে Muse Code-এ।
- Kimiko 3 চলেছে Kimiko-তে।
- Qwen 3.8 চলেছে Claude Code-এ।

আসল কথা হলো, Agent Performance স্রেফ মূল Model থেকে আসে না; এটি আসে Model, Harness, Tools, Context Management, এবং Execution Environment-এর সুষম Combo থেকে। তাই Open Models-কে স্রেফ Base Leaderboards দেখে বিচার না করে দেখা উচিত এগুলো বাস্তবের Agent Workflows-এ কতটা কার্যকরভাবে যুক্ত হতে পারছে!
