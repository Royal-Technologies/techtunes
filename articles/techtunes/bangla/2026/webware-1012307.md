PWA মানে হলো, এটি সাধারণ Website-এর চেয়ে বেশি কিছু, যা Browser-এর ভেতর App-এর মতো Experience দেয়। এর মানে হলো, আপনাকে আলাদা করে কোনো Software Download বা Install করতে হবে না। শুধু Pin.gl-এর Website-এ যান, আর Screen Sharing শুরু করে দিন! 🚀

Pin.gl আপনাকে Instant Screen Sharing এবং Camera Lens Sharing-এর সুবিধা দেয়। আপনি চাইলে আপনার Desktop-এর Screen Share করতে পারেন, আবার Smartphone বা Tablet থেকে Camera Lens-ও Share করতে পারেন। আর সবচেয়ে আকর্ষণীয় বিষয় হলো, Pin.gl ব্যবহার করার জন্য কোনো Account তৈরি করারও দরকার নেই! শুধু একটা Room Code Set করুন, আর Sharer (যে Screen Share করবে) ও Viewer (যারা Screen দেখবে) উভয়ের জন্যই আলাদা আলাদা Link তৈরি হয়ে যাবে। Laptop, Smartphone বা Tablet - আপনার হাতে যা আছে, তা দিয়েই Pin.gl ব্যবহার করতে পারবেন, যদি সেই Device-এ WebRTC Support থাকে। 💻📱

## WebRTC-এর জাদু - কেন Pin.gl এত দ্রুত এবং নিরাপদ?

![কেন Pin.gl এত দ্রুত এবং নিরাপদ?](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_cf66bacd78f6bc574ff9cb88f84cc91c.jpg)

Pin.gl-এর Core Technology হলো WebRTC (Web Real-Time Communication)। WebRTC এখনকার Mainstream Browser গুলোর একটি Standard Feature, তাই Compatibility নিয়ে কোনো চিন্তা নেই। WebRTC ব্যবহারের প্রধান সুবিধাগুলো হলো:

- Low Latency: WebRTC নিশ্চিত করে যে Screen Share করার সময় Delay খুবই কম হবে। এর ফলে Live Presentation, Online Meeting বা Remote Collaboration-এর Experience হবে একদম Seamless! 🚀
- High Security: Pin.gl আপনার Data-র Security-কে সর্বোচ্চ Priority দেয়। WebRTC End-to-End Encryption Support করে, যার মানে আপনার Data Share করার সময় Encrypted থাকবে, এবং শুধুমাত্র Receiver-ই Data Decrypt করতে পারবে। Pin.gl নিজেও আপনার Screen Content Record বা Analyze করে না, তাই Privacy নিয়ে কোনো চিন্তা নেই! 🛡️

## Pin.gl ব্যবহারের Step-by-Step Guide

![How to Use Pin.gl: The Ultimate Guide](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_0b2f728ba75226419cc3fbd5747f038a.jpg)

Pin.gl ব্যবহার করা খুবই সহজ। নিচের Step গুলো অনুসরণ করুন:

১. প্রথমে আপনার পছন্দের Browser-এ Pin.gl-এর অফিসিয়াল Website-এ যান।

![Pin.gl-এর Website](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_e9f7b152070c3540d918191dc0f51d00.png)

২. Website-এ প্রবেশ করার পর "Quick share" Button-এ Click করুন। System automatically একটি Random Room Code তৈরি করবে। আপনি চাইলে নিজের মতো Custom Room Code-ও Set করতে পারবেন।

![Start Sharing](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_f108183837359a5d7a6040815b67efe3.png)

৩. Screen বা Camera Lens Share করার জন্য Screen-এর ডানদিকে থাকা "Quick share" Button-এ Click করুন।

![Quick share](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_c496c69497a7e5b5f5cf597e1e70f720.png)

৪. যদি অন্যের Screen দেখতে চান, তাহলে Room Code Enter করে বামদিকের "Start Viewing" Button-এ Click করুন। তাহলেই আপনি Viewer Mode-এ প্রবেশ করতে পারবেন।

![Start Viewing](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_6343b2a73bd8bac4ffbc5bf5565151f8.png)

৪. Generated URL: Room Code তৈরি হওয়ার পর আপনি একটি URL পাবেন, যা দেখতে `https://pin.gl/yourRoomCode` -এর মতো হবে। যারা Screen Share করতে চান, তারা `https://pin.gl/yourRoomCode/host` (URL-এর শেষে /host যোগ করুন) এই Link-এ যান।

![Room Code তৈরি](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_2d834a828c4bfdc4256a3eb57c38884e.png)

⚠️ Security Alert: Pin.gl-এ Password বা Permission-এর কোনো Option নেই। Room Code জানা থাকলেই যে কেউ আপনার Screen দেখতে পারবে। Random Code Generate হলেও, সেটি Guess করা বা অন্য কোনো উপায়ে সংগ্রহ করা সম্ভব। তাই এই Service ব্যবহার করার সময় কোনো Sensitive Information Share করা থেকে অবশ্যই সাবধান থাকুন! 🕵️‍♀️

**Step 2:**Room Code Generate করার পর আপনি একটি QR Code পাবেন। QR Code Scan করে Camera Lens বা Screen Share করুন, এবং অন্যদের Room Code দিয়ে Join করতে বলুন!

![Room Code Generate করা](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_340dc58b41ee319b0be487a38cc4f807.png)

**Step 3:** যারা Screen Share করছেন, তারা URL-এ প্রবেশ করার পর Camera এবং Screen Share করার Option দেখতে পাবেন। ভিডিও শেয়ার করার সময় আপনি চাইলে Microphone On করেও Video Share করতে পারবেন! 🤳

![Microphone On করে Video Share](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_72020543aac382498e1d016eac533dc9.png)

**Step 4:** Computer থেকে Screen Share করার সময় আপনি Browser Tab, নির্দিষ্ট Window, নাকি Full Screen Share করতে চান, তা Select করার Option পাবেন। আপনার প্রয়োজন অনুযায়ী Option Select করুন। সবকিছু Select করার পর "Share" Button-এ Click করলেই Screen Share শুরু হয়ে যাবে!

![screen share Option Select](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_6fddf88aaf2c701e4c3cd1621e474a91.png)

Screen Share করার সময় আপনার Browser Screen-এর উপরে একটি Warning Message দেখাবে, যা আপনাকে মনে করিয়ে দেবে যে আপনার Screen Share করা হচ্ছে। কাজ শেষ হয়ে গেলে "Stop Sharing" Button-এ Click করতে ভুলবেন না।

![Stop Sharing](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_ea2716aa025780cd765823303fb2dfe5.png)
