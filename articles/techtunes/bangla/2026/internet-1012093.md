টেকটিউনস বন্ধুরা, কেমন আছেন সবাই? আশাকরি সবাই ভালো আছেন এবং সুস্থ আছেন। আজকের টিউনে আমি আপনাদের সাথে এমন একটি গুরুত্বপূর্ণ বিষয় নিয়ে আলোচনা করতে যাচ্ছি, যা আমাদের দৈনন্দিন জীবনে প্রায়শই দরকার হয়। বিষয়টি হলো File Sharing।

আমরা সবাই, কমবেশি, বিভিন্ন ধরনের File Share করে থাকি। সেটা হতে পারে জরুরি কোনো Document, সুন্দর কোনো ছবি (Image), মজার কোনো ভিডিও, অথবা অন্য কোনো File। এখন প্রশ্ন হলো, এই যে আমরা বিভিন্ন মাধ্যমে File Share করি, তার মধ্যে কতগুলো মাধ্যম নিরাপদ? কতগুলো আমাদের ব্যক্তিগত তথ্যের (Privacy) সুরক্ষা দেয়?

আজ আমি আপনাদের সাথে এমন একটি অসাধারণ টুলের (Tool) পরিচয় করিয়ে দেব, যা File Sharing-কে করবে আরও সহজ, নিরাপদ এবং ঝামেলামুক্ত। বিশেষ করে যারা Mozilla Firefox Send ব্যবহার করতেন, তাদের জন্য এটা সত্যিই দারুণ একটা খবর! কারণ, Firefox Send বন্ধ হয়ে যাওয়ায় অনেকেই হতাশ হয়েছিলে। তাদের সেই হতাশা দূর করতেই Send নামের একটি Open Source প্ল্যাটফর্ম নিয়ে এসেছি, যা প্রায় হুবহু Firefox Send-এর মতোই, তবে আরও উন্নত নিরাপত্তা বৈশিষ্ট্য সহ।

## কেন Send, অন্যান্য File Sharing Platform থেকে আলাদা?

![Send](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_303eaaf4c34fbc10a0d00049b90ac861.png)

বর্তমান সময়ে, অনলাইনে File Share করার জন্য অসংখ্য প্ল্যাটফর্ম উপলব্ধ। Google Drive, Dropbox, WeTransfer - এরকম অনেক জনপ্রিয় সার্ভিস রয়েছে। তাহলে কেন আমরা Send ব্যবহার করব? Send এর বিশেষত্বগুলো কী কী?

আসলে, Send অন্যান্য File Sharing Platform থেকে বেশ কিছু গুরুত্বপূর্ণ বিষয়ে আলাদা। Send মূলত তিনটি বিষয়ের উপর জোর দেয়:

- Security (নিরাপত্তা): Send আপনার File-কে End-to-End Encryption-এর মাধ্যমে সুরক্ষিত রাখে। এর মানে হলো, প্রেরক (Sender) এবং প্রাপক (Receiver) ছাড়া অন্য কেউ আপনার File দেখতে পারবে না। এমনকি Send এর Server-ও আপনার File access করতে পারবে না।
- Privacy (গোপনীয়তা): Send এ Upload করা File Permanently Server এ Store করা হয় না। File একটি নির্দিষ্ট সময় পর Automatically Delete হয়ে যায়। এছাড়াও, Download সংখ্যাও Limit করা যায়, যাতে অবাঞ্ছিত কেউ আপনার File Download করতে না পারে।
- Simplicity (সরলতা): Send ব্যবহার করা খুবই সহজ। যে কেউ কোনো প্রকার জটিলতা ছাড়াই File Upload এবং Download করতে পারবে। এর Interface খুবই User-Friendly।

## Firefox Send কেন বন্ধ হলো, Send কিভাবে তার অভাব পূরণ করবে?

![Firefox Send কেন বন্ধ হলো, Send কিভাবে তার অভাব পূরণ করবে?](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_6a99b59172e00291cb44351e99970b5f.jpg)

২০১৯ সালের আগে Mozilla Foundation "Firefox Send" নামে একটি File Sharing Service চালু করেছিল। এটি ছিল Web Lab-এর একটি Product, যা খুব অল্প সময়েই User-দের মধ্যে জনপ্রিয়তা লাভ করে। সবাই এর প্রশংসা করতে শুরু করে।

কিন্তু, দূর্ভাগ্যবশত, Mozilla পরের বছর সেপ্টেম্বরে ঘোষণা করে যে তারা Firefox Send Serviceটি Permanently বন্ধ করে দেবে। এর প্রধান কারণ ছিল কিছু User এই Service-টির অপব্যবহার করছিল। তারা Malicious Software ছড়াচ্ছিল এবং Cross-site Phishing Attack করছিল। Mozilla তাদের User-দের Security এবং Privacy-কে সবথেকে বেশি গুরুত্ব দেয়, তাই তারা বাধ্য হয়েই এই Service টি বন্ধ করে দেয়।

তবে, Mozilla Community-র কথা ভেবে এই Service-টির Source Code GitHub-এ Open Source করে দেয়। এর প্রধান উদ্দেশ্য ছিল, Community চাইলে এই Service টিকে Maintain করে User-দের জন্য আবার Open করতে পারে। আর ঠিক এই কাজটিই করেছে Send। Send, Firefox Send এর অভাব পূরণ করে File Sharing কে আরও নিরাপদ করার লক্ষ্যে কাজ করছে।

## Send Project-এর জন্ম: একটি নতুন শুরুর গল্প

![Send Project-এর জন্ম: একটি নতুন শুরুর গল্প](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_5f4856554a59678e26fc2e710ef8549a.jpg)

Send হলো Firefox Send থেকে Fork করা একটি Project। "Fork" মানে হলো, Send এর Source Code Firefox Send থেকেই নেওয়া হয়েছে, কিন্তু Send এর Developer-রা এটাকে আরও উন্নত করেছে এবং Maintain করছে। Developer Tim Visée নেদারল্যান্ডস এর বাসিন্দা। তিনি এবং তার Community নিরলসভাবে কাজ করে যাচ্ছে, যাতে এই Functionality টিকে User-রা ব্যবহার করতে পারে এবং File Sharing এর একটি নিরাপদ মাধ্যম খুঁজে পায়।

## Send এর বৈশিষ্ট্য এবং সুবিধা: বিস্তারিত আলোচনা

![Send এর বৈশিষ্ট্য এবং সুবিধা: বিস্তারিত আলোচনা](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_d203401b5a85139aff98997347c6ea27.jpg)

Send এর অসাধারণ কিছু বৈশিষ্ট্য রয়েছে, যা একে অন্যান্য Platform থেকে আলাদা করে তুলেছে। চলুন, সেই বৈশিষ্ট্যগুলো বিস্তারিতভাবে জেনে নেওয়া যাক:

- End-to-End Encryption: Send User-দের End-to-End Encryption-এর মাধ্যমে File Share করার সুবিধা দেয়। এর মানে হলো, আপনার File Upload করার পর সেটি Encrypt হয়ে যায় এবং শুধুমাত্র Receiver-ই সেটি Decrypt করতে পারবে। মাঝখানে অন্য কেউ, এমনকি Send এর Server-ও আপনার File দেখতে পারবে না।
- Automatic Expiry Link: Send Automatically Expire হয়ে যায় এমন Link তৈরি করে। আপনি যখন একটি File Upload করবেন, তখন একটি Unique Link তৈরি হবে। এই Link টি নির্দিষ্ট সময় পর Automatically Expire হয়ে যাবে। এর ফলে আপনার File Permanently ইন্টারনেটে থাকার কোনো ঝুঁকি নেই।
- Large File Support: Send এ Maximum 2.5 GB File Send করা যায়। সুতরাং, Large File Share করার জন্য এটা একটা দারুণ Option।
- Temporary File Transfer: Send অনেকটা Temporary File Transfer Tool-এর মতো কাজ করে। Free Space-এ File Upload করলে সেটি Permanently থেকে যায়, কিন্তু Send-এ File নির্দিষ্ট সময় পর Automatically Delete হয়ে যায়।
- Download Limit: Send এ Download Number Limit করার Option আছে। আপনি Set করতে পারবেন আপনার File কতবার Download করার পরে Automatically Expire হয়ে যাবে।
- Storage Time Limit: Send এ Storage Time Limit করার Option আছে। আপনি Set করতে পারবেন আপনার File কতক্ষণ পর্যন্ত Available থাকবে।
- Password Protection: আপনার File-কে আরও Secure করার জন্য Password Protection-এর Option ও আছে। এর মাধ্যমে আপনি আপনার File-কে অনাকাঙ্ক্ষিত User-দের হাত থেকে Download করা থেকে বাঁচাতে পারবেন।
- User-Friendly Interface: Send এর Interface খুবই User-Friendly। যে কেউ কোনো প্রকার জটিলতা ছাড়াই File Upload এবং Download করতে পারবে।
- Open Source: Send একটি Open Source Project, তাই যে কেউ এর Source Code দেখতে পারবে এবং নিজের প্রয়োজন অনুযায়ী পরিবর্তন করতে পারবে।

মোটকথা, Send হলো Security, Privacy এবং Simplicity-এর একটি Perfect Combination।

## Send ব্যবহারের নিয়মাবলী: Step by Step Guide ছবি সহ

![Send ব্যবহারের নিয়মাবলী](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_325f213a2adba18fc99e7be88a76730c.jpg)

Send ব্যবহার করা খুবই সহজ। আমি নিচে Step by Step Guide দিচ্ছি, যাতে আপনাদের বুঝতে সুবিধা হয়:

**STEP 1: Send Website এ যান:**

প্রথমে আপনার Browser-এ <https://send.vis.ee/> লিখে Enter করুন। Send এর Website টি Open হবে।

![Send এর Website](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_c36982a839bb59d0a969ebc3f0146657.png)

**STEP 2: File Upload করুন:**

Send খোলার পরে Upload করার Function দেখতে পাবেন। এখানে আপনি দুটি Option পাবেন:

Drag and Drop: যে File Transfer বা Share করতে চান, সেটি Drag করে নিয়ে এসে Send এর Upload Area-তে Drop করুন।

![Drag and Drop](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_b4177a691271ebbff3ef38bb021782fd.png)

Select File: "Upload Files" অপশনটি Select করে আপনার Computer থেকে File Browse করে Select করুন।

![Upload Files](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_cdc5d9b92690714ae57b560d31265938.png)

Maximum 2.5 GB এর বেশি File Send করা যাবে না। Files বেশি হলে Single File এ Compress করে নিন। Compress করলে File Size কমে যাবে এবং Upload করতে সুবিধা হবে।

**STEP 3: Download Limit Set করুন:**

File Upload করার আগে Download Limit Set করুন। আপনি Set করতে পারবেন আপনার File কতবার Download করার পরে Automatically Expire হয়ে যাবে। এখানে Minimum 1 বার এবং Maximum 10 বার Download করার Option আছে। আপনার প্রয়োজন অনুযায়ী Download Limit Set করুন।

![Download Limit Set](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_56aad679e4207fc67ab870beb6615b2f.png)

**STEP 4: Expiry Time Set করুন:**

Download Limit এর সাথে সাথে আপনি Expiry Time ও Set করতে পারবেন। এর মাধ্যমে আপনি নির্দিষ্ট করে দিতে পারবেন আপনার File কতক্ষণ পর্যন্ত Available থাকবে। Send এ File Download Link এর Expiry Time ও Set করা যায়। Minimum 5 মিনিট এবং Maximum 3 দিন পর্যন্ত Time Set করা যায়।

![Expiry Time Set](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_d95328e2b1e9114b12ca26d35544129d.png)

এই Option গুলো দেখেই বোঝা যায় যে এটি Permanent Download Link দেওয়ার জন্য Free Space Service নয়। Send এর প্রধান উদ্দেশ্য হলো Temporarily File Share করা। আপনি যদি চান আপনার File শুধুমাত্র নির্দিষ্ট কিছু সময়ের জন্য Available থাকুক, তাহলে Send আপনার জন্য Best। তবে, One-to-One File Share করার জন্য অথবা অল্প সংখ্যক Share করার জন্য এটি বেশি Safe এবং Reliable।

**STEP 5: Password Protection Enable করুন (Optional):**

আপনার File-কে আরও Secure করার জন্য Password Protection Enable করতে পারেন। Password Protection Enable করলে, Receiver-কে File Download করার আগে সঠিক Password দিতে হবে। Password Protection Enable করার জন্য "Password Protection" Function টি Check করুন।

![Password Protection Enable](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_10c35374be4b025826f53cabad3e4faf.png)

এরপর, আপনার পছন্দসই Password Set করুন।

![Password Set](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_71b33f72b30ea12c98ef2443abe7b277.png)

**STEP 6: Upload Complete করুন:**

সব Option Set করার পরে Upload Button এ Click করুন। Upload করার সময় আপনি Progress দেখতে পাবেন। Send এর Speed খুবই Fast, তাই File Upload হতে বেশি সময় লাগবে না। এছাড়াও, পুরো প্রক্রিয়ার Instruction গুলো খুব Clear করে দেওয়া আছে, তাই User-দের কোনো সমস্যা হবে না।

![Upload Button এ Click](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_06e636ee71c6b1296e0f5532e94e6da7.png)

**STEP 7: Link Share করুন:**

Upload Complete হওয়ার পরে একটি Download Link তৈরি হবে, সাথে একটি QR Code ও দেখতে পাবেন। Download Link টি Copy করার জন্য "Copy Link" Button এ Click করুন। Link টি Clipboard এ Copy হয়ে যাবে, এরপর আপনি Link টি Receiver-দের সাথে Share করতে পারবেন।

![Copy Link](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_4770b6cf1695b719ce0459d024cdf19e.png)

Send এর Homepage এ আগে Upload করা File Record গুলো দেখতে পাবেন। চাইলে Link copy করতে পারবেন অথবা File Download করতে পারবেন।

**STEP 8: File Download করুন (Receiver এর জন্য):**

Receiver যখন Download Link এ Click করবে, তখন তাকে Password দিতে হতে পারে, যদি আপনি Password Protection Enable করে থাকেন। সঠিক Password দেওয়ার পরেই সে File Download করতে পারবে।

![Download Link এ Click](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_7a1230f8e147864a608fdf2a5e25a3a3.png)

"Download" Button এ Click করার পরে Send থেকে File Download করতে পারবেন। Speed ও Fast এবং Website এ File Name ও File Size দেখতে পাবেন।

![Send থেকে File Download](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_acf172d4048d56c58a1c513ad45919bd.png)

**STEP 9: File Expiry Mechanism:**

File Share করার পরে Download Number অথবা Saving Time শেষ হয়ে গেলে, Download Page এ "এই Link টি Expire হয়ে গেছে" এই Message টি দেখতে পাবেন। এর পরে আর File Download করা যাবে না।

এই Expiry Mechanism এর কারণে Temporarily File Share করার জন্য Send খুবই Useful এবং File Server এ থেকে যাওয়ার চিন্তা থাকে না।
