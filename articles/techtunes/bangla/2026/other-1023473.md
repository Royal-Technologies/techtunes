Laptop কেনার আগে সবচেয়ে গুরুত্বপূর্ণ বিষয় হলো আপনি এটি দিয়ে কী করবেন।

শুধু browsing, YouTube, Microsoft Office, online class বা সাধারণ document-এর কাজ হলে খুব high-end configuration প্রয়োজন নাও হতে পারে।

অন্যদিকে Photoshop, video editing, programming, graphic design বা gaming-এর মতো কাজ করলে processor, RAM এবং graphics-এর দিকে বেশি নজর দিতে হবে।

তাই প্রথমে নিজের কাজের একটি তালিকা করুন। Laptop-এর specification পরে দেখলেও হবে।

## Processor কতটা গুরুত্বপূর্ণ?

Laptop-এর performance নিয়ে কথা বললে processor-এর বিষয়টি সামনে আসবেই। ASUS laptop-এ Intel এবং AMD-এর বিভিন্ন processor পাওয়া যায়।

সাধারণ কাজের জন্য entry-level বা mid-range processor যথেষ্ট হতে পারে। কিন্তু আপনি যদি নিয়মিত video editing, programming বা heavy multitasking করেন, তাহলে তুলনামূলক শক্তিশালী processor দরকার হতে পারে।

এখানে শুধু processor-এর নাম দেখলে হবে না। কোন generation, কত core এবং আপনার প্রয়োজনের জন্য performance কেমন হবে সেটাও বিবেচনা করা উচিত।

বর্তমানে নতুন laptop কেনার সময় SSD থাকা বেশ গুরুত্বপূর্ণ।

SSD ব্যবহার করলে operating system এবং application সাধারণত দ্রুত load হয়। Laptop চালু হওয়া থেকে শুরু করে software open করা পর্যন্ত অনেক কাজেই এর পার্থক্য বোঝা যায়।

ASUS laptop কেনার সময় SSD-এর capacity-ও দেখুন। সাধারণ কাজের জন্য 512GB SSD অনেকের জন্য practical option হতে পারে। তবে বড় game, video বা project file রাখলে আরও বেশি storage প্রয়োজন হতে পারে।

Gaming laptop হলে refresh rate-ও দেখতে হবে। বেশি refresh rate compatible gaming experience-এর জন্য কাজে আসতে পারে।

আপনি যদি নিয়মিত university, office বা বাইরে laptop ব্যবহার করেন, তাহলে portability এবং battery life-কে priority দেওয়া ভালো।
