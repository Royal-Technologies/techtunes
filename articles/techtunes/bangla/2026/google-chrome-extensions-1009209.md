আজকে আমি আপনাদের জন্য নিয়ে এসেছি Chrome Browser এর এমন একটা Hidden Gem, যেটা আপনার Tab Management এর ধারণাই পাল্টে দেবে। আমরা যারা Browser এ একসাথে অনেক Tab Open করে কাজ করি, তাদের কাছে এটা যেন এক নতুন দিগন্ত উন্মোচন করবে! 🌟

আমি জানি, অনেকেরই Chrome Browser এর Tab Organize করা নিয়ে frustration কাজ করে। কাজের সময় দরকারি Tab খুঁজে পাওয়া, অপ্রয়োজনীয় Tab Close করা – এগুলো যেন এক বিশাল কর্মযজ্ঞ! 😫

কিন্তু আর নয়! আজ আমি আপনাদের সাথে যে Extension টি নিয়ে কথা বলব, সেটা ব্যবহার করার পর Tab Organize করাটা আর কঠিন কাজ মনে হবে না, বরং এটা হয়ে উঠবে Fun এবং Efficient! 🎉

## কেন Vertical Tab দরকার? 🤔

![Sidebar Vertical Tabs](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_c62e51cb267c7d89cedbfcfff8ccb763.png)

আচ্ছা, প্রথমে একটু Personal Experience শেয়ার করি। কিছুদিন আগে আমি Ungoogled Chromium ব্যবহার করা শুরু করেছি। এটা Chrome Browser এরই মতো, কিন্তু Google এর Service গুলো ছাড়াই। যারা Privacy নিয়ে বেশি সচেতন, তাদের জন্য এটা অসাধারণ। 👍

এর আগে আমি Brave, Vivaldi, Microsoft Edge ও ব্যবহার করেছি। এই Browser গুলোর একটা Common Feature ছিল "Vertical Tab"। তখনই আমি Vertical Tab এর Power বুঝতে পারি। 💪

Vertical Tab এর সবচেয়ে কার্যকরী ব্যবহার আমি দেখেছিলাম Arc Browser এ। শুরুতে একটু confused লাগলেও, কয়েকদিন ব্যবহার করার পরেই আমি এর Fan হয়ে যাই! 😍 বিশ্বাস করুন, একবার অভ্যাস হয়ে গেলে Browser এর উপরে Tab দেখার পুরনো দিনগুলোতে ফিরে যেতে মন চাইবে না! 🙅‍♂️ বিশেষ করে যাদের বড় Screen এ কাজ করার অভ্যাস, তাদের জন্য Vertical Tab Screen এর জায়গা বাঁচিয়ে Productivity বাড়াতে দারুণ কাজে দেয়। 💯

কিন্তু সমস্যা হলো, আমাদের সবার প্রিয় Google Chrome এ তো Vertical Tab এর Feature নেই! 😥 তাহলে উপায়? মন খারাপ করার কিছু নেই! Chrome Extension এর মাধ্যমেই এই সমস্যার সমাধান সম্ভব। 😉

## "Sidebar Vertical Tabs" - আপনার Tab Management Hero! 🦸‍♂️

![Chrome ব্রাউজারেও Vertical Tab! 🤩 ](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_392197bef0286c0cf476d603bf0efa93.jpg)

এবার আসি আসল কথায়। আজকে আমি আপনাদের সাথে পরিচয় করিয়ে দেব "Sidebar Vertical Tabs" নামের একটি Free Chrome Extension এর সাথে। 🥳 এই Extension টি Google Chrome এবং অন্যান্য Chromium Browser এর Sideবারে Tab দেখাতে এবং Manage করতে সাহায্য করে।

আমি নিজে বেশ কয়েকটি Vertical Tab Extension ব্যবহার করে দেখেছি, কিন্তু আমার কাছে "Sidebar Vertical Tabs" কেই Best মনে হয়েছে। আমার মনে হয়েছে এটাই সবচেয়ে Clean, Efficient এবং User-Friendly। 🥰 অন্যগুলোতে অনেক অপ্রয়োজনীয় Function ছিল, যেগুলো ব্যবহার করাটা জটিল করে তোলে। 😕 আর এটা আমার নিজের কাজের ধরনের সাথেও খুব ভালোভাবে মিলে যায়। 😊

অন্যান্য Browser এর নিজস্ব Vertical Tab Function এর সাথে এর Operating এর সামান্য কিছু পার্থক্য থাকতে পারে, তবে আমি গ্যারান্টি দিচ্ছি, কয়েকদিন ব্যবহার করার পরেই আপনি এর সাথে Comfortable হয়ে যাবেন। 💯

এই Extension এর কিছু Killer Feature রয়েছে, যেগুলো আপনার Tab Management Experience কে Next Level এ নিয়ে যাবে: 🚀

- **Tab Grouping - Tab গুলোকে করুন Organize! 🗂️:** এই Feature টির মাধ্যমে আপনি Tab গুলোকে Different Category তে Group করে রাখতে পারবেন। ধরুন, আপনি Research এর জন্য কিছু Tab Open করেছেন, আবার Social Media দেখার জন্য কিছু Tab Open করেছেন। আপনি এই Tab গুলোকে আলাদা আলাদা Group এ ভাগ করে রাখতে পারবেন। Group এর Name, Color নিজের পছন্দ মতো Set করতে পারবেন, Fold এবং Expand ও করতে পারবেন। ফলে, Tab গুলোকে খুঁজে বের করা এবং Manage করা অনেক সহজ হয়ে যাবে। 🤩
- **Drag & Drop - Tab এর Position পরিবর্তন করুন সহজে! 🖱️:** এই Feature টির মাধ্যমে আপনি Mouse দিয়ে Drag করে Tab এর Position পরিবর্তন করতে পারবেন। Tab গুলোকে নিজের প্রয়োজন অনুযায়ী সাজিয়ে নিতে পারবেন। শুধু তাই নয়, Drag করে Tab গুলোকে Group এর মধ্যে Add করতে পারবেন, আবার Group থেকে Remove ও করতে পারবেন। এটা Tab Organize করার ক্ষেত্রে দারুণ Flexibility দেয়। 🤸‍♀️
- **Shortcut Support - Keyboard এই Tab Manage করুন! ⌨️:** Keyboard Shortcut ব্যবহার করে Tab Manage করাটা অনেক Fast এবং Efficient। এই Extension টি Popular Shortcut গুলো Support করে, ফলে আপনি Keyboard এর মাধ্যমেই Tab Create, Close, Switch এবং Organize করতে পারবেন। যারা Keyboard Shortcut ব্যবহার করতে ভালোবাসেন, তাদের জন্য এটা একটা Dream Come True! 😴
- **Tab Search Function - চোখের পলকেই Tab খুঁজে বের করুন! 🔎:** অনেক Tab Open থাকলে নির্দিষ্ট Tab খুঁজে বের করাটা কঠিন হয়ে যায়। কিন্তু "Sidebar Vertical Tabs" এর Tab Search Function এর মাধ্যমে আপনি চোখের পলকেই যেকোনো Tab খুঁজে বের করতে পারবেন। শুধু Tab এর Name লিখুন, আর Search Result আপনার সামনে হাজির! 🪄

## কিভাবে Install এবং Setup করবেন? 🤔

![Chrome ব্রাউজারেও Vertical Tab! 🤩 ](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_7de8a2b23aa1c40032709017ca93f44c.jpg)

"Sidebar Vertical Tabs" ব্যবহার করা খুবই সহজ। নিচে Step by Step Guide দেওয়া হলো: 👇

১. প্রথমে Chrome Web Store এ যান এবং "Sidebar Vertical Tabs" লিখে Search করুন। অথবা এই Link এ Click করুন: [Sidebar Vertical Tabs](https://chromewebstore.google.com/detail/vertical-tabs-in-side-pan/akahnknmcbmgodngfjcflnaljdbhnlfo)

![Sidebar Vertical Tabs](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_3d6ac8cd85eb0e8136ed3f01d968615f.png)

২. Extension টি খুঁজে পাওয়ার পর "Add to Chrome" Button এ Click করুন।

![Add to Chrome](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_f65882ec00db2c3336812c7accf622c6.png)

৩. একটা Popup আসবে, সেখানে "Add Extension" এ Click করুন।

![Add Extension](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_fe1edc1f3cd475aaf300d6d73ef857ca.png)

৪. Congratulations! 🎉 Extension টি আপনার Chrome Browser এ Install হয়ে গেছে।

![Chrome Browser এ Install](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_f9be8722c867a7149cbf6ed145123496.png)

৫. Install করার পর Side বারে Vertical Tab Function দেখতে পাবেন। Extension টি Basic ব্যবহার, Shortcut এবং Sidebar এর Position Settings সহ একটি Help Page Open করবে। Help Page টি ভালোভাবে পড়ে নিন, তাহলে Extension টি ব্যবহার করতে সুবিধা হবে।

![Help Page Open](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_b50c96d50ee4be447d7fc905744bebb4.png)

৬. যদি আগে থেকে Tab Group করা থাকে, সেগুলোও এখানে দেখতে পাবেন।

![Vertical Tab Function](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_dc86e4d7f02c700c3dd871b47e556a8c.png)

তবে এখানে একটা ছোট সমস্যা আছে, Google Chrome উপরের Tab গুলো Hide করতে দেয় না, 😔 এবং Chrome এর Policies এর কারণে Vertical Tab এর Width কমানো যায় না, তবে আপনি চাইলে বাড়াতে পারবেন। 🙂

### Position পরিবর্তন 🔄

![Chrome ব্রাউজারেও Vertical Tab! 🤩 ](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_3d45562c0da8ab60551c302ef2e391f0.jpg)

"Set the Position of the Sidebar" Option থেকে Side Panel এর Position Right Side অথবা Left Side এ পরিবর্তন করতে পারবেন। আমি ব্যক্তিগতভাবে Vertical Tab Browser এর Left Side এ রাখতে Prefer করি, কারণ আমার Left Side এ Tab দেখতে বেশি সুবিধা হয়। আপনি আপনার Comfort Zone অনুযায়ী Set করে নিতে পারবেন। 😉

### Setting নিজের মতো Customize করুন 🎨🖌️

![Chrome ব্রাউজারেও Vertical Tab! 🤩 ](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_717a2f6d600c9dca1143e44ce6c3d3f5.jpg)

"Sidebar Vertical Tabs" এর Setting এ Click করলে অনেক Customization Option পাবেন, যেগুলোর Meaning খুব সহজেই বোঝা যায়। নিচে কয়েকটি Option এর Details দেওয়া হলো: 👇

**Show New Tab Button:** নতুন Tab খোলার জন্য Sidebar এ একটা Button দেখাবে কিনা, সেটা Control করতে পারবেন।

![Show New Tab Button](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_b908d6d667f525650ae6e1f8e86cf083.png)

**Double-Click to Close the Tab:** Tab Close করার জন্য Double Click করতে চান কিনা, সেটা Select করতে পারবেন। Double Click করে Tab Close করাটা অনেকের কাছে Easy মনে হতে পারে।

![Double-Click to Close the Tab](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_7183acb97f782561c1528c596490a381.png)

**Search Box:** Tab Search Function টি Sidebar এ কোথায় দেখাতে চান, সেটা Control করতে পারবেন (যদিও দুঃখজনকভাবে এই Function টি Hide করার Option নেই)।

![Search Box](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_21b13117d59f25c5411eab8b662f5413.png)

**Font Size:** Sidebar এ Tab গুলোর Font Size কেমন হবে, সেটা Set করতে পারবেন। যাদের Font Size বড় করে দেখার প্রয়োজন হয়, তাদের জন্য এটা খুবই Useful।

![Sidebar এ Tab গুলোর Font Size](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_1f765341ec1b80b0d15269a8b5f47c17.png)

**Theme:** Light Theme নাকি Dark Theme ব্যবহার করতে চান, সেটা Select করতে পারবেন। Dark Theme ব্যবহার করলে রাতে Tab দেখতে সুবিধা হবে এবং চোখের উপর চাপ কম পড়বে। 🌙

![Theme](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_c69ecd1a68e77406f0acb2343b650d70.png)

এছাড়াও, নিচে Sidebar Position (Left Side, Right Side) এবং Keyboard Shortcut Setting ও করতে পারবেন। Defaultভাবে Alt + V Set করা আছে, যা Vertical Tab Open এবং Close করার জন্য ব্যবহার করা যায়। আপনি চাইলে নিজের Preference অনুযায়ী Shortcut Customize করতে পারবেন। 🤩

### Right Click Menu তে কি কি Magic আছে? ✨

![Chrome ব্রাউজারেও Vertical Tab! 🤩 ](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_c3af41e48d02b54e4cf34718d8230f4e.jpg)

Tab এর উপর Right Click করলে Tab Manage করার জন্য Multiple Option পাবেন। যেমন:

**Close Tab:** Tab টি Close করতে পারবেন।

![Close Tab](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_6f4b2a16e6ff599af6533683540a98f0.png)

**Close Other Tabs:** Current Tab ছাড়া বাকি Tab গুলো Close করতে পারবেন।

![Close Other Tabs](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_6ad3bbe0ddada4050717572c6e2006bc.png)

**Close Tabs to the Right:** Current Tab এর Right Side এর Tab গুলো Close করতে পারবেন।

![Close Tabs to the Right](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_8eabf1f47dd164d0c9a4bec50a8e5c37.png)

**Pin Tab:** Tab টি Pin করে রাখতে পারবেন। Pin করা Tab গুলো Browser Close করার পরেও Open থাকবে। যারা Important Tab সবসময় Open রাখতে চান, তাদের জন্য Pin Tab Optionটি খুবই Helpful।

![Tab টি Pin](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_4004272c0a485aff5f14de637402d40d.png)
