হ্যালো টেকটিউনস বন্ধুরা! কেমন আছেন সবাই? হাজির হয়েছি আপনাদের জন্য আরো একটি নতুন এবং দরকারি Windows টিউটোরিয়াল নিয়ে। আশাকরি সবাই ভালো আছেন এবং Internet এর দুনিয়ায় সবকিছু ঠিকঠাক চলছে। কিন্তু মাঝে মাঝে Internet Speed নিয়ে যে যুদ্ধটা হয়, সেটা নিশ্চয়ই আপনাদেরও পরিচিত? 😠

আজ আমরা কথা বলবো সেই Internet Speed নিয়েই। যারা ধীর গতির Internet নিয়ে বিরক্ত, Buffering এর যন্ত্রণায় কাতর, গেম খেলতে গিয়ে Lag এর শিকার, Video কলে কথা বলতে গিয়ে যাদের জীবন অতিষ্ঠ, তাদের জন্য আজ আমি নিয়ে এসেছি এক দারুণ সমাধান! 🥳 আজ আমি আপনাদের এমন একটা সহজ Magic Trick দেখাবো, যাতে আপনার Internet Speed বাড়বে রকেটের গতিতে! 🚀 বিশ্বাস করুন, এই Trick টি এতটাই সহজ যে, আপনার দাদু-দিদাও এটা করতে পারবেন! 👵👴

আজকের বিষয় হলো, কিভাবে মাত্র একটা ছোট্ট Settings পরিবর্তন করে আপনার Internet Speed কয়েকগুণ বাড়িয়ে নেয়া যায়। 🤯 কোনো জটিল Software বা কঠিন টেকনিক্যাল জ্ঞান ছাড়াই, শুধুমাত্র একটা সেটিংস পাল্টেই আপনি আপনার Internet Experience -কে অন্য লেভেলে নিয়ে যেতে পারবেন। এটা অনেকটা আপনার গাড়ির ইঞ্জিন টিউন করার মতো, যা আপনার গাড়ির স্পিড এবং পারফর্মেন্স বাড়িয়ে দেয়! 🏎️

আমরা সবাই জানি, আমাদের Internet Service Provider (ISP), মানে যাদের কাছ থেকে আমরা Internet কানেকশন নেই (যেমন ধরুন, ব্রডব্যান্ড লাইন অথবা মোবাইল ডেটা), তারা আমাদের Internet ব্যবহারের জন্য কিছু Network Settings দিয়ে থাকে। এই Settings গুলোর মধ্যে Domain Name System Addresses একটি গুরুত্বপূর্ণ বিষয়। কিন্তু সত্যি কথা বলতে কী, বেশিরভাগ ISP'র দেয়া Default DNS Server সবসময় সেরা নাও হতে পারে। 🐌 এই Server গুলো অনেক সময় স্লো, কম নির্ভরযোগ্য, এমনকি আমাদের মূল্যবান Online Privacy এর জন্যও নিরাপদ নাও হতে পারে। ভাবুন তো, আপনার অজান্তেই আপনার ডেটা অন্যের হাতে চলে যাচ্ছে! 😱

তাহলে উপায়? 🤔 এই সমস্যার সমাধান কী? ভয় নেই বন্ধুরা, যখন Brad আছে, তখন চিন্তা কীসের? আপনাদের জন্য একটা দারুণ এবং কার্যকরী সমাধান আছে! আপনার ISP এর ডিফল্ট DNS Server ব্যবহার না করে, বরং বেছে নিন একটি ফ্রি Public DNS Server। এটা অনেকটা ট্র্যাফিক জ্যামের মধ্যে শর্টকাট রাস্তা খুঁজে বের করার মতো! 🚦 Public DNS Server গুলো সাধারণত ISP গুলোর Server এর চেয়ে অনেক দ্রুতগতির হয়ে থাকে, এবং এরা আপনার Online Security -র দিকেও নজর রাখে। বিশ্বাস করুন, এটা আপনার Internet Speed এবং সামগ্রিক Online Experience সম্পূর্ণভাবে পাল্টে দেবে! 🤩 আপনার Website লোড হবে চোখের পলকে, Video Buffering এর যন্ত্রনা কমে গিয়ে Online Gaming হবে আরও স্মুথ এবং আনন্দদায়ক।

## DNS জিনিসটা আসলে কী? আসুন, একটু সহজ ভাষায় বুঝি! 🤓

![ধীর গতির ইন্টারনেটকে চিরতরে বিদায় বলুন! 🚀 একটি ছোট্ট সেটিং পাল্টেই আপনার নেট হবে সুপারসনিক! 💥](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_bc94ce4f046fe4b7e26e2111e399b6f2.jpg)

আচ্ছা, অনেকের মনে হয়তো এই প্রশ্নটা ঘুরপাক খাচ্ছে যে, এই Domain Name System (DNS) জিনিসটা আসলে কী? এটা কিভাবে কাজ করে, আর কেনই বা এটা এত গুরুত্বপূর্ণ? 🤔 একদম সহজ ভাষায় বলতে গেলে, DNS হলো একটি Translation Service। ধরুন, আপনি Internet এ কোনো ওয়েবসাইটে যেতে চান, যেমন Facebook অথবা YouTube। প্রতিটি Website -এর একটি নির্দিষ্ট ঠিকানা আছে, যাকে আমরা IP Address বলি। IP Address দেখতে অনেকটা এরকম: 66.249.64.0। কিন্তু সত্যি করে বলুন তো, এই জটিল নম্বরগুলো মনে রাখা কি আদৌ সম্ভব? 🤯 DNS ঠিক এই জায়গাতেই আমাদের সাহায্য করে। DNS এর কাজ হলো এই কঠিন IP Address কে সহজ Domain Name এ Convert করা। মানে, আপনি যখন আপনার Browser এ Facebook.Com অথবা YouTube.Com টাইপ করেন, তখন DNS Server এই নামটিকে খুঁজে বের করে এবং সেটিকে সংশ্লিস্ট IP Address এ Translate করে, যাতে আপনার Computer ওই Website এর সাথে কানেক্ট করতে পারে। DNS না থাকলে, আপনাকে সব Website এর IP Address মুখস্ত রাখতে হতো! 🤪 এবং সেটা যে কতটা ঝামেলার হতো, সেটা নিশ্চয়ই আপনারা বুঝতে পারছেন!

আগেও আমি এই Channel এ Windows 11 এবং Windows 10 এর জন্য Internet Speed বাড়ানোর কয়েকটা টিপস এবং ট্রিকস শেয়ার করেছি। কিন্তু আজকের Video টা DNS নিয়ে আরও গভীরে আলোচনা করবে। কোন DNS Server আপনার জন্য সবচেয়ে ভালো, সেটা খুঁজে বের করতেও সাহায্য করবে। 😉 শুধু তাই নয়, এই সেটিংস পরিবর্তন করার ফলে আপনার Online Security ও অনেকখানি বাড়বে, কারণ কিছু কিছু Public DNS Server ক্ষতিকর Website গুলোকে ব্লক করে দেয় এবং Malware Attack থেকে আপনার ডিভাইসকে রক্ষা করে। 🛡️ এটা অনেকটা আপনার বাড়ির সামনে একজন Security Guard রাখার মতো, যে আপনার Website কে খারাপ Website থেকে বাঁচায়।

## DNS সেটিংস পরিবর্তন করার সবচেয়ে সহজ উপায় Control Panel এর মাধ্যমে 🛠️

DNS সেটিংস পরিবর্তন করার অনেক উপায় আছে। Windows এর সেটিংস App টা অনেকের কাছে জটিল মনে হতে পারে, আবার Powershell Script ব্যবহার করাটাও সবার জন্য সহজ নয়। কিন্তু আমার মতে সবচেয়ে সহজ এবং কার্যকরী উপায় হলো Control Panel ব্যবহার করা। এই পদ্ধতিতে কোনো প্রকার টেকনিক্যাল জ্ঞান ছাড়াই খুব সহজে সেটিংস পরিবর্তন করা যায়। অনেকটা যেন Lego Building করার মতো, যেখানে আপনি একটা একটা করে পার্টস জোড়া লাগাচ্ছেন! 🧱 তাহলে চলুন, Step by Step দেখে নেয়া যাক কিভাবে এই সেটিংস পরিবর্তন করতে হয়:

১. **Control Panel খুলুন:** একেবারে প্রথমে আপনার Computer এর Taskbar এ Search অপশনে যান। সেখানে "control" লিখে Search করুন এবং Control Panel খুলুন। Control Panel হলো Windows এর একটা গুরুত্বপূর্ণ অংশ, যেখানে আপনি আপনার Computer এর প্রায় সব সেটিংস পরিবর্তন করতে পারবেন। এটা অনেকটা আপনার Computer এর কন্ট্রোল রুমের মতো! 🕹️

![CONTROL](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_bd97c4578920a2b43a7d7f09dab919d7.png)

২. **View by Large Icons:** Control Panel খোলার পর, উপরের ডানদিকে "View By" অপশন থেকে "Large Icons" সিলেক্ট করুন। এতে Control Panel এর সব অপশনগুলো বড় বড় Icon আকারে দেখাবে, যা ব্যবহার করতে অনেক বেশি সুবিধা হবে। এটা অনেকটা Menu Card দেখার মতো, যেখানে সবকিছু পরিষ্কারভাবে সাজানো থাকে! 📄

![View by Large Icons](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_832bd7b0d1318ea3af8659ed34d4ce2b.png)

৩. **Network and Sharing Center:** এরপর "network and Sharing Center" অপশনটিতে ক্লিক করুন। এখানে আপনি আপনার Network কানেকশন এবং Internet সেটিংস সম্পর্কিত সব তথ্য একসাথে দেখতে পারবেন। এটা অনেকটা আপনার বাড়ির Network এর Map দেখার মতো! 🗺️

![Network and Sharing Center](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_0370f7833ca9fee62f91793c382b82ce.png)

৪. **Change Adapter Settings:** network and Sharing Center খোলার পর, বামদিকের প্যানে "Change Adapter Settings" অপশনটিতে ক্লিক করুন। এখানে আপনি আপনার Computer এর সাথে কানেক্টেড Network Adapters গুলোর একটি List দেখতে পারবেন। Network Adapter হলো সেই ডিভাইস, যা আপনার Computer কে Internet এর সাথে কানেক্ট করতে সাহায্য করে। এটা অনেকটা আপনার Computer এর Internet Port এর মতো! 🔌

![Change Adapter Settings](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_38b6c2060dbe3a784b0a03f8423221ab.png)

৫. **Properties:** আপনার Active Internet কানেকশনের উপর রাইট ক্লিক করুন এবং "Properties" অপশনটি সিলেক্ট করুন। Properties Window টি খুললে আপনি কানেকশনটির বিভিন্ন সেটিংস দেখতে পারবেন।

![properties](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_d7152f5d9b17d970e2bf6e3c01804aa4.png)

৬. **Internet Protocol Version 4 (i Pv4):**

Properties Window তে "Internet Protocol Version 4 (TCP/i Pv4)" খুঁজে বের করুন (স্ক্রল করতে হতে পারে)। খুঁজে পাওয়ার পর, নিশ্চিত করুন যে এটি চেক করা আছে। এরপর এটি সিলেক্ট করে "Properties" বাটনে ক্লিক করুন। I Pv4 হলো Internet এ যোগাযোগের জন্য সবচেয়ে বেশি ব্যবহৃত Protocol।

![Internet Protocol Version 4](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_34ee331d9193b4f8181b63ee285379ac.png)

নতুন যে Window টি খুলবে, সেটির নিচের দিকে "Use the Following DNS Server Addresses" অপশনটি সিলেক্ট করুন। এই অপশনটি সিলেক্ট করার মাধ্যমে আপনি নিজের পছন্দের DNS Server ব্যবহার করতে পারবেন। ডিফল্ট অপশনটি সিলেক্ট করা থাকলে আপনার ISP এর DNS Server ব্যবহৃত হবে।

![Use the following DNS server addresses](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_e8b210b65981b559a12210747fa0e8e8.png)

এখানে "Preferred DNS Server" এবং "alternate DNS Server" এর Addresses লিখতে হবে। এই Address গুলোই আপনার Internet কানেকশনের জন্য DNS Server হিসেবে কাজ করবে। "Preferred DNS Server" হলো আপনার Primary DNS Server, এবং "alternate DNS Server" হলো Backup হিসেবে ব্যবহৃত হবে, যদি Primary Server টি কোনো কারণে কাজ না করে।

![Preferred DNS server এবং Alternate DNS server](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_da622075fa0466d0d38af5230b1a2f36.png)

একটা উদাহরণ দেই, Cloudflare এর Server ব্যবহার করলে:

- Preferred DNS Server: 1.1.1.1
- Alternate DNS Server: 1.0.0.1

সবশেষে "OK" বাটনে ক্লিক করে সেটিংস সেভ করুন।

## সেরা DNS Server কোনটি? 🤔 কিভাবে খুঁজে বের করবেন? 🧐 আপনার জন্য পারফেক্ট DNS Server! 🎯

Internet এ অনেক Public DNS Server পাওয়া যায়, যেমন Cloudflare, Google DNS, Open DNS ইত্যাদি। এদের প্রত্যেকেরই নিজস্ব কিছু বৈশিষ্ট্য আছে, এবং এদের মধ্যে কোনটি আপনার জন্য সবচেয়ে ভালো, তা কয়েকটি বিষয়ের উপর নির্ভর করে। আপনার Location, আপনার ISP, এবং আপনার Network এর কন্ডিশনের উপর ভিত্তি করে এক একটি Server এক এক রকম পারফর্মেন্স দিতে পারে। তাই আমি আপনাদের পরামর্শ দেব, কয়েকটা Server পরীক্ষা করে দেখুন, এবং যেটি সবচেয়ে ভালো কাজ করে, সেটি ব্যবহার করুন। এটা অনেকটা পোশাক কেনার মতো, কয়েকটা ট্রায়াল দিয়ে দেখুন, যেটা সবচেয়ে ফিট হয়, সেটাই কিনে নিন! 👕

এখানে কয়েকটি বিষয় মনে রাখতে হবে:

- **Location:** আপনার Location থেকে DNS Server এর দূরত্ব যত কম হবে, Response Time তত ভালো হবে। Response Time হলো সেই সময়, যা একটি DNS Query Resolve করতে লাগে। Response Time কম হওয়া মানে Internet Speed বেশি হওয়া।
- **RelIAbilITy:** DNS Server টিকে Reliable হতে হবে, মানে Server টিকে সবসময় Online থাকতে হবে এবং কোনো Problem ছাড়াই কাজ করতে হবে। Reliable Server আপনার Internet কানেকশনকে সবসময় Active রাখবে।
- **SECURITy:** কিছু DNS Server ক্ষতিকর Website এবং Phishing Attacks থেকে আপনার Device কে রক্ষা করে। এই Server গুলো Automatically খারাপ Website গুলোকে ব্লক করে দেয়, যা আপনার Online Security -কে আরও শক্তিশালী করে।
- **PrivACy:** কিছু DNS Server আপনার Online Activity ট্র্যাক করে না, যা আপনার Privacy রক্ষার জন্য খুবই জরুরি।

আমি ব্যক্তিগতভাবে Cloudflare ব্যবহার করি, এবং আমার জন্য এটা খুবই ভালো কাজ করে। এর কারণ হলো Cloudflare দ্রুত Response Time দেয় এবং এটি খুবই Secure। এছাড়াও, আমার ISP, মানে AT&T, DNS Handling এর জন্য খুব একটা সুবিধার নয়। তাই DNS Server পরিবর্তন করার পর আমি Internet Speed এ একটা বড় পার্থক্য দেখতে পেয়েছি। 😊 এটা অনেকটা নতুন চাকা লাগানোর মতো, যা আপনার গাড়ির গতি বাড়িয়ে দেয়! 🚗
