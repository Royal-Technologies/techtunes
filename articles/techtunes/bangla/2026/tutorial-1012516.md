## ImgToLink+ কিভাবে ব্যবহার করবেন? Step-by-Step গাইড:

![ImgToLink+ কিভাবে ব্যবহার করবেন? Step-by-Step গাইড](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_cac49d397807010bf9ee65b454b1e018.jpg)

চলুন, দেখে নেয়া যাক কিভাবে ImgToLink+ ব্যবহার করে ঝটপট ছবি Upload এবং Share করা যায়:

১. **Open করুন এবং ছবি Upload করুন:** প্রথমে ImgToLink+ Image Hosting Platform এ যান। সেখানে Upload Function দেখতে পাবেন। সরাসরি Click করে ছবি Select করুন অথবা Drag করে Website এ ছেড়ে দিন। খেয়াল রাখবেন, File Size যেন 50 MB এর বেশি না হয়।

![ছবি Upload করুন](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_c344fd8e849219b83d58f8db71ea260a.png)

২. **Single Upload Limit এর দিকে খেয়াল রাখুন:** এখানে Batch Upload Supported নয়। তাই একসাথে অনেকগুলো ছবি Drag করলেও, শুধুমাত্র একটি ছবি Upload হবে। Upload Speed বেশ ভালো, তাই Page টি Open রেখে অপেক্ষা করুন, যতক্ষণ না Upload শেষ হয় এবং Link তৈরি হয়।

![Single Upload process](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_6d6a456adb1ed5fb262d7590d4cfaaae.png)

৩. **Link দেখুন এবং সংগ্রহ করুন:** Upload Complete হওয়ার পরে, Upload করা Image এর File Name এবং File Size দেখতে পাবেন। "View Image & Get Links" এ Click করে Image দেখুন এবং Share Link সংগ্রহ করুন। নিচে একটা "Delete Link" পাবেন। যদি কখনো ছবি Delete করার প্রয়োজন হয়, তাহলে এই Link টি Save করে রাখুন।

![Link দেখুন এবং সংগ্রহ করুন](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_ca0162ce3a670ca0798d8a343121f0ad.png)

৪. **বিভিন্ন Format এ Share Code পান:** Image Link Open করার পরে আপনি আপনার Image টি দেখতে পাবেন। তার নিচে File Name, File Size, View Count এবং Direct Link Clicks এর তথ্যও দেখতে পারবেন। ডান দিকে Image এর Direct Link পাবেন, যা অন্য Website এ Image Paste করার জন্য খুব Useful। এছাড়াও, HTML, BBCode এবং Markdown Format ও Copy করার অপশন তো আছেই!
