## Looperman কিভাবে Use করবেন? A Step-by-Step Guide 💻 একদম Beginner দের জন্যও!

১. **Looperman Website Open করুন এবং Basic Layout সম্পর্কে জানুন:** প্রথমে আপনার Web Browser এ Looperman Website টি Open করুন। Homepage এই আপনি Recent Uploads, Popular Creator এবং বিভিন্ন Free Music Loops Material দেখতে পাবেন। প্রতিটি Music Material এর Thumbnail এর উপর Title, Creator Name, Upload Date, Music Waveform (visually representation of the sound), Time Duration এর মতো দরকারী Information দেওয়া থাকে।

![Looperman Website](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_5c1252755f535a61ddb7d0494c1efa1c.png)

এগুলোতে ক্লিক করলে একটু নিচের দিকে Tag Section এ Music Speed (BPM - Beats Per Minute), Music Style (Genre), Beat Marking (Time Signature), File Size এবং Music Key এর মতো Technical Details ও পেয়ে যাবেন। এই Information গুলো আপনাকে সঠিক Material টি খুঁজে পেতে সাহায্য করবে।

![Tag Section](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_ee786edce22df3ee91d15837bf8cc8b8.png)

২. **আপনার প্রয়োজনীয় Material Type Select করুন:** Looperman এর Top Menu Bar থেকে আপনার যা প্রয়োজন, সেই Material Type Select করুন। Music Loops, Vocal Samples (Acapellas), Single Tracks, Sound Effects অথবা Music Production Software – আপনার Production এর জন্য যা দরকার, সেটিতে Click করুন।

![Material Type Select](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_d27acfca9202a86f7f719da91c4b1ab1.png)

৩. **Advanced Search Function Use করে Result Refine করুন:** Material Type Select করার পর, আপনার Specific Requirement অনুযায়ী Material খুঁজে পেতে Advanced Search Function Use করুন। Keyword, Genre, Speed (Tempo), Key, Instrument, Mood ইত্যাদি Criteria Use করে Search Result কে আরও Refine করতে পারবেন। এতে আপনার Time বাঁচবে এবং Specific Material খুঁজে পাওয়া সহজ হবে।

![Advanced Search Function Use](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_9f9f80431b62bd783b9eb12150402952.png)

৪. **Account Registration করুন এবং Material Download করুন:** Looperman থেকে Free Material Download করার জন্য একটি Account Create করা Mandatory (বাধ্যতামূলক)। Music Player এর ঠিক নিচে "Login" Button এ Mouse Hover (রাখুন) করলেই Registration Link দেখতে পাবেন। Registration Page এ User Name, Email, Country, Password এর মতো Basic Information দিয়ে একটি Account Create করুন। এরপর আপনার Email Inbox এ একটি Verification Mail যাবে। Mail টি Open করে Link Click করে Account Activate করুন।

![Account Registration করুন](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_a993a73f251ac76f513f499f01cb167a.png)

৫. **Authorization Instruction ভালো করে পড়ুন এবং মেনে চলুন:** Material Download করার আগে অবশ্যই Material টির Authorization Instruction (Use Policy) ভালো করে দেখে নিবেন। Material টি Commercial Use এর জন্য Free কিনা, কোনো Restriction আছে কিনা, অথবা Attribution (Credit দিতে হবে কিনা) - এইসব Details ভালোভাবে জেনে নিবেন। যদি কোনো Restriction থাকে, তবে Material টি Use করা থেকে বিরত থাকুন।
