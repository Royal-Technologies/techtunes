## IPFS: কেন আপনার Picture এর জন্য Perfect একটা ঠিকানা?

![IPFS](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_604040d0afa67ca5753705c27c76dd60.png)

IPFS (Inter Planetary File System) হলো একটা Decentralized File System, যেটা Centralized Server এর ধারণাকে চ্যালেঞ্জ করে। সহজ ভাষায় বলতে গেলে, IPFS হলো একটা ক্লাইডের মতো, যেখানে আপনার Picture সারা বিশ্বে ছড়িয়ে থাকা বিভিন্ন Computer এ Store করা থাকে।

এখন প্রশ্ন হলো, এটা কিভাবে কাজ করে? যখন আপনি IPFS এ কোনো Picture আপলোড করেন, তখন সেই Picture টা ছোট ছোট অংশে ভাগ হয়ে যায়, এবং প্রতিটি অংশের একটা Unique Hash তৈরি হয়। এই Hash টাই হলো আপনার Picture এর Address। এরপর এই অংশগুলো Network এর বিভিন্ন Node এ Store করা হয়।

IPFS এর সবচেয়ে বড় সুবিধা হলো, যখন কেউ আপনার Picture Access করতে চায়, তখন IPFS সবচেয়ে কাছের Node থেকে Data টা Delivery করে। ফলে স্পীড নিয়ে কোনো চিন্তা করতে হয় না। আর যেহেতু Data অনেকগুলো Node এ Store করা থাকে, তাই একটা Server Down হয়ে গেলেও আপনার Picture গায়েব হয়ে যাওয়ার কোনো ভয় নেই।

IPFS অনেকটা টরেন্টের মতো কাজ করে, তবে টরেন্টের চেয়েও অনেক বেশি Smart। টরেন্টে যেমন File Seeding এর উপর নির্ভর করতে হয়, IPFS এ তেমনটা নয়। এখানে আপনার Data অটোমেটিকভাবে রেপ্লিকেট করা হয়, তাই সব সময় Available থাকার নিশ্চয়তা থাকে।
