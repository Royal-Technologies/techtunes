টেকটিউনস বন্ধুরা, আপনারা যারা Self-Hosting এবং Docker নিয়ে কাজ করতে পছন্দ করেন, তাদের জন্য আজ আমি নিয়ে এসেছি এক দারুণ খবর। সাধারণত Docker Containers ম্যানেজ করার জন্য আমাদের ল্যাপটপ বা পিসির সামনে বসতে হয় অথবা ব্রাউজারের ছোট স্ক্রিনে Portainer এর ড্যাশবোর্ড ব্যবহার করতে হয়, যা বেশ কষ্টকর। কিন্তু কেমন হয় যদি আপনি আপনার পকেটে থাকা Smartphone দিয়েই এই পুরো কাজটি নিয়ন্ত্রণ করতে পারেন? আজ আমরা আলোচনা করব AndroTainer নিয়ে, যা আপনার Docker Management এর অভিজ্ঞতাকে বদলে দিতে পারে।

## AndroTainer আসলে কী?

![AndroTainer আসলে কী?](https://dnc.techtunes.io/tDrive/tuner/2026/03/techtunes_31b5abb63fbcbcfbe1d289dd6c2dc300.png)

AndroTainer হলো একটি আধুনিক এবং শক্তিশালী Companion App, যা মূলত আপনার Self-Hosted Portainer Service-এর সাথে সংযোগ স্থাপন করে। এটি কোনো একক বা স্বতন্ত্র Docker Manager নয়, বরং আপনার বিদ্যমান Portainer সার্ভারের একটি মোবাইল ইন্টারফেস। আপনার Android Device ব্যবহার করে অত্যন্ত সহজে এবং স্বাচ্ছন্দ্যে Containers ম্যানেজ করার জন্য এই অ্যাপটি তৈরি করা হয়েছে।

## ব্যবহারের আগে যা জানা প্রয়োজন

![ব্যবহারের আগে যা জানা প্রয়োজন](https://dnc.techtunes.io/tDrive/tuner/2026/03/techtunes_956fbcb2e0f42d212e862a1b296952f7.jpg)

এই অ্যাপটি ব্যবহার করার জন্য আপনাকে কিছু প্রাথমিক শর্ত পূরণ করতে হবে। এগুলো নিশ্চিত না করলে আপনি অ্যাপটির পূর্ণ সুবিধা নিতে পারবেন না:

1. আপনার একটি Portainer Service সচল বা Up And Running থাকতে হবে।
2. আপনার সিস্টেমে আগেই একটি Username এবং Password সেট করা থাকতে হবে, যা আপনি অ্যাপে লগইন করার সময় ব্যবহার করবেন।
3. আপনি কানেক্টিভিটির জন্য আপনার সার্ভারের Local URL Address (যেমন আপনার ঘরের নেটওয়ার্কের IP) অথবা ইন্টারনেটের মাধ্যমে অ্যাক্সেস করার জন্য External URL ব্যবহার করতে পারেন।

## AndroTainer এর অসাধারণ সব ফিচারসমূহ

![AndroTainer এর অসাধারণ সব ফিচারসমূহ](https://dnc.techtunes.io/tDrive/tuner/2026/03/techtunes_4e40a26227e37d9ad9dd61ef84350d8d.jpg)

এই অ্যাপটি এমনভাবে ডিজাইন করা হয়েছে যাতে একজন ইউজার তার প্রয়োজনীয় সব কাজ দ্রুত সেরে নিতে পারেন। এর ফিচারগুলো নিচে বিস্তারিতভাবে দেওয়া হলো:

- Current State Monitoring: আপনার সব Docker Containers বর্তমানে কী অবস্থায় আছে (Running, Stopped, Or Paused) তা এক পলকেই দেখে নিতে পারবেন।
- Operational Control: প্রয়োজন অনুযায়ী আপনি সরাসরি অ্যাপ থেকেই Docker Containers শুরু (Start) অথবা বন্ধ (Stop) করতে পারবেন। এটি জরুরি সময়ে অত্যন্ত কার্যকর।
- Detailed Logs Monitoring: আপনি যদি দেখতে চান আপনার কন্টেইনারের ভেতরে কী ঘটছে, তবে যেকোনো Container Card-এর ওপর Long Press করলেই সরাসরি Container Logs দেখতে পাবেন।
- Deep Dive into Details: কন্টেইনারের কনফিগারেশন বা অন্যান্য তথ্য জানতে যেকোনো Container Card-এর ওপর ক্লিক করলেই আপনি Container Details এর পাতায় চলে যাবেন।
- Endpoint Switching: আপনার একই Portainer Server-এ যদি একাধিক Docker Endpoints থাকে, তবে আপনি খুব সহজেই সেগুলোর মধ্যে সুইচ করতে পারবেন।
- Multi-Server Support: আপনার যদি আলাদা আলাদা জায়গায় একাধিক Portainer Servers থাকে, তবে এই অ্যাপটি ব্যবহার করে আপনি সবগুলোকে একই প্ল্যাটফর্ম থেকে নিয়ন্ত্রণ করতে পারবেন।

## অ্যাপটি কীভাবে আপনার ডিভাইসে ইন্সটল করবেন?

![অ্যাপটি কীভাবে আপনার ডিভাইসে ইন্সটল করবেন?](https://dnc.techtunes.io/tDrive/tuner/2026/03/techtunes_03115c5e606c840769a739d0b929ccc0.jpg)

AndroTainer মূলত IzzyOnDroid F-Droid Repository-তে পাওয়া যায়। আপনি চাইলে সরাসরি APKs ফাইল ডাউনলোড করে নিতে পারেন, তবে সবচেয়ে ভালো উপায় হলো একটি F-Droid Client ব্যবহার করা। এতে করে অ্যাপটির নতুন কোনো আপডেট আসলে তা স্বয়ংক্রিয়ভাবে আপনার ডিভাইসে পৌঁছে যাবে।

কিছু নির্দিষ্ট ক্লায়েন্ট যেমন Sunil-এর তৈরি ক্লায়েন্টে এই Repo বা রিপোজিটরি আগে থেকেই এনাবল থাকে। তবে অন্যদের ক্ষেত্রে (যেমন:) আপনাকে ম্যানুয়ালি এই রিপোজিটরি অ্যাড করতে হতে পারে। এটি কীভাবে করবেন, তার জন্য রিপোজিটরি পেজের ওপরের দিকে থাকা Hint অপশনটি দেখে নিতে পারেন।

## টেকনিক্যাল ইন-ডেপথ: AndroTainer এর পেছনের কারিগরি শক্তি

![টেকনিক্যাল ইন-ডেপথ](https://dnc.techtunes.io/tDrive/tuner/2026/03/techtunes_02d601070870822c0cfa944dfab8f294.jpg)

একটি অ্যাপ কতটা শক্তিশালী তা নির্ভর করে সেটি তৈরিতে ব্যবহৃত লাইব্রেরি এবং ফ্রেমওয়ার্কের ওপর। AndroTainer তৈরিতে অসংখ্য আধুনিক টেকনোলজি ব্যবহার করা হয়েছে। নিচে তার একটি পূর্ণাঙ্গ তালিকা এবং সংক্ষিপ্ত ব্যাখ্যা দেওয়া হলো:

- Gson (Utility): এটি একটি বিখ্যাত Java Serialization/Deserialization Library। এর কাজ হলো Java Objects-কে JSON ফরম্যাটে রূপান্তর করা এবং উল্টোটা করা। ডাটা আদান-প্রদানে এটি অপরিহার্য।
- JavaX Annotation API (Utility): JavaTM Platform API-এর জন্য কিছু কমন Annotations এটি প্রদান করে, যা কোডিংয়ের মান উন্নত করে।
- Android Support Library (Development Framework): এটি কোনো একটি লাইব্রেরি নয়, বরং অনেকগুলো লাইব্রেরির সমষ্টি। এটি মূলত Compatibility এবং Component Libraries—এই দুই ভাগে বিভক্ত। বিস্তারিত জানতে Understanding The Android Support Library গাইডটি দেখা যেতে পারে।
- AppCompat (Utility): এটি একটি Base Activity Subclass প্রদান করে, যা অ্যাপের গঠন সুন্দর এবং সামঞ্জস্যপূর্ণ রাখতে সাহায্য করে।
- AndroidX Annotation (Utility): Android Jetpack-এর জন্য প্রয়োজনীয় বিশেষ কিছু Annotations এই লাইব্রেরিতে থাকে।

- AndroidX AppCompat Resources (Utility): পুরানো অ্যান্ড্রয়েড ফোনগুলোতে আধুনিক অ্যান্ড্রয়েড ফিচার সাপোর্ট করার জন্য এটি কাজ করে।
