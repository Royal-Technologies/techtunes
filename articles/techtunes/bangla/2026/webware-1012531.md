## CDN: কিভাবে এটা Website এর স্পীড বাড়ায়?

![CDN: কিভাবে এটা Website এর স্পীড বাড়ায়?](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_0d42715a0e6dd6f22be7568c3c2a9659.jpg)

CDN (Content Delivery Network) হলো ভৌগোলিকভাবে বিভিন্ন স্থানে ছড়িয়ে থাকা Server এর একটা Network। এই Server গুলোতে আপনার Website এর Content (ছবি, Video, Text ইত্যাদি) Cache করা থাকে। যখন কোনো User আপনার Website ভিজিট করে, তখন তার Location এর সবচেয়ে কাছের CDN Server থেকে Content সরবরাহ করা হয়। এতে Website দ্রুত Load হয়।

বিষয়টা সহজভাবে বোঝানো যাক। ধরুন, আপনার Website এর Server ঢাকাতে অবস্থিত। এখন যদি কেউ লন্ডন থেকে আপনার Website ভিজিট করে, তাহলে Data ঢাকা থেকে লন্ডনে যেতে কিছুটা সময় লাগবে। কিন্তু যদি আপনার Website CDN Use করে, তাহলে লন্ডনের Visitor তার কাছাকাছি CDN Server থেকে Data পাবে, এবং Website দ্রুত Load হবে।

Cloudflare এর মতো অনেক Service CDN এর সুবিধা দেয়। তবে Gumlet বিশেষভাবে Image Optimization এর ওপর জোর দেয়।
