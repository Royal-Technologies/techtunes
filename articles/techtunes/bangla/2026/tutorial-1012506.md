## CSV File: DATA সংরক্ষণের সহজ মাধ্যম! 🗄️

![CSV File: DATA সংরক্ষণের সহজ মাধ্যম!](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_7aa634856bcd10d901d6d8690103658b.jpg)

CSV (Comma-Separated VALUES) File হলো DATA সংরক্ষণের একটি Simple FORMAT। এটা Text Based FORMAT, যেখানে Table আকারে DATA গুলো কমা (, ) দিয়ে আলাদা করা থাকে। আপনি যদি Microsoft EXCEL বা Google SHEETS ব্যবহার করে থাকেন, তাহলে CSV File এর সাথে পরিচিত হওয়ার কথা। এই FORMAT টি বহুলভাবে ব্যবহৃত হয়, কারণ এটা সহজে তৈরি করা যায় এবং যেকোনো Program দিয়ে Open করা যায়।

কিন্তু CSV File এর একটা সমস্যা আছে। সরাসরি Text Editor দিয়ে Open করলে DATA গুলো এলোমেলো দেখায়, Column এবং Row গুলো বোঝা যায় না। 😵 DATA Edit করা বা Convert করাও বেশ কঠিন। এই সমস্যার সমাধানের জন্যই CSVInk এর আবির্ভাব।
