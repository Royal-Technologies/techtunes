## MozJPEG কিভাবে ব্যবহার করবেন? A to Z Step-by-Step গাইড 📝

![MozJPEG কিভাবে ব্যবহার করবেন?](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_e23c8c5abde4ff6e8194d42622379708.jpg)

MozJPEG ব্যবহার করা এতটাই সহজ যে, বাচ্চারাও এটা ব্যবহার করতে পারবে! আমি Step-by-Step পুরো Process টা বুঝিয়ে দিচ্ছি:

১. **Picture File Select করুন:** প্রথমে MozJPEG এর অফিসিয়াল Website এ যান। তারপর "Select files" Button এ Click করে আপনার Computer থেকে Picture Select করুন। আপনি চাইলে Picture গুলো Drag করে Website এ Drop ও করতে পারেন। মনে রাখবেন, এটা শুধু JPEG/JPG এবং PNG Format Support করে। অন্য Format এর Picture Upload করলে কোনো কাজ হবে না। ⛔

![Select files](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_daea436707aaed3d3c1979f0f9d945ea.png)

২. **Compression এর জাদু স্বচক্ষে দেখুন:** Picture Upload করার পর MozJPEG Automatic-ভাবে Picture Compress করা শুরু করবে। Compression হয়ে গেলে, প্রতিটি Picture এর File Size এর পরিবর্তন দেখতে পারবেন, সাথে Compression Ratio ও প্রদর্শিত হবে। JPG Picture এর ক্ষেত্রে Result সাধারণত খুবই সন্তোষজনক হয়। তবে PNG Format এর ক্ষেত্রে Result কিছুটা ভিন্ন হতে পারে। তাই Upload করার আগে একটু Test করে দেখা বুদ্ধিমানের কাজ। 🤔

![Compression](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_1505fd8e91e76f25811ab3c7c5ecc2dc.png)

৩. **সব Picture একসাথে Save করুন:** যদি আপনি Batch Compression করে থাকেন, তাহলে সব Picture একসাথে Download করার জন্য "Save all images" Button এ Click করুন। তাহলে একটি.zip File Download হবে, যেটার মধ্যে আপনার সব Compressed Picture গুলো সাজানো থাকবে। 📁

![Save all images](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_c9cee72a572425d803b60ce758035ae9.png)

৪. **Editing Tool ব্যবহার করুন মনের মতো:** প্রতিটি Picture এর পাশে "Edit" Option দেখতে পাবেন। এখানে Click করলে একটা নতুন Page খুলবে।

এখানে আপনি Picture Crop, Color Adjustment, Resize, Marking, Filter -এর মতো Editing Tool গুলো ব্যবহার করতে পারবেন। যেহেতু Editing আপনার Browser এই হচ্ছে, তাই আপনার Picture Third-Party Server এ যাওয়ার কোনো চান্স নেই। 🔒
