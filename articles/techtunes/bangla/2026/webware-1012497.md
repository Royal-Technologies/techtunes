আসসালামু আলাইকুম, প্রিয় টেকটিউনস বন্ধুরা! কেমন আছেন সবাই? আশাকরি ভালো আছেন। আজকের  টিউনে আমি আপনাদের জন্য নিয়ে এসেছি ডিজিটাল দুনিয়ার একটা দারুণ জিনিস – MiniQR! আমরা সবাই এখন Technology-র ওপর নির্ভরশীল, আর QR Code তার একটা গুরুত্বপূর্ণ অংশ। ভাবুন তো, কোনো Website-এ Visit করা, Online Payment করা, অথবা বন্ধুদের সাথে Wi-Fi Password share করা – সব কিছু কত সহজে হয়ে যায়, তাই না? QR Code যেন এক ক্লিকেই সব সমস্যার সমাধান!

কিন্তু সমস্যা হলো, নিজের মনের মতো, একটা সুন্দর Custom QR Code বানানোর জন্য সহজে কোনো ভালো Tool খুঁজে পাওয়া যায় না। অনেক Website-এ Customisation-এর Option থাকলেও, সেগুলো হয় Paid, নয়তো Open Source নয়। তাই আজ আমি আপনাদের সাথে পরিচয় করিয়ে দেব MiniQR-এর সাথে – একটা সম্পূর্ণ ফ্রি এবং Open Source QR Code জেনারেটর! এটা শুধু ফ্রি না, এটা ব্যবহার করাও খুবই সহজ। তাহলে চলুন, দেরি না করে জেনে নেই MiniQR সম্পর্কে বিস্তারিত।

## MiniQR আসলে কী? কেন এটা দরকার?

![MiniQR](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_e670c25a8f0cb796d03c439fc2af3167.png)

MiniQR হলো একটা Web Based Application। এর মাধ্যমে Users খুব সহজে Professional মানের QR Code Image Generate করতে পারে। ধরুন, আপনি আপনার Business-এর জন্য একটা QR Code বানাতে চান, যেখানে আপনার Company-র Logo থাকবে, Website-এর Link থাকবে, এবং Design টাও হবে আপনার Brand-এর সাথে মানানসই। MiniQR আপনাকে সেই সুযোগ করে দেবে একদম ফ্রীতে!

সবচেয়ে মজার বিষয় হলো, MiniQR Open Source। এর মানে হলো, আপনি যদি একজন Developer হন, তাহলে এর Source Code দেখতে পারবেন, নিজের মতো করে Edit করতে পারবেন, এবং নিজের Server-এ Host করতে পারবেন। তাই MiniQR শুধু একটা Tool নয়, এটা একটা Complete Solution!

MiniQR ব্যবহারের সুবিধাগুলো হলো:

- সহজে ব্যবহারযোগ্য Interface: MiniQR-এর Interface খুবই User-Friendly। নতুন Users-ও কোনো ঝামেলা ছাড়াই QR Code Generate করতে পারবে।
- Customisation-এর সুযোগ: আপনি আপনার QR Code-এর Design, Color, Style – সবকিছু নিজের মতো করে Customise করতে পারবেন। Company Logo যোগ করার Option তো আছেই!
- ফ্রেমিং Feature: MiniQR-এর Frame Feature টা আমার সবচেয়ে ভালো লেগেছে। QR Code-এর চারপাশে সুন্দর Text Description যোগ করা যায়, যা User-দের জন্য Information-টা বুঝতে সুবিধা করে। আলাদা করে কোনো Image Editing Software ব্যবহার করার দরকার নেই।
- বিভিন্ন Format-এ Export: আপনি আপনার QR Code PNG, JPG, বা SVG – যেকোনো Format-এ Download করতে পারবেন।
- QR Code Scan করার Feature: MiniQR শুধু QR Code Generate করাই না, এটা দিয়ে আপনি যেকোনো QR Code Scan ও করতে পারবেন।

## MiniQR দিয়ে কিভাবে QR Code বানাবেন? Step-by-Step Guide!

![MiniQR দিয়ে কিভাবে QR Code বানাবেন?](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_b86c165a166e4b0e1dfa75bb9acc40a6.jpg)

MiniQR ব্যবহার করা খুবই সহজ। নিচে Step by Step Guide দেওয়া হলো, যাতে আপনারা নিজেরাই সুন্দর QR Code বানিয়ে নিতে পারেন:

১. **QR Code Style নির্বাচন করুন:** প্রথমে MiniQR এর অফিসিয়াল Website-এ যান। তারপর "QR Code Setting" Section থেকে আপনার পছন্দের Style Select করুন। যদি সাধারণ Black and White QR Code চান, তাহলে "Plain" Option-টা Select করুন। এতে User-রা সহজেই বুঝতে পারবে যে এটা একটা QR Code। এছাড়া বিভিন্ন Option আছে, যেগুলো Click করে আপনি Preview দেখতে পারবেন।

![MiniQR Website](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_d9e39660eb0cc8b59c8ec34abe46470d.png)

২. **Data Input করুন এবং Custom Option গুলো Set করুন:** "Data To Encode" Field এ আপনার Website Address অথবা অন্য যেকোনো Information লিখুন, যা আপনি Encode করতে চান। আপনি চাইলে CSV File Upload করে একসাথে অনেক Data Batch Import করতে পারবেন। "Data Template" Section-এ আপনি Text, Email, Phone Number, SMS, Wi-Fi Details, vCard (Contact Information), Location, বা Event – যেকোনো Data Type Select করতে পারবেন। আপনার প্রয়োজন অনুযায়ী Data Select করে Information দিন।

![Data To Encod](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_f41fae93834e4b87637bbae3b2da072a.png)

৩. **Company Logo যোগ করুন**: "Logo Picture" Option-টা ব্যবহার করে আপনার QR Code-এ Company Logo যোগ করতে পারবেন। "Upload Image" Click করে আপনার Logo Select করুন। Logo Upload করার সাথে সাথেই Preview Section-এ দেখতে পারবেন। Logo-টা মাঝখানে বসবে এবং QR Code-এর Design-এর সাথে মিশে যাবে।

![Logo Picture](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_0227fbc1e5fea03a24aa8fba79701314.png)

৪. **Color এবং অন্যান্য Option গুলো Customise করুন:** MiniQR-এ Customisation-এর অনেক Option আছে। আপনি Background Color, Dot Color (QR Code-এর ভেতরের Dots-গুলোর Color), Corner Shape Color – সবকিছু নিজের ইচ্ছেমতো Set করতে পারবেন। Picture Size, Border Radius (QR Code-এর Corner-গুলো Round করার জন্য), Image Margin (QR Code-এর চারপাশে ফাঁকা জায়গা) – এই Option-গুলোও পরিবর্তন করতে পারবেন। যদি Special কোনো Requirement না থাকে, তাহলে Default Setting-গুলোই ভালো।

![MiniQR-এ Customisation](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_03738a830057c79e262308897077170e.png)

৫. **Frame যোগ করুন (Optional):** MiniQR-এর Frame Feature-টা খুবই কাজের। "Frame Setting" Section-এ গিয়ে "Add Frame" Checkbox-টা Select করুন। তারপর আপনার Description Text লিখুন। এই Text QR Code-এর চারপাশে দেখাবে, যা User-দের বুঝতে সাহায্য করবে যে QR Code-টা আসলে কিসের জন্য।

![Frame যোগ করুন](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_5a5eeef4858ab283917b2b22d549db55.png)

৬. **Export করুন:** সবশেষে "Export" Button-এ Click করে আপনার QR Code PNG, JPG অথবা SVG Format এ Save করুন। SVG Format-টা Vector Graphics-এর জন্য, তাই এটা Print করার জন্য সবচেয়ে ভালো।

![Export করুন](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_bd61140955be6b9ee056f9df6082b8fa.png)

৭. **QR Code Scan করুন:** MiniQR-এ একটা Built-in QR Code Scanner ও আছে। আপনি যদি কোনো QR Code Scan করতে চান, তাহলে Scanner Section-এ Image Upload করুন, MiniQR automatically Code-টা Decode করে Information দেখাবে।

![QR Code Scan](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_7b5460e2c3b5bf25a61a2a9352619dcd.png)
