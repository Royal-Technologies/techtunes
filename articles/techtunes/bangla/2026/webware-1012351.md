Orbiter ব্যবহার করা এতটাই সহজ, যে একজন পাঁচ বছরের বাচ্চাও এটা ব্যবহার করতে পারবে! 👶 তবুও, আপনাদের সুবিধার জন্য নিচে একটা Step by Step গাইড দেওয়া হলো:

২. **Account Login করুন:** প্রথমে আপনাকে Account Login করতে বলা হবে। এজন্য "Get Start" ক্লিক করুন।

![Sign up](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_a01416bc69b8ccd728dba47e420aa6da.png)

Orbiter বর্তমানে GitHub ও Google এই দুইটি Platform Support করে। আপনি আপনার Existing GitHub অথবা Google Account ব্যবহার করে খুব সহজেই Orbiter-এ Login করতে পারবেন। আপনি চাইলে নতুন Account ও তৈরি করতে পারেন। 👍

![Orbiter-এ Login](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_7331ed89a597c6fc82106708096ed3d2.png)

১. **Webpage Files Upload করুন:** প্রথমে Orbiter-এ প্রবেশ করুন। Dashboard-এ আপনি Webpage Files Upload করার Option দেখতে পাবেন। "Select Folder" Button-এ Click করে আপনার Webpage Folder Select করুন। Folder Select করার সাথে সাথেই Files Automatically Upload হওয়া শুরু করবে এবং কিছুক্ষণের মধ্যেই আপনার Website তৈরি হয়ে যাবে। এই Process টি সাধারণত ৩০ সেকেন্ডের মধ্যে সম্পন্ন হয়। ⏳ Orbiter এর Fast Uploading System এর কারণে, Files Upload হতে বেশি সময় লাগে না।

![Webpage Files Upload](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_ac359a92cbb3ebc880a87af4c107d306.png)

উদাহরণস্বরূপ, ধরুন আপনার Folder-এ `index.htm`, `CSS` Files, Images এবং অন্যান্য Assets রয়েছে। এই Folder টি Select করার সাথে সাথেই Orbiter Files গুলো Upload করে আপনার Website তৈরি করে দেবে। Dashboard-এ আপনি Select করা Files-এর সংখ্যা দেখতে পারবেন এবং Uploading Progress ও দেখতে পারবেন।

![Select করা Files](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_f16e347bbb23038a9d6103ad7673bfd5.png)

৩. **Subdomain Name Set করুন:** Webpage Files Upload করার আগে আপনাকে একটা Subdomain Name Set করতে হবে। Orbiter আপনাকে Free-তে "orbiter.website" Domain Name ব্যবহার করার সুযোগ দেবে। যদি আপনি Custom Domain (যেমন `yourname.com`) ব্যবহার করতে চান, তাহলে আপনাকে Premium Plan এ Upgrade করতে হবে। তবে Testing এবং Personal Project এর জন্য Orbiter এর Free Subdomain যথেষ্ট। আপনি চাইলে Domain Redirect করার মাধ্যমে আপনার Custom Domain Orbiter-এ ব্যবহার করতে পারেন। 💡 Domain Redirect করার জন্য আপনাকে আপনার Domain Registrar এর Control Panel এ কিছু DNS Record Change করতে হবে।

![Subdomain Name Set](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_0435ea9ae5ffe2211e6b130e43cac3e1.png)

Files Upload হওয়ার পরে আপনি Control Panel-এ সবুজ টিক চিহ্ন দেখতে পাবেন। এই URL ব্যবহার করে আপনি আপনার Website Browse করতে পারবেন, যা সত্যিই খুব সহজ! 😃 আপনি চাইলে QR Code ব্যবহার করেও Website Access করতে পারেন।

![Control Panel-এ সবুজ টিক চিহ্ন](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_79d7dddb5688ab486f7c052753e24794.png)

এখানে একটা বিষয় মনে রাখতে হবে, Free Plan-এ Upload করার জন্য Files Size Limit ২৫ MB এবং Total Storage Limit ৫০০ MB। তাই চেষ্টা করুন আপনার Files Size Optimize করে রাখার। আপনি Image Compression Tools ব্যবহার করে Images Size কমাতে পারেন।

৪. **Website Content Update করুন:** ভবিষ্যতে যদি কখনো আপনার Website Content Update করার প্রয়োজন হয়, তাহলে Setting-এ গিয়ে "Update Site" Button Select করে নতুন Files Re-upload করুন। Orbiter Automatically আপনার Website Content Update করে দেবে। Orbiter এর Intelligent Caching System এর কারণে, Update করার সাথে সাথেই Changes গুলো Live হয়ে যাবে। এছাড়াও, Orbiter-এ Webpage Version পরিবর্তনের Option রয়েছে, যা Premium Plan Upgrade করার পরেই ব্যবহার করা যাবে। 🔄

![Website Content Update](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_4b8fabb8acf2be073b37ce4590a79c01.png)

সবসময় মনে রাখবেন, প্রতিবার Update করার সময় "All Webpage Document" Select করতে হবে। তা না হলে Website-এ Error দেখাতে পারে, অথবা Design ভেঙে যেতে পারে।

৫. **Website Browse করুন:** সবকিছু ঠিকঠাক থাকলে, Orbiter-এর দেওয়া Subdomain Name ব্যবহার করে আপনি আপনার Website Browse করতে পারবেন। Free Plan ব্যবহার করলে Website এর Footer এ Orbiter এর Branding দেখানো হবে এবং Custom Domain ব্যবহার করা যাবে না। আপনি যদি Branding Remove করতে চান এবং Custom Domain ব্যবহার করতে চান, তাহলে Premium Plan এ Upgrade করতে পারেন। 🚀

![Website Browse](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_fe8ab0bb2ad1502d37b5e57bd808b4a0.png)
