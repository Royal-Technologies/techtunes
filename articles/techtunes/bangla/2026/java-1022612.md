Java শেখা শুরু করতে গিয়ে অনেকেই প্রথম ধাপেই আটকে যান। ভিডিও দেখে JDK নামালেন, ইনস্টল করলেন, কিন্তু Command Prompt এ javac লিখতেই লেখা আসে javac is not recognized as an internal or external command. ফলে এক লাইন কোড লেখার আগেই শেখার উৎসাহটা নষ্ট হয়ে যায়।

আসল কারণটা কঠিন কিছু নয়। Windows জানে না আপনার JDK কোন ফোল্ডারে বসেছে, তাই তাকে JAVA\_HOME ও Path এর মাধ্যমে সেই ঠিকানা দেখিয়ে দিতে হয়। এই টিউনে একদম শূন্য থেকে শুরু করে JDK ইনস্টল করা, JAVA\_HOME সেট করা, Path আপডেট করা, ইনস্টলেশন যাচাই করা এবং প্রথম Java প্রোগ্রাম কম্পাইল করে রান করা পর্যন্ত প্রতিটি ধাপ দেখাব। শেষে কমন এরর গুলোর সমাধানও থাকবে, যাতে কোথাও আটকে না যান।

![উইন্ডোজে JDK ইনস্টল করার ছয়টি ধাপের চিত্র](https://dnc.techtunes.io/tDrive/tuner/2026/08/techtunes_f8a73bb4515383638e6fc0598bf98233.png)

উপরের চিত্রটিতে পুরো কাজটি এক নজরে সাজিয়ে দেওয়া হয়েছে। কোন ধাপের পর কোনটি আসবে সেটি আগেই মাথায় গেঁথে নিলে মাঝপথে আর দিশা হারাবেন না। একটি বিষয় খেয়াল করুন, আসল ইনস্টলেশনের কাজ কিন্তু মাত্র দুটি ধাপ। বাকি চারটি ধাপের পুরো উদ্দেশ্য হলো উইন্ডোজকে জানিয়ে দেওয়া যে জাভা ঠিক কোন ফোল্ডারে বসেছে, আর তারপর সেটি সত্যিই কাজ করছে কিনা তা নিজের চোখে যাচাই করে নেওয়া।

নতুন যারা শিখতে শুরু করেন তাদের বেশির ভাগই তৃতীয় আর চতুর্থ ধাপটি বাদ দিয়ে সোজা কোড লিখতে বসে যান। ফল হয় এই, ইনস্টলেশন ঠিকঠাক হওয়ার পরও টার্মিনাল জাভার কমান্ড গুলো চিনতে পারে না এবং এরর দেখায়। তাই চিত্রটি একবার ভালো করে দেখে নিয়ে তারপর নিচের ধাপ গুলোতে হাত দিন, তাহলে কোথায় কী করছেন সেটি সব সময় পরিষ্কার থাকবে।

চিত্রের ধাপ গুলো ধরে ধরে এগোলে আরেকটি সুবিধা পাবেন। কোনো ধাপে আটকে গেলে আপনি ঠিক বলতে পারবেন সমস্যাটি কোন জায়গায় হচ্ছে, ফলে সমাধান খুঁজতে গিয়ে পুরো কাজ আবার শুরু থেকে করার দরকার পড়বে না।

## যা যা লাগবে

- Windows 10 বা Windows 11 চালিত একটি কম্পিউটার
- ন্যূনতম ৪ জিবি RAM এবং ১ জিবি ফ্রি স্টোরেজ
- ইন্টারনেট সংযোগ, JDK ডাউনলোড করার জন্য
- কম্পিউটারের Administrator অনুমতি সম্পন্ন একটি অ্যাকাউন্ট

## ধাপ ১: সঠিক JDK ভার্সন বেছে নেওয়া

Java দিয়ে প্রোগ্রাম লিখতে JRE নয়, দরকার হয় JDK অর্থাৎ Java Development Kit. JRE শুধু Java প্রোগ্রাম চালাতে পারে, কিন্তু কোড কম্পাইল করার javac টুলটি থাকে শুধু JDK এর ভেতরে।

নতুন শিখতে শুরু করলে LTS অর্থাৎ Long Term Support ভার্সন বেছে নিন। LTS ভার্সন গুলো দীর্ঘদিন আপডেট পায় এবং প্রায় সব টিউটোরিয়াল ও লাইব্রেরির সাথে মিলে যায়।

- Oracle JDK অথবা ওপেন সোর্স Eclipse Temurin, দুটোর যেকোনো একটি বেছে নিতে পারেন
- আপনার কম্পিউটার 64 Bit হলে x64 Installer ফাইলটি নামান
- ডাউনলোড করার সময় ফাইলের নামের শেষে exe বা msi আছে কিনা দেখে নিন

## ধাপ ২: JDK ইনস্টল করা

ডাউনলোড শেষ হলে ইনস্টলার ফাইলটিতে ডান বাটন ক্লিক করে Run as administrator দিন। এরপর নিচের ধাপ গুলো অনুসরণ করুন।

- Welcome স্ক্রিনে Next বাটনে ক্লিক করুন
- ইনস্টলেশন লোকেশন স্ক্রিনে যে পাথটি দেখাচ্ছে তা কোথাও লিখে রাখুন, সাধারণত এটি হয় C:\Program Files\Java\jdk অথবা এর কাছাকাছি একটি ফোল্ডার
- পাথ পরিবর্তনের দরকার নেই, ডিফল্ট রেখেই Next দিন
- ইনস্টলেশন শেষ হলে Close বাটনে ক্লিক করুন

এই পাথটিই পরের ধাপে JAVA\_HOME এর মান হিসেবে লাগবে, তাই ভুল না করে হুবহু কপি করে রাখুন।

## ধাপ ৩: JAVA\_HOME এনভায়রনমেন্ট ভ্যারিয়েবল সেট করা

JAVA\_HOME হচ্ছে একটি এনভায়রনমেন্ট ভ্যারিয়েবল, যেটি Windows ও অন্য সফটওয়্যারকে জানিয়ে দেয় JDK ঠিক কোথায় আছে। পরে Maven, Gradle, Android Studio, Tomcat এর মত টুল গুলোও এই ভ্যারিয়েবল খোঁজে, তাই এটি সেট করা জরুরি।

- কীবোর্ডে Windows বাটন চেপে env লিখুন এবং Edit the system environment variables অপশনটি খুলুন
- System Properties উইন্ডোতে Environment Variables বাটনে ক্লিক করুন
- নিচের System variables অংশে New বাটনে ক্লিক করুন
- Variable name ঘরে লিখুন JAVA\_HOME
- Variable value ঘরে ধাপ ২ এ লিখে রাখা JDK ফোল্ডারের পাথ বসান, শেষে bin যোগ করবেন না
- OK বাটনে ক্লিক করে সেভ করুন

![JAVA_HOME তৈরি ও Path এডিট করার ব্যাখ্যাচিত্র](https://dnc.techtunes.io/tDrive/tuner/2026/08/techtunes_fc4bb87ae5714a2dd338fa1e7a4ddbd8.png)

উপরের ব্যাখ্যাচিত্রে দেখানো হয়েছে উইন্ডোজের এনভায়রনমেন্ট ভ্যারিয়েবলের উইন্ডোটিতে কোন অংশে কী কাজ হয়। একটি ভুল এখানে প্রায় সবাই করেন, উপরের আর নিচের তালিকা দুটিকে এক করে ফেলেন। উপরের তালিকাটি শুধু আপনার নিজের ইউজার অ্যাকাউন্টের জন্য কাজ করে, আর নিচের তালিকাটি কম্পিউটারের সব ইউজারের জন্য কাজ করে। জাভার ভ্যারিয়েবল দুটি নিচের তালিকায় বসালে পরে অন্য কোনো টুল বা এডিটর সেটি খুঁজে নিতে পারবে।

আরেকটি বিষয় মনে রাখা দরকার, JAVA\_HOME এর মান হিসেবে শুধু জেডিকে ফোল্ডারটির পাথ বসবে, শেষে bin অংশটি যোগ করা যাবে না। bin অংশটি আলাদা করে Path তালিকায় বসাতে হয় এবং সেখানে পুরো পাথ আবার না লিখে শুধু ভ্যারিয়েবলটিকে ডেকে আনলেই কাজ চলে। এভাবে লিখলে ভবিষ্যতে জাভার ভার্সন বদলালে শুধু একটি জায়গার মান বদলে দিলেই পুরো সেটআপ আবার ঠিক হয়ে যাবে। যারা একাধিক প্রজেক্টে আলাদা আলাদা ভার্সন ব্যবহার করেন তাদের জন্য এই নিয়মটি আরও বেশি কাজে দেয়, কারণ তখন ভার্সন বদলানো এক মিনিটের কাজ হয়ে যায়।

## ধাপ ৪: Path এ bin ফোল্ডার যোগ করা

Command Prompt যেকোনো ফোল্ডার থেকে java ও javac কমান্ড চিনতে পারে শুধু তখনই, যখন JDK এর bin ফোল্ডারটি Path ভ্যারিয়েবলে থাকে।

- Environment Variables উইন্ডোতে System variables অংশ থেকে Path সিলেক্ট করে Edit বাটনে ক্লিক করুন
- New বাটনে ক্লিক করে লিখুন %JAVA\_HOME%\bin
- নতুন এন্ট্রিটি Move Up বাটন দিয়ে উপরের দিকে তুলে দিন, এতে পুরনো কোনো Java ইনস্টলেশন থাকলেও নতুনটি আগে কাজ করবে
- সব উইন্ডোতে OK দিয়ে বেরিয়ে আসুন

মনে রাখবেন, Path পরিবর্তনের পর আগে থেকে খোলা থাকা Command Prompt পুরনো সেটিংস মনে রাখে। তাই খোলা থাকা সব Command Prompt বন্ধ করে নতুন করে খুলুন।

## ধাপ ৫: ইনস্টলেশন ঠিক হয়েছে কিনা যাচাই করা

নতুন একটি Command Prompt খুলে নিচের দুটি কমান্ড আলাদা আলাদা ভাবে চালান।

```
java -version
javac -version
```

দুটি কমান্ডেই যদি ভার্সন নম্বর দেখায়, তাহলে আপনার সেটআপ সফল। শুধু java কাজ করলে কিন্তু javac কাজ না করলে বুঝবেন আপনি JDK এর বদলে শুধু JRE ইনস্টল করেছেন, অথবা Path এ bin ফোল্ডারটি ভুল ভাবে বসেছে।

![java -version ও javac -version কমান্ডের আউটপুট](https://dnc.techtunes.io/tDrive/tuner/2026/08/techtunes_a6436b6a4c99184e5a80b306a985afe2.png)

উপরের চিত্রটিতে সঠিক আউটপুট আর ভুল সেটআপের এররটি পাশাপাশি রাখা হয়েছে, যাতে নিজের পর্দায় কোনটি দেখছেন তা সাথে সাথে মিলিয়ে নিতে পারেন। উপরের অংশে দুটি কমান্ডই ভার্সন নম্বর দেখাচ্ছে, অর্থাৎ সেখানে সব ঠিক আছে। তৃতীয় কমান্ডটি বেশ কাজের, এটি সরাসরি দেখিয়ে দেয় আপনার তৈরি করা ভ্যারিয়েবলের ভেতরে আসলে কোন পাথটি জমা হয়েছে।

নিচের অংশে যে লাল লেখাটি দেখছেন সেটি আসলে জাভার কোনো সমস্যা নয়, এটি উইন্ডোজের বার্তা। এর মানে দাঁড়ায়, কমান্ডটি যে ফোল্ডারে আছে সেই ফোল্ডারের ঠিকানা Path তালিকায় নেই। তাই এই এররটি দেখলে জাভা আবার নামানোর দরকার নেই, বরং আগের ধাপে ফিরে গিয়ে Path তালিকার লাইনটি ঠিক আছে কিনা আর নতুন করে টার্মিনাল খুলেছেন কিনা সেই দুটি বিষয় মিলিয়ে দেখুন।

সব ঠিক থাকলে এবার নিশ্চিন্তে পরের ধাপে যেতে পারেন। তবে একটি অভ্যাস গড়ে তুলুন, বড় কোনো সেটআপ বদলানোর পর প্রতিবার এই যাচাইয়ের কমান্ড গুলো একবার চালিয়ে নিন। এতে সমস্যা থাকলে সেটি অনেক আগেই ধরা পড়বে এবং পরে কোড লিখতে বসে অকারণে সময় নষ্ট হবে না।

## ধাপ ৬: প্রথম Java প্রোগ্রাম লিখে কম্পাইল ও রান করা

এখন কোড লেখার পালা। প্রথম প্রোগ্রামের জন্য ভারী কোনো IDE দরকার নেই, Notepad দিয়েই শুরু করা যায়। এতে ভেতরে আসলে কী ঘটছে তা পরিষ্কার বোঝা যায়।

- C ড্রাইভে JavaPractice নামে একটি নতুন ফোল্ডার তৈরি করুন
- Notepad খুলে নিচের কোডটি লিখুন
- ফাইলটি HelloTechtunes.java নামে সেভ করুন, সেভ করার সময় Save as type ঘরে All Files নির্বাচন করুন

```
public class HelloTechtunes {
    public static void main(String[] args) {
        String tuner = "টেকটিউনার";
        System.out.println("Hello Java, আমার প্রথম প্রোগ্রাম চলছে");
        System.out.println("শুভেচ্ছা, " + tuner);
    }
}
```

কোডটিতে ক্লাসের নাম HelloTechtunes এবং ফাইলের নাম HelloTechtunes.java, এই দুটি হুবহু এক হতে হয়। Java তে ছোট হাতের ও বড় হাতের অক্ষর আলাদা, তাই একটি অক্ষরের গরমিলেও কম্পাইল হবে না।

এবার Command Prompt এ ফোল্ডারটিতে গিয়ে কোড কম্পাইল করে রান করুন।

```
cd C:\JavaPractice
javac HelloTechtunes.java
java HelloTechtunes
```

কম্পাইল সফল হলে ফোল্ডারে HelloTechtunes.class নামে একটি নতুন ফাইল তৈরি হবে। এটি হচ্ছে Bytecode, যেটি JVM পড়ে প্রোগ্রামটি চালায়। শেষ কমান্ডটি দিলে স্ক্রিনে আপনার লেখা দুটি লাইন দেখতে পাবেন।

লক্ষ করুন, রান করার সময় java HelloTechtunes লিখতে হয়, java HelloTechtunes.class লিখতে হয় না।

এখানে আরেকটি কথা যোগ করা দরকার। উপরের ছবি গুলো নিজের কম্পিউটারের পর্দার সাথে মিলিয়ে দেখতে দেখতে এগোলে কাজটি অনেক সহজ হয়ে যায়, কারণ তখন কোন বাক্সে কী লিখতে হবে সেটি নিয়ে আর দ্বিধা থাকে না। শুরুতে একটু সময় বেশি লাগলেও একবার সেটআপটি ঠিকভাবে হয়ে গেলে সেটি বছরের পর বছর কাজ করে যাবে, আর প্রতিবার নতুন প্রজেক্ট শুরু করার সময় এই ঝামেলায় ফিরে আসতে হবে না।

## কমন এরর ও সমাধান

### javac is not recognized as an internal or external command

এই এররটি আসে যখন Path এ JDK এর bin ফোল্ডার ঠিক ভাবে যোগ হয়নি। JAVA\_HOME এর মান আবার মিলিয়ে দেখুন এবং নিশ্চিত হোন যে Path এ %JAVA\_HOME%\bin এন্ট্রিটি আছে। এরপর Command Prompt বন্ধ করে নতুন করে খুলুন।

### Could not find or load main class

সাধারণত ফাইলের নাম ও ক্লাসের নাম আলাদা হলে, অথবা ভুল ফোল্ডারে থেকে কমান্ড চালালে এই এররটি আসে। dir কমান্ড দিয়ে দেখে নিন আপনি ঠিক ওই ফোল্ডারেই আছেন যেখানে class ফাইলটি তৈরি হয়েছে।

### Class file has wrong version অথবা UnsupportedClassVersionError

কম্পিউটারে একাধিক Java ভার্সন থাকলে এমন হয়। javac এক ভার্সনের আর java আরেক ভার্সনের হলে এই সমস্যা দেখা দেয়। java -version ও javac -version এর আউটপুট মিলিয়ে দেখুন, না মিললে পুরনো ভার্সনটি Path থেকে সরিয়ে দিন।

### ফাইল সেভ হয়েছে HelloTechtunes.java.txt নামে

Notepad এ সেভ করার সময় All Files নির্বাচন না করলে এটি ঘটে। ফোল্ডারের View অপশন থেকে File name extensions চালু করে ফাইলের আসল নাম দেখে নিন ও ঠিক করুন।

## শেষ কথা

এই ছয়টি ধাপ ঠিক ভাবে শেষ করার মানে হচ্ছে, আপনার কম্পিউটার এখন Java কোড কম্পাইল ও রান করার জন্য পুরোপুরি প্রস্তুত। শুরুতে এই সেটআপটি ঠিক ভাবে করে নিলে সামনে IDE, Maven বা Spring Boot নিয়ে কাজ করার সময় অনেক ঝামেলা এমনিতেই এড়ানো যায়।

আপনার সেটআপ করতে গিয়ে কোন ধাপে সমস্যা হয়েছে বা কোন এররটি দেখেছেন, টিউমেন্টে জানান। আমি ধরে ধরে সমাধান বলে দেওয়ার চেষ্টা করব।
