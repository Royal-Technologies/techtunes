আমাদের প্রতিদিনের স্মার্টফোন ব্যবহারে অজান্তেই হাজার হাজার ফাইল জমা হয়। ফোনের মেমোরি পূর্ণ হয়ে যাওয়া বা প্রয়োজনীয় ফাইলটি খুঁজে না পাওয়া আমাদের নিত্যদিনের সমস্যা। এই সমস্যার এক দুর্দান্ত সমাধান নিয়ে এসেছেন জনপ্রিয় Open Source App Amaze File Manager এর দক্ষ Developers রা। তাদের নতুন সৃষ্টি হলো Amaze File Utilities। এটি এমন একটি শক্তিশালী এবং All-In-One App যা আপনার ফোনের Internal Storage এর ফাইলগুলো দেখা, পরিচালনা করা এবং অত্যন্ত নিখুঁতভাবে Analyse করার সুবিধা দেয়। সবচেয়ে চমৎকার বিষয় হলো, এই অ্যাপটি সম্পূর্ণ Ads মুক্ত এবং এর UI ডিজাইন করা হয়েছে অত্যন্ত Beautiful ও আধুনিক ভাবে।

## স্টোরেজ অ্যানালাইসিস: আপনার মেমোরির প্রতিটি কোণা যখন আপনার নিয়ন্ত্রণে

![Amaze File Utilities](https://dnc.techtunes.io/tDrive/tuner/2026/03/techtunes_7486ab743169ef5cd889e163a0b90870.png)

Amaze File Utilities এর সবচেয়ে বড় শক্তি হলো এর Analyse করার ক্ষমতা। এটি কেবল ফাইল দেখায় না, বরং স্মার্ট Algorithms ব্যবহার করে আপনার স্টোরেজকে এমনভাবে সাজায় যা আপনি আগে কখনো ভাবেননি:

- **Junk Files:** এটি আপনার ফোনের অলিগলি খুঁজে Junk Files বের করে এবং সেগুলো Delete করে স্টোরেজ খালি করতে সাহায্য করে।
- **Intelligent Image Grouping:** গ্যালারিতে হাজার হাজার ছবির ভিড়ে এটি Similar Images, Memes, Low-Light Images, Blurred Images, Selfies কিংবা Group Images গুলোকে আলাদা আলাদা ভাবে Group করে দেয়। ফলে আপনার মেমে কিংবা ঝাপসা ছবিগুলো খুঁজে বের করা এখন এক মুহূর্তের কাজ।
- **File Organisation:** আপনার স্টোরেজে পড়ে থাকা বিশাল আকারের ফাইল (Large Files), হুবহু একরকম ফাইল (Duplicate Files) কিংবা লুকিয়ে থাকা ফাইলগুলো (Hidden Files) এটি সহজেই শনাক্ত করে।
- **Media Clutter Management:** ভিডিও ফাইলগুলোর ক্ষেত্রে এটি বিশেষ Algorithms ব্যবহার করে এমন সব ভিডিও খুঁজে বের করে যা সম্ভবত আপনার কোনো কাজেই লাগবে না (Cluttered Media Files)।
- **Specific Grouping:** আপনার পুরনো Downloads, Recordings কিংবা অনেকদিন ধরে পড়ে থাকা Screenshots গুলোকে এটি আলাদা করে সাজিয়ে রাখে।
- **App Analysis:** আপনার ফোনে ইনস্টল করা অ্যাপগুলোর মধ্যে কোনগুলো আপনি একেবারেই ব্যবহার করেন না (Unused Apps), কোনগুলো সবচেয়ে বেশি ব্যবহার হয় (Most Used) কিংবা কোন অ্যাপগুলো ফোনের সবচেয়ে বেশি জায়গা দখল করে আছে, তার একটি স্বচ্ছ ধারণা আপনি পাবেন। এছাড়া কোন অ্যাপগুলো সবচেয়ে বেশি Mobile Data অথবা WiFi Network Data খরচ করছে, তাও আপনি জানতে পারবেন।
- **Messaging Media Management:** আমাদের ফোনের বড় একটা জায়গা দখল করে থাকে WhatsApp এবং Telegram এর মিডিয়া ফাইল। এই অ্যাপটি সেগুলোকে আলাদাভাবে Group করে দেয়।
- **System Cleanup:** অনেক সময় অ্যাপ আনইনস্টল করার পরেও কিছু ফাইল থেকে যায়। এটি সেই সব Uninstalled Apps এর Junk Data Clean করে। এছাড়া সময়ের সাথে সাথে কোন অ্যাপগুলোর সাইজ অস্বাভাবিকভাবে বাড়ছে (Apps Growing in Size), স্টোরেজে থাকা অপ্রয়োজনীয় APK Files এবং ডিভাইসের গতি বাড়াতে RAM Clear করার সুবিধা এতে রয়েছে।

১. আপনি আপনার সব মিডিয়া ফাইল List অথবা Grid ভিউতে দেখতে এবং Sort করতে পারবেন।

![Go to Location](https://dnc.techtunes.io/tDrive/tuner/2026/03/techtunes_4004413007be84973cceed56933e2bc2.jpg)

৩. হাজারো ফাইলের মাঝে নির্দিষ্ট কোনো তারিখের ফাইলে যেতে আপনি সরাসরি যেকোনো Date এ Jump করতে পারেন এবং তাৎক্ষণিক Search এর সুবিধা তো আছেই।

- স্টোরেজ এবং ডেটা বাঁচাতে এটি Images এবং Video Files Compress করার দারুণ এক ফিচার অফার করে। আপনি ভিডিওর Aspect Ratio, Pitch এবং Speed ও আপনার ইচ্ছেমতো বদলে নিতে পারেন।

তবে আপনি যদি সম্পূর্ণ উন্মুক্ত বা FLOSS Version ব্যবহার করতে চান, তবে F-Droid Version টি ব্যবহার করে দেখতে পারেন। এই ভার্সনটিতে Face Analysis Capabilities বাদে বাকি সব ফিচার রয়েছে।

F-Droid এ অ্যাপটি Anti-Feature হিসেবে লিস্টেড থাকতে পারে। তবে ডেভেলপাররা নিশ্চিত করেছেন যে, তারা কোনো Third Party Network Service ব্যবহার করছেন না। আপনার ট্রায়ালটি যাচাই করার জন্য অ্যাপটি নিজেই একটি Random ID জেনারেট করে এবং সেটি দিয়ে শুধুমাত্র তাদের নিজস্ব Servers কল করে। এখানে ব্যবহারকারীর কোনো ব্যক্তিগত তথ্য (যেমন Email ID) নেওয়া হয় না।

## অ্যাপটি পাওয়ার উপায়

![অ্যাপটি পাওয়ার উপায়](https://dnc.techtunes.io/tDrive/tuner/2026/03/techtunes_85a35c93c5e44d93a62606235eb68d76.jpg)

আপনি F-Droid Main থেকে অ্যাপটি সংগ্রহ করতে পারেন। সরাসরি APKs Download করার চেয়ে একটি Client (যেমন Sunil এর তৈরি ক্লায়েন্ট বা অন্যান্য জনপ্রিয় ক্লায়েন্ট) ব্যবহার করা ভালো যাতে অ্যাপটি সবসময় Up-to-Date থাকে। কিছু ক্লায়েন্টে এই Repo ডিফল্টভাবে থাকে, আর না থাকলে আপনাকে Manually Add করে নিতে হবে।

## প্রয়োজনীয় পারমিশনসমূহ (Requested Permissions)

![Requested Permissions](https://dnc.techtunes.io/tDrive/tuner/2026/03/techtunes_f5c18cc6e74f2038baa2a29b2a986bb0.jpg)

অ্যাপটির পূর্ণ কার্যকারিতার জন্য কিছু অনুমতির প্রয়োজন হয়:

- **ACCESSCOARSELOCATION ও ACCESSFINELOCATION:** ফাইল ট্রান্সফারের সময় কাছাকাছি থাকা ডিভাইস খুঁজে পেতে।
- **MANAGEEXTERNALSTORAGE:** আধুনিক অ্যান্ড্রয়েড ভার্সনগুলোতে ফাইল ম্যানেজমেন্টের জন্য।
- **READPHONESTATE:** এটি আপনার ডিভাইসের জন্য একটি Unique Identifier (Device ID) তৈরি করতে ব্যবহৃত হয় যা ফোন ক্লিন করলেও হারিয়ে যায় না। এর মাধ্যমে আপনার Purchase বা Subscription Manage করা হয় কোনো ব্যক্তিগত ডেটা ছাড়াই।
- **REQUESTDELETEPACKAGES:** অ্যাপ অ্যানালাইজারের মাধ্যমে সরাসরি অ্যাপ আনইনস্টল করার জন্য।

## টেকনিক্যাল ব্যাকগ্রাউন্ড (Libraries Used)

![Libraries Used](https://dnc.techtunes.io/tDrive/tuner/2026/03/techtunes_b10a74623fa829a9daa055d9e7175b9a.jpg)

এই অ্যাপটি অত্যন্ত শক্তিশালী কিছু লাইব্রেরির ওপর ভিত্তি করে তৈরি করা হয়েছে। নিচে তার বিস্তারিত তালিকা দেওয়া হলো:

- Logback Android (Utility): একটি Logging Helper যা Log4j Project এর পরবর্তী সংস্করণ হিসেবে কাজ করে।
- Android-In-App-Billing-V3 (Utility): ডিভাইসে ইনস্টল থাকা অ্যাপ প্যাকেজগুলো নিয়ে কাজ করে।
- Android Support Library (Development Framework): এটি Compatibility এবং Component Libraries এর একটি সেট।
- AppCompat (Utility): অ্যাপের কাঠামোগত ভিত্তি হিসেবে কাজ করে।
- AndroidX Annotations (Utility): Android Jetpack এর জন্য প্রয়োজনীয় অ্যানোটেশন ধারণ করে।
- AndroidX Core (Utility): নতুন ফিচারগুলোকে পুরনো অ্যান্ড্রয়েড ভার্সনে কাজ করতে সাহায্য করে।
- ConstraintLayout (Utility): ভিউ ম্যানেজমেন্টকে সহজ করে।
- CoordinatorLayout (UI Component): জটিল ইউজার ইন্টারফেস এলিমেন্ট যেমন AppBarLayout এবং FloatingActionButton সাজাতে সাহায্য করে।
- AndroidX Legacy Support (Utility): পুরনো প্ল্যাটফর্মের অ্যাপ ব্যবহারের জন্য একটি স্ট্যাটিক লাইব্রেরি।
- Emoji Compatibility (UI Component): সব ডিভাইসে ইমোজি ঠিকভাবে দেখানোর জন্য।
- Fragment (UI Component): ইউজার ইন্টারফেসকে পুনরায় ব্যবহারযোগ্য কম্পোনেন্টে ভাগ করে।
- Lifecycle (Utility): অ্যাপের বিভিন্ন অংশের অবস্থার পরিবর্তনের ওপর ভিত্তি করে কাজ করে।
- Media & MediaRouter (Utility): মিডিয়া কন্টেন্ট শেয়ার এবং রিমোট প্লেব্যাকের জন্য।
- Navigation (Utility): অ্যাপের বিভিন্ন স্ক্রিনের মধ্যে যাতায়াত সহজ করার একটি ফ্রেমওয়ার্ক।
- Preference (Utility): ফোনের ইন্টারনাল স্টোরেজ ব্যবহার না করেই সেটিংস স্ক্রিন তৈরির সুবিধা।
- Room (Utility): SQLite এর ওপর ভিত্তি করে তৈরি একটি উন্নত ডাটাবেস লাইব্রেরি।
- Paging (Utility): মেমোরি খরচ কমিয়ে বিশাল ডেটা সেট প্রদর্শনের জন্য।
- App Startup (Utility): অ্যাপ চালুর সময় কম্পোনেন্টগুলোকে দ্রুত লোড করতে সাহায্য করে।
- Tracing (Utility): নিরাপদ ডেটা স্টোরেজ ও ট্র্যাকিংয়ের জন্য।
- ViewPager & ViewPager2 (UI Component): সোয়াইপযোগ্য পেজ বা ভিউ প্রদর্শনের জন্য।
- WorkManager (Utility): ব্যাকগ্রাউন্ডে জরুরি কাজগুলো শিডিউল করার জন্য।
- MaterialDialogs (UI Component): ম্যাটেরিয়াল ডিজাইন অনুযায়ী সুন্দর ডায়ালগ বক্স তৈরির জন্য।
- Android Trash Manager (Utility): ডিলিট হওয়া ফাইল নির্দিষ্ট সময় পর্যন্ত সংরক্ষণ করার জন্য।
- MuPDF (Utility): পিডিএফ এবং ই-বুক দেখার হালকা সফটওয়্যার ফ্রেমওয়ার্ক।
- Glide (Utility): দ্রুত ইমেজ লোডিং এবং ক্যাশিং নিশ্চিত করতে।
- Android-Image-Cropper (Utility): ছবি কাটার বা ক্রপ করার লাইব্রেরি।
- ExoPlayer (Utility): উন্নতমানের মিডিয়া প্লেয়ার লাইব্রেরি।
- Material Design Components for Android (Utility): গুগলের ডিজাইন গাইডলাইন অনুযায়ী অ্যাপ সাজাতে।
- Guava (Google Core Libraries for Java 6+): জাভার জন্য একগুচ্ছ প্রয়োজনীয় ইউটিলিটি লাইব্রেরি।
- Error Prone (Utility): কোডিংয়ের ভুল ধরার জন্য স্ট্যাটিক অ্যানালাইসিস টুল।
- Gson (Utility): জাভা অবজেক্টকে JSON এ রূপান্তরের লাইব্রেরি।
- AboutLibraries (Utility): ব্যবহৃত লাইব্রেরিগুলো সম্পর্কে তথ্য দিতে।
- Easy Permissions (Utility): পারমিশন ম্যানেজমেন্ট সহজ করার জন্য।
- PercentageChartView (UI Component): কাজের প্রগ্রেস দেখানোর জন্য চার্ট ভিউ।
- OkHttp (Utility): উন্নত ডেটা কানেকশন ও HTTP ক্লায়েন্ট।
- AppIntro (UI Component): সুন্দর ওয়েলকাম স্ক্রিন তৈরির জন্য।
- PhotoEditor (Utility): ছবি এডিট করার সব টুলস সমৃদ্ধ লাইব্রেরি।
- Waveform-Android (Utility): অডিওর এমপ্লিচিউড ক্যালকুলেট করার টুল।
- FastScroll (UI Component)
- ACRA (Utility): অ্যাপ ক্র্যাশ করলে তার রিপোর্ট পাঠানোর সিস্টেম।
- Apache Commons IO (Utility)
- OpenCV (Utility): কম্পিউটার ভিশন এবং মেশিন লার্নিংয়ের জন্য জনপ্রিয় লাইব্রেরি।
- SLF4J (Simple Logging Facade for Java): বিভিন্ন লগিং ফ্রেমওয়ার্কের সংযোগস্থল।
- PhotoView (UI Component): ছবি জুম করার সুবিধা সম্বলিত ইমেজ ভিউয়ার।

পরিশেষে বলা যায়, Amaze File Utilities একটি নিরাপদ অ্যাপ। Trackers এবং VirusTotal স্ক্যানে এতে ক্ষতিকর কিছু পাওয়া যায়নি। আপনার ফোনের ফাইল ম্যানেজমেন্টকে আরও উন্নত এবং আধুনিক করতে এটি একটি আদর্শ পছন্দ। এতে ব্যবহৃত PhotoView লাইব্রেরিটি টাচ জেসচারের মাধ্যমে ছবি জুম করার দুর্দান্ত অভিজ্ঞতা প্রদান করে।
