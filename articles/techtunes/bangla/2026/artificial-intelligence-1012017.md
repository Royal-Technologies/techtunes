### Online Editing

"Photext" সরাসরি আপনার Web Browser-এই কাজ করে। তাই Operating System নিয়ে কোনো চিন্তা নেই। Windows, Mac, Linux বা অন্য যেকোনো Operating System ব্যবহার করুন, শুধু Internet connection থাকলেই হলো! 🌍

### AI Text Recognition

এই Tool টির প্রাণ হলো এর Artificial Intelligence (AI)। আপনি যখন কোনো Image Upload করবেন, AI সেই Image এর Text গুলো Automatically সনাক্ত করবে। ফলে Text খুঁজে বের করার জন্য আপনার মূল্যবান সময় নষ্ট হবে না। 🤖

### Text Modification

"Photext" তে Text Edit করা খুবই সহজ। আপনি সনাক্ত করা Text গুলোকে নিজের মতো করে Modify করতে পারবেন, নতুন Text Add করতে পারবেন, আবার চাইলে Delete ও করতে পারবেন। একদম জলের মতো সহজ! ✍️

### Font Option

"Photext" তে আপনি অসংখ্য Font পাবেন। আপনার Design এর সাথে যেটা সবচেয়ে ভালো মানায়, সেই Font টি Select করতে পারবেন। আর যদি আপনার পছন্দের Font টি তালিকায় না থাকে, তাহলে Custom Font Upload করার Option তো আছেই! ✒️

### Image Enhancement

"Photext" শুধু Text Edit করার Tool নয়, এটি Image Enhancement এর জন্য ও কিছু দারুণ Feature নিয়ে এসেছে। আপনি ছবিতে বিভিন্ন Stamp যোগ করতে পারবেন, Filter ব্যবহার করতে পারবেন এবং আপনার ছবিকে আরও Attractive করে তুলতে পারবেন। 🎨

### Format Support

এই Tool টি বহুল ব্যবহৃত Format যেমন JPG, PNG, JPEG, WEBP এবং BMP Support করে। তাই Format নিয়ে আপনাকে কোনো চিন্তা করতে হবে না। 🖼️
