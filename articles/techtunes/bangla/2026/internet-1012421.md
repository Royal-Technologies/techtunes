হ্যালো টেকটিউনস বন্ধুরা, কেমন আছেন সবাই? আশাকরি সবাই ভালো আছেন এবং নিরাপদে আছেন। আজকের টিউনে আমি আপনাদের সাথে এমন একটি গুরুত্বপূর্ণ বিষয় নিয়ে আলোচনা করতে যাচ্ছি, যা আমাদের ডিজিটাল জীবনে শান্তি এনে দিতে পারে। আমরা প্রতিনিয়ত Online এ বিভিন্ন ধরনের তথ্য আদান প্রদান করে থাকি। ব্যক্তিগত ছবি থেকে শুরু করে অফিসের জরুরি Documents – সবকিছুই এখন Digital Platform এ Share করা হয়। কিন্তু এই তথ্য আদান প্রদানে Security কতটা নিশ্চিত, তা নিয়ে আমরা অনেকেই চিন্তিত। 😰

বর্তমান যুগে ব্যক্তিগত Privacy রক্ষা করা একটি বড় চ্যালেঞ্জ। হ্যাকাররা ওঁত পেতে আছে আপনার মূল্যবান তথ্যের জন্য। তাই, এমন একটা Tool এর খুব দরকার, যা আমাদের Data -কে Secure রাখতে পারে, একই সাথে ব্যবহার করাও সহজ।

আজকে আমি আপনাদের সাথে পরিচয় করিয়ে দিব "Enclosed" নামক একটি Open Source Web Application এর সাথে। এই Tool টি আপনার গোপনীয় সব Information সুরক্ষিত রাখতে বিশেষভাবে তৈরি করা হয়েছে। কল্পনা করুন, আপনি কাউকে একটা জটিল Password, Credit Card Number অথবা অন্য কোনো Secret Key পাঠাতে চান। এক্ষেত্রে সাধারণ Instant Messaging Software বা Email ব্যবহার করা কতটা ঝুঁকিপূর্ণ, তা নিশ্চয়ই আপনারা জানেন। 😨 কারণ, Delete করার পরেও Server-side এ Data Record হয়ে থাকার সম্ভাবনা থাকে। এমন পরিস্থিতিতে Enclosed হতে পারে আপনার সবচেয়ে বিশ্বস্ত Security Partner! 🦸‍♂️

## Enclosed ব্যবহারের সুবিধা কী কী? 🤔

![Enclosed](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_5c938c83707805cbbc331a0c35faa30c.png)

আমি সবসময় ব্যক্তিগত Security-কে সবচেয়ে বেশি গুরুত্ব দেই। তাই নিজের অভিজ্ঞতা থেকে বলতে পারি, যখন Sensitive Information Transfer করার প্রয়োজন হয়, তখন End-to-End Encryption Method ব্যবহার করা খুবই জরুরি। কিছুদিন আগে আমি "Bitwarden Send" নিয়ে একটা বিস্তারিত Review লিখেছিলাম। সেটি Private Data Transfer -এর জন্য নিঃসন্দেহে ভালো একটা Option। কিন্তু, সেখানে Operation Process টা অনেকের কাছেই জটিল মনে হতে পারে, কারণ Account Register করা বাধ্যতামূলক। 🙄

তখন আমার মনে প্রশ্ন জাগলো, এমন কোনো সহজ Tool আছে কি, যেটা একইসাথে Free এবং Secure হবে? খুঁজতে খুঁজতে অবশেষে আমি খুঁজে পেলাম "Enclosed"! 🎉

## Enclosed - কেন এটি অন্যান্য Tool থেকে আলাদা? 🌟

![Enclosed - কেন এটি অন্যান্য Tool থেকে আলাদা?](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_8948081c5281892b44a95d6888e25fcc.jpg)

Enclosed শুধু একটি সাধারণ Web Application নয়, এটা আপনার Digital জীবনের একজন বিশ্বস্ত Security Guard! Enclosed -এর কিছু অসাধারণ Feature রয়েছে, যা একে বিশেষভাবে আলাদা করে তুলেছে:

- **Open Source:** Enclosed একটি Open Source Platform, যার Source Code GitHub-এ Available আছে। এর মানে হলো, আপনি চাইলে Source Code দেখতে পারবেন, নিজের প্রয়োজন অনুযায়ী Customize করতে পারবেন এবং Community -কে Improve করতে Contribute ও করতে পারবেন। 🤓
- **End-to-End Encryption:** Enclosed AES-GCM Algorithm এবং PBKDF2 ব্যবহার করে শক্তিশালী End-to-End Encryption Support করে। এর ফলে, Sender এবং Receiver ছাড়া অন্য কেউ আপনার Data দেখতে পারবে না। এমনকি Server -ও না! 🔒
- **Read Once Feature:** এটি Enclosed এর সবচেয়ে আকর্ষণীয় Feature। Receiver যখন Content Open করবে, সাথে সাথেই Data Automatically Delete হয়ে যাবে! ফলে, ScreenShot নেওয়ারও কোনো সুযোগ নেই। 💥
- **Password Protection:** আপনি আপনার Note -এর জন্য আলাদা Password Set করতে পারবেন। Password ছাড়া Unauthorized Access করার কোনো সম্ভাবনাই নেই। 🔑
- **File Attachment:** Enclosed -এর মাধ্যমে আপনি Text Message এর পাশাপাশি যেকোনো ধরনের Documents ও Securely Send করতে পারবেন। এটা খুবই Useful একটা Feature। 📁
- **Expiration Time:** আপনি Data কতক্ষণ Available রাখতে চান, তা নিজের ইচ্ছেমতো Set করতে পারবেন। Expiration Time শেষ হয়ে গেলে Data Automatically Delete হয়ে যাবে। ⏱️
- **সহজ Interface:** Enclosed এর Interface খুবই User-friendly, যা নতুন User -দের জন্য ব্যবহার করা খুবই সহজ। 👍

ফ্রান্সের মেধাবী Developer CorentinTh অক্লান্ত পরিশ্রম করে Enclosed তৈরি করেছেন। তিনি PrivateBin এবং Bitwarden Send থেকে Inspiration নিয়ে Enclosed -এর Design করেছেন। Tool টি ব্যবহার করা খুবই সহজ এবং এটি Chinese সহ আরও অনেক Language Support করে। 🌍

## Enclosed কিভাবে ব্যবহার করবেন? ধাপে ধাপে গাইড 📝

![Enclosed কিভাবে ব্যবহার করবেন? ধাপে ধাপে গাইড](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_6468469ad1500507d3705a4643e88adc.jpg)

Enclosed ব্যবহার করা খুবই সহজ। নিচের Step গুলো Follow করে আপনি খুব সহজেই Enclosed ব্যবহার করতে পারবেন:

১. **Website ভিজিট করুন:** আপনার Computer বা Mobile Phone এর Browser Open করে Enclosed এর অফিসিয়াল Website -এ যান। 🌐

![Enclosed Website](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_6649e59f8a9707eb30ab61431f42e174.png)

২. **Language নির্বাচন করুন:** Website Open করার পরে Simplified Chinese Interface দেখতে পাবেন। স্ক্রিনের উপরের ডানদিকের Language Option থেকে আপনার পছন্দের Language Select করুন। English, Spanish, French সহ আরো অনেক Language Available আছে। 🗣️

![Language নির্বাচন](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_c94c8b9387e9d43ad1a4abb91314ce47.png)

৩. **Note তৈরি করুন:** এবার আপনার Secret Message অথবা Text Content Paste করুন। আপনি সরাসরি Type করেও Note লিখতে পারবেন। ✍️

![Note তৈরি](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_76008d1ac8c28ef8930e54905781dc96.png)

৪. **Settings পরিবর্তন করুন:** Note Password, Expiration Time (যেমন, এক ঘন্টা, একদিন, এক সপ্তাহ অথবা এক মাস) এবং Read Once Option নিজের প্রয়োজন অনুযায়ী Set করুন। Security Level বাড়ানোর জন্য শক্তিশালী Password ব্যবহার করুন। 💪

![Settings পরিবর্তন](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_ce19d2e351fcfaad05744d13009ab2de.png)

৫. **File Attach করুন (Optional):** আপনি যদি কোনো File পাঠাতে চান, তাহলে "Attach File" Option ব্যবহার করে File Upload করতে পারবেন। File Size এর ব্যাপারে Website এ কোনো নির্দিষ্ট Limit উল্লেখ করা হয়নি, তবে বড় File Upload করতে কিছুটা সময় লাগতে পারে। ⏳

![File Attach](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_430d904be33eeb6193bd0e861b66bed4.png)

৬. **Link Copy করুন:** সবকিছু ঠিকঠাক থাকলে "Create Note" Button -এ Click করার পরে একটি Sharing Link তৈরী হবে। "Copy Link" Button -এ Select করে Link টি Copy করুন। মনে রাখবেন, এই Link -এর সাথে Decryption Key ও থাকবে। 🔗

![Link Copy](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_db0c2f41da93b747089ce3edb1b59b09.png)

৭. **Link Share করুন:** সবশেষে, আপনি Link টি Receiver এর সাথে Share করুন। Receiver Link Open করার সাথে সাথেই আপনার Secure Message দেখতে পারবে। Mobile Phone এ Share করার সুবিধার জন্য Enclosed QR Code ও Generate করে। 📲

![Link Share](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_c1e5886eed92c2f3ea1d9850f06be7af.png)

## Receiver কিভাবে Content View করবে? 👁️

![Receiver কিভাবে Content View করবে?](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_0a4221e217615b67efdd2f93b80f1d93.jpg)

Receiver যখন আপনার পাঠানো Link -টি Open করবে, তখন তাকে Password দিতে হতে পারে (যদি আপনি Password Protection On করে থাকেন)। Password দেওয়ার পরেই সে মূল Content দেখতে পারবে। আর যদি Read Once Option On করা থাকে, তাহলে Content দেখার সাথে সাথেই Data Automatically Delete হয়ে যাবে। Content সাধারণত Plain Text Format -এ দেখাবে, যেটাকে Receiver চাইলে Clipboard এ Copy করে Save করতে পারবে।

## Enclosed কেন আপনার প্রথম পছন্দ হওয়া উচিত? 🤔

![Enclosed কেন আপনার প্রথম পছন্দ হওয়া উচিত?](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_11174b2f8e2f94f2b0286c9c5c061378.jpg)

1. Enclosed একটি Open Source Web Application, যা User-দের Private এবং Security সম্পন্ন Content Send করার সুবিধা দেয়। 💯
2. File Attach করা যায়, View Password, Expiration Time অথবা Read Once Mode On করার Option রয়েছে। ⚙️

4. Interface খুবই User-friendly এবং ব্যবহার করা সহজ। 🤩
5. সবচেয়ে গুরুত্বপূর্ণ বিষয় হলো, Enclosed সম্পূর্ণ Free এবং Open Source! 💰

যদি আপনি Online এ Data Security নিয়ে চিন্তিত থাকেন, তাহলে Enclosed আপনার জন্য Best Solution হতে পারে। Enclosed ব্যবহারের মাধ্যমে আপনি আপনার Personal এবং Professional Data -কে Secure রাখতে পারবেন। 👍
