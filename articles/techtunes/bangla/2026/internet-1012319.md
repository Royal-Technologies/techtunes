## GrosFichiers: আপনার File, আপনার হাতেই সুরক্ষিত! 🛡️

![GrosFichiers](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_4bd2dc27a0e951c666c53f77e48caf8b.png)

GrosFichiers হলো Switzerland এর Valais রাজ্যে অবস্থিত একটি Independent Company। এই Company প্রধানত Free Space Service প্রদান করে। তাদের মূল লক্ষ্য হলো Users-দের জন্য একটি সহজ, নিরাপদ এবং ঝামেলাবিহীন File Sharing Environment তৈরি করা। GrosFichiers এর মাধ্যমে Users রা কোনো Registration ছাড়াই 10 GB পর্যন্ত File Transfer করতে পারে। যাদের File Size এর Requirement আরও বেশি, তারা Paid Upgrade করে Upper Limit 50 GB পর্যন্ত বাড়াতে পারবে।

আমি ব্যক্তিগতভাবে মনে করি, যারা File Sharing এর জন্য একটি User-Friendly এবং Secure Platform খুঁজছেন, তাদের জন্য GrosFichiers হতে পারে একটি দারুণ Solution। ছোটখাটো ব্যক্তিগত ব্যবহারের পাশাপাশি অফিসের গুরুত্বপূর্ণ Confidential Documents Transfer করার জন্যও এটি খুবই উপযোগী।

## GrosFichiers-কে কেন এত স্পেশাল বলছি? ✨

![GrosFichiers-কে কেন এত স্পেশাল বলছি?](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_838578f1c38f8d0b916f1d357bfb9b20.jpg)

অন্যান্য File Sharing Platform থেকে GrosFichiers-কে আলাদা করার মতো অনেকগুলো Special Feature রয়েছে। চলুন, সেগুলো এক নজরে দেখে নেই:

- **কড়া Data Security:** GrosFichiers Switzerland এবং France এ অবস্থিত শক্তিশালী Server ব্যবহার করে। তারা Swiss Law এবং Privacy Policy অত্যন্ত কঠোরভাবে মেনে চলে, যা Users-দের Data Protection নিশ্চিত করে। এছাড়াও, Third-Party Company-র সাথে কোনো Information Share করে না। তাই Data Security নিয়ে আপনি নিশ্চিন্ত থাকতে পারেন।
- **Privacy সবার আগে:** এই Platform টি ব্যবহারের জন্য কোনো Registration এর প্রয়োজন নেই। ফলে Users-দের কোনো Personal Information, যেমন - Name, Email Address ইত্যাদি প্রদান করার বাধ্যবাধকতা নেই। আপনার Privacy GrosFichiers-এর কাছে সবসময় Priority পাবে।
- **ব্যবহার করা যেন ডাল-ভাত:** GrosFichiers-এর Interface এতটাই সহজ যে, নতুন Users-রাও কোনো ঝামেলা ছাড়াই ব্যবহার করতে পারবে। Default ভাষা French হলেও, Chinese Language Support করে।
- **বিনামূল্যে ব্যবহার:** GrosFichiers 10 GB পর্যন্ত File Transfer করার জন্য কোনো প্রকার Charge নেয় না। ফলে Students থেকে শুরু করে Professionals পর্যন্ত, সবাই Registration ছাড়াই File Transfer করতে পারবে।
- **Download Limit নিয়ে চিন্তা নেই:** Recipient-দের File Download করার জন্য কোনো Account এর প্রয়োজন নেই, এবং Download এর সংখ্যার উপর ও কোনো Restriction নেই। Download Link-এর মাধ্যমে যে কেউ File Download করতে পারবে।

GrosFichiers ব্যবহার করা খুবই সহজ। নিচে Step by Step একটি Guide দেওয়া হলো:

![File Select করুন](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_a117dcc539c45ef7aee6bb93a44776b0.png)

২. **Upload করুন:** File Select করার পর, File Name, File Size এবং Number of Documents সহ Information গুলো দেখতে পারবেন। এরপর "Start Upload Your Document" Button-এ Click করে Upload শুরু করুন। Upload Speed খুব বেশি না হলেও, Stability নিয়ে চিন্তা করতে হবে না। Upload করার সময় অবশ্যই আপনার Browser টি খোলা রাখতে হবে।

![Start Upload Your Document](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_b38fc6aa9f6812ac8e40513484a16c75.png)

৩. **Email Compose করুন:** Upload Process Complete হলে "Write your email message" Option-এ Click করুন। এখানে Uploader এবং Recipient-এর Email Address প্রদান করতে হবে। File Download Link পাওয়ার জন্য এই Method টি ব্যবহার করা আবশ্যক। Email-এর Subject এবং Message ও নিজের মতো করে Customize করতে পারবেন।

![Compose Email Message](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_aca11d3a5ad14c60e0b0c3e7add131c4.png)

৪. **Link সংগ্রহ করুন:** Email-এ File Download Link এবং Management URL পাঠানো হবে। Download Link টি Recipient-এর সাথে Share করুন। Management URL-এর মাধ্যমে আপনি File টি Manage করতে পারবেন।

![Link সংগ্রহ করুন](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_57c97a81006276d424ac479bd7722935.png)

৫. **Download করুন:** Recipient Download Page-এ গিয়ে Uploader-এর Name, Email এবং Date Time দেখতে পারবেন। File টি 14 দিন পর্যন্ত Available থাকবে, এরপর Automatically Delete হয়ে যাবে। File Download করার জন্য Document Name-এ Click করুন।

![Recipient Download Page](https://dnc.techtunes.io/tDrive/tuner/2025/12/techtunes_2f697dae2ad123f554d27270fdbb19ba.png)

৬. **File Management:** Uploader "File Management" Link ব্যবহার করে Sharing Link-এর Information দেখতে পারবেন। এছাড়াও, Sender, Recipient এবং Subject-এর Information Reuse করার জন্য "Use as Template" Option ও রয়েছে। Management Page থেকে Singleবারে 30 জন Recipient-কে Download Link Resend করার Option ও রয়েছে। File Download করার Date, Time এবং IP Address ও জানতে পারবেন।
