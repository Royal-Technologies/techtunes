**প্রিয় এডভারটাইজার,**

টেকটিউনসের সাথে নিয়মিত এডভারটাইজমেন্ট করবার জন্য আপনাকে অসংখ্য ধন্যবাদ। আপনার ব্যানার ইমেজ সমূহ বর্তমানে টেকটিউনসে live আছে। আপনার ব্যানার ইমেজ সমূহ টেকটিউনসে live হবার সাথে সাথে আপনাকে ব্যানার live notification mail এবং contorl panel এর full access এর mail পাঠানো হয়েছে।

## টেকটিউনস **Authorized Area:**

আপনার ব্যবহারের সুবিধার্থে নিম্নে contorl panel এর সম্পূর্ণ ব্যবহার সম্পর্কে আলোচনা করা হল।প্রথমে এই লিংকে ক্লিক করুন।

**➡ <http://ads.techtunes.io/r/www/admin/>**

![](https://dnc.techtunes.io/tDrive/tuner/techtunes/493902/Screenshot_1.png)

আমাদের tAds AD Server - Authorized Area এর access জন্য আপনাকে ই-মেইলের মাধ্যমে User Name এবং Password দিয়ে দেয়া হয়েছে। User Name এবং Password ব্যবহার করে login করুন।এখন আপনি Techtunes Advertising - tAds AD Server এ প্রবেশ করতে পেরেছেন।

## টেকটিউনস  **Server Admin Panel:**

![](https://dnc.techtunes.io/tDrive/tuner/techtunes/493902/Screenshot_2.png)

এখন আপনাকে আপনার নিজস্ব tAds AD Server Admin Panel এ প্রবেশ করতে হবে, আপনাকে টেকটিউনস থেকে tAds AD Server Admin Panel এর account  তৈরি করে দেয়া হয়েছে। tAds AD Server Admin Panel এর access জন্য আপনাকে ই-মেইলের মাধ্যমে User Name এবং Password দিয়ে দেয়া হবে। আপনাকে User Name এবং Password ব্যবহার করে login করতে হবে।

## Admin Panel ব্যবহারের নিয়ম:

সফলভাবে login করবার পর আপনি আপনার Admin Panel সম্পূর্ণ ব্যবহার করতে পারবেন।  
 প্রথমে আপনি left side এর উপরের দিকে ৩টা ট্যাব দেখতে পাবেন। ট্যাব গুলো হচ্ছে Statistic, inventory, Preference।

## নিয়মিত Advertisment Statistic দেখবার নিয়ম:

প্রথমেই আসা যাক Statistic এ, এখান থেকে আপনি আপনার History নিয়মিত দেখতে পারবেন।Advertiser History তে আপনি আপনার বর্তমান সময়ের Statistic দেখতে পাবেন।

![](https://dnc.techtunes.io/tDrive/tuner/tmentorvi/493902/1.png)

আপনি আজকে কেমন impression পেয়েছেন, click কেমন পেয়েছেন, আপনার click through rate কেমন এসেছে। এ সব কিছু আপনি খুব সহজেই দেখতে পাবেন।  
 এছাড়াও drop down box এ থেকে আপনি যদি weekly, monthly অথবা All statistic ও select করেও আপনি দেখতে পারবেন আপনার statistic সমূহ।

![](https://dnc.techtunes.io/tDrive/tuner/tmentorvi/493902/2.png)

![](https://dnc.techtunes.io/tDrive/tuner/tmentorvi/493902/3.png)

নিয়মিত Monthly or Specific Date এর ব্যানার performance দেখবার জন্য উপরের searchbox এ date উল্লেখ্য করে search দিলে ব্যানার performance দেখা যাবে।

![](https://dnc.techtunes.io/tDrive/tuner/techtunes/493902/screenshot-ads.techtunes.iom_.bd-2017-06-08-12-52-30.png)

## 

এছাড়াও, আপনি যদি আপনার default campaigns এ ব্যানার ইমেজ সমূহের impressions, click আলাদা আলাদা দেখতে চান, আপনি সেটাও দেখতে পারবেন। এজন্য আপনাকে প্রথমে statistics tab এর নিচে left side এর campaigns এ ক্লিক করতে হবে।

## Campaign এর  Live performance দেখবার নিয়ম:

![](https://dnc.techtunes.io/tDrive/tuner/tmentorvi/493902/4.png)

## প্রতি ব্যানার zone এর Performance দেখবার নিয়ম:

Default campaigns এর মাঝে প্রবেশ করবার পর আপনি Campaign History দেখতে পাবেন। এখানে আপনি দেখতে পারছেন Campaign History, Banners, Website Distribution এর popup Menu সমূহ। ব্যানার গুলোর আলাদা আলাদা performance দেখবার জন্য Banners এ ক্লিক করুন।

![](https://dnc.techtunes.io/tDrive/tuner/tmentorvi/493902/5.png)

Banners এ ক্লিক করবার পর আপনি খুব সহজেই দেখতে পারবেন আজকে আপনার কোন ব্যানার কেমন performance করেছে।আপনি যদি গতকালের ব্যানার সমূহের ব্যানার performance ও দেখতে পারবেন date পরির্বতন করে অথবা drop down menu select করেও।

![](https://dnc.techtunes.io/tDrive/tuner/techtunes/493902/screenshot-ads.techtunes.iom_.bd-2017-06-08-13-06-20.png)

## Banner Ads পরিবর্তন করবার নিয়ম:

কিভাবে ব্যানার আপনি আপনার ব্যানার গুলো পরির্বতন করতে পারবেন। আপনার ব্যানার গুলোর user interaction বাড়াবার জন্য অবশ্যই মাসের মাঝে কয়েকবার ব্যানার গুলো অবশ্যই পরির্বতন করতে হবে। কারন যত বেশি ব্যানার পরিবর্তন করা হবে, user  তত বেশি response করতে পারবে।  
 ব্যানার পরির্বতন করতে আপনাকে inventory তে ক্লিক করতে হবে। Inventory থেকে আপনাকে ক্লিক করতে হবে Banners এ,

![](https://dnc.techtunes.io/tDrive/tuner/tmentorvi/493902/6.png)

এবার আপনি আপনার ব্যানার জোন এ প্রবেশ করুন।

![](https://dnc.techtunes.io/tDrive/tuner/tmentorvi/493902/7.png)

এবার আপনি আপনার নতুন ব্যানারটি Choose file এর মাধ্যমে select করুন। ব্যানার Link পরির্বতন করুন এবং ব্যানার upload করা complete হবে save changes select করুন।

![](https://dnc.techtunes.io/tDrive/tuner/tmentorvi/493902/8.png)

এভাবেই, খুব সহজে আপনি আপনার ব্যানার গুলো নিয়মিত পরির্বতন করতে পারবেন এবং statistic এর মাধ্যমে ব্যানারের performance গুলো নিয়মিত দেখতে পারবেন।
