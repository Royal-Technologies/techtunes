নতুন ফোন কিনেছেন, কেও জিজ্ঞাসা করলো আপনার ফোনের কনফিগারেশন কি? RAM, ROM, processor Speed কত?এত কিছু মনে রাখা অনেক কঠিন। তাই আপনাদের একটা অ্যাপের সাথে পরিচয় করে দেই, যা আপনাদের এই সব ইনফর্মেশন দিবে।

এই সফটওয়্যার  আপনাকে আপনার ফোনের নারি-নক্ষত্র বের করে দেবে। যেন এটা একটা ফোনের ডাক্তার, ডাক্তার যেমন রুগীকে ব্যাবচ্ছেদ করে এই সফটওয়্যার আপনাকে আপনার ফোনকে ব্যাবচ্ছেদ করে দেখাবে। এটার সাইজ অনেক কম, প্রায় ৬ মেগা। তাইলে আর দেরি কেন, চলেন শুরু করা যাক:

- নাম: PhoneInfo
- link: [PhoneInfo](https://play.google.com/store/apps/details?id=com.appcoader.phoneinfo)
- <https://play.google.com/store/apps/details?id=com.appcoader.phoneinfo>
- Size : 6 MB

এই অ্যাপে যে যে অপশন গুলা আছে সেগুলো নিচের ছবিতে দেখতে পারবেন ঃ

## Feature List:

এখানে আপনি দেখতে পারবেন আপনার ফোন কি কি সাপোর্ট করে আর কি কি সাপোর্ট করে না। যেগুলো সাপোর্ট করে না সেগুলা NO লিখে ভিন্ন রঙে দেখান আছে। নিচের ছবিতে দেখতে পারেন ঃ

![Supported Features](https://lh3.googleusercontent.com/1O9xa1Z2gxWBS-5PgdX43PbF_Vz9QMlyTll7fCmKStVcgHu_1NZ39GjfNWWMwJ2m_Vs=h900-rw)

## ক্যামেরা ঃ

এখানে আপনি পাবেন আপনার ফোন ক্যামেরার কনফিগারেশন, ভিডিও, ইমেজ, প্রিভিউ সাইজ, জুম সাপোর্ট করে কিনা, ছবির ফরম্যাট এগুলা দেখা যায়। নিচের ছবিতে দেখুন ঃ

![Camera Details](https://lh3.googleusercontent.com/yHFCt6U8gDntGFaq73qewl8zXuA9hilbQpp0MyP91QEFcs7WbQJRZyb1snxsfTe6ofuD=h900-rw)

## Battery Details:

এখানে আপনি আপনার ফোনের ব্যাটারির চার্জ লেভেল, ক্যাপাসিটি কত mAh তা দেখতে পারবেন। আপনার ব্যাটারির ভোল্টেজ কত, এখন ব্যাটারির তাপমাত্রা কত, হেলথ কেমন, কখন ফোন অন করেছেন তা দেখতে পারবেন। বিশ্বাস না হলে নিচের ছবি দেখেন ঃ

![ব্যাটারি বিস্তারিত](https://lh3.googleusercontent.com/tXhyD6BIuNDVLcGBd3xIs9evvPuFcGxKJp2Q5SW5AIrH4_P052R_mgleny-pGpQoU_g9=h900-rw)

## Wifi Info:

আপনার মোবাইল যদি ওয়াইফাই তে সংযুক্ত থাকে তাহলে আপনার IP address koto, Signal Strength koto, ওয়াইফাই লেভেল কত তা জানতে পারবেন। আরও যাদের মান আপনি জানতে পারবেন তা হল ঃ Network ID, RSSI, SSID, MAC Address, BSSID, Link Speed (Mbps), Frequency, Subnet Mask, Server IP, Gateway IP. নিচের ছবি দেখেনঃ

## GPS Info :

আপনার লোকেশান বের করে দেয়া যায় Latitude, Longitude এর মাধ্যমে। আপনি এখানে আপনার Latitude, Longitude, Location Accuracy, Altitude, Connected Satellite এগুলার মান জানতে পারবেন। ছবিতে দেখেন ঃ

![](https://lh3.googleusercontent.com/z73v4r9-vtTb2bLtODHLWAq7vfgSDk30e0YOItinbz8nmaHH_4ewmb1vn_4x5Xoeww=h900-rw)
