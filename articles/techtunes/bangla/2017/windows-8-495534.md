আসসালামু আলাইকুম। কেমন আছেন সবাই? রোজা কেমন যাচ্ছে? অবশ্যই ভাল যাচ্ছে। দোআ করি সবাই যেন পরিপূর্ণ রোজা থাকতে পারে। আমিন।  
 আজকে আমি যে টিউনটা করছি সেটা হলো উইন্ডোজ বিষয়ক। অনেকেই জানে না কি ভাবে উইন্ডোজ আট কি ভাবে ইন্সটল করতে হয়। এটা শুধুমাত্র যারা নতুন তাদের জন্যই দিলাম। হ্যাঁ, সাথে ভিডিও টিউটোরিয়াল পাবেন।

## যেহেতু ইন্সটল করার সময় সকল কথা ইংরেজিতে থাকবে সেহেতু আমি ইংরেজিতে টাইপ করলাম

স্টেপ ১

- Insert the Windows 8.1 DVD into your optical drive and restart your computer. tap the F12 key repeatedly until the Please Select Boot Device: menu appears. SelectCD/DVD/CD-RW Device and press Enter.  
   The Windows 8.1 Setup appears.
- Select Language to install, Time and currency format, and Keyboard or input method and select Next.
- Select Install Now.
- Locate your Product Key and type it into the box provided, then click Next to continue.

## Note:

The Product Key is a 25 character sequence, separated by dashes.

- Accept the license terms described in the License Terms screen. Click the checkbox at the bottom of the screen to accept and click Accept to continue.
- At the Which Type of Installation do you Want screen, select Custom: Install Windows only (advanced).
- For a clean installation, delete all partitions that are shown by highlighting them one at a time and selecting Delete. After you have deleted all partitions select Unallocated Space and then selectNew. Click Apply to create your new Windows 8.1 partitions, then click Next.
- Windows will now be freshly installed on your computer.
- Your computer will restart several times. This may take some time to complete installation.
- Windows 8.1 will boot up for the first time.
