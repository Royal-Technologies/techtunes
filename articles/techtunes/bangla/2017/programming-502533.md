## আজ আমরা জানবো ডাটা টাইপ অ্যান্ড ভেরিয়েবল কি?

চলুন প্রথমে ভেরিয়েবল সম্পর্কে জানি।

X=10

X=20

Y=15.5

Z=100

## ভেরিয়েবল কি?

উপরে উল্লিখিত x=10 বা y=15.5 বা  z=100 এখানে x, y অ্যান্ড  z হচ্ছে ভেরিয়েবল কিন্তু এখানে যে এক্স এর মধ্যে ১০ আছে এটা আমরা বুঝতেছি কিন্তু কম্পিউটার বুঝতে পারবে না কারন কম্পিউটার কে বলে দিতে হবে এই ১০ কোন টাইপের ডাটা। নিচের মত করে লিখলে কম্পিউটার বুঝতে পারবে এগুল integer type এর ডাটা int  মানে integer

int X=10;

int X=20;

float Y=15.2;

int Z=100;

এই variable এর নাম লেখার আনেক নিয়ম আছে সেগুল আমরা পরে শিখবো।

## ডাটা টাইপ কি?

int X=10;

int X=20;

float Y=15.2;

int Z=100;

এখানে আমরা যে int লিখলাম এর মানে বুঝায় এটি একটি পূর্ণ সংখ্যা এই int বা float কে বলে ডাটা টাইপ। জাভাতে আট ধরনের primitive ডাটা টাইপ আছে। int  long  sort  byte  boolean char float double আরও non primitive ডাটা টাইপ ও আছে আমরা আস্তে আস্তে সব জানব। আজ এই পর্যন্ত।
