আসসালামু আলাইকুম। সবাই নিশ্চই ভাল আছেন। আর সব সময় ভাল থাকুন এটাই কামনা করি সারাক্ষন। সবার সহযোগীতায় IT Related YouTube Channel Era IT এগিয়ে যাচ্ছে তার জন্য সবার কাছে কৃতজ্ঞ। আশা করি সবাই আমার ভিডিওগুলো দেখবেন ও শেয়ার করবেন। ভিজিটর না থাকলে আসলে ভাল কিছু করার মনোযোগ আসে না।

আজ আলোচনা করব কিভাবে আপনার পিসির USB Port ডিজেবল করবেন এবং তা কিভাবে Enable করবেন। তার আগে বলে নেই USB Port কেন ডিজেবল করবেন? অনেক সময় দেখা যায় আপনার পিসিতে বিভিন্ন সময় অন্যেরা পেনড্রাইভ বা ম্যমরী কার্ড ইউজ করে। আর তাতেই সমস্যা। ঐসব পেনড্রাইভ ব্যবহারের কারনে অনেক সময় আপনার পিসিতে ভাইরাস ছড়িয়ে যায়। তার জন্য আপনার ব্যক্তিগত পিসি’র USB Port Disable করে রাখতে পারেন।  এটা করলে আপনার পিসিতে ভাইরাস আক্রমনের হাত থেকে রক্ষা পাবে। নিচে আমি দুইটি উপায়ে USB Port Disable পদ্দতি দেখলাম।

## পদ্বতি - ০১ :

প্রথমে আপনার ডেস্কটপে MY Pc / My Computer এ রাইট ক্লিক করুন। এখান থেকে Manage এ ক্লিক করুন। তারপর Devise Manager এ ক্লিক করুন। তারপর নিচের দিকে দেখবেন Universial Serial Bus Controller একটা অপশন দেখবেন এটাতে ক্লিক করলে দেখা যাবে Generic USB Hub নামে দুটি অপশন আছে এগুলোতে রাইট ক্লিক করে ডিজেবল করুন দেখবে এখন আর পোর্ট কাজ করছে না। আবার Enable করলে পোর্ট কাজ করবে।

## পদ্বতি ০২  :

Run - CMD - regedit এ যাওয়ার পর দেখবেন একটা উইন্ডো ওপেন হবে। HKEY Local Machine - System- CurrentControllset - Service - USBSTOR এখানে ক্লিক করলে দেখবেন ডান পাসের একটা উইন্ডোতে নিচে থেকে ২ নম্বর অপশন Start এ ডাবল ক্লিক করুন। আবার নতুন একটা উইন্ডো ওপেন হবে। এখানে Value Data নামে একটা ঘর আসবে এখানে সাধারনত 3 বসানো থাকে 3 এডিট করে 4 বসিয়ে ok করুন দেখবেন আপনাার USB Port Disable হয়ে গেছে। আবার ৪ এর পরিবর্তে ৩ বসালে এনাবল হবে।
