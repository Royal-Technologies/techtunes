## নিজের ওয়েব সাইট টিকে কিভাবে আর উন্নত করে তোলা যায় ভাবছেন?

এ ক্ষেত্রে সবার আগে আপনার জানতে হবে একটি ভাল মানের ওয়েবসাইটের কি কি বৈশিষ্ট্য থাকা উচিত। আপনাদের সুবিধার্থে আমি একটি ওয়েব সাইটের কিছু গুরুত্বপূর্ণ দিক তুলে ধরছি।

## অপটিমাইজড ইমেজ ব্যবহারঃ

আপনি যদি আপনার ওয়েব সাইটে অনেক বড় বা ভারি ছবি আপলোড করেন,আপনার সাইটের লোড টাইম অনেক বেড়ে যাবে।ইন্টারনেটে অনেক ইমেজ অপটিমাইজার পাবেন যেগুলো  ছবির মান অক্ষুন্ন রেখে সাইজে ছোট করে অর্থাৎ কম্প্রেস করে কমপ্রেসড সাইজে ফেরত দেয় :)। কমপ্রেসড ইমেজ ব্যবহার করলে ছবির মান ও ঠিক থাকছে আবার সাইটের স্পীড ও ঠিক থাকছে।

## অপটিমাইজড Java এবং CSS এর ব্যবহারঃ

আপনি সাইটের লোড টাইম কমাতে এবং সাইট স্পীড বাড়াতে মিনিফাইড Java এবং CSS ফাইল ব্যবহার করুন।

## গুগল সার্চ কনসল (Google Search Console)**:**

আপনার ওয়েব সাইট টিকে  গুগল সার্চ কনসলে যুক্ত করুন,সাইট টি সঠিক ভাবে পর্যালোচনা করার জন্য।

## গুগল অ্যানালাইটীক্স (Google Analytics Setup):

Google Analytics অ্যাকাউন্ট সেট আপ করে নিন আপনার সাইটটি সামগ্রিক ভাবে পর্যবেক্ষন এর জন্য।

## সাইট ম্যাপঃ

সাইট ম্যাপ অ্যাড করুন আপনার সাইটে।সাইট ম্যাপ হল  আপনার ওয়েব সাইটের প্রতি টি পেজ, টিউন  বা প্রোডাক্ট এর লিংক সংবলিত একটি xml file othoba html file.

## robots.txt:

robots.txt ফাইল নির্ধারণ  করে গুগল আপনার সাইট টি ক্রাউল করতে পারবে কি না। ক্রাউল করতে পারলেও সম্পূর্ণ নাকি আংশিক তাও এই ফাইল এর মাধ্যমে নির্দেশ দেয়া যায়।

আজ এ পর্যন্তই। আরো অনেক অপটিমাইজেশন করা জায়, যার মাধ্যমে আপনার ওয়েব সাইট টি গুগলে সহজে ভিজিবল করা যায়  এবং গুগল রাংকিং  এ প্রথম পাতায় নিয়ে আসা যায়। এগুলো পর্যায় ক্রমে আলোচনা করব। যদি আপনাদের আমার লেখা টি  ভাল  লাগে জানাতে ভুলবেন না। যে কোন জিজ্ঞাসায় টিউমেন্ট করুন,আমি চেষ্টা করব আপনাকে সাহায্য করার।

এতক্ষণ ধৈর্য ধরে লেখা টি পড়ার জন্য আন্তরিক ধন্যবাদ। 🙂
