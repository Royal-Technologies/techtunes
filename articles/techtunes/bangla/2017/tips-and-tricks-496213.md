আসসালামু আলাইকুম, সবাই কেমন আছেন। আজকে আলোচনা করব উইন্ডোজ আপডেট ছাড়া যেভাবে Safe রাখবেন আপনার পিসিকে Wanna Cry Attack থেকে। এই টিউনটি হল যারা তাদের উইন্ডোজ সব সময় আপডেট দিতে চান না তাদের জন্য। তাহলে শুরু করা যাক।

পদ্ধতি ১ঃ প্রথমে Control panel বা Settings থেকে Programs and Features জান।

![](https://dnc.techtunes.io/tDrive/tuner/emuakter/494070/Untitled-2.jpg)

তারপর Turn Windows features on or off এ ক্লিক করুন।

![](https://dnc.techtunes.io/tDrive/tuner/emuakter/494070/Untitled-3.jpg)

সেখান থেকে SMB 1.0/CIFS File Sharing Support এর চেক বক্স তুলেনিন  ok ক্লিক করুন।

পিসি restart করুন। এখন আপনার কম্পিউটার Safe আছে।

পদ্ধতি ২ঃ নিচের ফাইলটি ডাউনলোড করুন।

Download: [SMB2 Tools Disable](https://archive.org/download/SMB2ToggleToo/SMB2%20Toggle%20Too.exe "smb2 tools disable")

*তারপর RUN AS ADMINISTRATOR যান*

![](https://dnc.techtunes.io/tDrive/tuner/emuakter/496213/Untitled-1.jpg)

তারপর SMB2 currently enable থাকে তাহলে সেটি  disabled করতে হবে। ওকে  ক্লিক করুন  আবার একইভাবে  RUN AS ADMINISTRATOR যান।

![](https://dnc.techtunes.io/tDrive/tuner/emuakter/496213/Untitled2.jpg)

যদি SMB2 IS currently disabled দেখায় তারপর পিসি restart করুন। এখন আপনার কম্পিউটার Safe আছে।

![](https://dnc.techtunes.io/tDrive/tuner/emuakter/496213/Untitled3.jpg)

যদি টিউনটি ভাল লাগে তাহলে শেয়ার করতে ভুলবেন না। আর কোন সমস্যা হলে নিচে টিউমেন্ট করুন। 🙂 এই টিউনটি পূর্বে প্রকাশিত হয়েছে এই ফেসবুক পেজেঃ [WOWTURN](https://web.facebook.com/wowturn/)

তাই নতুন সব টিপস পেতে পেজে লাইক দিতে ভুলবেন না। ভাল থাকুন এবং টেকটিউনসের সাথে থাকুন।  খোদাহাফেজ 🙂
