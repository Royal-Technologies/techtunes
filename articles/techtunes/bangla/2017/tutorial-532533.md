আমরা কম বেশি সবাই এক্সেল ব্যবহার করি। আজ আপনাদের সাথে শেয়ার করব কি আমরা Subtotal function এর ব্যবহার করব। sum function ব্যবহার করে আমরা যোগফল বের করি Subtotal ও প্রায় একই রকম। তবে sum function ব্যবহার করলে কেবল মোট যোগফল বের হয়। যদি sheet এ একাধিক ব্যক্তির নাম থাকে তাহলে তাদের নাম filter করে ঐ filter করা ব্যক্তির মোট ফলাফল পাবো না। তবে যদি আমরা Subtotal function এর ব্যবহার করি তবে মোট যোগফলের সাথে সাথে কোন একক ব্যক্তির যোগফল ও বের হবে।
