কেমন আছেন টেকটিউনসবাসীরা? আশা করি অনেক বেশি ভাল আছেন। আজ আপনাদের জন্য নিয়ে এলাম কিভাবে রুট ছাড়াই কানেক্টেড ওয়াই ফাই পাসওয়ার্ড বের করতে হয়, অনেক সময় মোবাইলে ওয়াইফাই পাসওয়ার্ড কানেক্টেড থাকে বাট শো করেনা পাসওয়ার্ড টি, এমনকি আমরা ভুলে যাই, তার জন্য অন্য কাউকে শেয়ার করতে পারিনা, বা আরেকটা ফোনে কানেক্ট করতে পারিনা, আজ  আপনাদের নিয়ম টা বলে দিচ্ছি কিভাবে পাসওয়ার্ড টা বের করবেন

এই জন্য শুধু লাগবে একটা যেকোন ব্রাউজার, আপনার পছন্দের যেকোন ব্রাউজার হলেই হবে প্রথমে আপনার পছন্দের ব্রাউজারে ঢুকুন তারপর ব্রাউজারের  url box মানে যেখানে ওয়েবসাইটের এড্রেস দিতে হয় ওইখানে 192.168.0.1 লিখে সার্চ দিবেন বা ওকে দিবেন তারপর দেখবেন একটা লগিন বক্স আসছে লগইন বক্সের default ba user name এ দিবেন admin আর Password এ দিবেন admin, তারপর ওকে দিবেন।

দেয়ার পর যে পেজ টা আসবে তার নিচে Advance শব্দ টা লিখা দেখবেন Advance এ ক্লিক করবেন ক্লিক করার পর যে  পেজ টা আসবে ওই পেজে wireless option পাবেন Wireless এ ক্লিক করার পর বামে wireless security option দেখতে পাবেন, wireless security তে ক্লিক করেই  security key box এ  ক্লিক করলেই কাঙ্ক্ষিত পাসওয়ার্ড টি পেয়ে যাবেন। 🙂
