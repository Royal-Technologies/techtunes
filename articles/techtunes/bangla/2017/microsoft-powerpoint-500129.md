আপনি Microsoft Power Point এ একটি পুনাঙ্গ Presentation তৈরী করতে হলে প্রথমে Microsoft Power Point Software টি ওপেন করতে হবে।

তারপর insert মেনুতে গিয়ে Shapes িএ গিয়ে িকয়েকটি used shapes নিতে হবে দেন আপনি আপনার presentation েএর নাম দিবেন।এবং আপনি Home মেনুতে গিয়ে লেখা ছোট বা বড় করতে পারবেন এবং লেখা color করতে পারবেন।

এবং আপনি আপনার Presentation এর লেখা গুলো color করতে পারবেন। তারপর আপনি আপনার presentation এ Design করতে হলে Design মেনুতে েগিয়ে Design করতে পারবেন, এবং আপনার Presentation এর background দিতে পারবেন। আপনি আপনার presentation এ কোন Slide যুক্ত করতে হলে Animation মেনুতে গিয়ে ‍Slide যুক্ত করতে পারবেন। িএবং সেখানে বিভিন্ন ধরনের Slide রয়েছে।

তারপর আপনি আপনার Presentation টি Slide Show করতে হলে Shift+F5 বাটনটি ক্লিক করলেই আপনার presentation টি Slide Show হবে।

আপনি যদি এতে না বুজেন তাহলে আপনার জন্য আরেকটি সহজ পদ্ধতি রয়েছে তা হলো, আপনার জন্য আমি একটি ভিডিও তৈরী করেছি। এই ভিডিওতে রয়েছে কিভাবে Microsoft Power Point এ একটি পুনাঙ্গ Presentation তৈরী করবেন।
