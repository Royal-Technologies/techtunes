আসসালামু ওয়া আলাইকুম,

আমি মো:অলিউর রহমান খান।আমি সিদ্ধান্ত নিয়েছি ওরাকল নিয়ে ধারাবাহিক বাংলা টিউটোরিয়াল লিখবো,ইংশাআল্লাহ্।আমি এ পর্যায়ে দেখবো (টেবিল তৈরি করা,নতুন কলাম যুক্ত করা,তৈরি করা টেবিল দেখা)। আপনারা যদি বাংলায় প্রাকটিক্যালি শিখতে চান আশা করি শিখতে পারবেন। আপনাদের টাকা খরচ করে কোনো প্রতিষ্ঠানে শিখতে হবে না।  
 বি:দ্র: অবশ্যই এসকিউএল জানা থাকতে হবে।

## **টেবিলঃ**

টেবিল একটি স্কেমা (Scheme) অবজেক্ট যা তথ্য বা ডাটা ধারন করার জন্য ব্যবহ্রত হয়।একটি টেবিলে একাধিক রো বা কলাম থাকতে পারে।প্রতিটি রো তে নির্দিষ্ট ডাটা বা তথ্য থাকে।প্রতিটি কলাম একটি রো এর বিভিন্ন অংশ ধারন করে থাকে।

## **টেবিল তৈরী করাঃ**

টেবিল তৈরি করার জন্য create table কমান্ড ব্যবহার করতে হয়।  
 যেমন,  
 create table table\_name  
 (  
 column\_name data type null/not null,  
 column\_name data type null/not null,  
 column\_name data type null/not null  
 );  
 এখন STUDENT নামের একটা টেবিল তৈরি করবো।নিচের SQL কমান্ড ব্যবহার করবো,  
 create table STUDENT  
 (  
 STUDENT\_ID NUMBER NOT NULL,  
 STUDENT\_NAME VARCHAR2(30 BYTE),  
 STUDENT\_ADDRESS VARCHAR2(80 BYTE),  
 STUDENT\_EMAIL VARCHAR2(20 BYTE)  
 );

SQL>create table STUDENT  
 (  
 STUDENT\_ID NUMBER NOT NULL,  
 STUDENT\_NAME VARCHAR2(30 BYTE),  
 STUDENT\_ADDRESS VARCHAR2(80 BYTE),  
 STUDENT\_EMAIL VARCHAR2(20 BYTE)  
 );

Table Created.

SQL plus এ উপরের কমান্ড ব্যবহার করলেই টেবিল তৈরি হবে।এরপর table save করতে হবে।Save করার জন্য commit কমান্ড দিতে হবে।

SQL>COMMIT;

Commit complete.

commit command দিলেই উপরের টেবিল save হয়ে যাবে। এরপর save করা টেবিল দেখতে হবে।দেখার জন্য-নিচের মত command দিতে হবে-

DESC table name;  
 এই কমান্ড ব্যবহার করবো।

SQL>DESC STUDENT;

এই কমান্ড দিয়েই ENTER প্রেস করলেই আপনার তৈরি করা টেবিল দেখাবে।

## **টেবিলে নতুন কলাম যুক্ত করা:**

টেবিলে নতুন কলাম যুক্ত করতে চাইলে ALTER TABLE কমান্ড ব্যবহার করবো,নিচের মত,  
 ALTER TABLE table\_name  
 ADD column\_name data type;

SQL>ALTER TABLE STUDENT

          ADD phone\_number NUMBER(10); 

               (Click Enter Button)

এবারে DESC কমান্ড ব্যবহার করে নতুন Add করা কলামটি দেখবে।

SQL>DESC STUDENT;

এই কমান্ড দিয়েই ENTER প্রেস করলেই আপনার তৈরি করা টেবিল দেখাবে।
