“বিসমিল্লাহির রাহমানির রাহীম”. প্রথমে সবাইকে আমার সালাম ও আন্তরিক শুভেচ্ছা জানাচ্ছি। আশা করি সবাই অনেক ভালো আছেন।

সি# শিখতে চান? কিন্তু ভাল কোন বাংলা টিউটোরিয়াল খুজে পাচ্ছেন না? আমি আজ আপনাদের সাথে Share করব সি# এর সবচেয়ে ভাল বাংলা টিউটোরিয়াল। টিউটোরিয়ালটি ব্যাসিসের সি# course এর। এখানে .NET and ASP.NET দুইটা বিষয়ই দেখানো হয়েছে। আমি নিজেও এই টিউটোরিয়াল দেখে শিখছি। আশা করি যারা সি# শিখতে চান তাদের খুব উপকারে আসবে।

সি# এখনও জাভার পর সবচেয়ে শক্তিশালী ল্যাঙ্গুয়েজ। মাইক্রোসফট 2001 সালে এর ডিজাইন করেন এবং প্রগ্রাম্মাদের জন্য উন্মুক্ত করেন। এটি "functional, Creative, object oriented, structured and component oriented feature" এর সমষ্টি।

1. Introduction
2. Data type, condition and Iteration
3. Array, ArrayList and List
4. User defined type
5. Stack, Queue and Hashtable
6. How to debug

8. Object and Class
9. More
