আপনি C# Windows Form Application এ একটি পুণাঙ্গ Calculator তৈরী করতে হলে। প্রথমত Visual Studio Software টি Open করুন। তারপর একটি  Windows Form Application  তৈরী করুন। তারপর toolbox open করুন।  তো আপনাকে প্রথমে যেটা করতে হবে, সেটা হলো একটা text Box নিতে হবে সাথে একটা label নিতে হবে। এবং ২০ টা বাটন  তৈরী করতে হবে। তৈরী বলতে toolbox থেকে button নিতে হবে। প্রথম Button টি তৈরী করতে হবে শুধু Calculator On and OFF করার জন্য। দ্বিতীয় Button টি তৈরী করতে হবে, একটা একটা করে ইনপুট Delete করার জন্য। তৃতীয় Button তৈরী করতে হবে শুধু Calculator এর সকল ইনপুট একসাথে Delete করার জন্য। ৪ Number বাটন তৈরী করুন শুধু যোগ করার জন্য। ৫ নাম্বার বাটন তৈরী করুন ১ কী এর জন্য, ৬ নাম্বার বাটন তৈরী করুন ২ কী  এর জন্য, ৭ নাম্বার বাটন তৈরী করুন ৩ কী এর জন্য, ৮ নাম্বার বাটন তৈরী করুন ৪ কী এর জন্য,৯ নাম্বার বাটন তৈরী করুন ৫ কী এর জন্য,১০ নাম্বার বাটন তৈরী করুন ৬ কী এর জন্য,১১ নাম্বার বাটন তৈরী করুন ৭ কী এর জন্য,১২ নাম্বার বাটন তৈরী করুন ৮ কী এর জন্য,১৩ নাম্বার বাটন তৈরী করুন ৯ কী এর জন্য,১৪ নাম্বার বাটন তৈরী করুন ০ কী এর জন্য,১৫ নাম্বার বাটন তৈরী করুন . কী এর জন্য,১৬ নাম্বার বাটন তৈরী করুন = (সমান)এর জন্য,১৭ নাম্বার বাটন তৈরী করুন বিয়োগ করার জন্য,১৯ নাম্বার বাটন তৈরী করুন গুন করার জন্য,২০ নাম্বার বাটন তৈরী করুন ভাগ করার জন্য। তাহলেই একটি পুণাঙ্গ Calculator তৈরী হবে। যদি এতে ও আপনি না বুজেন তাহলে চিন্তার কোনো কারন নাই। আপনার জন্য একটি সহজ পদ্ধতি রয়েছে। তা হলো একটি ভিডিও র‌য়েছে এবং এই ভিডিওটি দেখতে [এখানে ক্লিক করুন](https://www.youtube.com/watch?v=l8qz6UbQuPk)। এই ভিডিওর মধ্যে রয়েছে কিভাবে একটি পুণাঙ্গ Calculator তৈরী করবেন। ধন্যবাদ
