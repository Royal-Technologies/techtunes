# যেভাবে এন্ড্রয়েড দিয়েই এন্ড্রয়েড এপ বানাবেন।

আজকে আপনাদের এমন একটি টিউনন উপহার করতেছি যা দ্বারা আপনি জানবেন কিভাবে আপনার এন্ড্রয়েড ফোন দিয়েই এপ বানাবেন যেকোনো ভার্শন।  
 তবে আপনি JAVA/JAVA C দিয়ে তা তৈরি করবেন। তবে প্রথমেই বলে দিই এই পোস্ট টি <http://biggoit.com> থেকে নেওয়া হয়েছে। অখানে ভিজিট করতে পারেন। সহজেই ভিজিট এর জন্য [ক্লিক করুন](http://biggoit.com)।

---

*ধারণাঃ*

---

আপনাকে প্রথমেই একটি এপ ডাউনলোড করে ইন্সটল করতে হবে। এটি হলো AIDE IDE for Android Java অথবা আপনার ফোন আপডেট ভার্শন (4.0+) হলে ব্যবহার করতে পারেন AIDE IDE for Android Java C তবে যেটাই ব্যবহার করেন ভালো তবে প্রথম টা আপডেট ভার্শন এ ভালো কাজ করবে না তাই দ্বিতীয় টাই ভালো। ওটাই আপনি ব্যবহার করলে আপনার জন্য ভালো হবে। এখন কাজের কথায় যাই। আমি প্রথম টাই নিয়ে কথা বলি কারণ এটা প্রাথমিক এটা নিয়ে কথা বললে দুটো নিয়েই কথা বলা হবে। আমার সাথে কাজ করে ফেলুন সহজ হবে।

---

কার্যপ্রণালীঃ

- প্লে ষ্টোর এ যান এবং ডাউনলোড করুন AIDE IDE For Android Java অথবা AIDE IDE For Android Java C যেকোনো একটি এপ তারপর সেটি ইন্সটল করুন।
- ক্লিক করে ওপেন করুন, আপনার কয়েকটি অপশন দেখাবে আপনি Beginner তাই Hello World নিয়ে কাজ করুন। পরবর্তীতে অন্য গুলো নিয়ে দেখবেন তাতে ভালো হবে।
- আপনি এতে অসুবিধা ফিল করলে  [এ সাইট](https://developer.android.com) এ যান।
- এখন ও কথায় যাই আপনাকে একটি XML ফাইলসহ আপনার AndroidMenifest করে দেবে আপনাকে শুধু মাত্র তা আপনার ইচ্ছা মত এডিট করতে হবে।
- আপনার Java Source Code পাবেন project/src/com…/MainActivity.java তে
- আপনার রিসোর্স ফাইল অর্থাৎ ছবি, xml ডিজাইন পাবেন project/res/ এই পাথ এ।
- আপনার এপ এর নাম যদি change করতে চান তাহলে যান project/res/strings এ গিয়ে srring.xml ফাইল ওপেন করুন তাতে App\_Name লিখিত আইটেম এ আপনার এপ এর নাম পাবেন তা চেঞ্জ করে আপনার নাম দিন।
- অত:পর hello\_world এর কন্টেন্ট চেঞ্জ করে আপনার বিবরণ দিন।
- AndroidMenifest.xml ফাইল টিতে যান সেখানে আপনার এপ টির ছবি নাম থিম চেঞ্জ করতে পারবেন। সব কাজ আপনার শেষ হয়ে গেলে এখন তা ডেক্সিং এবং ইন্সটল করার পালা মেনুতে যান সেভ দেন তারপর আবার ওই মেনু থেকে রান এ কমান্ড দেন। আপনার এপটি পুর্ণাঙ করুন বার বার রান করার মাধ্যমে তবে এই এপ টি দিয়ে বড় কোনো এপ বানাতে পারবেন না।

আপনার জন্য সমস্যা সমাধানের বক্স টিউমেন্ট বক্স তাছাড়া আমার সাথে যোগাযোগ করুন
