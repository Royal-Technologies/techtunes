MVC-Route পর্বের কোডঃ

```
<?php

Route::get('/', function () {
    return view('welcome');
});

Route:: get('/about', function(){

return view('about');

});

Route :: get('info/{id}/{name}', function($id, $name){

return "User id is " .$id. " And name is " .$name;

}) -> where ('id', '[0-9]+');
```
