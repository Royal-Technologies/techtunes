**আশাকরি সবাই ভালা আছেন। অাজকে আমি আমার প্রথম টিউনটি প্রকাশ করতে যাচ্ছি। যদি কোনো ভুল-ভ্রান্তি হয় তহলে ক্ষমা করবেন এবং অবশ্যই ভুলগুলো ধরিয়ে দেবেন। যাতে পরবর্তীতে আরো সুন্দর ও সঠিকভাবে টিউন প্রকাশ করতে পারি। তো আজকে আমি যে বিষয়টি নিয়ে আলোচনা করব সেটি হলো** **"কিভাবে Control Panel থেকে কোনো Program Hide or Unhide করা যায়"**। তো চলুন শুরু করা যাক:

1. প্রথমে আপনি আপনার Control Panel থেকে আপনি যে Program টি Hide করতে চান সেটি দেখে নিন এবং সেটির নামের বানান ভলোভাবে দেখে নিন। (অামি এক্ষেত্রে BijoyBayanno বাছাই করেছি)![](https://dnc.techtunes.io/tDrive/tuner/k4z0l/520599/01.jpg)
2. তারপর Start Menu তে গিয়ে Run Option এ যান। সেখানে Open Box এ regedit লিখে OK Option এ ক্লিক করুন। তারপর Yes Option এ ক্লিক করুন।  
    ![](https://dnc.techtunes.io/tDrive/tuner/k4z0l/520599/02.jpg)
3. সেখানে Registry Editor File Open হবে। সেখান থেকে Edit Option এ গিয়ে Find. Option এ ক্লিক করুন। (দ্রুত কাজ করার জন্য কীবোর্ড এ Ctrl+F Button চাপুন)![](https://dnc.techtunes.io/tDrive/tuner/k4z0l/520599/03.jpg)
4. তারপর Find What Box এ আপনার Program টির নাম এর বানান সঠিকভাবে লিখে Find Next Option এ ক্লিক করুন। ![](https://dnc.techtunes.io/tDrive/tuner/k4z0l/520599/04.jpg)
5. তারপর সেখানে আপনার Program এর সকল তথ্য চলে আসবে। সেখান থেকে Product Name এর উপর Mouse এর Right Button ক্লিক করে Modify Option এ ক্লিক করুন। ![](https://dnc.techtunes.io/tDrive/tuner/k4z0l/520599/05.jpg)
6. এরপর Edit String Option এ Value Data Box এ আপনার Program টির নাম ভালোভাবে Copy করে রাখুন অথবা মনে রাখুন। যাতে পরবর্তীতে Unhide করার সময় Program টির নাম সঠিকভাবে দিতে পারেন। ![](https://dnc.techtunes.io/tDrive/tuner/k4z0l/520599/06.jpg)
7. তারপর Value Data Box থেকে আপনার Program টির নাম ডিলিট করে দিন। এবং OK Option এ ক্লিক করুন। ![](https://dnc.techtunes.io/tDrive/tuner/k4z0l/520599/07.jpg)

এভাবে আপনি আপনার Computer এর Control Panel থেকে আপনার ইচ্ছামতো যেকোনো Program Hide করতে পারেন।

- আর Unhide করার জন্য প্রথম থেকে সকল Step গুলো সম্পন্ন করে Value Data Box এ আপনার Program টির নাম সঠিকভাবে বসিয়ে দিয়ে OK Option এ ক্লিক করলেই আপনি আবার আপনার Program টি Unhide করতে পারবেন। (আপনি Unhide করার সময় Value Data Box এ যে নামটি দিবেন সেটিই Control Panel এ Program টির নাম হিসাবে Show করবে। )

আশা করি আমার প্রথম টিউনটি আপনাদের সকলের পছন্দ হবে। আর যদি কোনো ভুল হয়ে থাকে তাহলে অবশ্যই জানাবেন। কোনো সমস্যা হলে অবশ্যই Comment করবেন। তো আজকে এ পর্যন্তই। সবাই ভলো থাকবেন। আল্লাহ্ হাফেজ।
