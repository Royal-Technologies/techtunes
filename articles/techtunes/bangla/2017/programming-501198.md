আপনি C# Windows Form Application এ একটি পুণাঙ্গ Student Bio-data তৈরী করতে হলে।

প্রথমত Visual Studio Software টি Open করুন। তারপর  একটা Windows Form Application তৈরী করুন।

তারপর Toolbox থেকে দশটা label নেন সাথে ১০ টা textbox নেন। 1 নাম্বার label এর নামদেন Name,2 নাম্বার label এর নামদেন Father Name,3 নাম্বার label এর নামদেন Mother Name,4 নাম্বার label এর নামদিন Country Name,5 নাম্বার label এর নামদেন Address(Home),6 নাম্বার label এর নামদেন Martial Status,7 নাম্বার label এর নামদেন religion Name,8 নাম্বার label এর নামদেন Mobile No,9 নাম্বার label এর নামদিন Email No,10 নাম্বার label এর নামদেন Birthday date। তারপর একটি Button তৈরী করুন। সবকিছু show করার জন্য। এই Button এর মধ্যে সকল Code লেখা হবে।

এবং এই গুলো কোথায় Show করবে সবকিছু Show করার জন্য আরো ১০টা Label নেন। তাহলেই একটি পুণাঙ্গ Student Bio-data তৈরী হবে। এতে ও যদি আপনি না বুঝেন তাহলে চিন্তার কোনো কারন নাই।

আপনার জন্য একটি সহজ পদ্ধতি রয়েছে তা হলো। একটি ভিডিও রয়েছে এই ভিডিওর মধ্যে রয়েছে কিভাবে একটি পুণাঙ্গ Student Bio-data তৈরী করবেন। সুতারাং এই ভিডিওটি দেখতে [এখানে ক্লিক করু](https://www.youtube.com/watch?v=v4jldJ8rxsk)ন। ধন্যবাদ
