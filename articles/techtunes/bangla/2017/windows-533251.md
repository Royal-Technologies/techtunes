আসসালামু আলাইকুম, আশা করি সবাই ভালোই আছেন,

আপনার অনেকেই উইন্জোজ এক্টিভেট করতে পারেন না। অনেক চেষ্টা করেছেন, কিন্তু কিছুতেই কিছু হচ্ছে না। তো এবার ঠিক জায়গায় এসেছেন।

তো প্রথমে আপনাকে একটি ফাইল ডাওনলোড করতে হবে। ডাওনলোড লিংক ভিডিওর ডিসক্রিপশন বক্সে পাবেন।

- ডাওনলোড করার পর জিপ ফাইলে থাকা KMSAUTONET নামক ফাইলটি আলাদা করুন।
- এর পর এটিকে Run As Administrator দিয়ে চালু করুন।
- তারপর ছবির মতো Active অপশনে ক্লিক করুন

![](https://dnc.techtunes.io/tDrive/tuner/shaikathasan/533251/Image-2.png)

- তারপর নতুন অপশন এলে তাতে Active Windows এ ক্লিক করুন

![](https://dnc.techtunes.io/tDrive/tuner/shaikathasan/533251/Image-4.png)

কাজ শেষ। কিছুক্ষন অপেক্ষা করার পর দেখতে পাবেন এক্টিভেট হয়ে গেছে। মনে রাখবেন, নেট কানেকশন যেনো ভালো হয়।

তো আজ এই পর্যন্তই। সবাই ভালো থাকবেন।

না বুঝলে ভিডিওটি দেখতে পারেন।
