চীনের [অ্যাপলখ্যাত](http://apple.com/) [Xiaomi](http://mi.com/) ফোন জনপ্রিয়তা এখন অনেক উপরে। কারণ এর রয়েছে অ্যাপলে মতো সব ফিচার আর এ কারণেই হয়ত এর জনপ্রিয়তা দিন দিন বেড়েই চলেছে। আর এজন্যই তা হয়ত এর ব্যবহারকারীদের জানা প্রয়োজন এর সব গুরুত্বপূর্ণ ফিচারগুলো:-- জানতে হলে নিচের পদ্ধতিগুলো অনুসরণ করুন:

Security > Virus Scan

![](https://1.bp.blogspot.com/-wxK1GgxTcH0/WaLq4aRLeMI/AAAAAAAAJGk/q4HH8yYsz_w4TykuNLQMQJyH_yOPBOwVwCLcBGAs/s320/Screenshot_2017-08-27-21-33-24-953_com.miui.securitycenter.png)

২। Data Set করুন নির্ধারিত অ্যাপের জন্য: অনেকেই আছে নির্দিষ্ট অ্যাপ ব্যবহার ছাড়া ডেটা ব্যবহার করে না। কিন্তু ওই নির্দিষ্ট অ্যাপ ছাড়াও ডেটা খরচ হয়ে থাকে যাকে ডেটা ড্রেনেজ বলে। আর এটি বন্ধ করতে নিচের টিপস:-

Security > Data Usage > Restrict Data Usage

[![](https://4.bp.blogspot.com/-o5oLobBqR40/WaLrA5I288I/AAAAAAAAJGo/OdUyweLwdX0Sjp4_fPv3XcjuNi1EPAnpwCLcBGAs/s320/Screenshot_2017-08-27-21-33-50-664_com.miui.securitycenter.png)](https://4.bp.blogspot.com/-o5oLobBqR40/WaLrA5I288I/AAAAAAAAJGo/OdUyweLwdX0Sjp4_fPv3XcjuNi1EPAnpwCLcBGAs/s1600/Screenshot_2017-08-27-21-33-50-664_com.miui.securitycenter.png)

৩। Data Statistics: কোন অ্যাপ বেশী ডেটা ব্যয় করে থাকে আর কোনটি কম তা জানার জন্য নিচের টিপস:

Security > Tools > Data Statistics.

![](https://3.bp.blogspot.com/-o5oLobBqR40/WaLrA5I288I/AAAAAAAAJGo/Gb-_CdnEk8UyIk12t1Gz_FuC70699o_AwCEwYBhgL/s320/Screenshot_2017-08-27-21-33-50-664_com.miui.securitycenter.png)

আবার কতটুকু ডেটার ব্যবহার করতে চাচ্ছেন তাও পারবেন: আর এজন্য:

Security > Data Usage > Set Data Usage Limit

![](https://3.bp.blogspot.com/-o5oLobBqR40/WaLrA5I288I/AAAAAAAAJGo/Gb-_CdnEk8UyIk12t1Gz_FuC70699o_AwCEwYBhgL/s320/Screenshot_2017-08-27-21-33-50-664_com.miui.securitycenter.png)

৪। Ram Clean করুন: ফোনের সবচেয়ে গুরুত্বপূর্ণ অংশ হচ্ছে এই র‌্যাম যা গতি’র সাথে সম্পর্কিত যা ইন্টারনেটের গতিও ঠিক রাখতে পারে। আর এজন্য দুটি কাজ করা যায়:

l: কুইক ক্লিন: দ্রুত র‌্যাম ক্লিন করার জন্য এই টিপস যা শুধুমাত্র র‌্যাম ক্লিন করবে।

> Security > Cleaner

> ![](https://2.bp.blogspot.com/-cpK8Juiot3w/WaLrTxs7yrI/AAAAAAAAJGs/qA0tFzCLTvMWx5Hhyf2MKWV-s7T58tknACLcBGAs/s320/Screenshot_2017-08-27-21-34-55-301_com.miui.cleanmaster.png)

ll:  Deep Clean: ফোনের হার্ড ডিস্কে ফুল হয়ে গেলেও ফোনের স্বাভাবিক গতি থাকে না আর জন্য এই টিপস্-

Security > Cleaner > Deep Clean

> > ![](https://3.bp.blogspot.com/-cpK8Juiot3w/WaLrTxs7yrI/AAAAAAAAJGs/c7vwteKwoFw9WAi6HyShoSEnvxe79vcywCEwYBhgL/s320/Screenshot_2017-08-27-21-34-55-301_com.miui.cleanmaster.png)

৫। Battery Usage বাড়ানোর উপায়: ব্যাটারি ইউসেজ বাড়ানোর জন্য অনেকেই অনেক ধরনের

Security > Battery > Battery Saver > Battery Saver ON

> > > ![](https://2.bp.blogspot.com/-wxK1GgxTcH0/WaLq4aRLeMI/AAAAAAAAJGk/ieKEDeJnh6gh12JjWRuBDjJ-BMi5V_glwCEwYBhgL/s320/Screenshot_2017-08-27-21-33-24-953_com.miui.securitycenter.png)

আর ব্যাটারি সেভার ফিচারটি সিডিউল অনুযায়ী চালু করতে নিচের পদ্ধতি: Security > Battery > Battery Saver > Schedule

> > > > ![](https://2.bp.blogspot.com/-ywAEi_bmAnc/WaLrqeMgNgI/AAAAAAAAJG0/aw20-fHrwuA0yNpM49XoPvkLWQdr_6uYQCLcBGAs/s320/Screenshot_2017-08-27-21-33-24-953_com.miui.securitycenter.png)

৬। App Lock: ফোনের গুরুত্বপূর্ন ফাইল বা অ্যাপ লক করে রাখাও জরুরি আর এজন্য এই টিপস:

Security > App Lock > Draw Pattern > Choose Apps

> > > > > ![](https://4.bp.blogspot.com/-fpacLCMn2go/WaLru2jZi7I/AAAAAAAAJG4/jwXmgp0kaY4QS1X0OrMWHOtMoigSM5O2ACLcBGAs/s320/Screenshot_2017-08-27-21-35-21-743_com.miui.securitycenter.png)

৭। Automated Schedule Task: স্বয়ংক্রিয়ভাবে কোন ফিচার চালু করতে এই ফিচার। যেমন একটি নামাযের সময় এয়ারপ্লেন মুডে রাখতে ভুলে গেলেও এটি তা করবে। চালু করতে নিচের পদ্ধতি:

Security > Tools > Automeated Tasks > From 00 to your scheduled time.

![](https://1.bp.blogspot.com/-Vu78n1rVHMM/WaLtCVOkrTI/AAAAAAAAJHE/fW0TyS0_a6kzGj6ercxy83V_5776Evu0gCEwYBhgL/s320/Screenshot_2017-08-27-21-57-50-585_com.miui.securitycenter.png)

আবার ব্যাটারি 20%  এ চলে আসলে Silent Mode, ‍Screen Brightness, Sync ইত্যাদি স্বয়ংক্রিয়ভাবে বন্ধ হয়ে যাবে। চালু করতে:

Security > Tools > Automeated Tasks > When battery reaches 20%

> ![](https://2.bp.blogspot.com/-Vu78n1rVHMM/WaLtCVOkrTI/AAAAAAAAJHE/gmVic1m9XUEiI-F7lW4u3czggQkb1tLhgCLcBGAs/s320/Screenshot_2017-08-27-21-57-50-585_com.miui.securitycenter.png)

৮। ইন্টারনেটের বর্তমান অবস্থা জানতে Internet Test: ইন্টারনেটে বার কানেকশন লস বা কোন ত্রুটি আছে কিনা তা দেখতে

Security > Tools > Test Network Test Network

![](https://2.bp.blogspot.com/-Ppz7D3j55QQ/WaLtKwiOrII/AAAAAAAAJHI/oZOAjElaQi8qC_0QJNai4ASjN8Pj2stYACLcBGAs/s320/Screenshot_2017-08-27-21-35-47-648_com.miui.securitycenter.png)

আজকের টিপস এই পর্যন্তই আর আপনি যদি অ্যান্ড্রয়েড ব্যবহারকারী হয়ে থাকেন তবে আমাদের সাথেই থাকুন। ধন্যবাদ!
