## প্রথমে কোডটি দেখবঃ

```
/**
 * Created by Asif on 8/15/2017.
 * Email:[email protected]
 * Web:techasif.com
 * Facebook:facebook.com/asifparvezsarker
 * Mobile:01744861779
 */
public class EscapeSequence {
    public static void main(String  args[]){
        System.out.println("B\taust");//this is tab escape sequence 
        System.out.println("B\baust");//this is backslash escape sequence
        System.out.println("B\naust");//this is newline escape sequence
        System.out.println("Ba\raust");//this is carrige return escape sequence
        System.out.println("a\\sif");//This is way of print escape sequence
    }
}
```

## escape sequence কি?

```
escape sequence হল যে কেরক্টার গুলর একটি আলাদা মানে থাকে কম্পাইলার এর কাছে।মনে করুন আমরা একটা লাইন লেখে পরের লাইন এ যাইতে 
চাই আমরা সাধারন্ত এটি করি System.out.println("asif") এর মাধ্যমে এটি দিরেক্ট হয়ে যায় কিন্তু আমরা ইচ্ছা করলে 
System.out.print("asif\n") এমন করে একটি নিউ লাইন escape sequence ব্যবহার করে করতে পরি। উপরে আরও কয়েকটি আছে বুঝতে পরবেন যদি নিযে কড করে রান করেন।
```

## গুরুত্বপূর্ণ কিছু কথাঃ

আপনি যদি কোড কপি পেস্ট করেন তাহলে শিখতে পারবেন না ভাল করে। আপনি অবশ্যই টিউন পরবেন সাথে আমি যে ভিডিও দিয়েছি সেটিও দেখবেন।

একটা কথা কি জানেন? প্রোগ্রামিং শিখতে হলে একটা বই পরে শেখা সম্ভব না। আর অনেক লেখা পড়েও শিখা সম্ভব না। প্রোগ্রামিং শিখতে হলে অনেক বই পরতে হই। আমিও অনেক বই পড়ে আপনাদের জন্য এমন কিছু দিতে চাই যেন আপনাদের আমার মত কষ্ট না করতে হয়। তাই ভিডিও টিও দেখবেন। আমি আশা করিছি আপনারা এই কোর্স টি কমপ্লিট করবেন।

আপনি যা শিখবেন তা আসলে একটি ভার্সিটিতে ও শেখা হয় না কারন এখানে শুধু ৬ মাস সময় থাকে। এই কোর্স কমপ্লিট করলে আপনি জাভা সফটওয়্যার ডেভেলপার হিসাবে জব করতে পরবেন বা বিশ্বকে অনেক কিছু দিতে পরবেন।

আমি চাই আমরা যে যা জানি তাই শেয়ার করে আমাদের দেশকে এগিয়ে নিতে। কেন আমাদের দেশের ছেলেমেয়েরা পিছিয়ে থাকবে। আমরা যদি আমাদের মন কে একটু উজাড় করে দিয়ে কোন প্রকার ব্যবসায়িক উদেশ্য ছাড়া আমাদের দেশ খুব শিগ্রই বিশ্বের মধ্যে মাথা উচু করে দাড়াবে।

## আমরা কেন শেয়ার করিনা যে যতটুকু জানিঃ

এই যে আমাদের দেশের অনেক শিক্ষক আছেন যারা আনেক কিছুই জানে তারা কি পারে না তাদের জানা জিনিস গুলো একটু শেয়ার করতে। মাসে  private,পরে ভাল টাকা পয়সা ইনকাম করছে। তাহলে তারা কিসের সরকারি চাকরি করে। সরকারতো টাকা দিচ্ছে মাসে মাসে। শুধু একটু আমাদের মনটা মানুষের প্রতি দয়াবান হয় তাহলে আমাদের দেশ যে এতটা উপরে উঠে যাবে আপনি কল্পনাও করতে পারবেন না। যারা করেন তাদের উদ্যেশ্য আমার এই লেখা নয়। আসুন আমরা সবাই মিলে দেশকে এগিয়ে নিয়ে যাই। আপনি কি কল্পনা করতে পারেন আপনি শুধু একটি বার কষ্ট করে একটি ভিডিও বা টিউন করবেন তা থেকে সারা জীবন মানুষ উপকৃত হবে এমনকি আমারা মৃত হয়ে যাবার পড়েও।

## আমি যেভাবে পরিঃ

আমার ক্লাস এ শিখি সামান্য কিছু তার পর ক্লাস থেকে এসে কিছু ইংলিশ টিউটোরিয়াল দেখি। কেন ভাই আমি ইংলিশ দেখব আমার দেশের অনেকেই তো বড় বড় ইউনিভারসিটি এর শিক্ষক। তারা কি পারে না আমাদের জন্য কিছু করতে? আমদের দেশে সবার ইউনিভারসিটি পড়া হয়না কারন সিট সংখ্যা কম। আমার কথায় কেউ কষ্ট পেলে ক্ষমা করে দিবেন। ভাল থাকবেন।
