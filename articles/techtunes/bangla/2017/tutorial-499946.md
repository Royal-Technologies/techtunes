IF Else স্টেটমেন্ট সব প্রোগ্রামিং ল্যাঙ্গুয়েজে একই। সিনট্যাক্স কিছু আলাদা হতে পারে কিন্তু অর্থপূর্ণ ভাবে একই। তাই একটিতে বুঝলে বাকি গুলোতে বুজতে অসুবিধা হবে না। IF Else ব্যবহার করা হয় সাধারণ আমাদের প্রোগ্রামে কোন কন্ডিশনের প্রয়োজন হলে। যেমন ধরেন অনেক সময় আপনারা কোন সাইটের ফর্ম ফিলাপ করে থাকেন সেখানে অনেক ফিল্ড যেমন ইমেইল এর উপর \* চিহ্ন দেখবেন।

অর্থাৎ এই ফিল্ডটি অবশ্যই পূরণ করতে হবে এবং তার সাথে সাথে এটাও চেক করে আপনার ইমেইলটি ফেইক কিনা। যদি আপনি এই ফিল্ডটি খালি রাখেন বা ফেইক আইডি ব্যবহার করেন তাহলে ফর্মে এরর দেখায় কারণ এগুলোতে কন্ডিশন ব্যবহার করা হয়ছে। এভাবে আপনার প্রোগ্রাম করার সময় অনেক কন্ডিশনের প্রয়োজন পরে। এবং এই কন্ডিশনাল স্টেটমেন্ট এর মধ্যে IF Else খুব জনপ্রিয়। একটি উদাহরণ নিছে দেওয়া হয়ছে জাভাস্ক্রিপ্ট এরঃ

**var a = 100;**  
 **var b = 100;**

**if (a > b) {**  
 **alert("Yes, a is greater than b");**  
 **} else if (a = b){**  
 **alert("Yes, a equal b");**  
 **} else {**  
 **alert("Yes, a is less than b");**  
 **}**

আপনাদের বুঝার সুবিধার্থে আমি এই ভিডিওটি তৈরি করেছি এটি দেখলে আপনি খুব সহজে IF Else স্টেটমেন্ট বুঝতে পারবেন। কারণ এটিতে খুব সহজে উদাহরণ সহকারে বুঝানো হয়ছে। টিউনটি ভাল লাগলে ফেসবুকে শেয়ার করতে ভুলবেন না।
