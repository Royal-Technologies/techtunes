আসসালামু আলাইকুম। কেমন আছেন সবাই? আশা করি মহান আল্লাহ্‌ তা’আলার অশেষ রহমতে ভাল আছেন? আমিও আলহামদুলিল্লাহ ভাল আছি।

আজ আমি আপনাদের এমন একটি সফটওয়্যারের সাথে পরিচয় করাব যেটার সাহায্যে আপনে আপনার wifi router অনান্য ব্যবহার কারিদের ইন্টারনেট বিছিন্ন করে দিতে পারবেন এই সফটওয়্যারটির নাম selfishnet এটি Windows operating system এর জন্য এটি আপনি আপনার windows চালিত ডেস্কটপ অথবা ল্যাপটপে ব্যবহার করতে পারে। এটি ব্যবহার খুবই সহজ। মাএ ১ এমবির এই সফটওয়্যার টি খুবই কার্যকর। নিচের ডাউনলোড লিংক থেকে ডাউনলোড করে নিন: [ডাউনলোড](https://uplod.ws/upk7vks2w4zg)
