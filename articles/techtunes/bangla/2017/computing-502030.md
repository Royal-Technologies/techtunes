## সমস্যাটি কি?

অনেক সময় দেখা যায় আপনার কম্পিউটার আপনি ছাড়া আনেক এ ব্যবহার করে।আপনি নাও বলতে পারছেন না আবার সমস্যা ও পরতে হয়। কারন অনেকে না বুঝে আপনার কোন একটা দরকারি সফটওয়্যার ডিলেট করে দিতে পারে আবার এমন একটা সফটওয়্যার ইন্সটল করলো যা অপনার কম্পিউটার এর ক্ষতি করতে পারে, আপনি অবশ্যই তা চান না এমনটি হক আপনার সাথে। তো চলুন দেখি কিভাবে এটি করতে হয়।

প্রথমে কন্ট্রোল প্যনেল এ ক্লিক করুন

![](https://dnc.techtunes.io/tDrive/tuner/asifparvezasif/502030/1_controll_panal.png)

এর পর add or remove user accounts  এ ক্লিক করুন।

![](https://dnc.techtunes.io/tDrive/tuner/asifparvezasif/502030/2_add_or_remove_user.png)

administrator এ  ক্লিক করুন

![](https://dnc.techtunes.io/tDrive/tuner/asifparvezasif/502030/3_administrator.png)

এর পর create a password এ ক্লিক করুন

![](https://dnc.techtunes.io/tDrive/tuner/asifparvezasif/502030/4_create_passowrd.png)

নিউ পাসওয়ার্ড এবং কনফার্ম  পাসওয়ার্ড দিয়ে create password  ক্লিক করুন।

![](https://dnc.techtunes.io/tDrive/tuner/asifparvezasif/502030/5_password-and-save.png)

create a new account এ ক্লিক করুন নিচের মত করে।

![](https://dnc.techtunes.io/tDrive/tuner/asifparvezasif/502030/6_create-new-account.png)

একটা নাম দেন আর standard user টিক  দেন। এর পর create account এ  ক্লিক করুন

![](https://dnc.techtunes.io/tDrive/tuner/asifparvezasif/502030/7_name_type_save-1.png)

administrator account এর মত করে এটিতে পাসওয়ার্ড সেট করে দিতে পারবেন। এখন থেকে আপনার কম্পিউটার এ আপনি ছারে অন্য কেউ লগিন করলে কন সফটওয়্যার ডিলেট বা ইনিস্টল করতে পারবেনা আপনার অনুমতি ছাড়া।
