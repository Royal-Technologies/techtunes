আসসালামু আলাইকুম। সবাই ভালো আছেন। প্রতিদিনের মত আজকেও আপনাদের মাঝে হাজির হলাম নতুন একটি টিউন নিয়ে।আমি কয়েকদিন আগে জিপি ফ্রি নেটের একটি ভিডিও টিউটোরিয়াল সহ টিউন করেছিলাম।সেখানে যে apps দিয়ে ফ্রি নেট কানেক্ট করতে হয় সেই apps টির নাম http injector. অনেকেই প্রশ্ন করবছেন যে, এটার configuration কিভাবে করতে হয়।তাদেরকে দেখাবো কিভাবে configuration করবেন।

আর যারা এখনো জিপি ফ্রি নেট কানেক্ট করতে পারেন নাই তারা এখনি আমার আগের ভিডিওটি খুব ভালো করে পুরা ভিডিওটি দেখুন। কানেক্ট হবেই হবে। না হয়ে যাবে কোথায়।আমি এই মাসে ৭৮ জিবি নেট ব্যবহার করেছি ফ্রি। আমি চার মাস যাবত কোন নেট কিনি নাই।সম্পূর্ণ ফ্রি ব্যবহার করে যাচ্ছি। আর এই apps টির স্পিড অসাধারণ। ব্যবহার করললেই বুঝতে পারবেন। এটা যে কোন browser দিয়ে ব্যবহার করতে পারবেন।আনলিমিটেড ডাউনলোড দিতে পারবেন। ২/৩ mb স্পিডে বড় ফাইল ডাউনলোড হবে। তো আমি ২টা ভিডিও লিংক দিব। প্রথমে http injector config তারপর দিব কিভাবে জিপি ফ্রি নেট কানেক্ট করতে হয় নতুন নিয়মে।
