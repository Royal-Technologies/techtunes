***বিসিল্লাহির রাহমানির রাহিম***

আসসালামলাইকুম, সবাই কেমন আছেন? আশা করি আল্লাহর অশেষ রহমতে সবাই ভাল আছেন। আজ আমি আপনাদেরকে দেখাব  কিভাবে আপনাদের  Wifi Password এবং Router er Username & password Change করবেন ত চলুন শুরু করি...

1. প্রথমে আপনার রাওটার এর Default Getway বের করতে হবে। বাংলাদেশ এর বেশিরবাগ Router এর Default getway  [192.168.0.1](http://192.168.0.1/)
2. click here   [192.168.0.1](http://192.168.0.1/)
3. তারপর আপনার Username & password দিয়ে লগ ইন করতে হবে [![](https://dnc.techtunes.io/tDrive/tuner/kowsar_ahmed/532067/1-1.png)](https://www.techtunes.io/internet/tune-id/532067/attachment/1-5347)
4. তারপর Router এর মেনু বার থেকে Wireless >> Wireless Security  তে যাবেন
5. তারপর WPA-PSK/WPA2-PSK এর মধ্যে PSK Password option দেখেবন[![](https://dnc.techtunes.io/tDrive/tuner/kowsar_ahmed/532067/2.png)](https://www.techtunes.io/?attachment_id=532073)
6. Old PassWord Remove করে New PassWord Set করুন। তবে PassWord  অবশ্যই ৮ ডিজিট এর হতে হবে
7. New Password set করে Save আ ক্লিক করতে হবে[![](https://dnc.techtunes.io/tDrive/tuner/kowsar_ahmed/532067/3.png)](https://www.techtunes.io/internet/tune-id/532067/attachment/3-2961)
8. Router Reboot করুন / Restart করুন[![](https://dnc.techtunes.io/tDrive/tuner/kowsar_ahmed/532067/4.png)](https://www.techtunes.io/internet/tune-id/532067/attachment/4-2296)
9. হয়ে গেল আপনার Wifi Password পরিবর্তন
