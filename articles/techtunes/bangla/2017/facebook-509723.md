প্রথমে আপনাকে [Business Manager](https://www.facebook.com/business/help/1612355968988019) এ [Create Account](https://business.facebook.com/) যদি কোনো Account আগে থেকে খোলা না থাকে।

![FB Page Ownership](https://4.bp.blogspot.com/-DKHxML4wl8c/WZUmJS1MRYI/AAAAAAAAAPI/hgtrPYm5nDQ671MDKWZThqgycH3axNmngCLcBGAs/s640/0.png "FB Page Ownership")

## যেভাবে Page এর Ownership নিতে হয়:

(১) [Business Manager](https://www.facebook.com/business/help/1612355968988019) যান এবং [Business Settings](https://business.facebook.com/settings) button টিতে Click করুন।

![FB Page Ownership](https://3.bp.blogspot.com/-1F2a0fFpVe0/WZUmAOw0ZuI/AAAAAAAAAPE/4SxyxIefqUY7oO7OXdvqE0JzBfxYbYxBwCLcBGAs/s640/1.png "FB Page Ownership")

(২) Pages tab টিতে Click করুন।

![FB Page Ownership](https://3.bp.blogspot.com/-3hl4KYlSS9E/WZUmdcDmHQI/AAAAAAAAAPM/yGfAgaikl5YZKzgntD2V6RuKSAPaIyrTgCLcBGAs/s640/2.png "FB Page Ownership")

(৩) Add New Pages এ Click করুন এবং Add a Page select করুন।

![FB Page Ownership](https://1.bp.blogspot.com/-RGb2t6KSIsw/WZUmvH85a6I/AAAAAAAAAPQ/Cgx9PIGoWZ0fvgmNXZAxKViq4Tyt82VEQCLcBGAs/s640/3.png "FB Page Ownership")

(৪) Facebook Page টির না অথবা URL Box টিতে লিখুন।

![FB Page Ownership](https://2.bp.blogspot.com/-ljx1CQBbe9I/WZUnFIUKgxI/AAAAAAAAAPU/py0mjJwBFiwTdJCgwJX-22jPyKL8wbMygCLcBGAs/s640/4.png "FB Page Ownership")

(৫) আপনি Page Owner হয়ে যাবেন এবং অন্যান্য Admins আপনাকে Page Role থেকে Remove করতে সক্ষম হবে না।

![FB Page Ownership](https://4.bp.blogspot.com/-kendOuQOGxU/WZUnUTFRVvI/AAAAAAAAAPY/bcIHcUCUwEwV234bKHebqPNrAZx04cZ_gCLcBGAs/s640/5.png "FB Page Ownership")

বিদ্রঃ কোনো Page এর Ownership নিতে হলে, আপনাকে অবশ্যই Page টির Admin হতে হবে। আর কেউ যদি আগেই কোনো Page এর Ownership নিয়ে নেয়, তাহলে সেই Page এর Ownership আর অন্য কেউ নিতে পারবে না।

অসুবিধাঃ Page Ownership নিলে, Opera Mini এবং UC Mini Browser দিয়ে (Mobile Basic Version Website: [mbasic.facebook.com](https://mbasic.facebook.com/) এবং Mobile Free Version Website: [free.facebook.com](https://free.facebook.com/)) Page এর হয়ে Post এবং Comment করা যায় না।
