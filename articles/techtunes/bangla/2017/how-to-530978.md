বিসমিল্লাহির রাহমানির রাহীম

আসসালামু আলাইকুম,

বন্ধুরা কেমন আছেন ? আশা করি মহান আল্লাহর ইচ্ছায় সবাই ভাল আছেন। আমিও ভাল আছি আলহামদুলিল্লাহ্‌। বন্ধুরা আজকের টিউন টি মূলত নতুনদের জন্য। যারা বিষয়টি জানেন তারা লাইক এবং শেয়ার করে নতুনদেরকে দেখার সুযোগ করে দিবেন আশা করি।

নতুনরা ধারাবাহিক ভাবে নীচের ধাপগুলি অনুসরন করুন।

```
১) আপনার কম্পিউটারে Google Chrome ব্রাউজার টি ওপেন করুন।
২) ব্রাউজারের উপরের ডান কোণে (Wrench) রেঞ্চ আইকনটিতে ক্লিক করুন।

![](https://dnc.techtunes.io/tDrive/tuner/i4mctg/530978/Bookmark-1-2.png)
৩) আপনার মাউস টি প্রথমে Bookmarks (বুকমার্ক) করুন এবং Bookmark manager 
"বুকমার্ক ম্যানেজার" নির্বাচন করুন।
![](https://dnc.techtunes.io/tDrive/tuner/i4mctg/530978/Bookmark-2.png)

৪) দেখুন বুকমার্ক ম্যানেজারের জন্য আপনার Chrome উইন্ডোতে একটি নতুন ট্যাব খুলেছে।

![](https://dnc.techtunes.io/tDrive/tuner/i4mctg/530978/Bookmark-3.png)
৫) Organize-এ ক্লিক করুন।
![](https://dnc.techtunes.io/tDrive/tuner/i4mctg/530978/Bookmark-4.png)

  ৬) "Export bookmarks to HTML file_" (HTML-এইচটিএমএল ফাইলে বুকমার্ক রপ্তানি) নির্বাচন করুন।

![](https://dnc.techtunes.io/tDrive/tuner/i4mctg/530978/Bookmark-5.png)

৭) প্রদর্শিত উইন্ডোতে আপনার বুকমার্ক ফাইলের একটি file name দিন এবং সংরক্ষণ করার জন্য একটি 
অবস্থান সেট করুন।

![](https://dnc.techtunes.io/tDrive/tuner/i4mctg/530978/Bookmark-6.png) 

৮) Save এ ক্লিক করুন। 
৯) আপনি দেখতে পারেন বুকমার্ক ফাইল আপনার ডেস্কটপে Export (রপ্তানি) করা হয়েছে।

![](https://dnc.techtunes.io/tDrive/tuner/i4mctg/530978/Bookmark-7.png)

১০) আপনি একইভাবে গুগল ক্রোম থেকে বুকমার্ক ইম্পোর্ট করতে পারেন। 
শুধুমাত্র "Export bookmarks to HTML file_" (HTML-এইচটিএমএল ফাইলে বুকমার্ক রপ্তানি) এর পরিবর্তে 
"Import bookmarks from HTML file_" (HTML-এইচটিএমএল ফাইল থেকে বুকমার্কগুলি আমদানি করুন) 
নির্বাচন করুন।
```
