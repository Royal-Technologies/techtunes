আসসালামু আলাইকুম, কেমন আছেন টেকটিউনস কমিউনিটি? আশা করছি সবাই ভাল আছেন। আজকে আবার হাজির হলাম নতুন টিউন নিয়ে। চলুন শুরু করা যাক।

বর্তমানে প্রযুক্তি অনেক বেশিই এগিয়ে, এখন আপনার পিসিটি ব্যবহার করার জন্য সব সময় যে এটি সাথেই রাখতে হবে এমন নয়। এখন খুব সহজেই Chrome Remote Desktop সাহায্যে বিশ্বের যেকোনো জায়গা থেকে আপনার কম্পিউটারে এক্সেস নিতে পারবেন।

## Chrome Remote Desktop কি?

![](https://dnc.techtunes.io/tDrive/tuner/2020/07/techtunes_32e696eb577b72c2d1758f94cfa5f0e9.png)

শুধু মাত্র ইন্টারনেট কানেকশন থাকলেই হাজার মাইল দূর থেকেই আপনার কম্পিউটার ব্যবহার করতে পারবেন, যেমনি সামনে থেকে করতেন। দুর থেকে কন্ট্রোল করার এমন অনেক অ্যাপ থাকলেও, Chrome Remote Desktop যথেষ্ট ভাল। যেটি ব্যবহার খুবই সহজ, ব্যবহারের জন্যও খুবই কম রিসোর্স লাগে, এবং মেজর অপারেটিং সিস্টেম গুলোতে সাপোর্ট করে।

## Chrome Remote Desktop

অফিসিয়াল ওয়েবসাইট @ [Chrome Remote Desktop](https://remotedesktop.google.com/)

## কিভাবে ব্যবহার করবেন Chrome Remote Desktop

দারুণ এই টুলটি ব্যবহার করার জন্য অবশ্যই আপনাকে কিছু কনফিগারেশন করতে হবে এটা হয়তো বলার অপেক্ষা রাখে না। তবে একবার কনফিগারেশন করে নিলে পরেরবার কোন কিছু করা ছাড়াই ব্যবহার করতে পারবেন।

প্রথমে গুগল একাউন্টে লগইন থাকা অবস্থায় [Chrome Remote Desktop](https://remotedesktop.google.com/) এর অফিসিয়াল ওয়েবসাইটে চলে যান।

পেজে Get Started অপশন দেখতে পাবেন ক্লিক করুন। নতুন পেজ ওপেন হলে **Set up remote access** এ ক্লিক করুন।

![](https://dnc.techtunes.io/tDrive/tuner/2020/07/techtunes_87ad6681e81996196afdf651358067fe.png)

এটি আপনাকে ক্রোম এক্সটেনশন স্টোরে নিয়ে যাবে। Chrome Remote Desktop এক্সটেনশনটি ইন্সটল করে নিন।

![](https://dnc.techtunes.io/tDrive/tuner/2020/07/techtunes_e6fcfd9d6da6721fb84112ad35459a5d.png)

আপনার পিসিটি রিমোট-লি এক্সেস পাবার জন্য প্রস্তুত।

## অন্য কেউ যেভাবে আপনার পিসি ম্যানেজ করবে

আপনার যদি কোন টেকনিক্যাল এসিস্ট্যান্ট থাকে অথবা চান অন্য কেউ আপনার পিসিতে এক্সেস নিক তাহলে সেটিও এনে-ভল করে দিতে পারবেন।

এজন্য আপনাকে একটি কোড তৈরি করে নিতে হবে।

প্রথমে [Chrome Remote Desktop](https://remotedesktop.google.com/) চলে যান এবং সেখানে দুটি ট্যাব দেখতে পাবেন। **Remote Support** ট্যাবটিতে ক্লিক করুন।

![](https://dnc.techtunes.io/tDrive/tuner/2020/07/techtunes_83dbd8c8e9627b6b854b73655687ec8e.png)

এখানে ক্লিক করে কোড জেনারেট করতে পারবেন। একটি বিষয় মাথায় রাখবেন, প্রতিটি কোড পাঁচ মিনিট পর্যন্ত কাজ করবে, এর পর আর এটি ব্যবহার করা যাবে না।

![](https://dnc.techtunes.io/tDrive/tuner/2020/07/techtunes_7e649a183b0d53334f6eb3c7138440e1.png)

## কিভাবে নিজে দূর থেকে এক্সেস নিবেন?

এবার চলুন দেখে নেয়া যাক কিভাবে দুর থেকে আপনার পিসিতে কানেক্ট হওয়া যায়। প্রথমে যান [Chrome Remote Desktop](https://remotedesktop.google.com/) এবং **Remote Support** ক্লিক করুন এবং Give Support এ কোড দিয়ে কানেক্ট করুন।

![](https://dnc.techtunes.io/tDrive/tuner/2020/07/techtunes_46a1cbaa28d9e5d900237ebcf58f36bb.png)

তবে আপনার পিসিতে ওই মুহূর্তে কাউকে থাকতে হবে কোডটি জেনেরেট করে দেয়ার জন্য। *আপনি যদি কারো সাহায্য ছাড়াই কানেক্ট হতে চান তাহলে কিভাবে সেটি করবেন তা টিউনের শেষে দেওয়া আছে।*

কোডটি দিয়ে কানেক্ট করা হলে নিচের মত একটি উইন্ডো আসবে এবং কাউকে Share এ ক্লিক করতে হবে।

![](https://dnc.techtunes.io/tDrive/tuner/2020/07/techtunes_f927ea3aed74c3d052fb1c2c6464bc3b.png)

কানেক্ট হয়ে গেলে আপনার স্ক্রিন সাইজ ঠিক করার জন্য নিচের অপশন গুলো পেতে পারেন। অপশন গুলো Macbook  এ আসলেও Windows 10 এ পাই নি।

![](https://dnc.techtunes.io/tDrive/tuner/2020/07/techtunes_b652ec544bf192dda55583bfb65d3994.png)

ডিস-কানেক্ট করার জন্য Stop Sharing  এ ক্লিক করুন

![](https://dnc.techtunes.io/tDrive/tuner/2020/07/techtunes_2370a79af78dd75b719d906fd0aba61a.png)

## কারো সাহায্য ছাড়া এক্সেস নেয়া

আপনার ডিভাইসটি আপনি [Chrome Remote Desktop](https://remotedesktop.google.com/) এ এড করে নিতে পারেন এজন্য প্রতিবার আপনাকে কোড তৈরি করতে হবে না বা এক্সেস নেয়ার জন্য অন্য কারো সাহায্য লাগবে না।

প্রথমে [Chrome Remote Desktop](https://remotedesktop.google.com/)এ চলে যান, Remote Access ট্যাবে ক্লিক করুন। নিচে Turn On করুন।

![](https://dnc.techtunes.io/tDrive/tuner/2020/07/techtunes_310c5fa512ba995f6a091e490e3619b5.png)

আপনার পিসির নামটি দিতে বলবে। মনে রাখার জন্য যেকোনো নাম দিতে পারেন।

![](https://dnc.techtunes.io/tDrive/tuner/2020/07/techtunes_53f660b3f4000ca7b001b23381ca905a.png)

দূর থেকে সহজেই এক্সেস পেতে মনে রাখার মত একটি পিন নাম্বার দিন।

![](https://dnc.techtunes.io/tDrive/tuner/2020/07/techtunes_cc42b00510e8c2ee34f40aac39ef5650.png)

দেখুন আমার পিসিটি সেভ হয়ে গেছে। এখন আমি [Chrome Remote Desktop](https://remotedesktop.google.com/) ঢুকে সহজেই এই ডিভাইসটি পেয়ে যাব।

![](https://dnc.techtunes.io/tDrive/tuner/2020/07/techtunes_5fa70d421433e5f0a651c70d255bab0d.png)

তবে মনে রাখতে হবে আপনার ডিভাইসটি কিন্তু নির্দিষ্ট গুগল একাউন্টে সেভ হয়ে থাকবে। পরবর্তীতে যখন [Chrome Remote Desktop](https://remotedesktop.google.com/) ব্যবহার করবেন তখন অবশ্যই একই একাউন্ট ব্যবহার করুন। আপনার পিসি Sleep Mode  এ থাকলে কিন্তু কানেক্ট হবে না বিষয়টি মাথায় রাখবেন।

## Chrome Remote Desktop এর সুবিধা

চলুন দেখা নেয়া যাক কেন ব্যবহার করবেন [Chrome Remote Desktop](https://remotedesktop.google.com/) এবং এর কিছু সুবিধা।

- বিশ্বের যেকোনো জায়গা থেকে আপনার পিসিতে এক্সেস পেতে পারবেন।
- অতিরিক্ত রিসোর্স এর দরকার হয় না।
- ভারী কোন সফটওয়্যার ইন্সটল ছাড়াই Remote Desktop এর সকল সুবিধা পাওয়া যায়।

## শেষ কথাঃ

আমরা যখন বাসা থেকে দুরে কোথাও থাকি তখন হটাৎ করেই পিসিতে থাকা কোন গুরুত্বপূর্ণ ফাইল দরকার হতে পারে, তৎক্ষণাৎ ফাইলটি পাবার জন্য ব্যবহার করতে পারেন Chrome Remote Desktop অথবা কোথাও ঘুরতে গিয়েও নিজের পিসি প্রয়োজনে ব্যবহার করতে পারেন এটি।

কেমন হল আজকের টিউন তা অবশ্যই টিউমেন্টের মাধ্যমে জানাবেন।

পরবর্তী টিউন পর্যন্ত ভাল থাকুন। আমাদের সমসাময়িক যে সংকট চলছে এর থেকে রক্ষা পেতে সবাই সচেতন থাকবেন কারণ আপনার সচেতনতাই পারে আমাদের সবাইকে খারাপ অবস্থা থেকে বাঁচাতে। সবাই বাসায় থাকুন আর আল্লাহর উপর ভরসা রাখুন, আল্লাহ হা-ফেজ।
