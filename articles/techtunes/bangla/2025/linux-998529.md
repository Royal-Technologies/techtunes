নতুন একটা ল্যাপটপ বা ডেস্কটপ কিনেছেন? পুরনো পিসি-তে নতুন করে Ubuntu 25.04 ইন্সটল করেছেন? ভাবছেন, "উফফ! আবার সব নতুন করে শুরু করতে হবে!" 😫 আরে, চিন্তা কীসের? Ubuntu ইন্সটল করা তো সবে শুরু! আসল মজা তো এরপর! 😉

আজ আমি Ubuntu 25.04 ইন্সটল করার পরপরই কী কী করা উচিত, সে বিষয়ে একটা বিস্তারিত গাইড দেবো। এই Tipsগুলো আপনার Ubuntu Experience-কে আরও স্মুথ, কার্যকরী, এবং ব্যক্তিগত করে তুলবে। System সেটিংস কাস্টমাইজ করা থেকে শুরু করে প্রোডাক্টিভিটি App ইন্সটল করা, গেমিংয়ের জন্য সিস্টেম প্রস্তুত করা – সবই থাকবে এই টিউনে। তাই, আর দেরি না করে, আরাম করে বসুন, কফি বা চা নিয়ে তৈরি থাকুন, আর আমার সাথে Ubuntu-র জাদু আবিষ্কার করুন! ☕✨

## 1. System আপডেট: প্রথম ধাপ, সাফল্যের চাবিকাঠি! 🔑

![Ubuntu 25.04 ইন্সটলের পরপরই যে ১৩টি জরুরি প্রো কাজ করবেন!](https://dnc.techtunes.io/tDrive/tuner/2025/05/techtunes_064852cb4a524b0f79715c42120d1a89.png)

Ubuntu ইন্সটল করার পরেই প্রথম এবং সবচেয়ে গুরুত্বপূর্ণ কাজ হলো System আপডেট করা। কেন ভাই? কারণ, System আপডেটের মাধ্যমে আপনার অপারেটিং System লেটেস্ট Security Threats থেকে সুরক্ষিত থাকে, Performance Improvements পাওয়া যায়, আর বিভিন্ন Software-এর মধ্যে Compatibility Improve হয়। এটা অনেকটা আপনার গাড়ির নিয়মিত সার্ভিসিং করার মতো! 🛠️

Terminal খুলুন (`ctrl + Alt + T` চাপুন), আর নিচের Command টি লিখে Enter চাপুন:

```
sudo apt update &amp;&amp; sudo apt upgrade -y
```

এখানে:

- `sudo`: এই Command টি অ্যাডমিনিস্ট্রেটর প্রিভিলেজ-এর সাথে রান করার জন্য ব্যবহার করা হয়।
- `apt`: এটি Ubuntu-র Package Management Tool।
- `update`: এই Command টি আপনার Software Sources থেকে লেটেস্ট Package Information ডাউনলোড করে।
- `upgrade`: এই Command টি আপনার System-এ ইন্সটল করা সমস্ত Packages-কে লেটেস্ট Version-এ আপগ্রেড করে।
- `-y`: এই Option টি ব্যবহার করলে আপগ্রেড করার সময় কোনো Confirmation Prompt আসবে না। System অটোমেটিকভাবে সব Package আপগ্রেড করে দেবে।

এই Process-এ একটু সময় লাগতে পারে, বিশেষ করে যদি আপনার Internet Connection স্লো হয়। তাই, ধৈর্য ধরে অপেক্ষা করুন, আর System-কে তার কাজ করতে দিন। আপগ্রেড শেষ হওয়ার পরে Computer রিস্টার্ট করতে পারেন।

## 2. Graphics Card Drivers: গেমিং ও গ্রাফিক্সের দুনিয়ায় সুপার পাওয়ার! 💪

আপনার যদি Nvidia বা Amd-এর মতো ডেডিকেটেড Graphics Card থাকে, তাহলে Graphic-Intensive Applications (যেমন গেমিং, ভিডিও এডিটিং, থ্রিডি মডেলিং) চালানোর জন্য Optimized Gpu Drivers ইন্সটল করাটা খুবই জরুরি। ভুল Drivers ইন্সটল করলে System Crash করতে পারে, Performance খারাপ হতে পারে, আর Graphical Glitches দেখা দিতে পারে। 😱

Ubuntu তে সঠিক Graphics Card Drivers খুঁজে বের করা এবং ইন্সটল করার জন্য নিচের Command টি ব্যবহার করুন:

```
ubuntu-drivers devices
```

এই Command টি আপনার Graphics Card মডেল এবং তার জন্য Available Drivers-এর একটা List দেখাবে। List-এ Open Source এবং Proprietary Drivers দুটোই থাকতে পারে। Generally, Proprietary Drivers Open Source Drivers-এর চেয়ে বেটার Performance দেয়। রিকমেন্ডেড Driver-এর Name খুঁজে বের করুন, আর তারপর নিচের Command টি ব্যবহার করে সেটি ইন্সটল করুন:

```
sudo apt install <driver_name>
```

<driver\_name> এর জায়গায় List থেকে পাওয়া Driver-এর Name বসিয়ে দিন। উদাহরণস্বরূপ:

```
sudo apt install nvidia-driver-535
```

ইন্সটলেশন শেষ হওয়ার পরে System রিস্টার্ট করুন।

যদি আপনি নিশ্চিত না হন যে কোন Driver আপনার জন্য সবচেয়ে ভালো, তাহলে Ubuntu-কে অটোমেটিকভাবে Best Driver খুঁজে ইন্সটল করতে দিন:

```
sudo ubuntu-drivers autoinstall
```

এই Command টি আপনার Hardware কনফিগারেশন এনালাইসিস করে Optimal Driver ইন্সটল করবে। এটা অনেকটা অটোমেটিক ট্রান্সমিশন গাড়ির মতো! 🚗

## 3. Flatpak: Apps-এর অবাধ রাজত্ব! 👑

![Ubuntu 25.04 ইন্সটলের পরপরই যে ১৩টি জরুরি প্রো কাজ করবেন!](https://dnc.techtunes.io/tDrive/tuner/2025/05/techtunes_8fca18b4568c57f37b987fe774510470.jpg)

[Flatpak](https://flathub.org/) হলো একটি Universal Package Management System, যা যেকোনো লিনাক্স ডিস্ট্রিবিউশনে Application ইন্সটল করার একটি সহজ এবং নির্ভরযোগ্য উপায়। Flatpak ব্যবহার করার সবচেয়ে বড় সুবিধা হলো, এটি Applications-কে System থেকে আলাদা করে রাখে (sandboxing), যার ফলে Security বাড়ে। এছাড়াও, Flatpak Applications-এর Dependencies System-এর সাথে Conflict করে না। 🤝

Flatpak ইন্সটল করার জন্য নিচের Command টি ব্যবহার করুন:

```
sudo apt install flatpak
```

এরপর, Flat Hub Repository যোগ করুন, যাতে Android Studio, vs Code, Chrome, Discord-এর মতো হাজারো Applications Access করতে পারেন:

```
sudo flatpak remote-add -if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo
```

এই Command টি আপনার System-এ Flat Hub Repository যোগ করবে। Repository যোগ করার পরে, Computer রিস্টার্ট করুন। তারপর, Gnome Software Center-এর জন্য Flatpak প্লাগইন ইন্সটল করুন, যাতে আপনি Graphical Interface ব্যবহার করে Flatpak Applications ইন্সটল করতে পারেন:

```
sudo apt install gnome-software-plugin-flatpak
```

এখন আপনি Gnome Software Center ব্যবহার করে Flatub থেকে Apps ব্রাউজ করতে এবং ইন্সটল করতে পারবেন।

## 4. প্রয়োজনীয় Applications, Packages এবং Fonts: কাজের পরিবেশ তৈরি করুন! 💼

![Ubuntu 25.04 ইন্সটলের পরপরই যে ১৩টি জরুরি প্রো কাজ করবেন!](https://dnc.techtunes.io/tDrive/tuner/2025/05/techtunes_9e479312c05f432081e665c077e5c7f0.png)

Ubuntu Experience আরও স্মুথ এবং প্রোডাক্টিভ করার জন্য কিছু Essential Applications, Packages এবং Fonts ইন্সটল করা দরকার। Multimedia Codecs, Flash Player এবং অন্যান্য Restricted Components ইন্সটল করার জন্য নিচের Command টি ব্যবহার করুন:

```
sudo apt install ubuntu-restricted-extras
```

এই Package-এর মধ্যে অনেকগুলো Useful Components আছে, যা আপনার Daily Tasks-এর জন্য দরকার হতে পারে।

এছাড়াও কিছু Useful Gui Applications যেমন:

- Obs Studio: স্ক্রিন রেকর্ডিং এবং লাইভ স্ট্রিমিং-এর জন্য।
- Vlc Media Player: প্রায় সব ধরনের Video এবং Audio Files প্লে করার জন্য।
- Gimp: Image এডিটিং এবং Graphic ডিজাইন করার জন্য।
- Libreoffice: Document তৈরি করা, স্প্রেডশীট বানানো, এবং Presentation তৈরি করার জন্য।
- Transmission: টরেন্ট ডাউনলোড করার জন্য।
- Discord: বন্ধুদের সাথে চ্যাট করা এবং ভয়েস কল করার জন্য।

এই Applications গুলো আপনি App Store থেকে সার্চ করে ইন্সটল করতে পারেন, অথবা Terminal ব্যবহার করে ইন্সটল করতে পারেন।

এছাড়াও কিছু প্রয়োজনীয় Fonts ইন্সটল করার জন্য:

```
sudo apt install fonts-liberation ttf-mscorefonts-installer
```

এই Command টি Liberation Fonts এবং Microsoft Core Fonts ইন্সটল করবে, যা Document এবং Web Page দেখার সময় কাজে লাগবে।

## 5. Firefox কাস্টমাইজেশন: Web Browsing হোক আরও নিরাপদ ও আরামদায়ক! 🌐

![Ubuntu 25.04 ইন্সটলের পরপরই যে ১৩টি জরুরি প্রো কাজ করবেন!](https://dnc.techtunes.io/tDrive/tuner/2025/05/techtunes_38609ee631c5ee2d208f4e3fd87ef58d.png)

Firefox Ubuntu-র ডিফল্ট Web Browser। Firefox-কে আরও নিরাপদ এবং আরামদায়ক করার জন্য কিছু Settings কাস্টমাইজ করা যেতে পারে।

- Privacy Settings পরিবর্তন করুন: Firefox-এর Preferences-এ গিয়ে Privacy & Security Section-এ Tracking Protection Enable করুন, Cookies এবং Site Data ম্যানেজ করুন, এবং Security Certificates সেটিংস কনফিগার করুন।
- Search Engine পরিবর্তন করুন: ডিফল্ট Search Engine Google থেকে পরিবর্তন করে Duckduckgo বা Startpage ব্যবহার করতে পারেন, যা আপনার Search History ট্র্যাক করে না।
- Extensions ইন্সটল করুন: Firefox Add-Ons Store থেকে Useful Extensions ইন্সটল করতে পারেন, যেমন Adblock Plus, Umatrix, Https Everywhere, Lastpass।

এছাড়াও, Firefox-এর Appearance নিজের পছন্দমতো কাস্টমাইজ করতে পারেন Themes ব্যবহার করে।

## 6. Dock সেটিং করুন: Application Access হোক আরও ফাস্ট! 🚀

Ubuntu Dock হলো Screen-এর বাম দিকে থাকা Application Launcher। Dock-টিকে নিজের কাজের সুবিধা অনুযায়ী কাস্টমাইজ করা যেতে পারে।

- Dock Size এবং Icon Size পরিবর্তন করুন: Settings > Appearance এ গিয়ে Dock Size এবং Icon Size অ্যাডজাস্ট করতে পারেন।
- Dock Position পরিবর্তন করুন: Dock-টিকে Screen-এর বাম, ডান, বা নীচে রাখতে পারেন।
- Launcher Behavior পরিবর্তন করুন: Single Click-এ Application লঞ্চ করার জন্য Settings পরিবর্তন করতে পারেন।

এছাড়াও, আপনি Dock-এ নিজের পছন্দের Application যোগ করতে বা সরাতে পারেন।

## 7. Wellbeing ফিচার: নিজের শরীরের প্রতি খেয়াল রাখুন! ❤️

![Ubuntu 25.04 ইন্সটলের পরপরই যে ১৩টি জরুরি প্রো কাজ করবেন!](https://dnc.techtunes.io/tDrive/tuner/2025/05/techtunes_9b9ac1a051c8bc836ae36e26f08c8ca2.png)

কম্পিউটারে কাজ করার সময় নিজের শরীরের প্রতি খেয়াল রাখাটা খুবই জরুরি। Ubuntu-র Wellbeing ফিচার আপনাকে এই ব্যাপারে সাহায্য করতে পারে। Settings > Wellbeing এ গিয়ে Screen Time Limit সেট করতে পারেন, Break Reminders Enable করতে পারেন, এবং Night Light মোড ব্যবহার করতে পারেন।

## 8. Touchpad Settings: ল্যাপটপ ব্যবহার আরও সহজ করুন! 💻

Ubuntu ল্যাপটপে ইন্সটল করা থাকলে Touchpad Settings কাস্টমাইজ করাটা খুবই দরকারি। Mouse & Touchpad Settings থেকে Touchpad Sensitivity, Scrolling Speed, এবং Gestures নিজের পছন্দমতো সেট করে নিন।

## 9. Appearance কাস্টমাইজেশন: Desktop হোক আপনার মনের মতো! 🎨

Ubuntu-র Look and Feel কাস্টমাইজ করার জন্য অনেক Options রয়েছে। Settings > Appearance এ গিয়ে Theme পরিবর্তন করতে পারেন, Icon Pack ইন্সটল করতে পারেন, এবং Cursor Theme পরিবর্তন করতে পারেন। আপনি নিজের পছন্দমতো Wallpaper সেট করতে পারেন, এবং Desktop Icons-এর সাইজ এবং পজিশন পরিবর্তন করতে পারেন।

## 10. Multimedia Codecs: সব Video চালান কোনো ঝামেলা ছাড়াই! 🎬

Ubuntu তে ডিফল্টভাবে Mp4, Avi, Mkv-এর মতো কিছু জনপ্রিয় Video Formats প্লে করা যায় না, কারণ প্রয়োজনীয় Codecs ইন্সটল করা থাকে না। Video প্লে করার জন্য নিচের Command টি ব্যবহার করে Multimedia Codecs ইন্সটল করুন:

```
sudo apt install ubuntu-restricted-extras
```

এই Package-এর মধ্যে অনেকগুলো Video এবং Audio Codecs আছে, যা আপনার Multimedia Experience Improve করবে। ইন্সটলেশন শেষ হওয়ার পরে Computer রিস্টার্ট করুন।

## 11. Terminal কাস্টমাইজেশন উইথ Starship: Terminal হোক আরও আকর্ষণীয়! ✨

Ubuntu-র ডিফল্ট Terminal-টা দেখতে একটু Boring লাগে, তাই না? Starship ব্যবহার করে Terminal-কে আরও আকর্ষণীয় এবং তথ্যপূর্ণ করে তুলতে পারেন। প্রথমে, একটি Nerd Font ডাউনলোড এবং ইন্সটল করুন (fira Code Nerd Font রিকমেন্ডেড)। তারপর নিচের Command গুলো ব্যবহার করুন:

```
curl -sS https://starship.rs/install.sh | sh
```

এই Command টি আপনার System-এ Starship ইন্সটল করবে। তারপর, আপনার Shell Configuration File (যেমন.bashrc বা.zshrc) এ নিচের Line টি যোগ করুন:

```
eval "$(starship init bash)" # or eval "$(starship init zsh)"
```

নতুন করে Terminal খুলুন, আর দেখুন Starship আপনার Terminal-এর Look and Feel পাল্টে দিয়েছে! Starship আপনার বর্তমান ডিরেক্টরি, Git Branch, Language Version এবং অন্যান্য গুরুত্বপূর্ণ Information দেখাবে।

## 12. Gnome Tweaks এবং Extension Manager: কন্ট্রোল করুন আপনার Desktop-কে! 🎛️

Gnome Tweaks এবং Extension Manager হলো দুটি Powerful Tool, যা Ubuntu Desktop কাস্টমাইজ করার জন্য ব্যবহার করা হয়।

Gnome Tweaks ইন্সটল করার জন্য নিচের Command টি ব্যবহার করুন:

```
sudo apt install gnome-tweaks
```

Gnome Tweaks ব্যবহার করে আপনি Window Title Bars কাস্টমাইজ করতে পারেন, Fonts পরিবর্তন করতে পারেন, Power Settings অ্যাডজাস্ট করতে পারেন, এবং আরও অনেক কিছু করতে পারেন।

Extension Manager ইন্সটল করার জন্য নিচের Command টি ব্যবহার করুন:

```
sudo apt install gnome-shell-extensions
```

Extension Manager ব্যবহার করে আপনি Desktop-এ নতুন ফিচার যোগ করতে পারেন, যেমন Weather Indicator, System Monitor, এবং Dock Customization।

## 13. Pika Backup: ডেটা হোক সুরক্ষিত, টেনশন ফ্রি থাকুন! 😌

![Ubuntu 25.04 ইন্সটলের পরপরই যে ১৩টি জরুরি প্রো কাজ করবেন!](https://dnc.techtunes.io/tDrive/tuner/2025/05/techtunes_8c5952638c6b4d39552cbacf5eed3798.jpg)

Data Loss একটি ভয়ঙ্কর অভিজ্ঞতা। Pika Backup ব্যবহার করে আপনি আপনার গুরুত্বপূর্ণ Data সুরক্ষিত রাখতে পারেন। Pika Backup একটি Simple এবং Easy-To-Use Backup Tool, যা আপনার Files এবং Folders-এর Regular Backup তৈরি করে।

Pika Backup ইন্সটল করার জন্য নিচের Command টি ব্যবহার করুন:

```
sudo apt install pika-backup
```

Pika Backup ওপেন করুন, একটি Backup Location সিলেক্ট করুন (যেমন একটি External Hard Drive বা একটি Network Share), এবং আপনার Files এবং Folders সিলেক্ট করুন। তারপর, Schedule সেট করুন, যাতে Pika Backup অটোমেটিকভাবে আপনার Data Backup করতে পারে।

এই ছিলো Ubuntu 25.04 ইন্সটল করার পরে ১৩টি জরুরি কাজ। এছাড়াও, আপনারা Gaming-এর জন্য Steam ইন্সটল করতে পারেন এবং Proton ব্যবহার করে Windows Games খেলতে পারেন। যারা Windows Application ব্যবহার করতে চান, তারা Bottles ব্যবহার করতে পারেন। আর System-এ ভার্চুয়াল মেশিন চালানোর জন্য Qemu/kvm সেট আপ করতে পারেন।

আশাকরি, এই বিস্তারিত গাইড আপনাদের Ubuntu 25.04 Experience-কে আরও আনন্দময় এবং ফলপ্রসূ করে তুলবে।
