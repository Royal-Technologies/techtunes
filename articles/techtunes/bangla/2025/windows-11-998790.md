আচ্ছা, একটা সত্যি কথা বলি? Laptop বা Desktop Shut Down হতে গিয়ে কার না বিরক্তি লাগে? বিশেষ করে যখন দেখেন, "Shut Down" Button এ Click করার পরেও আপনার প্রিয় PC টা ঘণ্টার পর ঘন্টা ধরে যেন ধ্যানমগ্ন হয়ে বসে আছে! 🐢 মনে মনে ভাবেন, "যাক বাবা, একটু ঘুরে এসে ফিরতেই তো সব ঠান্ডা!", 🚿 কিন্তু ফিরে এসে দেখেন সেই পুরোনো, চেনা Error Message – "This App Is Preventing You from Restarting." 😫 সত্যি করে বলুন তো, কেমন লাগে তখন? আমার তো মনে হতো যেন কেউ ইচ্ছে করে রাগিয়ে দিচ্ছে! 😠

বিশ্বাস করুন, এই যন্ত্রণার ভাগীদার শুধু আপনি একা নন। 🤝 Windows ব্যবহারকারী আমরা অনেকেই এই সমস্যায় ভুগি। তাই ভাবলাম, এমন একটা সহজ Solution বের করি, যেটা একেবারে "সবার জন্য"। 🎯 আর সেই ভাবনা থেকেই আজ আমি আপনাদের সাথে এমন একটা কার্যকারী Trick শেয়ার করতে যাচ্ছি, 💡 যেটা আপনার Windows 11 এর Shut Down Speed শুধু বাড়াবেই না, একেবারে উড়ন্ত গতি এনে দেবে! ✈️

আসলে, ঘটনাটা একটু অন্যরকম। 🤔 এটা আদতে কোনো Bug নয়, 🐛 বরং Microsoft তাদের ব্যবহারকারীদের কথা ভেবেই এই Safety Feature টি রেখেছে। 🛡️ মানে, তারা হয়তো ভেবেছে আপনার ভালোর জন্য এটা করা হয়েছে। 😇 কিন্তু সত্যি বলতে কী, এই Feature টা সব সময় কাজে লাগে না। 🤷 Windows 11 কী করে, জানেন? সে দেখে যে কোনো App খোলা আছে, 👁️ আর ভাবে, "আহা! হয়তো User এর কোনো Unsaved Work আছে!" 🥺 ব্যস! এইটুকু সন্দেহের বশেই সে আর Shut Down হতে চায় না, 🙅 পাছে আপনার অতি মূল্যবান Data Loss হয়ে যায়! 💾

## কেন এই Error Message, আর এর পেছনের আসল রহস্য 🕵️‍♀️

এবার আসি আসল কথায়। সবথেকে Interesting ব্যাপার হলো, 🤩 Text Editor 📝 বা Photo Editor 🖼️ এর মতো কোনো App খোলা না থাকলেও অনেক সময় এই Error Message টা Screen এ ভেসে ওঠে। 👻

আমার নিজের জীবনের একটা বাস্তব Story শেয়ার করি। 📖 একবার আমি MKSInvisibleWindow নামের একটা App এর জন্য এই Error পেয়েছিলাম, 🤯 আর সত্যি বলতে, আমি আজও জানি না ওই App টা আসলে কী ছিল! 🤷‍♀️ আবার এমনও হয়েছে, হয়তো Notepad এ সামান্য কিছু Text লিখেছি, ✍️ Save করার কোনো Plan ও ছিল না। 📝 কিন্তু Shut Down এর সময় Windows একেবারে নাছোড়বান্দা! 😠 Cancel করে Save করতে হবে, ❌ নাহলে সেই "Restart Anyway" অথবা "Shut Down Anyway" Button এ Click করতে হবে। 🖱️

এখন আপনারা নিজেরাই বলুন, আমরা যারা সাধারণ User, 🧑‍💻 তারা কি এত ঝক্কি সামলাতে রাজি? আমরা তো চাই এক Click এই Windows বন্ধ হয়ে যাক! 😴 প্রতিবার Button টিপে টিপে Shut Down করার Mood কি আর সব সময় থাকে, বলুন? 🙄 Good News হলো, 🥁 এই সমস্যার একটা চমৎকার সমাধান আছে! 🥳 Registry Edit করে Windows 11 কে Auto End Tasks করার জন্য Configure করা সম্ভব। ⚙️ তার মানে কী? তার মানে হলো, Windows নিজেই সব App Close করে দেবে, 🧹 আপনাকে আর কোনো বাড়তি ঝামেলা পোহাতে হবে না! 😌

## Apps Prevent করলে Windows 11 Shut Down করার Step-By-Step সহজ Guide 📝

![Windows 11 Shut Down হতে চায় না? আর সেই বিরক্তির দিন শেষ! এই Setting Change করুন, বিদ্যুৎ গতিতে PC বন্ধ করুন!](https://dnc.techtunes.io/tDrive/tuner/2025/05/techtunes_0e3cc525598a2a182589c217068ecc74.jpg)

তাহলে আর দেরী কেন? ⏳ চলুন, Registry Edit এর মাধ্যমে এই বিরক্তিকর সমস্যার একটা Permanent Solution বের করি: ✅

১. প্রথমেই Regedit Open করুন। 🖱️ আপনার Computer এর Search Bar এ "Regedit" লিখুন, তারপর Enter Button চাপুন। ⌨️ User Account Control থেকে Permission চাইলে "Yes" Button এ Click করতে ভুলবেন না। 👍 এটা Administrative Access এর জন্য খুবই জরুরি। 🔑

![Windows 11 Shut Down হতে চায় না? আর সেই বিরক্তির দিন শেষ! এই Setting Change করুন, বিদ্যুৎ গতিতে PC বন্ধ করুন!](https://dnc.techtunes.io/tDrive/tuner/2025/05/techtunes_768dfc52c1dba00724b816430214c3c2.jpg)

২. এবার Computer এর Address Bar এ নিচের Address টি Copy করে Paste করুন এবং Enter চাপুন: `HKEY_CURRENT_USER\Control Panel\Desktop` 🎯

যদি উপরের Address টি Copy করতে অসুবিধা হয়, তাহলে Registry Editor এর বাম দিকের Panel থেকে Manual ভাবে Navigate করতে পারেন। 🧭 প্রথমে `HKEY_CURRENT_USER` Folder টি Expand করুন। 📂

তারপর `Control Panel` Folder টি Expand করুন। 📁

সবশেষে `Desktop` Folder টি Select করুন। 🗂️

![Windows 11 Shut Down হতে চায় না? আর সেই বিরক্তির দিন শেষ! এই Setting Change করুন, বিদ্যুৎ গতিতে PC বন্ধ করুন!](https://dnc.techtunes.io/tDrive/tuner/2025/05/techtunes_16340f0565fb3b69501c2676b255e77e.jpg)

৩. ডান দিকের Panel এ Right Click করুন, 🖱️ তারপর New অপশন থেকে String Value তে Click করুন। 📝 এবার নতুন Value টির নাম দিন `AutoEndTasks` (যদি আগে থেকে না থাকে)। 🏷️

যদি `AutoEndTasks` নামের কোনো Value আগে থেকেই Listed থাকে, 📜 তাহলে নতুন করে Create করার কোনো প্রয়োজন নেই। 😌 আপনি সরাসরি Step 4 এ চলে যেতে পারেন। 🏃

![Windows 11 Shut Down হতে চায় না? আর সেই বিরক্তির দিন শেষ! এই Setting Change করুন, বিদ্যুৎ গতিতে PC বন্ধ করুন!](https://dnc.techtunes.io/tDrive/tuner/2025/05/techtunes_2d0cdc8b4afe60a1bddfa956dcce852c.jpg)

৪. `AutoEndTasks` এর উপর Double Click করুন, 🖱️ তারপর "Value Data" Field এ 1 লিখুন। ✍️ এরপর "OK" Button এ Click করুন। 👍

![Windows 11 Shut Down হতে চায় না? আর সেই বিরক্তির দিন শেষ! এই Setting Change করুন, বিদ্যুৎ গতিতে PC বন্ধ করুন!](https://dnc.techtunes.io/tDrive/tuner/2025/05/techtunes_eafc47184e7dbdfc28476247c6423324.jpg)

"Value Data" Field এ 1 লেখার মানে হলো, আপনি Windows কে Instruct করছেন যে, Shut Down এর সময় Automatically সব Task End করতে। 🤖

৫. Shut Down Process এর Speed আরও Boost করার জন্য নিচের String গুলো Add করুন: 🚀

**WaitToKillAppTimeout:** Windows 11 একটি Open App কে Forcefully Kill করার আগে যত Milliseconds পর্যন্ত Patience ধরে অপেক্ষা করে, ⏳ সেটাই হলো WaitToKillAppTimeout। সাধারণত এর Default Value 20, 000 Milliseconds (মানে 20 Seconds) থাকে। ⏱️ তবে, আমার ব্যক্তিগত পরামর্শ হলো, Wait Time কমিয়ে আনার জন্য এটিকে 2, 000 (অর্থাৎ 2 Seconds) এ Set করুন। 👍

![Windows 11 Shut Down হতে চায় না? আর সেই বিরক্তির দিন শেষ! এই Setting Change করুন, বিদ্যুৎ গতিতে PC বন্ধ করুন!](https://dnc.techtunes.io/tDrive/tuner/2025/05/techtunes_19d9de24c3cfcd9e10cede204a5dc361.jpg)

এই Value টি Change করার জন্য Registry Editor এর ডান দিকের Panel এ Right Click করুন, 🖱️ তারপর New> String Value তে Click করুন, 📝 এবং নতুন Value টির নাম দিন `WaitToKillAppTimeout`। 🏷️ তারপর Value Data Field এ 2000 লিখুন এবং "OK" Button এ Click করুন। 👍

**HungAppTimeout:** কোনো Non-Responsive App (মানে যে App গুলো কাজ করা বন্ধ করে দিয়েছে) নিজে থেকে Close হওয়ার জন্য Windows যত Milliseconds পর্যন্ত অপেক্ষা করে, ⏳ সেটা হলো HungAppTimeout। এর Default Value 5, 000 Milliseconds। ⏱️ আপনি চাইলে এটিকে কমিয়ে 2, 000 করতে পারেন। 👍

আগের মতোই Registry Editor এর ডান দিকের Panel এ Right Click করুন, 🖱️ তারপর New> String Value তে Click করুন, 📝 এবং নতুন Value টির নাম দিন `HungAppTimeout`। 🏷️ তারপর Value Data Field এ 2000 লিখুন এবং "OK" Button এ Click করুন। 👍

এবার Registry Editor এর বাম দিকের Panel এ Navigate করে Computer এর ভেতরের এই Location এ যান: `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control` 🧭

আগের Step গুলোর মতোই `HKEY_LOCAL_MACHINE`, `SYSTEM`, `CurrentControlSet` Folder গুলো Expand করুন এবং `Control` Folder টি Select করুন। 📁

`WaitToKillServiceTimeout` এর Value টি 2, 000 তে Set করুন। ⚙️

Registry Editor এর ডান দিকের Panel এ `WaitToKillServiceTimeout` নামের Value টি খুঁজে বের করার চেষ্টা করুন। 🔍 যদি Value টি খুঁজে না পান, তাহলে Right Click করুন 🖱️ এবং New> String Value তে Click করুন, 📝 তারপর নতুন Value টির নাম দিন `WaitToKillServiceTimeout`। 🏷️ এরপর Value Data Field এ 2000 লিখুন এবং "OK" Button এ Click করুন। 👍

Registry Editor Close করুন ❌ এবং আপনার PC Restart করুন। 🔄

ওয়াও! 🎉 কাজ শেষ! 🎯 এখন থেকে আপনার Windows 11, Shut Down এর সময় App গুলোকে Force-Close করার আগে আর বেশি Time নষ্ট করবে না। 🚀 মাত্র কয়েক Second এর মধ্যেই সবকিছু বন্ধ হয়ে যাবে! ⏱️ তবে একটা কথা, এই Setting Change করার আগে অবশ্যই আপনার Important Document বা File গুলো Save করে নেবেন। 💾 কারণ Windows কিন্তু কোনো Warning ছাড়াই App Close করে দেবে! ⚠️

আশাকরি, এই Step গুলো Follow করে আপনি আপনার Windows 11 এর Shut Down Speed কয়েকগুণ বাড়াতে পারবেন। 💯 যদি কোনো Step বুঝতে Trouble হয়, 😕 অথবা আপনার অন্য কোনো Question থাকে, ❓ তাহলে Comment Section এ Feel Free to জানাতে পারেন। 💬 আমি অবশ্যই Help করার জন্য Ready আছি! 🤝 আপনার PC Speed Up করার Journey শুভ হোক! 🌠
