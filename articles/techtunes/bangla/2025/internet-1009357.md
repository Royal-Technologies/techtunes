## Salad Room কী? এক নজরে চিনে নিন! 🔍

![Salad Room কী](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_09433038f602c4d0a8c66f70dc10bdf1.png)

Salad Room হলো Cloud-Based একটি Free এবং Open Source Tool, যা User-দের বিভিন্ন Device-এ Securely Message, Link অথবা File Transfer করতে সাহায্য করে। এর সবচেয়ে বড় সুবিধা হলো, এটি Cross-Platform এবং Browser-Based। তার মানে, আপনার Operating System (Windows, macOS, Linux) বা Device (Computer, Laptop, Tablet, Smartphone) যাই হোক না কেন, শুধু একটা Modern Browser (Chrome, Firefox, Safari, Edge) থাকলেই আপনি Salad Room ব্যবহার করতে পারবেন। 🌐

Data Transfer করার জন্য Salad Room WebRTC Technology ব্যবহার করে। WebRTC (Web Real-Time Communication) হলো এমন একটি Technology, যা Browser-এর মাধ্যমে Real-Time Audio, Video এবং Data Communication করতে সাহায্য করে। WebRTC Device গুলোর মধ্যে Direct Connection তৈরী করে, ফলে Data কোনো Third-Party Server-এর মাধ্যমে যায় না। 🛡️

Security-র জন্য Salad Room End-to-End Encryption ব্যবহার করে। End-to-End Encryption হলো এমন একটি Process, যেখানে Data Send করার সময় Encrypt করা হয়, এবং শুধুমাত্র Receiver-ই সেটা Decrypt করতে পারে। ফলে মাঝপথে কেউ Data Access করতে পারলেও, সেটা বুঝতে পারবে না। 🔐

তবে Salad Room কিন্তু জনপ্রিয় Cloud Storage Service বা File Sharing Platform-গুলোর মতো নয়। এখানে Data Permanently Store করা হয় না, এবং File Versioning-এর Option-ও নেই। Salad Room শুধুমাত্র Temporary File Sharing-এর জন্য Designed করা হয়েছে। 😊

## Salad Room কিভাবে কাজ করে? ভেতরের কলকব্জা জেনে নিন! ⚙️

![Salad Room কিভাবে কাজ করে? ভেতরের কলকব্জা জেনে নিন! ](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_e0c4a13fb0e2cda1eb66c68bb23c2759.png)

Salad Room এর Operation খুবই Straightforward। এখানে File Transfer করার Process টা খুবই সহজ:

1. **Room Creation:** প্রথমে একজন User Salad Room-এ একটি Private Room তৈরী করে। Room তৈরী করার সময় একটি Unique Room Code Generate হয়। এই Code টি Room-এর Address হিসেবে কাজ করে।
2. **Invitation:** এরপর Room Creator অন্যদের Room-এ Join করার জন্য Invitation Send করে। Invitation-এ Room Code এবং Join করার Instructions দেওয়া থাকে।
3. **Connection:** Invitation পাওয়া User-রা Salad Room-এ Room Code Enter করে Room-এ Join করে। Room-এ Join করার সাথে সাথেই Device গুলোর মধ্যে একটা Secure Connection Establish হয়।
4. **File Transfer:** এরপর User-রা Directly File Transfer করতে পারে। File Transfer করার সময় Data Encrypt করা হয়, ফলে Security নিয়ে কোনো চিন্তা থাকে না।
5. \* অটোমেটিক Disconnect:\* ৩০ মিনিট পর, সব Data Automatically Delete হয়ে যায় এবং Room টি Destroy হয়ে যায়।

Salad Room WebRTC Technology ব্যবহার করে Device গুলোর মধ্যে Direct Connection তৈরী করে, ফলে File Transfer Speed অনেক বেশি থাকে। এছাড়া, যেহেতু Data কোনো Third-Party Server-এর মাধ্যমে যায় না, তাই Privacy ও অনেক বেশি Secure থাকে। 👍

## Salad Room ব্যবহারের কিছু Limitation - যা আপনার জানা উচিত ❗

![Salad Room ব্যবহারের কিছু Limitation - যা আপনার জানা উচিত](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_5585668e94acb14533dde83af2a39b98.png)

Salad Room ব্যবহার করার সময় কিছু Limitation অবশ্যই মাথায় রাখতে হবে। এই Limitation গুলো Service টির Design এবং Architecture-এর সাথে সরাসরি জড়িত:

- **Temporary Storage:** Salad Room কোনো Data Permanently Store করে না। Room Expire হওয়ার সাথে সাথেই সব Data Automatically Delete হয়ে যায়। তাই Long-Term Storage-এর জন্য এটা Suitable নয়।
- **Limited Room Time:** প্রতিটি Room ৩০ মিনিটের জন্য Available থাকে। এই সময়ের মধ্যে File Transfer এবং Communication শেষ করতে হয়।
- **Participant Limit:** Room এ সর্বোচ্চ ২৫ জন Participant Join করতে পারবে। বড় Group Collaboration-এর জন্য এটা Limitেশন হতে পারে।
- **File Size Limit:** প্রতিটি File Size 2 GB-এর মধ্যে হতে হবে। বড় Video File বা Design Project Share করার জন্য এটা Limitেশন হতে পারে।
- **Message Limit:** Room এ ৫০ টির বেশি Message করা যাবে না।

## Salad Room এর Privacy Policy: আপনার ব্যক্তিগত Data কতটা সুরক্ষিত? 🔒

![Salad Room এর Privacy Policy: আপনার ব্যক্তিগত Data কতটা সুরক্ষিত?](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_a4596040ffc20608b28adef11b834c10.png)

Salad Room User-দের Privacy Protection-এর ব্যাপারে খুবই Serious। তারা নিম্নলিখিত Privacy Practice গুলো Follow করে:

- **No IP Logging:** Salad Room User-দের IP Address Collect করে না। ফলে, কে কখন Service টা ব্যবহার করছে, সেটা Track করা সম্ভব নয়।
- **End-to-End Encryption:** File Transfer করার সময় End-to-End Encryption ব্যবহার করা হয়। ফলে, Data Leak হওয়ার কোনো সম্ভাবনা নেই।
- **No Third-Party Tracking:** Salad Room Third-Party Tracking Tool ব্যবহার করে না। ফলে, User-দের Online Activity Track করা হয় না।
- **Minimal Data Retention:** Salad Room Limited Data Collect করে এবং খুব অল্প সময়ের জন্য Retain করে। Room Expire হওয়ার সাথে সাথেই সব Data Delete করে দেওয়া হয়।

Salad Room GDPR (General Data Protection Regulation) এবং CCPA (California Consumer Privacy Act)-এর মতো Privacy Law গুলো মেনে চলে। ফলে, User-রা তাদের Personal Data Control করতে পারে। 💯

তবে Security Expert-রা সবসময় পরামর্শ দেন, যেকোনো Service ব্যবহার করার আগে Privacy Policy ভালোভাবে পড়ে নেওয়া উচিত।

- Room-এ Join করার পর Chat Room-এর মতো একটা Interface দেখতে পাবেন। Screen-এর উপরের দিকে কতগুলো Device Connect করা আছে, সেটা দেখতে পারবেন।

### ৩. Cross-Device Data Transfer করুন - Expert-এর মতো! 📲 💻

1. প্রথমে Smartphone এবং Computer, দুটো Device-এই Salad Room Open করুন।

4. Computer থেকে File Download করুন।

এভাবে খুব সহজেই যেকোনো File Cross-Device Transfer করতে পারবেন। Data Transfer করার জন্য কোনো Cable বা Extra Software-এর দরকার হবে না! 👌

"Share Room" Function টি Room Code এবং QR Code দেখাবে। Code ব্যবহার করে বা Scan করে অন্য Device গুলোকেও Connect করতে পারবেন।

File Download করার জন্য File-এর নামের পাশে "Download" Button-এ Click করুন। Message Copy করার জন্য Clipboard ব্যবহার করুন। File এবং Message, দুটোই ৫ মিনিটের মধ্যে Save/Copy করতে হবে, না হলে Data Delete হয়ে যাবে। ⏳

## Salad Room বনাম WebRTC: আপনার জন্য কোনটি Best? 🤔

![Salad Room বনাম WebRTC: আপনার জন্য কোনটি Best?](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_bea4dac27d4ffe5e42bc4325b28d4cde.png)

Salad Room এবং WebRTC দুটোই Real-Time Data Transfer করার জন্য খুবই Powerful Technology। তবে, এদের Architecture এবং Feature-এর মধ্যে কিছু Fundamental Difference আছে।

Salad Room WebRTC Technology-র উপর ভিত্তি করে তৈরী করা হয়েছে। WebRTC Device গুলোর মধ্যে Direct Connection তৈরী করে, ফলে Latency অনেক কম থাকে এবং Speed অনেক বেশি পাওয়া যায়। কিন্তু WebRTC ব্যবহার করার জন্য Device গুলোকে Online থাকতে হয়, এবং Network Condition ও ভালো থাকতে হয়।

অন্যদিকে, Salad Room File Transfer করার জন্য Third-Party Server ব্যবহার করে। ফলে, Speed কিছুটা কম হতে পারে, কিন্তু Device গুলো Offline থাকলেও File Access করা যায়। এছাড়া, Server-Based Architecture-এর জন্য Salad Room Scalability এবং Reliability অনেক বেশি।

যদি আপনি Security এবং Privacy নিয়ে Serious হন, তাহলে Salad Room আপনার জন্য ভালো Option হতে পারে। কারণ, তারা IP Address Collect করে না এবং Data Third-Party-র সাথে Share করে না।

অন্যদিকে, যদি আপনি Speed এবং Large File Transfer নিয়ে আগ্রহী হন, তাহলে WebRTC আপনার জন্য ভালো Option হতে পারে।

যদি আপনি বড় Size-এর File Transfer করতে চান এবং Service Provider-এর কাছে File Save না করতে চান, তাহলে WebRTC-Based নিম্নলিখিত Service গুলো ব্যবহার করতে পারেন:

- [PairDrop](https://pairdrop.net/): Cross-Device, Cross-Network, File Size Limit ছাড়া Free P2P Online File Transfer Tool।
- [rDrop](https://www.techtunes.io/internet/tune-id/1008480): Simple, Fast P2P File Transfer Service, কোনো Compression ছাড়াই File Transfer করা যায়।
- [ShareDrop](https://sharedrop.io/): Mobile phone-এর Photo, Video Computer-এ Transfer করুন, শুধু Browser Open করে QR Code Scan করুন।
