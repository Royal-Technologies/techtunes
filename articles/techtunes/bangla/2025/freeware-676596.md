আসসালামু আলাইকুম, কেমন আছেন টেকটিউনস কমিউনিটি? আশা করছি সবাই ভাল আছেন। আজকে আবার হাজির হলাম নতুন টিউন নিয়ে। আজকে আলোচনা করব দারুণ একটি ফ্রি সফটওয়্যার নিয়ে।

আপনি কিভাবে আপনার কম্পিউটারের পারফরম্যান্স চেক করেন? অবশ্যই Task Manager থেকে। আমরা Task Manager থেকে খুব সহজেই দেখে নিতে পারি কোন অ্যাপটি ওপেন আছে কোন অ্যাপটি কি পরিমাণ র‍্যাম ব্যবহার করছে ইত্যাদি। একই সাথে Resource Monitor এর সাথে আমরা রিসোর্স ব্যবহারও দেখতে পারি।

তবে কখনো কখনো এটি অতটা সুবিধাজনক হয় না, তাছাড়া পিসি ভাল ভাবে চলে তখন কে এগুলো চেক দেয়?

## Taskbar Stats কি?

![](https://dnc.techtunes.io/tDrive/tuner/2020/12/techtunes_6e11249d5008176444d0a6c737457197.png)

Taskbar Stats একটি ওপেন সোর্স এবং ফ্রি সফটওয়্যার যার মাধ্যমে আপনি কম্পিউটারের রিসোর্স ব্যবহার দেখতে পারবেন Task Bar এর মধ্যেই। এই সফটওয়্যারের মাধ্যমে ফ্রিতে দেখতে পারবেন নেট স্পিড, ডিস্ক Read & Write এবং RAM Usage।

**Taskbar Stats**

ডাইরেক্ট ডাউনলোড লিংক @ [Taskbar Stats](https://github.com/openhoangnc/taskbar-stats/releases/download/v20.11.21.1/TaskbarStats_20.11.21.1_setup.exe)

## Taskbar Stats কিভাবে ব্যবহার করবেন

প্রথমে [Taskbar Stats](https://github.com/openhoangnc/taskbar-stats/releases/download/v20.11.21.1/TaskbarStats_20.11.21.1_setup.exe) সফটওয়্যারটি ডাউনলোড করে ইন্সটল দিন।

ইন্সটল হয়ে গেলে আপনার টাস্ক-বারে রাইট ক্লিক করুন এবং Toolbars এ ক্লিক করুন

![](https://dnc.techtunes.io/tDrive/tuner/2020/12/techtunes_7787405da550743b018f3a34c90cc411.png)

Toolbars এ আপনি চারটি নতুন অপশন দেখতে পাবেন

![](https://dnc.techtunes.io/tDrive/tuner/2020/12/techtunes_6e11249d5008176444d0a6c737457197.png)

আপনি NetSpeedBit এ টিক দিলে আপনার টাস্ক-বারে পেয়ে যাবেন ফ্রি নেট স্পীড মিটার।

![](https://dnc.techtunes.io/tDrive/tuner/2020/12/techtunes_488a5aa4656fc37a9d3a60652d7c369f.png)

দেখতে পারবেন আপনার ডাউন স্পীড কত আপলোড স্পীড কত। সেক্ষেত্রে আপনার নেট স্পীড bit এ দেখাবে।

![](https://dnc.techtunes.io/tDrive/tuner/2020/12/techtunes_0e9c056be36eabd61da7c7376e180af8.png)

এবার যদি NetSpeed এ ক্লিক করেন তাহলে আপনি KB তে স্পীড দেখবে।

![](https://dnc.techtunes.io/tDrive/tuner/2020/12/techtunes_2b713d53fd373e78d366f186fe47e46d.png)

আপনি যদি CPU Usage এবং RAM Usage দেখতে চান হলে, Toolbars থেকে CPURam সিলেক্ট করুন।

![](https://dnc.techtunes.io/tDrive/tuner/2020/12/techtunes_c607d6966e549ddc553109d812d9c4f8.png)

নিচের ছবিটি খেয়াল করুন, C মানে হচ্ছে CPU Usage এবং R মানে হচ্ছে RAM Usage।

![](https://dnc.techtunes.io/tDrive/tuner/2020/12/techtunes_dcbe45bd9c784ac6fab0c0f10db2935e.png)

আপনি যদি ডিস্ক Write এবং Read স্পীড দেখতে চান তাহলে Toolbars থেকে DiskSpeed এ ক্লিক করুন।

![](https://dnc.techtunes.io/tDrive/tuner/2020/12/techtunes_f80b5673871dc88f6e47d95770d9982a.png)

নিচের ছবিতে খেয়াল করুন, R মানে হচ্ছে Disk Read স্পীড এবং W মানে হচ্ছে Disk Write স্পীড

![](https://dnc.techtunes.io/tDrive/tuner/2020/12/techtunes_c8b7392cca59fe43a9207694ebfa23e9.png)

## Taskbar Stats এর কিছু সুবিধা

![](https://dnc.techtunes.io/tDrive/tuner/2020/12/techtunes_397618e9543ca4774c12b3b8c475d274.png)

চলুন [Taskbar Stats](https://github.com/openhoangnc/taskbar-stats/releases/download/v20.11.21.1/TaskbarStats_20.11.21.1_setup.exe) এর কিছু সুবিধা জেনে নেয়া যাক।

- ফ্রিতেই দেখতে পারবেন নেট স্পীড
- একই সাথে KB অথবা bit উভয় ফর্মেটেই ডাটা ইউজেস দেখতে পারবেন
- টাস্ক-বারে দেখতে পারবেন CPU Usage
- টাস্ক-বারে দেখতে পারবেন RAM Usage
- টাস্ক-বারে দেখতে পারবেন ডিস্ক Read স্পীড
- টাস্ক-বারে দেখতে পারবেন ডিস্ক Write স্পীড

## Taskbar Stats এর কিছু অসুবিধা

![](https://dnc.techtunes.io/tDrive/tuner/2020/12/techtunes_60aa5242821a3ea796b9eeffb7e9ffa7.png)

Taskbar Stats চাইলেই আপনি কাস্টমাইজ করতে পারবেন না। আপনি ফন্ট কালার, সাইজ, ইত্যাদি চেঞ্জ করতে পারবেন না। আপনি রিসোর্স ইনডিকেটর গুলোও চেঞ্জ করতে পারবেন না। সম্প্রতি এই সফটওয়্যারটির ডেভেলপাররা জানিয়েছে তাদের সফটওয়্যারটিতে কাস্টমাইজেশনের অপশন যোগ করার কোন ইচ্ছে নেই।

এই সফটওয়্যারটির বড় অসুবিধা হল লাইট থিমে এটি দেখতে অস্পষ্ট লাগে। যেহেতু ফন্ট গুলোর কালার সাদা সুতরাং থিমও সাদা হলে সমস্যা তৈরি হয়। নিচের স্ক্রিনশটটি দেখুন।

এটি ফ্রি ওপেন সোর্স হলেও এটি পোর্টেবল নয়।
