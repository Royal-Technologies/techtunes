আচ্ছা, আমরা যারা ইন্টারনেট ব্যবহার করি, তারা সবাই কোনো না কোনো সময় URL নিয়ে কাজ করি, তাই তো? কখনো বন্ধুদের সাথে মজার ভিডিও শেয়ার করি, কখনো দরকারি কোনো ওয়েবসাইটের ঠিকানা Save করে রাখি, আবার কখনো কোনো Article বা Blog পড়ার জন্য Link-এ Click করি। কিন্তু, এই URL ব্যাপারটা সবসময় সহজ থাকে না। অনেক সময় URL গুলো এত বড় আর জটিল হয় যে, দেখতেও বিরক্ত লাগে, আর কাউকে Share করতেও অসুবিধা হয়। ঠিক এই সমস্যার সমাধান করার জন্যই Short URL Service গুলোর জন্ম।

আপনারা নিশ্চয়ই TinyURL, Bitly-এর মতো Short URL Service গুলোর নাম শুনেছেন? এই Service গুলো লম্বা URL গুলোকে ছোট করে, যাতে সেগুলো দেখতে সুন্দর লাগে, সহজে মনে রাখা যায় এবং Social Media বা Email-এ Share করতে সুবিধা হয়। কিন্তু, Short URL Service গুলোর কাজ শুধু URL ছোট করাই নয়। এখন অনেক Service আরও অনেক Extra Feature নিয়ে হাজির হয়েছে।

যেমন ধরুন, আপনি জানতে চান আপনার Share করা Link-এ কতজন Click করলো, অথবা আপনি চান আপনার Link টি শুধু নির্দিষ্ট কিছু মানুষ দেখুক, তাই সেটিতে Password বসিয়ে দিলেন। আবার এমনও হতে পারে, আপনি নিজের Brand এর নামে Custom Domain ব্যবহার করে একটি Professional Look দিতে চান আপনার Link-এ। এই Feature গুলো কিন্তু আজকাল অনেক Short URL Service এই দিয়ে থাকে। এই Feature গুলোর মাধ্যমে আপনি আপনার Link গুলোকে আরও Attractive এবং Secure করতে পারেন।

## URLcast.io: ব্যবহারের Step by Step গাইড

এবার চলুন, Step by Step দেখে নেয়া যাক URLcast.io কিভাবে ব্যবহার করতে হয়:

১. প্রথমেই আপনার Device থেকে URLcast.io তে প্রবেশ করুন। আপনি দেখবেন, আর পাঁচটা সাধারণ URL Shortener Service এর মতোই একটা Page খুলে গেছে। Page টির Design খুব Simple এবং Clear, যাতে নতুন Users দের ব্যবহার করতে কোনো অসুবিধা না হয়।

![URLcast.io URL Shortener Service](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_95cfb29e658b80206c70b5ada11bfe11.png)

২. এবার "The URL scheduler" নামের Option টিতে আপনার Original URL টি Paste করুন। URL Paste করার পরে, আপনি চাইলে URL টির একটা Preview দেখতে পারেন।

![URL Paste করার অপশন](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_451203c7bfc8a27308bfb80f82550417.png)

৩. এরপর Page এর নিচে থাকা "Schedule" Button-এ Click করে আপনার পছন্দের Date এবং Time টি Set করুন। Date এবং Time Select করার জন্য একটা Calendar এবং Clock এর Option দেওয়া আছে, যাতে Users রা সহজে Date এবং Time Select করতে পারে।

![Date এবং Time Select করা](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_02cf13edcea1086aea7b3f3603b1312e.png)

URLcast এর সবথেকে বড় Feature হল, আপনি এখানে Public Date নির্দ্ধারণ করতে পারছেন। শুধু তাই নয়, আপনি চাইলে Landing Page টির জন্য একটি Custom Message ও লিখে রাখতে পারেন, যেটা ঐ Link-এ Click করলে সবাই দেখতে পারবে (এখানে বাংলাতেও Message লেখা যাবে!)। Date Option থেকে Redirect করার Date ও Time Set করার সময় একটু খেয়াল রাখবেন, কারন আমার মনে হয় এটা Creator-এর Time Zone অনুযায়ী কাজ করে। Date Set করার পরে Short URL টি কেমন দেখাবে, তার একটা Preview আপনি দেখতে পারবেন। Preview দেখে আপনি নিশ্চিত হতে পারবেন যে আপনার Set করা Information গুলো ঠিক আছে।

Time Set করার পরে, একটা নতুন Short URL Create হবে। যেহেতু URLcast.io-তে Custom Link Create করার Feature নেই, তাই URL গুলো সাধারণত Random হয়ে থাকে। Date Set করার সময় এটা অবশ্যই খেয়াল রাখবেন যে, আপনার Set করা Time যেন Current Time থেকে পাঁচ মিনিটের বেশি হয়, তা না হলে Page-এ Error Message দেখাবে।

এখন, আপনার Share করা Link-এ যদি কেউ Time হওয়ার আগে Click করে, তাহলে সে আপনার Custom Message এবং Countdown Timer দেখতে পাবে। এবং যখন Time হবে, Short URL টি Automatically Target Page-এ Redirect হয়ে যাবে।
