আসসালামু আলাইকুম বন্ধুরা, কেমন আছেন সবাই? আশাকরি ভালো আছেন।

আজকে আমি আপনাদের সাথে এমন একটা Extension নিয়ে কথা বলব, যেটা আমার নিজেরও খুব পছন্দের। আমরা যারা দিনের অনেকটা সময় Internet এ বিভিন্ন Website ভিজিট করে কাটাই, তাদের জন্য এটা সত্যিই খুব কাজের একটা জিনিস। বিশেষ করে Research এর কাজে বা যখন অনেকগুলো Website থেকে Data কালেক্ট করার দরকার হয়, তখন এই Extension টি জীবন বাঁচিয়ে দেয়, এটা আমি হলফ করে বলতে পারি!

আমরা অনেকেই ব্রাউজারে দরকারি Website গুলোকে Tab আকারে খুলে রাখি, যাতে পরে সেগুলো আবার দেখতে পারি বা কোনো Content কাজে লাগাতে পারি। কিন্তু সমস্যাটা হয় তখনই, যখন Tab এর সংখ্যা অনেক বেড়ে যায়। ধরুন, আপনি একটা Research করছেন, আর তার জন্য 20-25টা Website খুলে রেখেছেন। এবার যদি সেই Website গুলোর Link কাউকে Share করতে হয়, অথবা নিজের জন্য কোথাও Save করে রাখতে হয়, তখন কেমন লাগবে বলুন তো? নিশ্চয়ই খুব বিরক্তিকর লাগবে, তাই না?

আমি আপনাদের সেই বিরক্তি থেকেই মুক্তি দিতে এসেছি! আজ আমি আপনাদের সাথে পরিচয় করিয়ে দিব "Copy URLs" নামের একটি অসাধারণ Extension এর সাথে। এই Extension টি আপনার ব্রাউজিংয়ের অভিজ্ঞতাকে সহজ করার পাশাপাশি, আপনার মূল্যবান সময়ও বাঁচাবে।

## Copy URLs: আপনার জন্য সেরা সমাধান?

![Copy URLs](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_cdfb957eb775790786c0756121fe4a26.png)

"Copy URLs" হলো একটি ফ্রি Chrome এবং Opera Extension। সহজ ভাষায় বলতে গেলে, এটা একটা Tools, যেটা আপনার ব্রাউজারে খোলা থাকা সমস্ত Tab এর URL গুলোকে এক ক্লিকেই Clipboard এ Copy করতে পারে।

### Copy URLs

অফিসিয়াল ওয়েবসাইট @ [Copy URLs](https://chromewebstore.google.com/detail/copy-urls/efkmnflmpgiklkehhoeiibnmdfffmmjk?hl=en)

## Copy URLs এর স্পেশাল ফিচারগুলো কী কী?

![Copy URLs এর স্পেশাল ফিচারগুলো কী কী?](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_d7d9d02504676bbc227cd0866447821e.png)

"Copy URLs" আপনাকে আরও কিছু সুবিধা দিবে, যা আপনার কাজকে আরও সহজ করে তুলবে। যেমন:

- বিভিন্ন ধরনের Export Format Option (URL, HTML, Csv, JSON, Custom Format)।
- চাইলে সমস্ত Window এর Tab অথবা শুধু বর্তমান Window এর Tab Copy করার Option।
- Data Search করার সময় সমস্ত Link একসাথে করার সুবিধা।

তাহলে বুঝতেই পারছেন, "Copy URLs" আপনার ব্রাউজিংয়ের অভিজ্ঞতাকে কতোটা সহজ করে দিতে পারে।

![TOOLBAR এ Copy URLs এর BUTTON](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_4325ae16751e6edc8a62300b522f8f48.png)

![Export tabs from](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_0df2fcdb5b1142000887c362283c6eb9.png)

![CUSTOM FORMAT ও SELECT](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_858d030ab7033c64fa6ed93451ebbac6.png)

## "Copy URLs": কাদের জন্য এটা সেরা?

![Copy URLs কাদের জন্য এটা সেরা?](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_19a78f1dc23caba0d831e95df21e2ad2.png)

আমার মতে, "Copy URLs" এমন সবার জন্য সেরা, যারা Internet এ নিয়মিত কাজ করেন। বিশেষ করে, এই Extension টি নিম্নলিখিত Category এর মানুষদের জন্য খুবই উপযোগী:

- Researcher: যারা কোনো Research এর কাজে অনেকগুলো Website থেকে Data Collect করেন।
- Student: যাদের Assignment বা Project এর জন্য বিভিন্ন Website ভিজিট করতে হয়।
- Blogger: যারা নিজেদের Article এর জন্য Resource কালেক্ট করেন।
- Web Developer: যাদের Website Testing বা Debugging এর জন্য অনেকগুলো Page খুলতে হয়।
- Social Media Marketer: যারা বিভিন্ন Social Media Platform এর জন্য Content কালেক্ট করেন।

এছাড়াও, যারা Internet এ কাজ করেন, তাদের সবার জন্যই "Copy URLs" একটি দারুণ Tools।
