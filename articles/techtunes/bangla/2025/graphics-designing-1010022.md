## Vector Shelf-এর Material Format নিয়ে আরও কিছু কথা 📁

![Vector Shelf-এর Material Format নিয়ে আরও কিছু কথা](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_0b5177990798f5d5c420f32d6ebd081b.jpg)

Vector Shelf Website-এ Material গুলো সাধারণত তিনটি Format-এ পাওয়া যায়। এই Format গুলো কী, এবং Design-এর ক্ষেত্রে এদের Advantages কী, তা বিস্তারিতভাবে জেনে নেওয়া যাক:

- **PNG:** Portable Network Graphics (PNG) Format টি বহুল ব্যবহৃত Raster Image Format। এটি Lossless Compression ব্যবহার করে, তাই Image-এর Quality অক্ষুণ্ণ থাকে। PNG Format Transparency Support করে, তাই Background-বিহীন Image ব্যবহারের জন্য এটি Ideal। প্রায় সব Platform-এই PNG Support করে, তাই এটি ব্যবহার করা খুবই Convenient। Logo, Icon এবং Web Graphics-এর জন্য PNG Format খুবই Popular।
- **AI:** Adobe Illustrator (AI) Format হলো Vector Graphics-এর জন্য Industry Standard। Adobe Illustrator ব্যবহারকারীদের জন্য এটি Native Format। AI Format ব্যবহার করে Shape ও Color পরিবর্তন করা এবং প্রয়োজন অনুযায়ী Customize করা যায়। Design-এর ওপর সম্পূর্ণ Control রাখার জন্য AI Format খুবই Powerful। AI Format Print Design, Logo Design এবং Illustration-এর জন্য বিশেষভাবে উপযোগী।
- **SVG:** Scalable Vector Graphics (SVG) Format টি Vector-based Image-এর জন্য XML Format ব্যবহার করে। SVG Format-এর সবচেয়ে বড় সুবিধা হলো, Image-এর Quality ঠিক রেখে Size ছোট-বড় করা যায়। SVG Format Responsive Design-কে Support করে, তাই এটি Webpage-এর জন্য বিশেষভাবে উপযোগী। Icon, Logo এবং Animation-এর জন্য SVG Format ব্যবহার করা হয়।
