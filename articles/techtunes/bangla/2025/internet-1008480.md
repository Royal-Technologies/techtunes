## rDrop Step-by-Step: কিভাবে Lightning Speed-এ File Transfer করবেন?

![rDrop Step-by-Step: কিভাবে Lightning Speed-এ File Transfer করবেন?](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_25305a4cddb426d6364333d0b0d3b2b8.png)

rDrop Use করা এতটাই Straightforward যে, First Time Use করলেও যে কেউ Easily File Transfer করতে পারবে। তবুও, আপনাদের সুবিধার জন্য Step-by-Step Guide নিচে দেওয়া হলো:

**Step 1: Initial Setup**

প্রথমত, যে Device থেকে File Transfer করতে চান, সেই Device এ rDrop Website টি Open করুন (<https://rdrop.link/>). এরপর Webpage এর Left Side এ "Drop Files Here" নামক Section এ আপনার Required File Drag করে নিয়ে আসুন, অথবা Click করে আপনার Selectable File Select করুন। এখানে Multiple Files Select করার Option ও রয়েছে, যা Time Save করতে সাহায্য করে।

![Device এ rDrop Website](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_28ead5c5f72cac5c79a9e91545969fb0.png)

**Step 2: Generating and Distributing the Secure Code**

File Select করার সাথে সাথেই একটি Unique Random Code এবং Machine-Readable QR Code Generate হবে। Code টির Right Side এ Copy Button দেখতে পাবেন, সেখানে Click করে Code টি Securely Copy করুন এবং আপনার Preferred Communication Channel (যেমন Messenger, WhatsApp, Email, Telegram ইত্যাদি) এর মাধ্যমে Receiver কে Send করুন।

![file upload](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_a16397da24f4c92511a76a21c1ede07e.png)

Important Note: File Transfer চলাকালীন Webpage টি Close করা যাবে না।

**Step 3: Establishing the Secure Connection**

Receiver তার Device এ rDrop Website Open করে Right Side এর "Receive Files" Section এ Code টি Paste করুন অথবা Available QR Code Scanner Use করে QR Code Scan করুন। Code Paste করার সাথে সাথেই Both Devices এর মধ্যে একটি Secure এবং Encrypted Connection Establish হয়ে যাবে।

![Code paste](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_19be27c7153228d8ad90a82914a08d4a.png)

**Step 4: Enjoy Fast and Safe Transfer**

Both Devices Successfully Connect হওয়ার সাথে সাথেই Lightning Speed এ File Transfer Start হয়ে যাবে! Always Remember, File Transfer করার সময় Both Devices যেন Same Local Area Network (LAN) এর Under এ থাকে, যেমন Reliable Wi-Fi Network। Transfer Completed হওয়ার পর Download Button এ Click করে আপনার Desired Location এ File Save করুন। Local Network এর মাধ্যমে Data Transfer হওয়ার কারণে Transfer Speed অবিশ্বাস্য রকমের Fast হবে এবং File Size নিয়ে কোনো Worries থাকবে না।

![Transfer Completed হওয়ার পর Download Button](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_2f4e7271173fe0ea6b7b2b8f0adb6066.png)

Sender Real-Time File Transfer Status এবং Progress Monitor করতে পারবে এবং যদি Additional Files Transfer করার প্রয়োজন হয়, তাহলে সে Files ও Add করতে পারবে।
