যদি আপনি IoT প্রোজেক্ট তৈরি করতে চান কিন্তু জটিল **C বা C+ কোড** শেখা আপনার জন্য কঠিন হয়ে উঠছে, তাহলে **Wemos D1 Mini** আর **MicroPython** হতে পারে পারফেক্ট কম্বো!

এই ব্লগে আপনি জানতে পারবেন — [**Wemos D1 Mini**](https://techshopbd.com/product/wemos-d1-mini-esp8266-wifi-nodemcu-iot-module) তে কিভাবে **MicroPython** ফার্মওয়্যার ফ্লাস করতে হয় এবং কিভাবে মাইক্রোপাইথনে প্রোগ্রাম করে LED ব্লিংক করা যায়।

**প্রিরিকুইজিট**

প্রথমেই কম্পিউটারে [esptool.py](http://esptool.py) ইন্সটল করতে হবে, যা দিয়ে **Wemos D1 Mini** মাইক্রোকন্ট্রোলারে ফার্মওয়্যার ফ্ল্যাশ করা যাবে।

এই টুলটি ব্যবহার করতে হলে, প্রথম থেকে আপনার সিস্টেমে **Python 2.7, Python 3.4**, বা তার নতুন কোনো ভার্সন ইন্সটল থাকতে হবে। তবে আমি সাজেস্ট করবো **Python 3.7.X** ব্যবহার করতে — এজন্য সরাসরি [Python-এর অফিসিয়াল ওয়েবসাইটে](https://www.python.org/downloads/) গিয়ে ইনস্টল করে নিন।

Python 3 ইন্সটল হয়ে গেলে, Command Prompt ওপেন করে নিচের কমান্ডটি রান করুন, যাতে esptool.py এর সর্বশেষ ভার্সন ইন্সটল হয়।

pip install esptool

![](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_1e94e15925c56d27880b8fda91f29950-640x360.png)

সব কিছু ঠিকভাবে ইন্সটল হয়ে গেলে, আপনি সরাসরি টার্মিনালে নিচের কমান্ড দিয়ে esptool.py রান করতে পারবেনঃ

python -m esptool

ইন্সটলেশন সাকসেসফুল হলে, টার্মিনালে টুলটির ভার্সন ও ইনফরমেশন দেখা যাবে — মানে সব ঠিকঠাক কাজ করছে!

![](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_4c4bba180c17f0e004049829ff1d7f61-640x360.png)

**ডাউনলোড মাইক্রোপাইথন**

যেহেতু **Wemos D1 Mini** বোর্ডে **ESP8266 SoC** ব্যবহার করা হয়েছে, তাই আমাদের এখানে ESP8266-এর জন্য বিশেষভাবে তৈরি **MicroPython firmware** ব্যবহার করতে হবে।

এর জন্য [লিংকে](https://micropython.org/download/ESP8266_GENERIC/) ক্লিক করে [**v1.26.1 (2025-09-11).bin**](https://micropython.org/resources/firmware/ESP8266_GENERIC-20250911-v1.26.1.bin) ফাইলটি ডাউনলোড করে নিন। (আমি যখন এই টিউটোরিয়্যালটি লিখছি, তখন **v1.26.1** হচ্ছে MicroPython-এর Latest ভার্সন। )

![](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_d9648668dd00fe0a5d332cdf965df142-640x360.png)

**সিরিয়াল পোর্ট**

আপনার [Wemos D1 Mini](https://techshopbd.com/product/wemos-d1-mini-esp8266-wifi-nodemcu-iot-module)-টি কম্পিউটারের সাথে কানেক্ট করে Device Manager থেকে মাইক্রোকন্ট্রোলারটির জন্য Dedicated COM Port নম্বরটি মনে রাখতে হবে। আমার ক্ষেত্রে এটি COM14।

![](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_6167345aff92e6dac260d5a16a8d1e89-640x360.png)

যদি আপনার Wemos D1 Mini **Board** এর **COM Port** লিস্টে না দেখা যায়, তাহলে বেশিরভাগ সময়ই এর কারণ হলো — আপনার সিস্টেমে এখনো প্রয়োজনীয় **USB Driver** ইন্সটল করা নেই।

Wemos D1 Mini ড্রাইভার হিসেবে CH340 ব্যবহার করা হয়েছে। এমন সমস্যার সম্মুখীন হলে, আপনি এই [লিংকে](https://cdn.sparkfun.com/assets/learn_tutorials/8/4/4/CH341SER.EXE) ক্লিক করে ড্রাইভারটি ডাউনলোড করে ইন্সটল করে নিন।

**ফ্ল্যাসিং মাইক্রোপাইথন ফার্মওয়্যার**

ESP8266 এর **.bin ফাইলটি** ডাউনলোড করার পর, এটি সাধারণত আপনার **Downloads** ফোল্ডারেই সেভ হয়ে থাকবে। তাই এখন **Command Prompt** খুলে নিচের কমান্ড দিয়ে সেই ফোল্ডারে চলে যান —

cd Downloads

![](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_30ee7b37c3fb5da0ec3d89edbb067b45-640x360.png)

এরপর নিশ্চিত হতে যে ফাইলটি সত্যিই সেখানে আছে। এজন্য নিচের কমান্ডটি রান করুন

dir

![](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_f94c262a198ae9701dfac8658ff4bbee-640x360.png)

এখন নিচের Command টি ব্যবহার করে আপনার Wemos D1 Mini টি ফ্ল্যাস মেমোরি Erase করে নিন।

python -m esptool -chip esp8266 erase-flash

তারপর নিচের Command এ আপনার COM পোর্ট এবং ডাউনলোড হওয়া Micropython Firmware ফাইলটি নাম সঠিক জায়গায় বসিয়ে Enter প্রেস করতেই কিছুক্ষনের মধ্যে মাইক্রোপাইথন ফার্মওয়্যার আপনার Wemos D1 Mini তে ফ্ল্যাস হয়ে যাবে।

python -m esptool -chip esp8266 -port <serial\_port> write-flash -flash-mode dio -flash-size detect 0x0 <ESP8266\_GENERIC-X-vX.bin>

আমার জন্য ফাইনাল Command টি এমন হয়েছে-

python -m esptool -chip esp8266 -port COM14 write-flash -flash-mode dio -flash-size detect 0x0 ESP8266\_GENERIC-20250911-v1.26.1.bin

![](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_d23833e4c411ffeb91d65ed6f7070f7e-640x360.png)

**প্রোগ্রামিং**

এখন এই লিংক থেকে [Thonny IDE](https://thonny.org/) ডাউনলোড করে Install করে নিন। তারপর ডান পাশের নিচের দিকে Local Python 3. Thonny’s Python অপশনটি ক্লিক করলে একটি Top Up ম্যেনু appear হবে।

![](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_67cbab5d1e136380dfaa64b95e4b53ef-640x360.png)

সেখান থেকে MicroPython (ESP8266). USB Serial Port @ COMX সিলেক্ট করুন।

![](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_0e347577339504b6b820a960568ee8a1-640x360.png)

এখন Code Editor এ নিচের কোডটি Copy করে পেস্ট করুন। তারপর Run>Run current script (বা F5) ক্লিক করতেই মাইক্রোকন্ট্রোলারে কোডটি Run করবে!

from machine import Pin

from time import sleep

led = Pin(2, Pin.OUT)  # Create a Pin object

while True:

led.value(1) # Turn LED ON

sleep(0.5) # Wait 0.5 seconds

led.value(0) # Turn LED OFF

sleep(0.5) # Wait 0.5 seconds

![](https://dnc.techtunes.io/tDrive/tuner/2025/11/techtunes_fbdaa11b6d9fb80e44b58d8e94666ccf-640x360.png)

***(বিঃদ্রঃ যদি পাওয়ার আপ করলেই Wemos D1 Mini তে  কোডটি  Run করুক চান। সেক্ষেত্রে Wemos D1 Mini এর Root Directory তে ফাইলটি*** [***main.py***](http://main.py) ***নামে সেভ করে নিন। ব্যাস যতোবার আপনি D1 Mini তে Power Up করবেন ততবার স্ক্রিপটি Default ভাবে Run করবে। )***
