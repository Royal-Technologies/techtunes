## 7-Zip, কেন এটি আপনার প্রয়োজন?

![](https://dnc.techtunes.io/tDrive/tuner/2025/01/techtunes_647682e8dee3efb938c6d1ad5008a2e4.jpg)

আমরা অনেকেই File Compression করার জন্য বিভিন্ন Software ব্যবহার করি, কিন্তু 7-Zip কেন আলাদা? 7-Zip একটি ফ্রি এবং Open-Source file archiver Utility। এর মানে, এটি ব্যবহারের জন্য আপনাকে কোনো টাকা খরচ করতে হবে না, এবং এর Source Code সবার জন্য উন্মুক্ত। ফলে, আপনি যদি Software Development বা Security নিয়ে আগ্রহী হন, তাহলে এর Source Code আপনার জন্য একটি দারুণ Learning Resource হতে পারে।

এই Software টি বিভিন্ন Compression Format-এর সাথে Compatible। Default হিসেবে, 7-Zip.7z Format-এ Archives তৈরী করে, যার File Extension.7z। কিন্তু যখন আপনি Zip এবং Gzip Format ব্যবহার করেন, তখন 7-Zip এমন Compression Ratio দেয়, যা Pkzip এবং Winzip এর চেয়ে ২-১০% ভালো। তার মানে, আপনি File Size কমিয়ে আনতে পারবেন, কিন্তু File-এর Quality একই থাকবে। ধরুন, আপনি কিছু ছবি বা ভিডিও Compress করতে চাচ্ছেন, 7-Zip এক্ষেত্রে আপনার জন্য একটি অসাধারণ সমাধান।

আপনি 7-Zip যেকোনো Computer-এ ব্যবহার করতে পারেন, এমনকি Commercial Organization-এও কোনো খরচ ছাড়াই। এর বেশিরভাগ Source Code GNU LGPL License-এর অধীনে আছে। Unrar Code-এর জন্য একটি Mixed License ব্যবহার করা হয়েছে, GNU LGPL + Unrar Restrictions। 7-Zip ব্যবহার করার জন্য কোনো Registration বা Payment এর ঝামেলা নেই।

## 7-Zip-এর আকর্ষণীয় Features, যা আপনার কাজকে সহজ করে

![](https://dnc.techtunes.io/tDrive/tuner/2025/01/techtunes_4f9aca2b7b67c78f669ec05d2eacede5.jpg)

7-Zip-এ এমন কিছু আকর্ষণীয় Features আছে, যা একে অন্যান্য File Archiver থেকে আলাদা করে তুলেছে। এই Feature গুলো আপনার File Management-এর অভিজ্ঞতাকে আরও সহজ এবং কার্যকরী করে তুলবে। আসুন, সেই Feature গুলো বিস্তারিতভাবে দেখে নেওয়া যাক:

### High Compression Ratio

7-Zip নতুন 7z Format-এ Lzma Compression ব্যবহার করে, যা High Compression Ratio Provide করে। এর মানে, আপনি আপনার File Size অনেক কমিয়ে আনতে পারবেন, যা আপনার Computer-এর Storage Space বাঁচাতে সাহায্য করবে।

### Supported Formats

7-Zip অনেক ধরনের File Format Support করে। এটি শুধু.7z Format-এই সীমাবদ্ধ নয়, বরং আরও অনেক Format নিয়ে কাজ করতে পারে। যেমন:

**Packing / Unpacking:** 7z, Zip, Gzip, Bzip2, এবং Tar। আপনি এই Format-গুলোতে File Pack এবং Unpack করতে পারবেন।

**Unpacking Only:** rar, cab, iso, arj, lzh, chm, msi, wim, Z, cpio, ppm, deb, এবং nsis। এই Format-গুলোর File শুধুমাত্র Unpack করতে পারবেন।

### উন্নত Zip এবং Gzip Compression

Zip এবং Gzip Format-এর জন্য, 7-Zip এমন Compression Ratio প্রদান করে, যা Pkzip এবং Winzip থেকে ২-১০% বেশি ভালো। এর মানে, আপনি যখন Zip বা Gzip Format-এ File Compress করবেন, তখন 7-Zip আপনাকে আরও বেশি Space Save করতে সাহায্য করবে।

### Strong Encryption

7-Zip 7z এবং Zip Format-এ Aes-256 Encryption ব্যবহার করে, যা আপনার File-গুলোকে Secure রাখে। ধরুন, আপনি কিছু Confidential Documents Compress করতে চাচ্ছেন, Encryption-এর মাধ্যমে সেগুলোকে সুরক্ষিত রাখতে পারবেন।

### Self-Extracting Capability

7-Zip 7z Format-এর জন্য Self-Extracting Archive তৈরী করার সুবিধা দেয়। এর মানে, আপনি এমন একটি Archive তৈরী করতে পারবেন, যা Unpack করার জন্য কোনো Software-এর প্রয়োজন হবে না।

### Windows Integration

7-Zip Windows Shell-এর সাথে সহজে Integrate করা যায়। এর ফলে, আপনি File Explorer থেকেই Right Click করে File Compress এবং Unpack করতে পারবেন।

### Powerful File Manager

এতে একটি শক্তিশালী File Manager আছে, যা File Manage করতে সাহায্য করে। আপনি File Manager ব্যবহার করে File Compress, Extract, Copy, Paste এবং Delete করতে পারবেন।

### Command Line Version

যারা Command Line ব্যবহার করতে ভালোবাসেন, তাদের জন্য একটি শক্তিশালী Command Line Version আছে। Command Line ব্যবহার করে আপনি Script লিখতে পারবেন, যা File Management-এর কাজকে আরও Automatic করে তুলবে।

### Far Manager Plugin

Far Manager ব্যবহারকারীদের জন্য একটি Plugin-এর সুবিধা আছে। এর মাধ্যমে আপনি Far Manager-এর মধ্যেই 7-Zip-এর সুবিধাগুলো ব্যবহার করতে পারবেন।

### Localizations

7-Zip ৬৯টি ভাষায় ব্যবহার করা যায়। এর মানে, আপনি আপনার পছন্দের ভাষায় এই Software-টি ব্যবহার করতে পারবেন।

### Cross-Platform Support

7-Zip Windows 98/Me/Nt/2000/Xp/Vista/7/8/10/11 এ কাজ করে। এছাড়াও, Linux/Unix ব্যবহারকারীদের জন্য Command Line Version রয়েছে।

## 7-Zip 24.09 - নতুন আপডেটে কি কি থাকছে?

![](https://dnc.techtunes.io/tDrive/tuner/2025/01/techtunes_437bce3066cb20a8c5b90e16b64dca3b.jpg)

7-Zip Team সবসময় চেষ্টা করে, যাতে ব্যবহারকারীরা সবসময় সেরা সুবিধা পায়। 24.09 Version-এ কিছু গুরুত্বপূর্ণ পরিবর্তন আনা হয়েছে।

### এই Update-গুলো Software-টিকে আরও শক্তিশালী এবং User-Friendly করে তুলেছে

- **Lzma/Lzma2 Improvement:** Lzma/Lzma2 Compression Methods-এর জন্য Default Dictionary Size Value বাড়ানো হয়েছে। এর ফলে, Compression আরও উন্নত হবে।
- **নতুন Hash Checksums:** 7-Zip এখন Sha-512, Sha-384, Sha3-256, এবং Md5 Hash Checksums গণনা করতে পারে। এর মাধ্যমে File Integrity Verify করা আরও সহজ হবে।
- **Apm এবং Hfs Support:** Apm এবং Hfs Support উন্নত করা হয়েছে।
- **Archive Update Progress:** যদি কোনো Archive Update Operation-এ Temporary Archive Folder ব্যবহার করা হয় এবং Archive-টি Destination Folder-এ সরানো হয়, তাহলে 7-Zip Archive File সরানোর Progress দেখায়। কারণ, বড় Archive-এর ক্ষেত্রে এই Operation-এ অনেক সময় লাগতে পারে।
- **Bug Fixes:** কিছু Bug Fix করা হয়েছে। যেমন: 7-Zip File Manager Extracted File-গুলোর জন্য Nested Archives থেকে Zone.Identifier Stream Propagate করত না, যা এখন Fix করা হয়েছে। (যদি একটি Open Archive-এর ভিতরে অন্য Open Archive থাকে)।

এছাড়াও, আরও কিছু ছোটখাটো Bug Fix করা হয়েছে।

### পূর্ববর্তী Release Note-এ আরও কিছু Bug Fix ছিল

- 7-Zip কিছু Incorrect Zstd Archive-এর জন্য Crash করত, যা Fix করা হয়েছে।
- 7-Zip কিছু Zstd Archive Unpack করতে পারত না, সেটিও Fix করা হয়েছে।
- 7z Archive তৈরীর জন্য Decoder Compatibility Version সেট করার জন্য নতুন Switch -myv={Mmmn} যোগ করা হয়েছে।
  - {Mmmn} হলো 4-Digit Number, যা Dot ছাড়া 7-Zip এর Version বোঝায়।
  - যদি -myv={Mmmn} Switch ব্যবহার করা হয়, 7-Zip শুধুমাত্র সেই Compression Methods ব্যবহার করবে, যা Specified Version {Mmmn} এবং তার নতুন Version-এ Decode করা যায়।
  - যদি -myv={Mmmn} Switch ব্যবহার করা না হয়, তাহলে -myv=2300 ব্যবহার করা হবে, এবং 7-Zip শুধুমাত্র 7-Zip 23.00 ও নতুন Version দিয়ে Decode করা যায় এমন Compression Methods ব্যবহার করবে।
- 7z Archive তৈরীর জন্য Specified Filter Method ব্যবহারের অনুমতি দিতে নতুন Switch -myfa={Filterid} যোগ করা হয়েছে।
- 7z Archive তৈরীর জন্য Specified Filter Method ব্যবহার করার অনুমতি না দিতে নতুন Switch -myfd={Filterid} যোগ করা হয়েছে।

আরও কিছু ছোটখাটো Bug Fix করা হয়েছে।
