- **যেকোনো Text-এর সারমর্ম (Summary) তৈরি করা:** লম্বা Article বা Report পড়তে ভালো লাগছে না? চোখের আরাম চান, কিন্তু Information-ও দরকার? Aria কয়েক সেকেন্ডেই Summary বানিয়ে দেবে! Time বাঁচিয়ে Knowledge বাড়াতে এর জুড়ি মেলা ভার! 🤓 ধরুন, আপনি Artificial Intelligence নিয়ে একটা Research Paper পড়ছেন, কিন্তু সময়ের অভাবে পুরোটা শেষ করতে পারছেন না। Aria Summary করে দিলে আপনি মূল বিষয়গুলো সহজেই জেনে নিতে পারবেন।
- **হালকা Android Browser-এই সুন্দর Images বানানো:** Travel করছেন, আর Phone-এ Data কম? কোনো চিন্তা নেই! এমন পরিস্থিতিতে Aria দিয়ে সুন্দর Images বানিয়ে Memories Capture করুন! 📸 Artificial Intelligence-এর কল্যাণে এটা এখন Possible। আপনি হয়তো তাজমহলের সামনে দাঁড়িয়ে আছেন, আর দারুণ একটা ছবি Edit করতে চান। Aria কয়েকটা Click-এই ছবিটাকে করে তুলবে আরও Attractive!
- **Software Code ও তৈরি করা:** হ্যাঁ, আপনি ঠিক শুনেছেন! Aria আপনার হয়ে Software Code-ও লিখে দিতে পারে! 🤯 তার মানে, Coding শেখাটা এবার Opera Mini-তেই শুরু করে দেওয়া যেতে পারে! 💻 যারা Coding শিখতে আগ্রহী, কিন্তু Computer কেনার সামর্থ্য নেই, তাদের জন্য Aria একটা দারুণ সুযোগ।

2. Search Bar-এ "Opera Mini Browser" লিখুন। 🔍 Play Store-এর Search Option-এ গিয়ে Opera Mini লিখুন।

5. Aria ব্যবহার করার জন্য, Browser-এর Bottom Bar-এ Aria Icon-এ Tap করুন, অথবা Address Bar-এ Question টাইপ করুন। ✍️ Aria-কে Active করার জন্য Icon-টা খুঁজে বের করুন, অথবা Address Bar-এ সরাসরি Question লিখুন।
