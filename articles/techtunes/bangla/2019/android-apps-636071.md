## অ্যাপটির কিছু ফীচার

1. আনলিমিটেড HTTP/HTTPS রিকুয়েস্ট পাঠাতে পারবেন যেকোন সার্ভারে
2. GET, POST, PUT, DELETE, HEAD, PATCH, OPTIONS এর যেকোন মেথডে সার্ভারে রিকুয়েস্ট পাঠাতে পারবেন
3. JSON বা HTML ফরম্যাটে Response দেখতে পারবেন
4. সব পাঠানো Request পরে History তে দেখতে পারবেন
5. সহজ ইন্টারফেস
6. মাত্র ২MB সাইজ
