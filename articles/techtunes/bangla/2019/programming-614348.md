আশাকরি ভালো আছেন। আজ*পাইথন জ্যাঙ্গো* টিউটোরিয়ালে, কিভাবে আমরা ব্যবহার শুরু করার বিষয়ে শেখার করা হবে জ্যাঙ্গো ফ্রেমওয়ার্ক। আমরা প্রয়োজনীয় প্যাকেজগুলি ইনস্টল দেব। তো শুরু করা জাক।

Django 2.1.5 Install 2019 with cmd Python Virtualenv and how to Connect with LocalHost.  
 All Commands for you:  
 check version: "python -version"  
 then install:  
 "pip install virtualenv"  
 then install:  
 "pip install virtualenvwrapper-win"  
 then install django:  
 "pip install django"  
 now create a project:  
 "django-admin startproject mysite"  
 create a project folder:  
 "cd.\mysite\"  
 now connect with xampp localhost:  
 "python manage.py runserver"
