আজকে ‍আমি Facebook Messenger এর ২১ টি ছোট বড় ট্রিকস নিয়ে আলোচনা করব. অনেকেই  এই ট্রিকস গুলোর ব্যাপারে জানেন. এর মদ্ধ্যে কিছু ট্রিকস আছে যেগুলো অনেকের কাছেই অজানা. আর এই টিউন তাদের জন্যই. বর্তমানে সমগ্র পৃথিবী জুড়ে ১০০ মিলিয়ন মানুষ Facebook Messenger  ব্যবহার করে. প্রায় প্রতি সপ্তাহেই Facebook কর্তৃপক্ষ Messenger এর কিছু না কিছু আপডেট করে থাকে. Tricks গুলো নিচে দেয়া আছে দেখে নিতে পারেন.

- 01. Log in : Facebook এ ৩ ভাবে Log in করা যায় Email, Phone Number, Username
- 2. Facebook Bot : কিছুদিন আগে আপডেট করা হয়েছে. এটা ভার্চুয়াল অ্যাসিসট্যান্ট হিসেবেও পরিচিত.
- 03. Scan Code : এটার মাধ্যমে ক্যামেরাকে কাজে লাগিয়ে Friend Request এবং Messenger এ Add করা যায়.
- 04. Nick Name : Friends দের নাম পরিবর্তন করে অন্য নাম রাখা যায়.
- 05. Chat Color : Chat Field এর রং পরিবর্তন করতে পারবেন.
- 06. Send Files : এই Tricks এর মাধ্যমে Audio, Video, PDF File, Document এবং Apk Filesপাঠাতে পারবেন.
- 07. Notification OFF : ম্যাসেজ অ্যালার্ট বন্ধ করতে পারবেন.
- 08. Emoji Change : ইমুজি পরিবর্তন.
- 09. Play Games : ফুটবল ও বাস্কেটবল খেলতে পারবেন.
- 10. Secret Conversation : গোপন চ্যাট করতে পারবেন.
- 11. Many ID Use : একটি APP দিয়ে অনেকগুলো ID তে Log in করতে পারবেন.
- 12. SMS : ফোনের ম্যাসেজ এটা দিয়ে Control করা যাবে.
- 13. Ringtone Change : Video এবং Audio কলের  Ringtone পরিবর্তন
- 14. Auto Save Pictures : অটোমেটিক ভাবে ফটো সেভ হবে.
- 15. Chat Head OFF : ম্যাসেজ আসলে মাথা ভেসে উঠবে না.
- 16. Daily Cute Alert : প্রতিদিন কিউট পিক পাবেন.
- 17. Play Chess : দাবা খেলতে পারবেন.
- 18. Photo Edit : ফটো Edit করা যাবে.
- 19. Shortcut : প্রিয় মানুষটির মুখ সামনে রাখা যাবে.
- 20. Sound Clips : মজার মজার সাউন্ড ক্লিপ পাঠানো যাবে.
- 21. Talkz Message : টেকস্ট এ কিছু লিখে পাঠালে তা ভয়েস হয়ে যাবে.
