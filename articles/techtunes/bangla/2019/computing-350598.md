আপনার মোবাইল দিয়ে পৃথিবীর যে কোন জায়গা থেকে ই-মেইল পাঠিয়ে কম্পিউটার শার্ট-ডাউন করতে পারলে কেমন হয়। আমরা খুব সহজেই এই কাজটা করতে পারি। হয়তো ভাবছেন কোন বাড়তি হার্ডওয়্যার প্রয়োজন হবে কিনা? না সত্যিই কোন  বাড়তি হার্ডওয়্যার প্রয়োজন হবে না। তাহলে আসুন জেনে নেই কাজটি করতে আমাদের কি কি লাগবে।

![](https://dnc.techtunes.io/tDrive/tuner/ashim/350598/images.jpg)

## এক নজরে  কি কি লাগবে লাগবে

১. Microsoft Outlook

২.একটা ই-মেইল আইডি Gmail বা Yahoo

৩.ইন্টারনেট কানেকশন

৪. ফোন থেকে ই-মেইল করা যায় এমন যে কোন অ্যাপ

তাহলে আসুন শুরু করা যাক।

## পদক্ষেপ ১

প্রথমে Microsoft Outlook কম্পিউটারে ইন্সটল করে নিতে হবে এবং ইমেইল আইডি সেটাপ করে নিতে হবে। আশা করি সবাই কাজটি করতে পারবেন। না পারলে Youtube থেকে ভিডিও দেখে নিতে পারেন।

## পদক্ষেপ ২

এখন একটা.bat ফাইল তৈরি করতে হবে। একটা নোটপ্যাড ওপেন করে লিখুন

%systemroot%\system32\shutdown.exe -s -t 0

![](https://dnc.techtunes.io/tDrive/tuner/ashim/350598/Shutdown-script.png)

এরপর File মেনু থেকে Save as এ ক্লিক করে File name  হিসেবে Shutdown.bat লেখতে হবে। Save as type হিসেবে All Files নির্বাচন করে দিতে হবে।

![](https://dnc.techtunes.io/tDrive/tuner/ashim/350598/1.png)

তাহলে Shutdown.bat ফাইল তৈরি হবে।

## পদক্ষেপ ৩

Microsoft Outlook ওপেন করে  Rules মেনু থেকে Manage Rules and Alerts নির্বাচরন করতে হবে।

![](https://dnc.techtunes.io/tDrive/tuner/ashim/350598/2.png)

*Rules and Alerts* window তে *Email Rules* ট্যাব থেকে *New Rule* এ ক্লিক করতে হবে।

![](https://dnc.techtunes.io/tDrive/tuner/ashim/350598/3.png)

Rules Wizard থেকে  *Apply rule on messages I receive*d নির্বাচন করে Next এ ক্লিক করতে হবে।

![](https://dnc.techtunes.io/tDrive/tuner/ashim/350598/4.png)

নিচের ছবির মতো নির্বাচন করুন

![](https://dnc.techtunes.io/tDrive/tuner/ashim/350598/5.png)

উপরের ছবির নিচের অংশে আন্ডার লাইন করা লেখা গুলোর উপর এক এক করে ক্লিক করুন। আর নিচের ধাপগুলো অনুসরণ করুন

এখানে আপনার মেইল আইডি দেখাবে। Ok বাটনে ক্লিক করুন।

![](https://dnc.techtunes.io/tDrive/tuner/ashim/350598/6.png)

২য় আন্ডার লাইন করা লেখা গুলোর উপর ক্লিক করুন। নিচের মতো keyword লিখে add বাটনে ক্লিক করুন।

![](https://dnc.techtunes.io/tDrive/tuner/ashim/350598/7.png)

তাহলে নিচের ছবির মতো দেখাবে। Ok বাটনে ক্লিক করুন।

![](https://dnc.techtunes.io/tDrive/tuner/ashim/350598/8.png)

৩য় আন্ডার লাইন করা লেখা গুলোর উপর ক্লিক করুন। keyword লিখে add বাটনে ক্লিক করলে নিচের ছবির মতো দেখাবে। Ok বাটনে ক্লিক করুন।

![](https://dnc.techtunes.io/tDrive/tuner/ashim/350598/9.png)

সবকিছু ঠিক থাকলে Next বাটনে ক্লিক করুন।

নিচের ছবির মতো নির্বাচন করুন

![](https://dnc.techtunes.io/tDrive/tuner/ashim/350598/101.png)

নিচের অংশে স্ক্রল করলে Start application দেখতে পাবেন।

আন্ডারলাইন করা application  লেকার উপর ক্লিক করে Shutdown.bat ফাইলের লোকেশন দেখিয়ে দিন।

সবশেষে Finish বাটনে ক্লিক করুন।

এখন কোন মোবাইল ডিভাইস থেকে সে সকল Keyword সিলেক্ট করে দেয়া হয়েছে, ঐ Keyword গুলো ব্যবহার করে মেইল করুন। তাহলেই কম্পিউটার Shutdown হবে। .

আজ এখানেই শেষ করছি। সবার জন্য শুভকামনা রইলো।
