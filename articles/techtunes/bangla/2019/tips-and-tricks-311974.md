**প্রথমে আমি টিম ভিউয়ার সম্পর্কে আলোচনা করি।**

প্রায়ই হয়বা আপনি কম্পিউটারে এমন কোন সমস্যায় পড়েন, যার সমাধান আপনার জানা থাকেনা, তখন বসে বসে  ভাবেন “ইস্ কেউ যদি সহায্য করত” ফলে আপনি ফোন দেন আপনার কম্পিউটার ভাল জানা কোন বন্ধুকে। কিন্তু কি দু:খের বিষয় আপনি ভালভাবে সমস্যা বর্ণনা করেতে না পারায়, ফোন বিলই শুধু খরচ হয়, কিন্তু সমাধান আর হয় না।

তাই বর্তমান প্রযুক্তিবিদগণেরা এই সমস্যার কথা চিন্তা করেই তৈরী করেন TeamViewer Software (টিম ভিওয়ার)। যা Remote Access এর মাধ্যমে অর্থাৎ দূর হতেই আপনার অথবা আপনার বন্ধুর কম্পিউটর Access করতে পারবেন।

এর জন্য অবশ্যই দুটি কম্পিউটারেই TeamViewer Software ইন্সটল করতে হবে। একই ভার্সন হলে ভাল হয়।

আসুন জেনে নিই কিভাবে TeamViewer Software ইন্সটল করবেন এবং ব্যবহার করবেন।

আমার সাথে সাথে নিচে দেয়া ধাপগুলো অনুসরণ করুন:

০১. প্রথমেই আপনার এবং আপনার পার্টনারের কম্পিউটারে TeamViewer Software ইন্সটল করুন। [software download link : [Click This Link](http://download.cnet.com/TeamViewer/3000-7240_4-10398150.html?part=dl-6271747&subj=dl&tag=button)]

দুই কম্পিউটারে TeamViewer Software ইন্সটল এর পর:

০২. TeamViewer Software দুটি কম্পিউটারেই ওপেন করুন।

০৩. ID এবং Password পাবেন, দুটি কমিপউটারেই, নিচে দেয় বক্সটি আসবে:

[![TeamViewer_Screenshot_on_a_machine_running_Windows_8](http://www.techdiary24.com/wp-content/uploads/2014/09/TeamViewer_Screenshot_on_a_machine_running_Windows_8-300x237.png)](http://www.techdiary24.com/wp-content/uploads/2014/09/TeamViewer_Screenshot_on_a_machine_running_Windows_8.png)

০৪. আপনি আপনার বন্ধুর কম্পিউটারের ID জেনে নিন এবং নিচে দেয় বক্সটিতে টাইপ করে “connect to partner” বাটনে click করুন। (remote support এ যেন দেয়া থাকে)

![](http://i52.tinypic.com/29cndxy.jpg)

০৫. এরপর আরেকটি বক্স আসবে সেখানে আপনার বন্ধুর কম্পিউটারের Passwordটি বসিয়ে (অবশ্যই তার কাছ থেকে জেনে নেবেন Passwordটি) বক্সটির বামের বাটনে click করে আপনার বন্ধুর PCকে connect করুন।

দেখবেন আপনার PCর মনিটরে আপনার বন্ধুর PCর মনিটরটি আসবে।

আর আপনি তখন অতি সহজেই আপনার বা আপনার বন্ধুর PCটি বিশ্বের যেকোন প্রান্ত থেকেই নিয়ন্ত্রণ করতে পারবেন।
