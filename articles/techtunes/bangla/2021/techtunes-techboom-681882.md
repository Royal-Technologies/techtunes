সম্প্রতি [টুইটার](https://www.twitter.com/) গবেষকদের জন্য উন্মুক্ত করেছে তাদের Tweet Archive। Twitter API v2 এর প্রাথমিক অ্যাক্সেসের মাধ্যমে গবেষকরা Archive গুলোতে অ্যাক্সেস নিয়েছে।

শেষ পর্যন্ত [টুইটার](https://www.twitter.com/) তাদের বর্তমান Standard, Premium, এবং Enterprise, API গুলো সম্পূর্ণরূপে প্রতিস্থাপন করার জন্য নতুন API এর পরিকল্পনা করেছে। ইতিমধ্যে, গবেষকদের কাছ থেকে ফিডব্যাক পেতে, সংস্থাটি Twitter API v2 এর জন্য প্রাথমিক অ্যাক্সেস চালু করেছে।

[টুইটার](https://www.twitter.com/) তার API প্ল্যাটফর্মে একটি নতুন পণ্য ট্র্যাক চালু করছে। [Twitter Blog](https://blog.twitter.com/developer/en_us/topics/tools/2020/introducing_new_twitter_api.html) এর একটি যৌথ প্রতিবেদন প্রোডাক্টের প্রধান ইয়ান কেয়ার্নস এবং প্রোডাক্ট ম্যানেজার প্রিয়াঙ্কা শেঠির ঘোষণা হিসাবে, এটি একটি সম্পূর্ণ নতুন API পুনর্নির্মাণের অংশ।

এই ট্র্যাকটির লক্ষ্য হচ্ছে একাডেমিক রিসার্চে সাহায্য করা যেখানে, প্ল্যাটফর্মে টিউন হওয়া প্রতিটি টুইটে অ্যাক্সেস দেয়া হবে রিসার্চারদের।

আপনিও যদি আগ্রহী হন তবে আপনি [Twitter Developer](https://developer.twitter.com/en/portal/petition/use-case) ওয়েবসাইটে অ্যাক্সেসের জন্য আবেদন করতে পারেন।

[The Verge](https://www.theverge.com/2021/1/26/22250203/twitter-academic-research-public-tweet-archive-free-access) রিপোর্ট করেছে যে গবেষকরা আরও সুনির্দিষ্ট ফিল্টারিং সক্ষমতায় অ্যাক্সেস পাবেন। প্রারম্ভ এবং শেষ সময় প্যারামিটারগুলি প্রবেশ করে অনুসন্ধান গুলো সংকীর্ণ করা যাবে। তবে এখানে কিছু লিমিটেশন অবশ্যই থাকবে, টুইটার বলছে এটি ইতিমধ্যে যে অ্যাকাউন্টগুলিকে সাসপেন্ড করছে বা নিষিদ্ধ করা হয়েছে, সেগুলি থেকে ডেটা অ্যাক্সেস সরবরাহ করা হবে না।

![](https://dnc.techtunes.io/tDrive/tuner/2021/02/techtunes_39e50c7ffa85cf9f9b0fefe7a6e346c7.png)

তবে যারা অনলাইন বিদ্বেষমূলক বক্তৃতা, মনগড়া গল্প এবং টুইটারের নিয়ম লঙ্ঘনকারী অন্যান্য কথোপকথনের ইতিহাস সম্পর্কে জানতে চান তাদের এই খবরটি অবশ্য সুখকর নয়৷ উদাহরণস্বরূপ, সাবেক মার্কিন রাষ্ট্রপতি ডোনাল্ড ট্রাম্পের নিষিদ্ধ অ্যাকাউন্টটি টুইটারের সংরক্ষণাগারের মাধ্যমে অ্যাক্সেসযোগ্য নয়।

এই ঘোষণাটি অনেকের কানে সংগীতের মত লাগলেও ডেভেলপার এবং গবেষণা গ্রুপ টুইটারের এমন সিদ্ধান্তে সন্তুষ্ট নয় বা আগেও ছিল না। প্রকৃতপক্ষে, এই পরিবর্তনটি তৃতীয় পক্ষের ইকোসিস্টেমের সমন্বয়ে গঠিতদের সাথে সংশোধন করার চেষ্টা করার দ্বিতীয় ধাপ হিসাবে দেখা যেতে পারে।

এর আগে ২০১২ সালে, [টুইটার](https://www.twitter.com/) সম্ভাব্য প্রতিযোগীরা কী ডেটা ব্যবহার করতে দেয় তার উপর আরও নিয়ন্ত্রণ রাখতে চেয়েছিল। পরবর্তীকালে এটি প্ল্যাটফর্মে সকল প্রধান ডেভেলপারদের অ্যাক্সেস বন্ধ করে দেয়, যাতে হতাশ হয়েছিল সারা বিশ্বের সকল ডেভেলপার।

[Twitter blog](https://blog.twitter.com/developer/en_us/topics/tips/2021/enabling-the-future-of-academic-research-with-the-twitter-api.html) প্রোডাক্ট ম্যানেজার অ্যাডাম টর্নেস এবং লিয়েন ট্রু বলেছেন, "আমাদের ডেভেলপার প্ল্যাটফর্মটি গবেষকদের জন্য প্রয়োজনীয় ডেটাতে অ্যাক্সেস করতে সবসময় সহযোগিতা করে না।

তাছাড়া কয়েক বছর আগে টুইটার যখন তার API ব্যবহারের নিয়মগুলোকে সম্পূর্ণ পরিবর্তন করেছিল, তখন ডেভেলপাররা ইন্টারনেটে এটি নিয়ে বিরক্তি প্রকাশ করেছিল, তবে এবার সেই ঘটনা মনে করে হয়তো টুইটার তাদের Twitter API v2 এ ডেভেলপারদের এক্সেস দিচ্ছে।
