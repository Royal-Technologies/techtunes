আসসালামু আলাইকুম, কেমন আছেন টেকটিউনস কমিউনিটি? আশা করছি সবাই ভাল আছেন। আজকে আবার হাজির হলাম নতুন টিউন নিয়ে। চলুন শুরু করা যাক।

স্মার্টফোন আমাদের দৈনন্দিন জীবনের অতীব গুরুত্বপূর্ণ একটি ডিভাইস। স্মার্টফোনের যেকোনো সমস্যায় আমাদের পড়তে হয় মহা বিপাকে। আমাদের স্মার্টফোন গুলোর কমন একটি সমস্যা হচ্ছে স্টোরেজ ফুল হয়ে যাওয়া। স্টোরেজ ফুল সমস্যার আল্টিমেট সমাধান হতে পারে ডিভাইসটি পুরোপুরি রিসেট দেয়া কিন্তু ফোনে গুরুত্বপূর্ণ ফাইল থাকার কারণে এই কাজটিও সব সময় করা সম্ভব হয়ে উঠে না।

আপনার ফোনের স্টোরেজ লিমিটেড হলে খুব তাড়াতাড়ি বিভিন্ন অ্যাপ থেকে তৈরি হওয়া টেম্পোরারি ফাইল ফোনে স্টোরেজকে ফুল করে দিতে পারে। ফোন তৈরি হওয়া এই সমস্ত ফাইল গুলোকে বলা হয় Cache। আজকের টিউনে আমি দেখাব কিভাবে আপনার অ্যান্ড্রয়েড ফোনের Cache ফাইল গুলো ডিলিট করবেন।

## Cache ডেটা কি?

![](https://dnc.techtunes.io/tDrive/tuner/2021/01/techtunes_9a0292d2afe162a363faba1f756ab033.jpg)

ফোন তার কাজকে দ্রুত করতে এবং ইউজারের চাহিদা মত সঠিক সময়ে সঠিক সুবিধাটি দিতে আগে থেকে কিছু ডেটা Cache হিসেবে জমা রাখে। ধরুন ফেসবুক অ্যাপে যখন আপনি প্রথমবার প্রবেশ করবেন তখন এটির বেশ কিছু Cache ফাইল তৈরি হয়ে আপনার ডিভাইসে জমা হবে, এবং পরবর্তীতে অ্যাপটি ওপেন করলে কোন ধরনের সময় নেয়া ছাড়াই সকল কন্টেন্ট দেখানো শুরু করবে। আপনি খেয়াল করে দেখবেন, ডাটা বা ওয়াই-ফাই অফ থাকলেও ফেসবুকে ঢুকলে অ্যাপটিতে বিভিন্ন Post, ফটো দেখা যায়। এটা কিভাবে হয়? হ্যাঁ, Cache ফাইল গুলোর মাধ্যমে নতুন করে কন্টেন্ট ডাউনলোড করা ছাড়াই আমরা আগের কন্টেন্ট গুলো দেখতে পাই।

তবে এই Cache বিষয়টি কিন্তু একেক অ্যাপের জন্য একেক রকম। আপনি ফেসবুক হয়তো রিগুলারলি ইউজ করেন সুতরাং আপনার ফেসবুক অ্যাপের Cache কাজে লাগতে পারে, কিন্তু যে সমস্ত অ্যাপ সব সময় ব্যবহার করেন না সেই সমস্ত অ্যাপের Cache আপনার সুবিধা থেকে অসুবিধা বেশি তৈরি করে কারণ স্টোরেজের অধিকাংশ জায়গা দখল করে রাখতে পারে এই সমস্ত Cache গুলো।

এই Cache যে শুধু মাত্র ফোনেই হয় এমন কিন্তু না ডেক্সটপেও Cache তৈরি হয়। তাছাড়া সকল ব্রাউজারেই Cache তৈরি হয়, কারণ এতে করে নির্দিষ্ট একটি ওয়েবসাইটের কন্টেন্ট প্রতিবার ওপেন প্রতিবার করলে প্রতিবার ডাউনলোড হতে হয় না।

## কিভাবে অ্যান্ড্রয়েড ডিভাইসের Cache ক্লিয়ার করবেন

![](https://dnc.techtunes.io/tDrive/tuner/2021/01/techtunes_a0b14c1831482e921ddaf420fa4d3e1d.jpg)

নতুন অ্যান্ড্রয়েড ডিভাইসের ক্ষেত্রে আপনাকে প্রতিটা অ্যাপের Cache ফাইল আলাদা ভাবে ডিলিট করতে হবে৷ তবে সকল অ্যাপের Cache ফাইল ডিলিট করতে হয় না নির্দিষ্ট কিছু অ্যাপই রয়েছে যেগুলোর Cache ফাইল তেমন প্রয়োজনীয় না তার উপরে সমস্যাও তৈরি করে। সে সমস্ত অ্যাপের Cache ফাইল ডিলিট করলে আপনার সমস্যার সমাধান হয়ে যেতে পারে।

চলুন দেখে নিয়া যাক কিভাবে নির্দিষ্ট অ্যাপের Cache ডিলিট করা যায়, আমি বিষয়টি দেখানোর জন্য অ্যান্ড্রয়েড 11 ভার্সন ব্যবহার করছি।

- প্রথমে Settings এ যান এবং Storage সিলেক্ট করুন
- এবার Other Apps ক্লিক করুন
- এবার যে অ্যাপের Cache ডিলিট করতে চান সেটি সিলেক্ট করুন। প্রয়োজনে থ্রি ডটে ক্লিক করে Sort by Size করে নিতে পারেন।
- নির্দিষ্ট অ্যাপে ক্লিক করুন। অ্যাপ পেজ থেকে Clear Cache এ ক্লিক করুন।

এভাবে আপনি যেকোনো অ্যাপের Cache ক্লিয়ার করতে পারেন। তাছাড়া আপনি Clear Storage এ ক্লিক করে পুরো অ্যাপটিকে রিসেট দিয়ে নতুন করে শুরু করতে পারেন।

পুরনো অ্যান্ড্রয়েড ফোন গুলোর ক্ষেত্রে আপনি Settings > Storage > Cached Data তে গিয়ে এক ক্লিকে সকল Cache ক্লিয়ার করতে পারেন।

## Cache ক্লিয়ার হওয়ার পর কি ঘটবে?

![](https://dnc.techtunes.io/tDrive/tuner/2021/01/techtunes_47d540444397ca85885d9d006aa4f9d3.jpg)

আপনি Cache ক্লিয়ার করে দিলে ফোন কিছু স্টোরেজ ফিরে পাবে এবং অ্যাপ স্বাভাবিক ভাবেই কাজ করবে। তবে যেহেতু সকল টেম্পোরারি ফাইল ক্লিয়ার হয়ে গেছে সেহেতু কিছু কিছু এলিমেন্ট প্রথমবার লোড হতে সময় বেশি লাগতে পারে।

আবার অ্যাপ গুলো ওপেন করলে কাজের স্বার্থে আবার Cache ফাইল জমা হবে। আপনাকে মনে রাখতে হবে Cache ফাইল ডিলিট করলে আপনার ব্রাউজারের হিস্ট্রি, গেমের বিভিন্ন লেভেল ইত্যাদি চলে যেতে পারে।

## Cache ক্লিয়ারের সুবিধা

![](https://dnc.techtunes.io/tDrive/tuner/2021/01/techtunes_3d264cbe5ebd74819f371bf55de4808c.png)

কখনো কখনো Cache ফাইল আপনার ফোনের জন্য উপকারী হতে পারে তাই সকল Cache একবারে মুছে দেয়া ভাল সিদ্ধান্ত নয়। আপনি আলাদা আলাদা এবং অপ্রয়োজনীয় অ্যাপের Cache ডিলিট করে বেশ কিছু সুবিধা পেতে পারেন।

- Cache ক্লিয়ারের মাধ্যমে আপনি আপনার স্টোরেজ ফিরে পেতে পারেন। তবে আবার অ্যাপ গুলো ব্যবহার করলে একই অবস্থায় ফিরে আসবে।
- কখনো কখনো পুরনো Cache গুলো corrupt হয়ে যেতে পারে এবং অ্যাপ ব্যবহার করায় সমস্যা তৈরি করতে পারে সেক্ষেত্রে এগুলো ডিলিট করলে আপনার ডিভাইসের পারফরম্যান্স বাড়তে পারে।
- কখনো পুরনো Cache আপনার প্রাইভেসি ঝুঁকির কারণ হতে পারে যেমন ব্রাউজারের Cache ফাইল গুলো যদি কখনো অসাধু পক্ষের নিকট চলে যায় তাহলে আপনার গুরুত্বপূর্ণ একাউন্ট বা প্রাইভেসি লিক হবার সম্ভাবনা থাকে।
- পুরনো Cache গুলো থাকলে আপনার ব্রাউজারে আপডেট পেজ গুলো শো হতে বাধার সৃষ্টি হতে পারে। সেক্ষেত্রে এই টেম্পোরারি ফাইল গুলো ক্লিয়ার করলে নতুন পেজ গুলো সহজেই শো করতে পারে।

## আপনি কি নিয়মিত Cache ফাইল ডিলিট করবেন?

![](https://dnc.techtunes.io/tDrive/tuner/2021/01/techtunes_5aaa75be57be73127f720f50a6b7e8ed.png)

আমরা এতক্ষণ জানলাম Cache ফাইল গুলো রিমুভ করার কিছু সুবিধা, তবে সব সময় এই সমস্ত ফাইল রিমুভ আপনার জন্য সঠিক সিদ্ধান্ত নাও হতে পারে। আমরা আগেই জেনেছি এই ফাইল গুলো অ্যাপের স্পীড বাড়াতে সাহায্য করে সুতরাং আপনি যদি রেগুলার ইউজ করা অ্যাপ গুলোর Cache ডিলিট করেন তাহলে এটি সুবিধার বদলে অসুবিধা বেশি সৃষ্টি করবে। অ্যাপ গুলো প্রয়োজনের সময় লোড নিতে বেশি সময় নেবে।

সুতরাং প্রতিনিয়ত Cache ফাইল ডিলিট করা যাবে না। তাছাড়া মডার্ন ফোন গুলোতে Cache অটো ডিলিট হবার উপযুক্ত ম্যাকানিজমও রয়েছে। যেমন আমার Galaxy M21 ফোনে প্রতিদিন রাত ১২ টায় অটোমেটিক ভাবে Cache ক্লিয়ার হয়। তবে কখনো কখনো আপনার জন্য Cache ডিলিট করা বাধ্যতামূলক হয়ে যেতে পারে,

- যখন অ্যাপ অস্বাভাবিক আচরণ শুরু করবে বা Cache ফাইল Corrupt হয়ে যাবে।
- যখন আপনি পারসোনাল ডেটা গুলো লিক হওয়া এড়াতে সেগুলো ডিলিট দিতে চাইবেন
- যখন পুরো ফোনের স্টোরেজ রানিং আউট হয়ে যাবে, প্রয়োজনীয় কাজের জন্য স্টোরেজ ক্লিয়ার করতে হবে

## আপনি কি থার্ডপার্টি Cleaner অ্যাপ ব্যবহার করতে পারবেন

![](https://dnc.techtunes.io/tDrive/tuner/2021/01/techtunes_66104b865cf558b7fc122e5440043407.jpg)

প্লে-স্টোরে ফোনের টেম্পোরারি ফাইল ক্লিয়ার করার অসংখ্য অ্যাপ রয়েছে যেগুলো অতি দ্রুত এবং সহজে ফোনের সকল টেম্পোরারি ফাইল ক্লিয়ার করতে পারে৷ কিছু ক্ষেত্রে অ্যাপ গুলো সুবিধাজনক হলেও অধিকাংশ ক্ষেত্রে এই সমস্ত অ্যাপ সমস্যার সৃষ্টি করতে পারে,

- অধিকাংশ ক্ষেত্রে তারা মিথ্যে বলে, যে Cache ক্লিয়ার করে ফোনের স্পীড বাড়াচ্ছে। আবার কখনো যতটুকু ক্লিয়ার করে তার চেয়ে বেশি নাম্বার শো করায়।
- সে সমস্ত অ্যাপ গুলো আরও বেশি স্টোরেজ দখল করে থাকে। সব সময় ব্যাকগ্রাউন্ডে রান হয় বলে ফোনের পারফরম্যান্সও কমে যায়।
- অধিকাংশ ক্ষেত্রে এই অ্যাপ গুলো এড দিয়ে ভর্তি থাকে ফোনে বিভিন্ন স্ক্রিনে এড শো করায় যা আমাদের বিরক্তির কারণ হয়ে দাঁড়ায়।

সুতরাং থার্ডপার্টি অ্যাপ ব্যবহারে সতর্কতা অবলম্বন করুন ভাল হয় সম্পূর্ণ এড়িয়ে চলুন, আজ কাল অধিকাংশ ফোনেই বিল্ড-ইন ক্লিনার দেয়া থাকে, সেগুলো ব্যবহার করুন।

## শেষ কথাঃ

ফোনের স্টোরেজ কিছুটা ফ্রি করতে আপনি Cache ডিলিট করতে পারেন তবে খেয়াল রাখবেন অযথা টেম্পোরারি ফাইল ডিলিট করে যেন নতুন সমস্যার সৃষ্টি না হয়।

কেমন হল আজকের টিউন তা অবশ্যই টিউমেন্টের মাধ্যমে জানাবেন।

পরবর্তী টিউন পর্যন্ত ভাল থাকুন, আল্লাহ হা-ফেজ।
