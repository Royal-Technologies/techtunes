সম্প্রতি [মাইক্রোসফট](https://www.microsoft.com/) তাদের একমাত্র ব্রাউজার Microsoft Edge এর জন্য প্রকাশ করেছে ডেডিকেটেড রোডম্যাপ। Microsoft 365 এর পর নতুন আরেকটি রোডম্যাপ প্রকাশ করল [মাইক্রোসফট](https://www.microsoft.com/)।

Microsoft Edge সাম্প্রতিক সময়ে ব্রাউজার যুদ্ধের একটি অন্যতম প্রধান প্রতিযোগী হয়ে উঠেছে। তবে এতদিন এই ব্রাউজারটির পরিকল্পনা বা পরবর্তী ফিচার গুলো কি হতে সেগুলো জানার কোন মাধ্যম ছিল না। তবে সম্প্রতি মাইক্রোসফট প্রকাশ করছে Microsoft Edge নিয়ে একটি পূর্ণ রোডম্যাপ।

Microsoft Edge এর নতুন রোডম্যাপটি "What's Next" শিরোনামে [Microsoft Edge Insider](https://www.microsoftedgeinsider.com/en-us/whats-next)  এর ওয়েবসাইটে পাওয়া যাবে। আপনি যদি আগে মাইক্রোসফটের রোডম্যাপ সম্পর্কে পরিচিত থাকেন তাহলে এটি আপনার জন্য নতুন কিছু নয়।

![](https://dnc.techtunes.io/tDrive/tuner/2021/01/techtunes_962b4ab125be61d10279c06d151002c4.png)

এর আগে এটি Microsoft 365 এরও রোডম্যাপ প্রকাশ করেছিল। রোডম্যাপ গুলো সাধারণ ব্যবহার করা হয় ইউজারদের ভবিষ্যৎ আপডেট সম্পর্কে পূর্ণ ধারণা দেয়ার জন্য। Microsoft Edge এর জন্য করা নতুন রোডম্যাপটি আগের Microsoft 365 এর ফরমেটেই করা হয়েছে।

এখন, আপনি পরিকল্পিত ফিচার গুলো ব্রাউজ করে দেখতে পারবেন এবং Microsoft Edge এর পরবর্তী রিলিজ ডেট দেখতে পারবেন। ইতিমধ্যে, Edge রোডম্যাপটি আকর্ষণীয় আপডেট দ্বারা পূর্ণ যা ২০২১ এর এপ্রিল বা আগে আসবে।

উদাহরণস্বরূপ, Microsoft Edge এ আপনার বার্থডেট বিভিন্ন ফর্মে অটোমেটিক ফিল-আপ হবে এবং ক্লাউডে জমা হওয়া আপনার ডেটা আপনি কন্ট্রোল করার সুযোগ পাবেন। একই সাথে মাইক্রোসফট জানিয়েছে ভার্টিক্যাল ট্যাব ফিচার পাবলিকলি রিলিজ করা হবে।

![](https://dnc.techtunes.io/tDrive/tuner/2021/01/techtunes_b1e6604616dafb5da0e30f10dce64a32.png)

বর্তমানে মাইক্রোসফট কী বিপ্লবী নতুন ফিচারের পরিকল্পনা করছে তা দেখার জন্য এই নতুন রোডম্যাপটি খুব সহজ উপায় বলে মনে হচ্ছে। [মাইক্রোসফট](https://www.microsoft.com/) ইতিমধ্যে Edge এর সাথে দুর্দান্ত ভাবে ২০২১ সাল শুরু করেছে। এই রোডম্যাপে পরবর্তীতে কি আসতে যাচ্ছে এটি নিয়েও ইউজাররা ব্যাপক ভাবে আগ্রহী হবে বলে আশা করছে রোডম্যাপ টিম।

উইন্ডোজ পিসি তথা অন্যান্য অপারেটিং সিস্টেম গুলোর ব্রাউজার মার্কেটে যে প্রতিযোগিতা রয়েছে সেই প্রতিযোগিতার নতুন এক সদস্য হচ্ছে Microsoft Edge। বলতে গেলে খুব কম সময়ের মধ্যে জনপ্রিয় পেয়ে যায় মাইক্রোসফটের একমাত্র ব্রাউজার Microsoft Edge। আশা করা যায় খুব তাড়াতাড়ি এটি বিশাল ইউজার বেজ অর্জন করবে।

যাই হোক, এবার Microsoft Edge এখন নিজস্ব ডেডিকেটেড রোডম্যাপ পাওয়ায়, সফটওয়্যার জায়ান্টটি তাদের ব্রাউজারটির জন্য কী প্ল্যান করছে তা দেখতে সহজ হবে।
